## 第一部分 集合

### 集合与元素

1. 理解集合中元素的意义是解决集合问题的关键：元素是函数关系中自变量的取值？还是因变量的取值？还是曲线上的点？……
2. 数形结合是解集合问题的常用方法：解题时要尽可能地借助数轴、直角坐标系或韦恩图等工具，将抽象的代数问题具体化、形象化、直观化，然后利用数形结合的思想方法解决。

### 子集与计数

3. 集合 {a₁, a₂, …, aₙ} 的子集个数共有 2ⁿ 个；真子集有 2ⁿ−1 个；非空子集有 2ⁿ−1 个；非空真子集有 2ⁿ−2 个。
4. ∅ 是任何集合的子集，是任何非空集合的真子集。

## 第二部分 函数与导数

### 映射与值域

1. 映射：注意 ①第一个集合中的元素必须有象；②一对一或多对一。
2. 函数值域的求法：①分析法；②配方法；③判别式法；④利用函数单调性；⑤换元法；⑥利用均值不等式 √ab ≤ (a+b)/2 ≤ √[(a²+b²)/2]；⑦利用数形结合或几何意义（斜率、距离、绝对值的意义等）；⑧利用函数有界性（aˣ、sinx、cosx 等）；⑨平方法；⑩导数法。

### 复合函数与分段函数

3. 复合函数有关问题：
   - （1）复合函数定义域求法：① 若 f(x) 的定义域为 [a, b]，则复合函数 f[g(x)] 的定义域由不等式 a ≤ g(x) ≤ b 解出；② 若 f[g(x)] 的定义域为 [a, b]，求 f(x) 的定义域，相当于 x∈[a, b] 时求 g(x) 的值域。
   - （2）复合函数单调性的判定：①将原函数 y=f[g(x)] 分解为内函数 u=g(x) 与外函数 y=f(u)；②分别研究内、外函数在各自定义域内的单调性；③根据"同性则增，异性则减"判断。
4. 分段函数：值域（最值）、单调性、图象等问题，先分段解决，再下结论。

### 奇偶性与单调性

5. 函数的奇偶性：
   - (1) 定义域关于原点对称是函数具有奇偶性的必要条件。
   - (2) f(x) 是奇函数 ⇔ f(−x) = −f(x)；f(x) 是偶函数 ⇔ f(−x) = f(x)。
   - (3) 奇函数 f(x) 在 0 处有定义，则 f(0) = 0。
   - (4) 在关于原点对称的单调区间内：奇函数有相同的单调性，偶函数有相反的单调性。
   - (5) 所给函数解析式较复杂时，先等价变形，再判断奇偶性。
6. 函数的单调性：
   - (1) 定义：① f(x) 在区间 M 上是增函数 ⇔ ∀x₁,x₂∈M，当 x₁<x₂ 时有 f(x₁)<f(x₂)；② 减函数 ⇔ 当 x₁<x₂ 时有 f(x₁)>f(x₂)。
   - (2) 判定：①定义法（将 f(x₁)−f(x₂) 化为几个因式作积或作商，利于判断符号）；②导数法；③复合函数法；④图像法。注：证明单调性主要用定义法和导数法。

### 周期性

7. 函数的周期性：
   - (1) 定义：对定义域内任意 x，若有 f(x+T)=f(x)（T 为非零常数），则 f(x) 为周期函数，T 为一个周期。所有正周期中最小的称为最小正周期。
   - (2) 三角函数周期：① y=sinx: T=2π；② y=cosx: T=2π；③ y=tanx: T=π；④ y=Asin(ωx+φ)、y=Acos(ωx+φ): T=2π/|ω|；⑤ y=tan(ωx): T=π/|ω|。
   - (3) 与周期有关的结论：f(x+a)=f(x−a) 或 f(x−2a)=f(x)（a>0）⇒ f(x) 的周期为 2a。

### 基本初等函数

8. 基本初等函数的图像与性质：
   - (一) (1) 指数函数 y=aˣ (a>0, a≠1)；(2) 对数函数 y=logₐx (a>0, a≠1)；(3) 幂函数 y=xᵃ (α∈R)；(4) 正弦函数 y=sinx；(5) 余弦函数 y=cosx；(6) 正切函数 y=tanx；(7) 一元二次函数 y=ax²+bx+c (a≠0)；(8) 其它常用函数：①正比例函数 y=kx (k≠0)；②反比例函数 y=k/x (k≠0)；③函数 y=x+a/x (a>0)。
   - (二) (1) 分数指数幂：a^(m/n) = ⁿ√(aᵐ)；a^(−m/n) = 1/a^(m/n)（a>0, m,n∈N*, n>1）。
   - (2) 对数：① aᵇ=N ⇔ logₐN=b；② logₐ(MN)=logₐM+logₐN；③ logₐ(M/N)=logₐM−logₐN；④ log_{aᵐ}bⁿ = (n/m)logₐb。
   - (3) 换底公式：logₐN = logₘN/logₘa。对数恒等式：a^(logₐN) = N。

### 二次函数

9. 二次函数：
   - (1) 解析式：①一般式 f(x)=ax²+bx+c；②顶点式 f(x)=a(x−h)²+k，(h,k) 为顶点；③零点式 f(x)=a(x−x₁)(x−x₂) (a≠0)。
   - (2) 二次函数问题需考虑的因素：①开口方向；②对称轴；③端点值；④与坐标轴交点；⑤判别式；⑥两根符号。
   - 对称轴方程 x=−b/2a，顶点坐标 (−b/2a, (4ac−b²)/4a)。

### 图象与变换

10. 函数图象：
   - (1) 作法：①描点法（特别注意三角函数的五点作图）；②图象变换法；③导数法。
   - (2) 变换：①平移：y=f(x)→y=f(x±a)（a>0）左"+"右"−"；y=f(x)→y=f(x)±k 上"+"下"−"。②对称：y=f(x)→y=−f(−x)（关于原点）；→y=−f(x)（关于 x 轴…原稿写作关于 y 轴处按标准）；iii) y=f(x)→y=f(−x)（关于 y 轴）；iv) y=f(x)→x=f(y)（关于 y=x）。③翻折：y=f(x)→y=f(|x|)（去左翻右）；y=f(x)→y=|f(x)|（留上翻下）。
11. 函数图象（曲线）对称性的证明：
   - (1) 证明 y=f(x) 图像的对称性，即证明图像上任意点关于对称中心（对称轴）的对称点仍在图像上。
   - (2) 证明 y=f(x) 与 y=g(x) 图象的对称性，即证明 y=f(x) 图象上任意点关于对称中心（对称轴）的对称点在 y=g(x) 的图象上，反之亦然。
   - 注：①曲线 C: f(x,y)=0 关于原点 (0,0) 的对称曲线为 f(−x,−y)=0；关于 x=0 的对称曲线为 f(−x,y)=0；关于 y=0 的对称曲线为 f(x,−y)=0；关于 y=x 的对称曲线为 f(y,x)=0。
   - ② f(a+x)=f(b−x)（x∈R）⇔ y=f(x) 图像关于直线 x=(a+b)/2 对称；特别地 f(a+x)=f(a−x) ⇔ 关于直线 x=a 对称。
   - ③ y=f(x) 的图象关于点 (a,b) 对称 ⇔ f(a+x)+f(a−x)=2b；特别地关于点 (a,0) 对称 ⇔ f(a+x)=−f(a−x)。
   - ④ 函数 y=f(x−a) 与 y=f(a−x) 的图象关于直线 x=a 对称；y=f(a+x) 与 y=f(a−x) 的图象关于直线 x=0 对称。

### 零点与导数

12. 函数零点的求法：(1) 直接法（求 f(x)=0 的根）；(2) 图象法；(3) 二分法。(4) 零点定理：若 y=f(x) 在 [a,b] 上满足 f(a)·f(b)<0，则 y=f(x) 在 (a,b) 内至少有一个零点。
13. 导数：
   - (1) 定义：f(x) 在点 x₀ 处的导数 f'(x₀) = lim(Δx→0) [f(x₀+Δx) − f(x₀)]/Δx。
   - (2) 常见导数公式：① C'=0；② (xⁿ)'=nxⁿ⁻¹；③ (sinx)'=cosx；④ (cosx)'=−sinx；⑤ (aˣ)'=aˣ·lna；⑥ (eˣ)'=eˣ；⑦ (logₐx)'=1/(x·lna)；⑧ (lnx)'=1/x。
   - (3) 四则运算法则：(u±v)'=u'±v'；(uv)'=u'v+uv'；(u/v)'=(u'v−uv')/v²。
   - (4) 应用：①求切线：注意所给点是切点吗？求的是"在"还是"过"该点的切线？②判断单调性：f'(x)>0 ⇒ 增函数；f'(x)<0 ⇒ 减函数；f'(x)≡0 ⇒ 常数函数。③求极值：求 f'(x) → 求 f'(x)=0 的根 → 列表得极值。④求最大最小值：求极值 → 求区间端点值 → 比较得最值。

## 第三部分 三角函数、三角恒等变换与解三角形

### 弧度制与弧长

1. (1) 角度制与弧度制互化：π 弧度 = 180°；1° = π/180 弧度；1 弧度 = (180/π)° ≈ 57°18′。
   (2) 弧长公式 l = θR；扇形面积公式 S = (1/2)lR = (1/2)θR²。

### 定义与符号

2. 三角函数定义：角 α 终边上任一点（非原点）P(x,y)，设 |OP|=r，则 sinα = y/r，cosα = x/r，tanα = y/x。
3. 三角函数符号规律：一全正，二正弦，三正切，四余弦（简记"全 s t c"）。
4. 诱导公式记忆规律："奇变偶不变，符号看象限"。

### y=Asin(ωx+φ) 的性质

5. (1) y=Asin(ωx+φ) 对称轴：令 ωx+φ = kπ+π/2，得 x=…；对称中心：((kπ−φ)/ω, 0) (k∈Z)。
   (2) y=Acos(ωx+φ) 对称轴：令 ωx+φ = kπ，得 x=(kπ−φ)/ω；对称中心：((kπ+π/2−φ)/ω, 0) (k∈Z)。
   (3) 周期公式：① y=Asin(ωx+φ) 及 y=Acos(ωx+φ) 的周期 T=2π/|ω|；② y=Atan(ωx+φ) 的周期 T=π/|ω|（A、ω、φ 为常数且 A≠0）。

### 同角关系与图象性质

6. 同角三角函数的基本关系：sin²x + cos²x = 1；sinx/cosx = tanx。
7. 三角函数的单调区间及对称性：
   - (1) y=sinx：递增区间 [2kπ−π/2, 2kπ+π/2]，递减区间 [2kπ+π/2, 2kπ+3π/2] (k∈Z)；对称轴 x=kπ+π/2；对称中心 (kπ, 0)。
   - (2) y=cosx：递增区间 [2kπ−π, 2kπ]，递减区间 [2kπ, 2kπ+π] (k∈Z)；对称轴 x=kπ；对称中心 (kπ+π/2, 0)。
   - (3) y=tanx：递增区间 (kπ−π/2, kπ+π/2) (k∈Z)；对称中心 (kπ/2, 0)。

### 和差倍角公式

8. 两角和与差公式：① sin(α±β)=sinαcosβ±cosαsinβ；cos(α±β)=cosαcosβ∓sinαsinβ；tan(α±β)=(tanα±tanβ)/(1∓tanαtanβ)。② sin(α+β)sin(α−β)=sin²α−sin²β；cos(α+β)cos(α−β)=cos²α−sin²β。③ asinα+bcosα=√(a²+b²)·sin(α+φ)（辅助角 φ 所在象限由点 (a,b) 决定，tanφ=b/a）。
9. 二倍角公式：① sin2α=2sinαcosα；(sinα±cosα)²=1±2sinαcosα=1±sin2α。② cos2α=cos²α−sin²α=2cos²α−1=1−2sin²α（升幂公式）；cos²α=(1+cos2α)/2，sin²α=(1−cos2α)/2（降幂公式）。

### 正余弦定理与三角形面积

10. 正、余弦定理：
   - (1) 正弦定理：a/sinA = b/sinB = c/sinC = 2R（2R 是 △ABC 外接圆直径）。注：① a:b:c = sinA:sinB:sinC；② a=2RsinA, b=2RsinB, c=2RsinC；③ a/sinA = b/sinB = c/sinC = (a+b+c)/(sinA+sinB+sinC)。
   - (2) 余弦定理：a² = b²+c²−2bc·cosA 等三个；cosA = (b²+c²−a²)/(2bc) 等三个。
11. 几个公式：(1) 三角形面积：① S=(1/2)ahₐ=(1/2)bh_b=(1/2)ch_c；② S=(1/2)ab·sinC=(1/2)bc·sinA=(1/2)ca·sinB；③ S_△OAB = (1/2)√[(|OA|·|OB|)²−(OA·OB)²]。
   (2) 内切圆半径 r = 2S_△ABC/(a+b+c)；外接圆直径 2R = a/sinA = b/sinB = c/sinC。

## 第四部分 立体几何

### 三视图与直观图

1. 三视图与直观图：(1) 画三视图要求：正视图与俯视图长对正；正视图与侧视图高平齐；侧视图与俯视图宽相等。(2) 斜二测画法画水平放置几何体的直观图要领。

### 表面积与体积

2. 表(侧)面积与体积公式：
   - (1) 柱体：① 表面积 S=S侧+2S底；② 侧面积 S侧=2πrh；③ 体积 V=S底·h。
   - (2) 锥体：① 表面积 S=S侧+S底；② 侧面积 S侧=πrl；③ 体积 V=(1/3)S底·h。
   - (3) 台体：① 表面积 S=S侧+S上底+S下底；② 侧面积 S侧=π(r+r')l；③ 体积 V=(1/3)(S+√(SS')+S')·h。
   - (4) 球体：① 表面积 S=4πR²；② 体积 V=(4/3)πR³。

### 位置关系证明

3. 位置关系的证明（主要方法）：
   - (1) 线线平行：①公理 4；②线面平行的性质定理；③面面平行的性质定理。
   - (2) 线面平行：①线面平行的判定定理；②面面平行⇒线面平行。
   - (3) 面面平行：①面面平行的判定定理及推论；②垂直于同一直线的两平面平行。
   - (4) 线面垂直：①线面垂直的判定定理；②面面垂直的性质定理。
   - (5) 面面垂直：①定义——两平面所成二面角为直角；②面面垂直的判定定理。
   - 注：以上理科还可用向量法。

### 角与距离

4. 求角（步骤——Ⅰ.找或作角；Ⅱ.求角）：(1) 异面直线所成角：①平移法（平移直线，构造三角形）；②向量法。(2) 直线与平面所成的角：①直接法（利用线面角定义）；②向量法。
5. 求距离（步骤——Ⅰ.找或作垂线段；Ⅱ.求距离）：点到平面的距离：①等体积法；②向量法。

### 常用结论

6. 结论：
   - (1) 棱锥的平行截面性质：截面与底面相似，截面面积与底面面积之比等于顶点到截面距离与棱锥高的平方比；相应小棱锥侧面积之比同理。
   - (2) 长方体从一顶点出发的三条棱长为 a,b,c，则体对角线 √(a²+b²+c²)，全面积 2ab+2bc+2ca，体积 V=abc。
   - (3) 正方体棱长 a：体对角线 √3a，全面积 6a²，体积 V=a³。
   - (4) 球与长方体：外接球直径 = 体对角线长。球与正方体：内切球直径 = 棱长；棱切球直径 = 面对角线长；外接球直径 = 体对角线长。
   - (5) 正四面体棱长 a：①高 h=√6/3·a；②对棱间距离 √2/2·a；③内切球半径 √6/12·a；④外接球半径 √6/4·a。

## 第五部分 直线与圆

### 斜率与直线方程

1. 斜率公式：k = (y₂−y₁)/(x₂−x₁)，其中 P₁(x₁,y₁)、P₂(x₂,y₂)。直线方向向量 v⃗=(a,b)，则斜率 k=b/a (a≠0)。
2. 直线方程的五种形式：(1) 点斜式 y−y₁ = k(x−x₁)；(2) 斜截式 y = kx+b；(3) 两点式 (y−y₁)/(y₂−y₁) = (x−x₁)/(x₂−x₁)；(4) 截距式 x/a + y/b = 1 (a,b≠0)；(5) 一般式 Ax+By+C=0（A、B 不同时为 0）。

### 位置关系与线性规划

3. 两条直线的位置关系：
   - (1) l₁: y=k₁x+b₁，l₂: y=k₂x+b₂：① l₁∥l₂ ⇔ k₁=k₂ 且 b₁≠b₂；② l₁⊥l₂ ⇔ k₁k₂=−1。
   - (2) l₁: A₁x+B₁y+C₁=0，l₂: A₂x+B₂y+C₂=0：① 平行 ⇔ A₁B₂−A₂B₁=0 且 A₁C₂−A₂C₁≠0；② 垂直 ⇔ A₁A₂+B₁B₂=0。
4. 线性规划解题步骤：(1) 列约束条件；(2) 作可行域，写目标函数；(3) 确定目标函数的最优解。

### 距离公式

5. 两个公式：(1) 点 P(x₀,y₀) 到直线 Ax+By+C=0 的距离 d = |Ax₀+By₀+C|/√(A²+B²)；(2) 两平行线 Ax+By+C₁=0 与 Ax+By+C₂=0 的距离 d = |C₁−C₂|/√(A²+B²)。

### 圆的方程与位置关系

6. 圆的方程：(1) 标准方程 (x−a)²+(y−b)²=r²；x²+y²=r²。(2) 一般方程 x²+y²+Dx+Ey+F=0（D²+E²−4F>0）。注：Ax²+Bxy+Cy²+Dx+Ey+F=0 表示圆 ⇔ A=C≠0 且 B=0 且 D²+E²−4AF>0。
7. 圆的方程的求法：(1) 待定系数法；(2) 几何法。
8. 位置关系（主要掌握几何法，d 表示距离）：
   - (1) 点与圆：d=R ⇔ 在圆上；d<R ⇔ 在圆内；d>R ⇔ 在圆外。
   - (2) 直线与圆：d=R ⇔ 相切；d<R ⇔ 相交；d>R ⇔ 相离。
   - (3) 圆与圆（d 为圆心距，R>r）：d>R+r ⇔ 相离；d=R+r ⇔ 外切；R−r<d<R+r ⇔ 相交；d=R−r ⇔ 内切；0<d<R−r ⇔ 内含。
9. 直线与圆相交所得弦长 |AB| = 2√(r²−d²)。

## 第六部分 圆锥曲线

### 定义

1. 定义：(1) 椭圆：|MF₁|+|MF₂|=2a（2a>|F₁F₂|）；(2) 双曲线：||MF₁|−|MF₂||=2a（2a<|F₁F₂|）；(3) 抛物线：|MF|=d。

### 常用结论

2. 结论：
   - (1) 直线与圆锥曲线相交的弦长公式：弦端点 A(x₁,y₁)、B(x₂,y₂)，则 |AB|=√[(x₁−x₂)²+(y₁−y₂)²]，或 |AB|=|x₁−x₂|√(1+k²)，或 |AB|=|y₁−y₂|√(1+1/k²)。
   - 注：①抛物线 |AB|=x₁+x₂+p；②通径（最短弦）：椭圆、双曲线 2b²/a；抛物线 2p。
   - (2) 过两点的椭圆、双曲线标准方程可设为 mx²+ny²=1（m,n 同时大于 0 表示椭圆；mn<0 表示双曲线）；当点 P 与椭圆短轴顶点重合时 ∠F₁PF₂ 最大。
   - (3) 双曲线结论：① x²/a²−y²/b²=1（a>0,b>0）的渐近线：x²/a²−y²/b²=0（即 y=±(b/a)x）；②共渐近线 y=±(b/a)x 的双曲线标准方程可设为 x²/a²−y²/b²=λ（λ≠0）；③等轴双曲线 ⇔ e=√2 ⇔ 渐近线互相垂直。
   - (4) 焦点三角形问题：利用圆锥曲线定义和余弦定理联立求解。

### 解法与轨迹

3. 直线与圆锥曲线问题解法：
   - (1) 直接法（通法）：联立直线与圆锥曲线方程，构造一元二次方程求解。注意：①联立的关于"x"还是关于"y"的一元二次方程？②直线斜率不存在时考虑了吗？③判别式验证了吗？
   - (2) 设而不求（点差法——代点作差法）：处理弦中点问题。步骤：①设点 A(x₁,y₁)、B(x₂,y₂)；②作差得 k_AB=(y₁−y₂)/(x₁−x₂)=…；③解决问题。
4. 求轨迹的常用方法：(1) 定义法（利用圆锥曲线的定义）；(2) 直接法（列等式）；(3) 代入法（又称相关点法或坐标转移法）；(4) 待定系数法；(5) 消参法；(6) 交轨法；(7) 几何法。

## 第九部分 不等式

### 均值不等式与极值定理

1. 均值不等式：√ab ≤ (a+b)/2 ≤ √[(a²+b²)/2]（a,b≥0）。注意：①一正二定三相等；②变形 ab ≤ [(a+b)/2]² ≤ (a²+b²)/2（a,b∈R）。
2. 极值定理：已知 x,y 都是正数：(1) 如果积 xy 是定值 p，那么当 x=y 时和 x+y 有最小值 2√p；(2) 如果和 x+y 是定值 s，那么当 x=y 时积 xy 有最大值 s²/4。

### 各类不等式解法

3. 解一元二次不等式 ax²+bx+c>0（或 <0）：若 a>0，解集为"大两边，小中间"。如 x₁<x₂ 时：(x−x₁)(x−x₂)<0 ⇔ x₁<x<x₂；(x−x₁)(x−x₂)>0 ⇔ x>x₂ 或 x<x₁。
4. 含有绝对值的不等式：a>0 时：① |x|<a ⇔ x²<a² ⇔ −a<x<a；② |x|>a ⇔ x²>a² ⇔ x>a 或 x<−a。
5. 分式不等式：(1) f(x)/g(x)>0 ⇔ f(x)·g(x)>0；(2) f(x)/g(x)<0 ⇔ f(x)·g(x)<0；(3) f(x)/g(x)≥0 ⇔ {f(x)·g(x)≥0 且 g(x)≠0}；(4) f(x)/g(x)≤0 ⇔ {f(x)·g(x)≤0 且 g(x)≠0}。
6. 指数不等式与对数不等式：(1) a>1 时：a^f(x)>a^g(x) ⇔ f(x)>g(x)；logₐf(x)>logₐg(x) ⇔ {f(x)>0；g(x)>0；f(x)>g(x)}。(2) 0<a<1 时：a^f(x)>a^g(x) ⇔ f(x)<g(x)；logₐf(x)>logₐg(x) ⇔ {f(x)>0；g(x)>0；f(x)<g(x)}。

### 不等式性质

7. 不等式的性质：(1) a>b ⇔ b<a；(2) a>b, b>c ⇒ a>c；(3) a>b ⇔ a+c>b+c；a>b, c>d ⇒ a+c>b+d；(4) a>b, c>0 ⇒ ac>bd（原文为 ac>bc）；a>b, c<0 ⇒ ac<bc；(5) a>b>0, c>d>0 ⇒ ac>bd；(6) a>b>0 ⇒ aⁿ>bⁿ>0（n∈N*）；a>b>0 ⇒ ⁿ√a>ⁿ√b（n∈N*）。

## 第十部分 复数

### 基本概念

1. 概念：(1) z=a+bi∈R ⇔ b=0（a,b∈R）⇔ z=z̄ ⇔ z²≥0；(2) z=a+bi 是虚数 ⇔ b≠0；(3) z=a+bi 是纯虚数 ⇔ a=0 且 b≠0 ⇔ z+z̄=0（z≠0）⇔ z²<0；(4) a+bi=c+di ⇔ a=c 且 b=d（a,b,c,d∈R）。

### 运算与重要结论

2. 复数的代数形式及其运算：设 z₁=a+bi，z₂=c+di（a,b,c,d∈R），则：(1) z₁±z₂ = (a±c)±(b±d)i；(2) z₁z₂ = (ac−bd)+(ad+bc)i；(3) z₁/z₂ = (ac+bd)/(c²+d²) + (bc−ad)/(c²+d²)·i（z₂≠0）。
3. 几个重要的结论：(1) |z₁+z₂|²+|z₁−z₂|² = 2(|z₁|²+|z₂|²)；(2) z·z̄ = |z|² = |z̄|²；(3) (1±i)² = ±2i；(4) (1+i)/(1−i) = i；(1−i)/(1+i) = −i；(5) i 的周期 T=4：i⁴ⁿ=1, i⁴ⁿ⁺¹=i, i⁴ⁿ⁺²=−1, i⁴ⁿ⁺³=−i；i⁴ⁿ+i⁴ⁿ⁺¹+i⁴ⁿ⁺²+i⁴ⁿ⁺³=0。
4. 模的性质：(1) |z₁z₂| = |z₁||z₂|；(2) |z₁/z₂| = |z₁|/|z₂|；(3) |zⁿ| = |z|ⁿ。

### 实系数一元二次方程

5. 实系数一元二次方程 ax²+bx+c=0 的解：① Δ=b²−4ac>0：x₁,₂ = (−b±√Δ)/(2a)；② Δ=0：x₁=x₂=−b/(2a)；③ Δ<0：实数集 R 内无实根；复数集 C 内有两个共轭复根 x = (−b±√(−Δ)·i)/(2a)。

## 第十一部分 概率

### 事件关系

1. 事件的关系：(1) 事件 B 包含事件 A：A 发生则 B 一定发生，记作 A⊆B；(2) 事件 A 与 B 相等：A⊆B 且 B⊆A，记作 A=B；(3) 并（和）事件：A 发生或 B 发生，记作 A∪B（或 A+B）；(4) 交（积）事件：A 发生且 B 发生，记作 A∩B（或 AB）；(5) 互斥：A∩B 为不可能事件（A∩B=∅）；(6) 对立事件：A∩B 为不可能事件且 A∪B 为必然事件。

### 概率公式

2. 概率公式：(1) 互斥事件概率：P(A+B)=P(A)+P(B)；(2) 古典概型：P(A) = A 包含的基本事件个数 / 基本事件总数；(3) 几何概型：P(A) = 构成事件 A 的区域长度（面积或体积等）/ 试验的全部结果构成的区域长度（面积或体积等）。

## 第十二部分 统计与统计案例

### 抽样方法

1. 抽样方法：
   - (1) 简单随机抽样：总体个数 N，逐个不放回抽取容量为 n 的样本，每个个体被抽到的机会相等。注：①每个个体被抽到的概率为 n/N；②常用方法：抽签法、随机数表法。
   - (2) 系统抽样：总体个数较多时，均衡分成几部分，按预先制定规则从每一部分抽取一个个体。步骤：①编号；②分段；③在第一段用简单随机抽样确定起始编号；④按规则抽取样本。
   - (3) 分层抽样：总体差异明显时，按各部分占总体的比例抽样。注：每部分抽取的样本数 = 该部分个体数 × n/N。三种抽样共同点：每个个体被抽到的概率相等。

### 图表与特征数

2. 频率分布直方图与茎叶图：(1) 用直方图反映样本频率分布规律。(2) 两位有效数字时，中间数字表示十位（茎），两边数字表示个位（叶）。
3. 总体特征数的估计：(1) 样本平均数 x̄ = (1/n)∑xᵢ；(2) 样本方差 S² = (1/n)∑(xᵢ−x̄)²；(3) 样本标准差 S = √[(1/n)∑(xᵢ−x̄)²]。

### 相关与回归

4. 相关系数（判定两个变量线性相关性）：r = ∑(xᵢ−x̄)(yᵢ−ȳ) / √[∑(xᵢ−x̄)²·∑(yᵢ−ȳ)²] = ∑(xᵢ−x̄)(yᵢ−ȳ) / √[(∑xᵢ²−nx̄²)(∑yᵢ²−nȳ²)]。注：(1) r>0 正相关，r<0 负相关；(2) |r| 越接近 1，线性相关性越强；|r| 越接近 0，几乎不存在线性相关关系。
5. 回归直线方程：y = a+bx，其中 b = ∑(xᵢ−x̄)(yᵢ−ȳ)/∑(xᵢ−x̄)² = (∑xᵢyᵢ−nx̄ȳ)/(∑xᵢ²−nx̄²)；a = ȳ − bx̄。

### 四种命题与量词

## 第十五部分 推理与证明

### 推理

1. 推理：
   - (1) 合情推理：归纳推理和类比推理统称合情推理。①归纳推理：由部分对象具有某特征推出全部对象都具有该特征，或由个别事实概括出一般结论（由部分到整体、个别到一般）。②类比推理：由两类对象具有某些类似特征和其中一类对象的已知特征，推出另一类对象也具有这些特征（特殊到特殊）。
   - (2) 演绎推理：从一般原理出发推出特殊情况下的结论（一般到特殊）。"三段论"是演绎推理的一般模式：①大前提——已知的一般结论；②小前提——所研究的特殊情况；③结论——根据一般原理对特殊情况得出的判断。

### 证明

2. 证明：
   - (1) 直接证明：①综合法（顺推法、由因导果法）：利用已知条件和定义、定理、公理等，经一系列推理论证推导出结论成立。②分析法（逆推法、执果索因法）：从要证明的结论出发，逐步寻求使它成立的充分条件，直至归结为判定一个明显成立的条件。
   - (2) 间接证明（反证法）：假设原命题不成立，经过正确推理得出矛盾，说明假设错误，从而证明原命题成立。
