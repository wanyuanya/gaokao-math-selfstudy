01集合与常用逻辑· 本章公式速查

与《高中数学常用公式·修订版》第一部分（集合）、第十四部分（常用逻辑用语）核对一致。

元素与集合的关系

a ∈ A（a 属于 A）
  • 大白话：a 这个东西，A 这个口袋里有它。
  • 用的时候：判断某个对象在不在集合里；在就写 ∈，不在就写 ∉，二选一，别空着。
a ∉ A（a 不属于 A）
  • 大白话：A 这个口袋里没有 a。
  • 用的时候：和 ∈ 配套，注意常用数集 N 含 0、N* 不含 0。

集合间的关系

A ⊆ B（A 包含于 B）
  • 大白话：A 里的每样东西 B 里都有，A 整个装进 B 里。
  • 用的时候：判断包含关系；别忘 ∅ ⊆ A 恒成立，写子集先写空集。
  • 记忆要点：⊆ 开口朝向"装得多"的那个大集合。
A  =  B（A 等于 B）
  • 大白话：A 和 B 元素一模一样。
  • 用的时候：要证 A = B，得两边互相 ⊆，即 A⊆B 且 B⊆A。
∅ ⊆ A（空集是任何集合的子集）
  • 大白话：空口袋能装进任何口袋。
  • 用的时候：问"某集合的所有子集"，第一个就写 ∅，最后别忘了它自己；{0} ≠ ∅。
含 n 个元素 ⇒ 子集 2n、真子集 2n−1、非空真子集 2n−2
  • 大白话：每个元素"带不带"两种选择，n 个元素就是 2 的 n 次方。
  • 用的时候：{1,2,3} 有 8 个子集、7 个真子集；先写 ∅ 再逐个加。
  • 记忆要点：去掉空集减 1，再去掉它自己再减 1。
若 A ⊆ B ⊆ C，A 有 m 个元素、C 有 n 个元素（n>m），则这样的 B 有 2n−m 个（苏州教研·专题1 补充）
  • 大白话：A 的元素必须全进 B，C 比 A 多出的 (n−m) 个元素每个"带不带进 B"都行，共 2n−m 种。
  • 用的时候：如 {1,2}⊆B⊆{1,2,3,4,5}，多出 3 个元素，B 有 23  =  8 个。
  • 记忆要点：夹在中间的 B，自由度全在"A 没有、C 有"的那批元素上。

集合的基本运算

A ∩ B  =  {x | x ∈ A 且 x ∈ B}（交集）
  • 大白话：两个集合重叠的那部分，"既在 A 又在 B"。
  • 用的时候：数集运算画数轴取公共段；盯紧端点该闭还是该开。
A ∪ B  =  {x | x ∈ A 或 x ∈ B}（并集）
  • 大白话：两个集合合起来的全部，重叠处只算一次。
  • 用的时候：画数轴取两段盖住的全部；"或"是至少满足一个。
∁uA  =  {x | x ∈ U 且 x ∉ A}（A 在全集 U 中的补集）
  • 大白话：从大背景 U 里把 A 扣掉，剩下的就是补集。
  • 用的时候：先写清楚全集 U 是什么；补集  =  数轴上"剩下的部分"。

运算律与计数

德摩根律：∁u(A∩B)  =  (∁uA)∪(∁uB)，∁u(A∪B)  =  (∁uA)∩(∁uB)
  • 大白话：交的补 = 补的并，并的补 = 补的交，括号一拆 ∩ 和 ∪ 对调。
  • 用的时候：见到"补的交并"想拆开，或反过来合并。
  • 记忆要点："交补变并、并补变交"。
|A∪B|  =  |A| + |B| − |A∩B|（容斥计数）
  • 大白话：两个集合总个数，重叠部分被算了两次，要减掉一次。
  • 用的时候：数元素个数、做概率题常用。
A ∪ B  =  B ⇔ A ⊆ B；A ∩ B  =  A ⇔ A ⊆ B（运算结果反推包含，苏州教研·专题1）
  • 大白话：并完还是 B、交完剩 A，都说明 A 整个被 B 装着。
  • 用的时候：题目给运算等式，先翻译成包含关系再动手，别硬算。
  • 记忆要点："谁被吸收了，谁就是小的那个。"

充分与必要条件

A ⊆ B ⇒ "A 的条件"是"B 的条件"的充分条件（小推大）
  • 大白话：落在小集合里，一定落在大集合里。
  • 用的时候：把两个命题翻成数集，小集合推大集合就是充分；A=B 才充要。
  • 记忆要点："谁是谁的充分条件"，箭头从 p 指向 q，别读反主宾。

量词与命题否定

¬(∀x∈M, p(x))  =  ∃x∈M, ¬p(x)
  • 大白话："所有 x 都成立"的否定是"存在某个 x 不成立"。
  • 用的时候：量词 ∀ 换成 ∃，结论否定，条件 M 不动。
¬(∃x∈M, p(x))  =  ∀x∈M, ¬p(x)
  • 大白话："存在某个 x 成立"的否定是"所有 x 都不成立"。
  • 用的时候：∃ 换成 ∀，再否定结论；别去动条件 M。
  • 记忆要点："换量词 + 否结论"，两步就够。
常见词语否定：都→不都；或⇔且互换；至少一个→一个也没有（苏州教研·专题42）
  • 大白话："都是"的否定是"不都是"（存在一个不是），不是"都不是"；"p或q"的否定是"¬p且¬q"。
  • 用的时候：否定命题先换量词、再对词；"至少有一个"否定成"一个也没有"，"至多有一个"否定成"至少有两个"。
  • 记忆要点：全称特称互换 + 连接词或且互换。

02函数的概念与性质· 本章公式速查

与《高中数学常用公式·修订版》第二部分（函数与导数）核对一致。

函数的概念与三要素

函数三要素：定义域、对应关系、值域
  • 大白话：x 取哪些值（定义域）、按什么规则算 y（对应关系）、算出哪些 y（值域）。
  • 用的时候：定义域是命门，一切问题先看 x 能取什么。
同一函数  =  定义域相同 且 对应关系相同
  • 大白话：两个函数"x 的范围"和"算 y 的规则"都一样，才是同一个。
  • 用的时候：先比定义域再比对应关系；y=x 与 y=x2/x 不是同一函数（后者 x≠0）。
  • 记忆要点：字母用 x 还是 t 不影响。
垂直检验：函数图象与任意竖直线 x = m 至多一个交点（苏州教研·专题2）
  • 大白话：一个 x 只能对应一个 y，竖直线切到两个点就不是函数图象。
  • 用的时候：给一张图判断它是不是函数，拿竖直线去扫一遍；点 (a,b) 在图象上 ⇔ f(a) = b。

定义域的求法

定义域红线：分母 ≠ 0；偶次根号内 ≥ 0；0 次幂底数 ≠ 0
  • 大白话：分母不能为 0，根号里不能是负数，底不能为 0。
  • 用的时候：把每条红线列成不等式，全部取交集（不是并集），再写成区间。
  • 记忆要点：求定义域别先化简，约掉前的禁区要保留。
抽象函数定义域：盯住"被同一个 f 作用的对象范围相同"（苏州教研·专题2）
  • 大白话：f(x) 定义域是 (a,b)，则 f(g(x)) 要求 a<g(x)<b；反过来 f(g(x)) 定义域是 (a,b)，则 f(x) 定义域是 g(x) 在 (a,b) 上的值域。
  • 用的时候：f(x) 定义域 (1,3) 求 f(2x+1) → 解 1<2x+1<3 得 (0,1)。
  • 记忆要点：括号里整体的范围  =  f 原本的定义域。

单调性

单调递增：x1<x2 ⇒ f(x1)<f(x2)
  • 大白话：x 越大 y 越大，图象从左下走到右上。
  • 用的时候：定义法证单调按"取值—作差—变形—定号"四步走。
单调递减：x1<x2 ⇒ f(x1)>f(x2)
  • 大白话：x 越大 y 越小。
  • 用的时候：断开的区间要分开说，如 y=1/x 在 (−∞,0) 和 (0,+∞) 上分别递减，不能说"整个定义域递减"。

奇偶性

偶函数：f(−x) = f(x)，图象关于 y 轴对称
  • 大白话：左右翻折图象重合，如 f(x)=x2。
  • 用的时候：先查定义域是否关于原点对称，不对称直接非奇非偶。
奇函数：f(−x) = −f(x)，图象关于原点对称
  • 大白话：转 180° 图象重合，如 f(x)=x3。
  • 用的时候：同样先查定义域对称；对称后算 f(−x) 跟 ±f(x) 比。
奇函数若在 x = 0 有定义，则 f(0) = 0
  • 大白话：奇函数图象过原点。
  • 用的时候：小题秒杀结论；只对"奇函数且 0 在定义域内"成立，偶函数别套用。
奇函数对称区间单调性相同，偶函数对称区间单调性相反（苏州教研·专题6）
  • 大白话：奇函数左右两半一增俱增；偶函数左右两半一增一减。
  • 用的时候：已知一半区间的单调性，推另一半；别记反。
偶函数 f(x) = f(|x|)；F(x) = f(x)+f(−x) 为偶，F(x) = f(x)−f(−x) 为奇（苏州教研·专题7）
  • 大白话：偶函数问题翻成绝对值比大小；任何对称定义域的函数，加 f(−x) 是偶函数、减 f(−x) 是奇函数。
  • 用的时候：解抽象不等式 f(x1)<f(x2)（偶+单调）→ |x1|<|x2|；对数型函数判奇偶常用后一条。

图象的平移与翻折

左右平移左加右减、上下平移上加下减（苏州教研·专题5）
  • 大白话：右移 a 把 x 换成 x−a，上移 b 整个函数加 b。
  • 用的时候：y = f(x) 右移 2、上移 3 → y = f(x−2)+3。
  • 记忆要点：左右动的是括号里的 x，上下动的是函数值整体。
y = |f(x)| 下往上翻；y = f(|x|) 右翻左（偶函数）（苏州教研·专题5）
  • 大白话：|f(x)| 把负的图象翻到 x 轴上方；f(|x|) 留右半、沿 y 轴对称出左半。
  • 用的时候：见到套绝对值的函数，先想"翻折"而不是硬画。

二次函数与最值

二次函数顶点式 f(x) = a(x−h)2+k，顶点 (h,k)
  • 大白话：配方后一眼看到最高点/最低点。
  • 用的时候：求最值先配方找顶点；a>0 开口向上有最小值，a<0 有最大值。
闭区间最值  =  区间内极值与端点值一起比
  • 大白话：把山顶、山谷、两头的函数值摆一块，挑最大最小。
  • 用的时候：先看顶点在不在区间内，再算 f(端点)，三者比大小。

分段函数

分段函数：不同区间不同解析式，仍是一个函数
  • 大白话：一个函数分几段写，每段一个范围配一个式子。
  • 用的时候：求 f(某值) 先看它落在哪段，再套那段的式子；画图注意端点实心空心。

03基本初等函数（指数、对数、幂函数）· 本章公式速查

与《高中数学常用公式·修订版》第二部分 8（基本初等函数）核对一致。

指数运算

指数律：am·an = am+n，(am)n = amn，(ab)n = anbn（a>0）
  • 大白话：同底相乘指数加，幂上叠幂指数乘。
  • 用的时候：化简指数式先看底数是否相同；am÷an=am−n。
分数指数幂：a^(m/n) = n√(am)，a^(−m/n) = 1/a^(m/n)（a>0）
  • 大白话：根号就是分数指数，负指数就是倒数。
  • 用的时候：如 4^(3/2)=(√4)3=8；4√(x2) 要带绝对值。
  • 记忆要点：分子是"几次方"，分母是"开几次根"。

对数的定义与恒等式

对数定义：ab = N ⇔ logaN = b（a>0，a≠1，N>0）
  • 大白话：a 的几次方等于 N，那个"几次方"就是 logaN。
  • 用的时候：负数和 0 没有对数；真数必须 >0。
对数恒等式：a^(logaN) = N
  • 大白话：底数不动，指数和对数互相抵消。
  • 用的时候：见到 a^(logaN) 直接换成 N。
loga1 = 0，logaa = 1
  • 大白话：a0=1，a1=a，所以 log 出来就是 0 和 1。
  • 用的时候：常数秒算，别硬套公式。

对数运算律

积：loga(MN) = logaM+logaN
  • 大白话：乘出来的对数 = 对数相加。
  • 用的时候：注意 loga(M+N) 不能拆！只对乘除拆加减。
商：loga(M/N) = logaM−logaN
  • 大白话：相除的对数 = 对数相减。
  • 用的时候：M、N 都得 >0。
幂：logaMn = n·logaM
  • 大白话：幂上的 n 可以搬到前面当系数。
  • 用的时候：化简 log29=2log23。
换底公式：logab  =  log꜀b / log꜀a
  • 大白话：随便换个好算的底（lg 或 ln）来比。
  • 用的时候：连乘 log23·log34·log48 中间全约掉，只剩 log28=3。
换底推论：log_{an}bm  =  (m/n)logab；logab  =  1/log_b a（苏州教研·专题10）
  • 大白话：底数真数的次方提前当系数；底数真数一颠倒，对数就取倒数。
  • 用的时候：log29 = log_{22}32 = log23（同次约掉）；log23 = 1/log32。
  • 记忆要点：logax2 = 2loga|x|（提幂必带绝对值），常用 lg2+lg5=1。

指数函数

y = ax（a>0，a≠1）：定义域 R，值域 (0,+∞)，恒过 (0,1)
  • 大白话：指数函数永远为正，都从 (0,1) 出发。
  • 用的时候：a>1 递增、0<a<1 递减；定点题"让指数为 0"，如 ax+1−2 过 (−1,−1)。

对数函数

y = logax（a>0，a≠1）：定义域 (0,+∞)，值域 R，恒过 (1,0)
  • 大白话：真数必须 >0，图象都过 (1,0)。
  • 用的时候：a>1 递增；它和 y=ax 互为反函数，图象关于 y=x 对称。

幂函数

y = xα：都过点 (1,1)；α>0 在 (0,+∞) 增，α<0 在 (0,+∞) 减（苏州教研·专题11）
  • 大白话：底数在变、指数固定，x=1 时永远是 1；正指数第一象限往上走，负指数第一象限往下走。
  • 用的时候：常见 α=−1,1/2,1,2,3；注意和指数函数区分（谁在底数谁在指数）。

指对函数里的奇偶模型与定点（苏州教研·专题9/10/12）

奇函数：f(x) = (ax−a−x)/2、f(x) = (ax−1)/(ax+1)、f(x) = loga(√(x2+1)+x)；偶函数：f(x) = a^|x|、f(x) = (ax+a−x)/2、f(x) = loga|x|
  • 大白话：指数项"正负成对"拼出奇偶，对数套"√(x2+1)±x"也出奇函数。
  • 用的时候：含参 a 的指对函数过定点——令 a 的指数=0（或令真数=1），参数即隐身，剩下的坐标就是定点。
  • 记忆要点：a^(x−1)+3 过 (1,4)；loga(x−2)+4 过 (3,4)。

比较大小

先分档（0、1），再用单调性精排
  • 大白话：正数>0>负数，大于 1 的>0到1的>负数，先分三类再排。
  • 用的时候：同底看单调、同指看幂函数；两数接近时构造函数或作差作商。
  • 记忆要点："先定符号，再定过不过 1"。

04函数的应用与方程（零点、二分法、函数模型）· 本章公式速查

与《高中数学常用公式·修订版》第二部分核对一致。

零点的概念

零点  =  使 f(x) = 0 的实数 x
  • 大白话：函数图象和 x 轴交点的横坐标，就是方程 f(x)=0 的根。
  • 用的时候：零点是一个数 x，不是一个点 (x,0)；求零点就是解方程。
三件事一回事：有实根 ⇔ 有零点 ⇔ 图象交 x 轴
  • 大白话：解方程、找零点、看图象和 x 轴交几次，说的是同一件事。
  • 用的时候：不会解方程就画图，看曲线和 x 轴交几次。

零点存在定理

f 连续，且 f(a)·f(b)<0 ⇒ (a,b) 内至少一个零点
  • 大白话：图象从 x 轴上方连续走到下方，中间必然至少穿过一次。
  • 用的时候：两个前提——图象要连续、两端一正一负；它只是充分条件，同号也可能有零点。
  • 记忆要点：定理只保"至少一个"，不保"只有一个"。

二分法

取中点 c = (a+b)/2，看 f(c) 与哪端异号，把区间砍一半
  • 大白话：每次取区间中点，根据中点值符号，保留根所在的那一半。
  • 用的时候：f(c)=0 直接得根；否则 f(a) 与 f(c) 异号就缩到 (a,c)。
砍 n 次后区间长度  =  (b−a)/2n
  • 大白话：每砍一次区间减半，越缩越接近真根。
  • 用的时候：想精确到 ε，就砍到 (b−a)/2n<ε 为止。

零点个数判断

单调 + 变号 ⇒ 恰一个零点
  • 大白话：函数一路单调，又在区间两端变号，那中间一定穿过且只穿过 x 轴一次。
  • 用的时候：零点定理只说"至少一个"，加上单调性才升级成"恰一个"。

增长模型

指数模型 y = a·bx（b>1）：长期最快，指数爆炸
  • 大白话：开头慢，后来越涨越猛，最终压倒一切幂函数和对数函数。
  • 用的时候：细胞分裂、复利、传染病扩散，长期都归指数模型。
对数模型 y = lnx/lgx：越涨越慢
  • 大白话：一开始快，后来后劲不足、涨不动。
  • 用的时候：学新东西的边际递减，就是这个脾气。
x 足够大时：指数 > 幂 > 线性 > 对数
  • 大白话：时间拉长，指数模型笑到最后。
  • 用的时候：别被指数开头慢骗了，长期必看指数。
指数增长模型 y = N(1+p)x（复利/细胞分裂/半衰期）（苏州教研·专题16）
  • 大白话：原有量 N，每次乘 (1+p)，利滚利；p<0 就是衰减（半衰期）。
  • 用的时候：复利、人口增长、放射性衰减都套它；应用题四步"审题→建模→解模→回归"。

恒成立与能成立（苏州教研·专题13）

λ≥f(x) 恒成立⇔λ≥f(x)max；λ≤f(x) 恒成立⇔λ≤f(x)min；λ≥f(x) 有解⇔λ≥f(x)min；λ≤f(x) 有解⇔λ≤f(x)max
  • 大白话：恒成立看"离得最远"的最值，能成立看"离得最近"的最值。
  • 用的时候：优先分离参数 λ=g(x)/f(x)，再求 g(x)/f(x) 的最值；一次函数区间恒正看 f(m)>0、f(n)>0；二次函数 R 上恒正看 a>0 且 Δ<0。
  • 记忆要点："恒压最高、恒托最低；够到最低、够到最高"，端点等号单独验。

二次方程根的分布（苏州教研·专题15）

同区间三抓：Δ≥0、对称轴 −b/2a 落在区间内、两端 f 值同号（>0）；异区间一抓：x1<m<x2 ⇔ f(m)<0
  • 大白话：两根挤在一个区间里，要同时满足"有根、对称轴在里面、两头都在 x 轴上方"；两根分居 m 两侧，只要 f(m)<0 即可。
  • 用的时候：开口向上 a>0；先画抛物线，再写不等式组；一根大于 m 一根小于 m 时，直接 f(m)<0，Δ 都不用算。
  • 记忆要点："同区间三抓（Δ、轴、端点），异区间一抓（端点符号）"。

05导数及其应用· 本章公式速查

与《高中数学常用公式·修订版》第二部分（函数与导数）核对一致。

导数的定义与几何意义

f′(x0)  =  lim(Δx→0) [f(x0+Δx)−f(x0)]/Δx
  • 大白话：无限短时间内的平均变化率，就是瞬时变化率。
  • 用的时候：用定义求导就按"算增量比 → 让 Δx→0"。
几何意义：f′(x0)  =  切线斜率；切线方程 y−f(x0) = f′(x0)(x−x0)
  • 大白话：导数就是曲线在那一点切线的坡度。
  • 用的时候：求切线先算导数值当斜率，再用点斜式写方程。

基本求导公式（必背）

(C)′ = 0
  • 大白话：常数不变，变化率为 0。
(xn)′ = n·xn−1
  • 大白话：指数搬下来，指数减 1。
  • 用的时候：如 (x3)′=3x2，(x4)′=4x3。
(sin x)′ = cos x，(cos x)′ = −sin x
  • 大白话：正弦求导变余弦，余弦求导带个负号变正弦。
(ex)′ = ex
  • 大白话：e 的 x 次方求导还是自己，最"自恋"。
(ax)′ = ax·ln a
  • 大白话：比 ex 多个 ln a 系数。
  • 用的时候：只有 ex 没有 ln 系数，别多写。
(ln x)′ = 1/x
  • 大白话：自然对数求导是倒数。
(logax)′ = 1/(x·ln a)
  • 大白话：一般对数求导多个 ln a 在分母。

四则运算与复合

和差：[f±g]′ = f′±g′
  • 大白话：逐项求导再加减。
积：[f·g]′ = f′g+fg′
  • 大白话：前导后不导 + 前不导后导。
  • 用的时候：如 (x·ex)′=ex+x·ex=(1+x)ex。
商：[f/g]′ = (f′g−fg′)/g2
  • 大白话：分子是"上导下不导 − 上不导下导"，分母是下的平方。
  • 用的时候：g≠0；如 (lnx/x)′=(1−lnx)/x2。
复合：[f(g(x))]′ = f′(g(x))·g′(x)
  • 大白话：外层求导乘以内层求导，链式一路乘下去。
  • 用的时候：如 (e^(2x))′=e^(2x)·2=2e^(2x)。

导数与单调性

f′(x)>0 ⇒ 增；f′(x)<0 ⇒ 减
  • 大白话：导数正函数涨，导数负函数跌。
  • 用的时候：求单调区间先写定义域，再求导判号；f′≥0 且不恒为 0 才是增。

极值与最值

极值点：f′(x0) = 0 且两侧 f′ 变号
  • 大白话：导数为零还不够，左右坡度得一反一正才是山顶/山谷。
  • 用的时候：左正右负是极大、左负右正是极小；f′(x0)=0 但不变号（如 x3 在 0）不是极值。
闭区间最值  =  区间内极值与端点值一起比
  • 大白话：把山顶、山谷、两头的函数值摆一块挑最大最小。

恒成立问题

a≤f(x) 恒成立 ⇔ a≤f(x)_min；a≥f(x) 恒成立 ⇔ a≥f(x)_max
  • 大白话：要 a 永远不超过 f，a 最多只能等于 f 的最小值。
  • 用的时候：分离参数把 a 单独放一边，再求另一边函数的最值。
∀x≥p 时 f(x)≥0 恒成立，且端点 f(p) = 0 ⇒ 先看 f′(p)、f″(p) 定分界（端点效应）（苏州教研·专题51，题型7）
  • 大白话：函数在起点"贴地"时，拿二阶导数在起点的值当分类分界，一刀切开参数范围。
  • 用的时候：f″(p) 含参，令 f″(p) = 0 解出的那个参数值就是分类标准；a 比它小就单调成立，比它大必在 (p,p+δ) 内破。
|f(x1)−f(x2)|≥λ|x1−x2| 恒成立 ⇔ h(x) = f(x)±λx 单调（苏州教研·专题51，题型1）
  • 大白话：两点函数值之差要被 x 之差"管住"，就把 f 加/减 λx 凑成单调函数。
  • 用的时候：去绝对值移项凑成 f(x1)−λx1≤f(x2)−λx2，再对 h′(x) = f′(x)±λ 分离参数。

切线放缩不等式族（苏州教研·专题51）

ex ≥ x+1（x = 0 取等）；lnx ≤ x−1（x = 1 取等）；ln(1+x) ≤ x（x = 0 取等）
  • 大白话：指数甩成一次式、对数压成一次式，等号都贴在切点上。
  • 用的时候：证含 ex、lnx 的不等式时，先用它们把超越项"砍"成多项式，再解普通不等式。
  • 记忆要点：每条都是"曲线 ≥ 切线"或"曲线 ≤ 切线"，等号点就是切点 x=0 或 x=1。
ex ≥ 1+x+x2/2（x≥0，x = 0 取等）（苏州教研·专题51，例12/例27）
  • 大白话：要更紧的放缩时，把二次项也补上；可由两次求导证（h″ = ex−1≥0）。
  • 用的时候：直接放 ex≥x+1 太松时换这条；答题卡上引用要补一句"可由导数证明"。

06三角函数的概念与性质· 本章公式速查

与《高中数学常用公式·修订版》第三部分核对一致。

弧度制：用弧长量角

π rad  =  180°；1°  =  π/180 rad；1 rad  =  (180/π)°  ≈  57.3°
  • 大白话：半圈就是 π 弧度，角度和弧度是量同一个角的两把尺子。
  • 用的时候：度化弧度乘 π/180，弧度化度乘 180/π；从这章起做题默认弧度。
  • 记忆要点：整圈 2π = 360°，其余都从这一句推。
弧长 l  =  |α|·r；扇形面积 S  =  ½·l·r  =  ½·|α|·r2（α 必须用弧度）
  • 大白话：弧度制下弧长就是"圆心角乘半径"，扇形面积是弧长乘半径再折半。
  • 用的时候：题目给角度就先换成弧度；看到扇形直接套，别再绕"底乘高"。

三角函数的定义（单位圆）

单位圆上交点 P(x,y)：sinα  =  y，cosα  =  x，tanα  =  y/x
  • 大白话：sin 就是那个点的纵坐标，cos 就是横坐标。
  • 用的时候：别死守初中"对边比斜边"，直接把 sin、cos 想成单位圆上点的 y、x。
终边上一般点 P(x,y)、r  =  √(x2+y2)：sinα  =  y/r，cosα  =  x/r，tanα  =  y/x
  • 大白话：圆半径不是 1 也不怕，先把 r 算出来再比。
  • 用的时候：给终边上一点求三角值，第一步永远是先算 r。
符号口诀：一全正，二正弦，三正切，四余弦
  • 大白话：按象限记谁正谁负——第一象限全正，第二象限只有 sin 正，第三象限只有 tan 正，第四象限只有 cos 正。
  • 用的时候：判断正负不用算具体值，先定象限再套口诀。

同角基本关系

sin2α + cos2α  =  1
  • 大白话：同一个角的 sin、cos 平方和永远等于 1，不管角多大。
  • 用的时候：已知 sin 求 cos 时用它；注意开方取正负要看角所在象限。
  • 记忆要点：画单位圆，斜边是 1，勾股定理就是它。
tanα  =  sinα / cosα（要求 cosα ≠ 0）
  • 大白话：tan 就是 sin 除以 cos。
  • 用的时候：角落在 y 轴上（cos = 0）时 tan 没意义，这是 tan 定义域的根。

诱导公式（大角化锐角）

口诀：奇变偶不变，符号看象限
  • 大白话：加减的是 π/2 的几倍？奇数倍函数名 sin↔cos 互换，偶数倍名字不变；再把 α 当锐角，看原来那个角在第几象限、原函数取正还是负，符号就照带过去。
  • 用的时候：负角、补角、平角、互余全靠它化回锐角；符号看的是变换前那个角，不是变换后。
常用四组（大角化锐角的成品公式）

负角：sin(−α)  =  −sinα，cos(−α)  =  cosα，tan(−α)  =  −tanα

补角 π−α：sin(π−α)  =  sinα，cos(π−α)  =  −cosα

平角 π+α：sin(π+α)  =  −sinα，cos(π+α)  =  −cosα

互余 π/2−α：sin(π/2−α)  =  cosα，cos(π/2−α)  =  sinα

  • 大白话：上面口诀在负角、补角、平角、互余四种情形下的成品，直接套用。

三条基本函数的性质

周期：y = sin x、y = cos x 周期 2π；y = tan x 周期 π
  • 大白话：正弦余弦转一整圈才重复，正切转半圈就重复。
  • 用的时候：tan 周期别误写成 2π。
值域与奇偶：sin、cos ∈ [−1,1]，tan ∈ R；sin、tan 是奇函数，cos 是偶函数
  • 大白话：sin、cos 被夹在 −1 到 1 之间；sin 关于原点对称，cos 关于 y 轴对称。
  • 用的时候：求最值先看值域；判奇偶就看 sin(−x)=−sinx、cos(−x)=cosx。
对称轴与中心：sin x 轴 x = π/2+kπ、中心 (kπ,0)；cos x 轴 x = kπ、中心 (π/2+kπ,0)；tan x 无对称轴、中心 (kπ/2,0)
  • 大白话：正弦"峰谷连线是轴、零点是中心"；余弦正好错开 π/2；正切没有轴但有中心。
  • 用的时候：tan 别漏了对称中心 (kπ/2,0)。

y = A sin(ωx + φ) 的读法

振幅 A、周期 T  =  2π/|ω|、初相 φ；最大值 A、最小值 −A
  • 大白话：A 管波形上下拉多高，ω 管波形挤多密，φ 管波形左右挪多少。
  • 用的时候：ω 越大周期越小；T=2π/ω，别把 ω 和 T 搞反（y=sin2x 周期是 π）。
对称轴令 ωx+φ  =  π/2+kπ；对称中心令 ωx+φ  =  kπ；y = A tan(ωx+φ) 周期 T  =  π/|ω|
  • 大白话：把括号里那串整体当作标准正弦的角，套进 sin 的轴/中心公式再反解 x。
  • 用的时候：正切型周期是 π/|ω|，别套成 2π/|ω|。

周期与对称的进阶结论（苏州教研·专题27）

加绝对值后周期减半/不减半：y = |sin(ωx+φ)|、|cos(ωx+φ)|、|tan(ωx+φ)| 的周期 T  =  π/ω；y = |A sin(ωx+φ)+B|、|A cos(ωx+φ)+B|（B≠0）的周期 T  =  2π/ω（不减半）
  • 大白话：光给 sin、cos 套一层绝对值会把负半周"翻上去"，波形挤成原来一半密（周期减半）；但如果底下还垫了常数 B（整体平移过），翻上去后破坏了对称，周期又恢复成 2π/ω。
  • 用的时候：见 |sin(ωx+φ)| 直接写 T=π/ω；见 |A sin(ωx+φ)+B|（B 不为 0）别减半。
  • 记忆要点：纯绝对值包函数本身减半，包"函数+竖直平移"不减半。
对称轴过最值点：x = m 是 f(x) = A sin(ωx+φ) 的对称轴 ⇔ f(m) = ±A；点 (m,0) 是对称中心 ⇔ f(m) = 0
  • 大白话：正弦曲线的对称轴一定穿过峰或谷（函数取到 ±A 的地方），对称中心一定落在平衡位置（函数取 0 的地方）。
  • 用的时候：判断直线 x=m 是不是对称轴、点 (m,0) 是不是中心，只需代入看它取不取到 ±A / 0，不用画图。
确定性奇偶性的条件：y = A sin(ωx+φ)、A cos(ωx+φ)、A tan(ωx+φ) 有确定奇偶性 ⇔ φ  =  k·π/2（k∈Z）
  • 大白话：当初相 φ 是 π/2 的整数倍时，这个函数才"天生"是奇函数或偶函数；否则既非奇也非偶。
  • 用的时候：题目问"f(x) 是奇函数/偶函数求 φ"，答案就是 φ=kπ（sin 型奇、cos 型偶）或 φ=kπ+π/2 这一类，圈在 φ=k·π/2 上。
由一段最值反求 A、B：y = A sin(ωx+φ)+B（A>0）的值域为 [−A+B, A+B]，故 A = (ymax−ymin)/2，B = (ymax+ymin)/2
  • 大白话：有上下平移 B 时，最大值与最小值不再关于 0 对称，中线就是 B，振幅是上下两半差的一半。
  • 用的时候：给一段图象读出最大、最小值，直接套这两条反解 A 和 B。
三角方程：sin α  =  sin β ⇒ α  =  β + 2kπ 或 α + β  =  π + 2kπ（k∈Z）
  • 大白话：两个正弦值相等，要么两个角终边相同，要么它们关于 π/2 对称（和为 π 的奇数倍）。
  • 用的时候：解 sin 方程别只写 α=β，漏掉"和为 π"那组解就扣分。

三角不等式与勾股数速算（苏州教研·专题26）

x∈(0, π/2) 时：sin x < x < tan x
  • 大白话：在锐角范围内，正弦比弧度 x 小，正切比 x 大，x 夹在中间。
  • 用的时候：比较 sin、x、tan 三者大小，或给"sin x<x"这类不等式提供直觉。
x∈(0, π/2) 时：1 < sin x + cos x ≤ √2
  • 大白话：锐角正弦加余弦，最小趋近 1（不取到），最大是 √2（在 x=π/4 取到）。
  • 用的时候：判断 sin x+cos x 的范围，或辅助角 sin x+cos x=√2 sin(x+π/4) 的最值。
勾股数速记（秒出三角函数值）：(3,4,5)、(5,12,13)、(8,15,17)、(7,24,25)
  • 大白话：背熟这四组勾股数，遇到直角三角形边长能立刻写出 sin、cos、tan。
  • 用的时候：给了两条边长求三角值，先看是不是这几组勾股数，是的话直接读比值，但别忘了先按象限定符号。

07三角恒等变换· 本章公式速查

与《高中数学常用公式·修订版》第三部分第 8、9 条核对一致。

和差角公式（一切的根）

根：cos(α−β)  =  cosα cosβ + sinα sinβ
  • 大白话：两角差的余弦，等于"余弦余弦相加、正弦正弦相加"。整套和差角公式都从它推出来。
  • 用的时候：记不住全套时，先推出这一条，再用"把 β 换成 −β"变出其余。
sin(α±β)  =  sinα cosβ ± cosα sinβ（中间符号相同）
  • 大白话：正弦展开是"正余、余正"，括号里是加号结果就加号、减号就减号。
  • 用的时候：这是最不容易记反的一条，中间符号跟着 α±β 走。
cos(α±β)  =  cosα cosβ ∓ sinα sinβ（中间符号相反）
  • 大白话：余弦展开是"余余、正正"，但中间符号要反过来——α+β 反而用减号。
  • 用的时候：这是最容易写反的地方，cos(α+β) 中间是减号。
tan(α±β)  =  (tanα ± tanβ)/(1 ∓ tanα tanβ)
  • 大白话：分子同号、分母反号。
  • 用的时候：分母符号别写反；出现"1±tan"的结构就想到它（如 tan(45°±α)）。

和差角的乘积推论

sin(α+β)sin(α−β)  =  sin2α − sin2β
  • 大白话：两个正弦相乘（角相差 2β），能化成"大角正弦平方减小角正弦平方"。
  • 用的时候：选填里见到 sin(A+B)sin(A−B) 这种结构可直接套。
cos(α+β)cos(α−β)  =  cos2α − sin2β
  • 大白话：余弦版本的同款化简。
  • 用的时候：和上一条配对记，现场推不出来再查。

二倍角公式

sin 2α  =  2 sinα cosα
  • 大白话：二倍角的正弦 = 正弦余弦乘积的 2 倍。
  • 用的时候：注意 sin2α ≠ 2sinα，别把系数直接乘进去。
cos 2α  =  cos2α − sin2α  =  2cos2α − 1  =  1 − 2sin2α
  • 大白话：二倍角余弦有三张"面孔"，给 sin 就用 1−2sin2α，给 cos 就用 2cos2α−1。
  • 用的时候：哪种给的三角函数值方便就用哪张脸，省得再开方。
tan 2α  =  2tanα/(1 − tan2α)
  • 大白话：正切的二倍角，分子 2tan、分母 1−tan2。
  • 用的时候：分母是 1−tan2α，别漏平方。

升幂与降幂

降幂：cos2α  =  (1+cos2α)/2，sin2α  =  (1−cos2α)/2
  • 大白话：看到 sin2、cos2 就用它把平方"打下来"，同时角变成原来的 2 倍。
  • 用的时候：选填见平方先想降幂，降完往往能再用辅助角合一。
升幂：1+cos2α  =  2cos2α，1−cos2α  =  2sin2α
  • 大白话：降幂反过来就是升幂，把常数变成平方。
  • 用的时候：方向别反——见 cos2α 降幂，见 cos2α 升幂。
(sinα ± cosα)2  =  1 ± sin2α
  • 大白话：正弦余弦和（差）的平方，展开后就剩 1 和 sin2α。
  • 用的时候：见到"sin±cos 的平方"直接化简，省得展开。

辅助角公式（合一变形）

a sinx + b cosx  =  √(a2+b2)·sin(x+φ)，tanφ  =  b/a，φ 所在象限由点 (a,b) 的符号决定
  • 大白话：任何"正弦加余弦"都能捏成一个正弦；捏出来的振幅就是 √(a2+b2)。
  • 用的时候：合一后周期、最值、单调区间直接读；只写 tanφ=b/a 会丢符号，φ 的象限要结合 a、b 正负定。
  • 记忆要点：φ 就是坐标平面里点 (a,b) 对应的那个角。
经典两例：sinx + cosx  =  √2 sin(x+π/4)；√3 sinx − cosx  =  2 sin(x−π/6)
  • 大白话：两个最常考的合一成品，背下来小题能秒。
  • 用的时候：第一个 a=b=1；第二个 a=√3、b=−1（φ 在第四象限）。

tan 与根式的进阶结论（苏州教研·专题29）

tan 变形公式：tanα + tanβ  =  tan(α+β)(1 − tanα tanβ)；tanα − tanβ  =  tan(α−β)(1 + tanα tanβ)
  • 大白话：正切和角公式倒过来用——见到"tanα±tanβ"和"tanα tanβ"同框，就能把前者用 tan(α±β) 整体换掉。
  • 用的时候：tan18°+tan42°+√3 tan18°tan42° 这类题，代换后乘积项抵消，一步出结果。
去根号（半角平方）：1 ± sinα  =  (sin(α/2) ± cos(α/2))2；1 + cosα  =  2cos2(α/2)；1 − cosα  =  2sin2(α/2)
  • 大白话：根号里的"1±sinα""1±cosα"都能写成完全平方，根号直接脱掉。
  • 用的时候：化简 √(1+sinα)、√(1−cosα) 时先配方；注意开方后要按角的范围定正负。
两个小结论（选填可秒）：α+β = π/4 时 (1+tanα)(1+tanβ) = 2；α+β = 3π/4 时 (1−tanα)(1−tanβ) = 2
  • 大白话：两角和为特殊角 π/4 或 3π/4 时，"1±tan"的乘积是常数 2。
  • 用的时候：选填见到这两个乘积结构，不用展开直接写 2。
辅助角的对称轴：f(x) = a sinx + b cosx 关于 x = x0 对称 ⇔ f(x0) = ±√(a2+b2)（即取到最值）
  • 大白话：合一后是 y=R sin(x+φ)，对称轴一定过峰或谷，也就是函数取到 ±R 的地方。
  • 用的时候：题目说"f(x) 关于 x=x0 对称"，立刻知 f(x0) 等于振幅 ±√(a2+b2)，不用求导。

08解三角形· 本章公式速查

与《高中数学常用公式·修订版》第三部分第 10、11 条核对一致。

正弦定理（管"角 ↔ 对边"的比例）

a / sin A  =  b / sin B  =  c / sin C  =  2R（R 为外接圆半径）
  • 大白话：每条边和它对角的正弦之比都相等，而且正好等于外接圆直径 2R。
  • 用的时候：已知两角一边、或两边及一边对角，首选它。
边化角（比例）：a : b : c  =  sin A : sin B : sin C
  • 大白话：边的比等于对角正弦的比。
  • 用的时候：见到"边的齐次式"，可以整体换成"正弦的齐次式"，反过来也行。
边化角（代换）：a  =  2R sin A，b  =  2R sin B，c  =  2R sin C
  • 大白话：每条边都能写成"外接圆直径乘对角正弦"。
  • 用的时候：大题第一步常把边全换成正弦；混着常数的式子不能硬换。
已知两边及一边对角可能有两解：b·sin A < a < b 且 A 为锐角时，B 有两解
  • 大白话：给了两边和其中一边的对角，射线和圆弧可能交两次。
  • 用的时候：先用 h=b·sinA 比一比；a>b 或 a=bsinA 一解，bsinA<a<b 且 A 锐角两解，a<bsinA 无解。
等比性质：a/sinA  =  (a+b+c)/(sinA+sinB+sinC)
  • 大白话：连等的比例式，分子分母分别加起来比值不变。
  • 用的时候：知道三边和三个正弦的总和时可一步求 2R。

余弦定理（管"三边 ↔ 夹角"）

a2  =  b2 + c2 − 2bc·cos A（及 b2、c2 两式）
  • 大白话：一边的平方等于另两边平方和，再减去"两倍两边乘夹角余弦"；直角时 cos90° = 0 就退回勾股定理。
  • 用的时候：已知两边夹一角求第三边，或已知三边求角，用它。
变形：cos A  =  (b2 + c2 − a2)/(2bc)（及 B、C 两式）
  • 大白话：三边全给时反解出角。
  • 用的时候：分子里"对边 a 的平方带负号"，别写反。
判角类型：a2  =  b2+c2 → 直角；a2 > b2+c2 → 钝角；a2 < b2+c2 → 锐角
  • 大白话：把最大边的平方和另两边平方和一比，就知道最大角是直、钝还是锐。
  • 用的时候：不用真算角度，比大小就够。

三角形面积

S  =  ½·底·高
  • 大白话：初中那条老公式。
  • 用的时候：知道高时最直接。
S  =  ½·ab·sin C  =  ½·bc·sin A  =  ½·ca·sin B
  • 大白话：面积等于"两边及其夹角正弦乘积的一半"。
  • 用的时候：夹角必须是那两边夹住的角；大题第二问求面积常用这条。
海伦公式：S  =  √(s(s−a)(s−b)(s−c))，s  =  (a+b+c)/2（选学）
  • 大白话：三边全给、又不知道高和角时，用半周长硬算面积。
  • 用的时候：三边已知才方便，平时优先用 ½ab sinC。

外接圆与内切圆

外接圆直径 2R  =  a/sinA  =  b/sinB  =  c/sinC
  • 大白话：正弦定理里那个比值就是外接圆直径。
  • 用的时候：题目提到外接圆，立刻想到这条。
内切圆半径 r  =  2S/(a+b+c)
  • 大白话：内切圆半径等于面积的 2 倍除以周长。
  • 用的时候：见到内切圆半径直接套；能由面积法现场推。

面积与边角的进阶结论（苏州教研·专题30）

面积外接圆形式：S  =  abc/(4R)（R 为外接圆半径）
  • 大白话：面积等于三边乘积除以四倍外接圆半径。
  • 用的时候：题目同时给了三边和外接圆半径（或能求出 R），求面积用这条。
坐标面积：已知 AB = (x1,y1)、AC = (x2,y2)，则 S  =  ½|x1y2 − x2y1|
  • 大白话：两边向量坐标知道后，三角形面积就是"交叉相乘再相减"绝对值的一半。
  • 用的时候：建系后求三角形面积直接套；平行四边形面积则是 |x1y2−x2y1|（不折半）。
正余弦整合定理（余弦定理的正弦版）：sin2A  =  sin2B + sin2C − 2 sinB sinC cosA
  • 大白话：把余弦定理里的边 a、b、c 全换成对应角的正弦，等式照样成立。
  • 用的时候：遇到 sin2B + sin2C ± sinB sinC 这类结构（两角和确定），用它一步化成 sin2(第三角)，不用真算边长。
边角单调性：A<B ⟺ a<b ⟺ sinA<sinB ⟺ cos2A>cos2B；且 A<B ⟺ cosA>cosB
  • 大白话：大角对大边，且这个顺序一路传到 sinA、cos2A、cosB 上。
  • 用的时候：比较两个角的大小，等价于比较对边、比较 sin、或比较 cos2A，挑方便的用。
内角半角：sin((A+B)/2)  =  cos(C/2)，cos((A+B)/2)  =  sin(C/2)
  • 大白话：因为 A+B = π−C，所以 (A+B)/2 = π/2−C/2，互余直接换掉。
  • 用的时候：大题里把 (A+B)/2 的三角式化成 C/2，往往能和别的项合并。
锐角三角形与角范围：锐角三角形两内角 A、B 满足 sinA>cosB；三角形最小内角 ∈ (0, π/3]，最大内角 ∈ [π/3, π)
  • 大白话：锐角三角形任意两锐角互余有余量，故 sinA>cosB；三个角的平均是 π/3，所以最小角不超过 π/3、最大角不小于 π/3。
  • 用的时候：题目说"锐角三角形"就能用 sinA>cosB；说某角是最大/最小内角，先圈它的范围。
由正弦值定角：sinA = sinB ⇒ A = B；sin2A = sin2B ⇒ 2A = 2B 或 2A+2B = π（即 A+B = π/2）
  • 大白话：两个正弦相等，在三角形里要么两角相等，要么它们的二倍角互余（推出直角）。
  • 用的时候：判形状时见到 sin2A=sin2B，要想到"等腰或直角"两种可能，别漏直角。

09平面向量· 本章公式速查

与《高中数学常用公式·修订版》第七部分核对一致。

向量的坐标运算

a = (x1,y1)，b = (x2,y2)：a±b  =  (x1±x2, y1±y2)，λa  =  (λx1, λy1)
  • 大白话：建系之后，向量加减数乘就是坐标逐项加减乘。
  • 用的时候：能建系就建系，把几何题全变成算术；别漏负号。
与 a 同向的单位向量：a/|a|
  • 大白话：把一个向量除以它的长度，就得到方向相同、长度为 1 的向量。
  • 用的时候：题目说"沿 a 方向走一个单位"就写它。

共线与垂直（最容易用反的一对）

共线（平行）：a∥b ⇔ b  =  λa ⇔ x1y2 − x2y1  =  0
  • 大白话：两个向量平行，就是坐标交叉相乘再相减等于 0。
  • 用的时候：求平行用这条"叉积式"；别和下面垂直那条混。
垂直：a⊥b（a、b 非零）⇔ a·b  =  0 ⇔ x1x2 + y1y2  =  0
  • 大白话：两个向量垂直，就是对应坐标相乘再相加等于 0。
  • 用的时候：求垂直用这条"点积式"；共线用减、垂直用加，千万别交叉用。

数量积（点乘）

a·b  =  |a||b|cosθ  =  x1x2 + y1y2
  • 大白话：点乘 = 两模相乘再乘夹角余弦；坐标里就是对应坐标相乘再相加。
  • 用的时候：结果是一个数（不是向量）；零向量和任何向量点乘为 0。
求模：|a|2  =  a·a  =  x12 + y12
  • 大白话：向量自己点乘自己，就是坐标平方和，等于模的平方。
  • 用的时候：求模先平方再开方。
|a±b|2  =  |a|2 ± 2a·b + |b|2
  • 大白话：和（差）的模平方，像完全平方公式那样展开。
  • 用的时候：求 |a+b|、|a−b| 先平方，别直接把模相加。
夹角：cosθ  =  (a·b)/(|a||b|)
  • 大白话：夹角余弦 = 点积除以两模乘积。
  • 用的时候：夹角范围是 [0,π]；cosθ 为负说明夹角是钝角。
投影：b 在 a 方向上的投影数量  =  |b|cosθ  =  (a·b)/|a|
  • 大白话：把 b 垂直投影到 a 所在直线上，那段带方向的长度就是投影。
  • 用的时候：锐角投影为正、钝角为负、直角为 0。

距离与中点

两点距离：d_AB  =  √((x2−x1)2 + (y2−y1)2)
  • 大白话：两点横纵坐标差的平方和开根号，就是勾股定理。
  • 用的时候：向量里求线段长，本质就是两点距离。
中点：M  =  ((x1+x2)/2, (y1+y2)/2)
  • 大白话：中点坐标就是两端点坐标的平均。
  • 用的时候：见到中线、中点直接套。

三点共线的向量判定

P、A、B 三点共线 ⇔ OP  =  x·OA + y·OB 且 x + y  =  1
  • 大白话：P 能写成 OA、OB 的加权平均，且权重加起来正好是 1，P 就被摁在直线 AB 上。
  • 用的时候：见到 OP = x·OA + y·OB，先加系数看是不是 1，是就共线，小题秒判。

三角形与向量的二级结论（苏州教研·专题28）

中线向量定理：D 为 BC 边中点 ⇔ AD  =  ½(AB + AC)（即 AB + AC  =  2 AD）
  • 大白话：从顶点指向底边中点的向量，等于两条邻边向量和的一半。
  • 用的时候：见到三角形中线，直接用它把中线向量拆成两边向量；和"三点共线 x+y=1"配合做基底题。
重心：P 为 △ABC 重心 ⇔ PA + PB + PC  =  0；重心坐标  =  ((x1+x2+x3)/3, (y1+y2+y3)/3)；使 PA2+PB2+PC2 最小的点就是重心
  • 大白话：重心是三条中线交点（分中线 2:1），它到三顶点向量和为零、坐标是三顶点平均、到三顶点距离平方和最小。
  • 用的时候：见到 PA+PB+PC=0 立刻认重心；给三顶点坐标求重心直接取平均。
角平分线方向向量：AD 平分 ∠A（D 在 BC 上）⇔ AD 方向  =  AB/|AB| + AC/|AC|（两个单位向量相加）
  • 大白话：角平分线方向，就是把两条邻边各自取单位向量再相加。
  • 用的时候：要写角平分线的方向向量，别瞎设，直接用"两个单位向量的和"。
极化恒等式（平行四边形对角线平方和）：|a+b|2 + |a−b|2  =  2(|a|2 + |b|2)；从而 a·b  =  (|a+b|2 − |a−b|2)/4
  • 大白话：两向量和与差的模平方相加，等于模平方和的两倍；反解出数量积就是"和模平方减差模平方再除以 4"。
  • 用的时候：已知"中线"或"共起点两向量"的和模、差模（如三角形两边中线），用它一步求数量积，省得展开。
外心数量积结论：O 为 △ABC 外心，则 AO·BC  =  ½(b2 − c2)（b = |AC|、c = |AB|）
  • 大白话：外心到 A 的向量，点乘 BC 边向量，等于两边平方差的一半。
  • 用的时候：题目出现"外心 + 数量积"，直接套这个秒出（由 AO·BC  =  (AD+DO)·BC，DO⊥BC 消掉，再展开即得）。
夹角锐/钝角判定：a·b>0 且 a 不平行于 b ⇔ 夹角锐角；a·b<0 且不平行 ⇔ 钝角
  • 大白话：点积为正只是锐角的必要条件，还要排除两向量同向（点积正但夹角 0°）的情况。
  • 用的时候：题目说"夹角为锐角"列不等式，除了 a·b>0，记得再加"不共线"，否则会把 0° 角也算进去。
定比分点公式：P 在 P1P2 上且 P1P  =  λ·PP2，则 P  =  ((x1+λx2)/(1+λ), (y1+λy2)/(1+λ))；λ = 1 即中点
  • 大白话：分点坐标是两端点坐标按 λ 的"加权混合"，权重在两端点间按 λ 分配。
  • 用的时候：已知分点比 λ，直接套；λ=1 退化成中点公式。

10复数· 本章公式速查

与《高中数学常用公式·修订版》第十部分核对一致。

复数的概念

z  =  a + bi（a、b 为实数）：a 叫实部，b 叫虚部；b = 0 是实数，b≠0 是虚数，a = 0 且 b≠0 是纯虚数
  • 大白话：复数 = 实数部分 + 一个 i 乘出来的部分；纯虚数要求实部为 0 且虚部不为 0。
  • 用的时候：说"纯虚数"必须同时写 a=0 和 b≠0 两个条件；0 不是纯虚数。
复数相等：a + bi  =  c + di ⇔ a  =  c 且 b  =  d
  • 大白话：两个复数相等，必须实部等于实部、虚部等于虚部，两个条件缺一不可。
  • 用的时候：给含 x、y 的复数等式求未知数，就靠它列两个方程。

四则运算（i2 = −1 是唯一新规则）

加减：(a+bi) ± (c+di)  =  (a±c) + (b±d)i
  • 大白话：实部、虚部分别相加减。
  • 用的时候：像合并同类项一样，别把实部和虚部混着加。
乘法：(a+bi)(c+di)  =  (ac−bd) + (ad+bc)i
  • 大白话：像多项式一样展开，最后把 i2 换成 −1。
  • 用的时候：乘完一定记得 i2=−1，这是唯一容易漏的代换。
除法：(a+bi)/(c+di)  =  [(ac+bd) + (bc−ad)i] / (c2+d2)（分母不为 0）
  • 大白话：分子分母同乘分母的共轭，把分母"实数化"成 c2+d2。
  • 用的时候：结果要写成 a+bi 标准形；别忘乘共轭这一步。

共轭与模

共轭：z  =  a+bi 的共轭 z  =  a − bi（实部不变，虚部变号）
  • 大白话：取共轭就是把点沿实轴翻个面。
  • 用的时候：除法里乘的那个"分母共轭"就是它。
z·z  =  |z|2  =  a2 + b2
  • 大白话：一个复数乘它的共轭，一定等于模的平方，是个实数。
  • 用的时候：小题里常用它"消掉 i"、化简分母。
模：|z|  =  √(a2 + b2)
  • 大白话：模就是复平面上点 (a,b) 到原点的距离，是个非负实数。
  • 用的时候：复数本身不能比大小，但模能比。
模的乘法性质：|z1·z2|  =  |z1||z2|；|z1/z2|  =  |z1|/|z2|
  • 大白话：乘积的模等于模的乘积，商的模等于模的商。
  • 用的时候：求复杂复数的模，可以先拆开算模再相乘，比先化简省事。

i 的幂与常用小结论

i 的幂每 4 个一循环：i4n = 1，i4n+1 = i，i4n+2 = −1，i4n+3 = −i
  • 大白话：i 的大数次幂，指数除以 4 看余数——余 0 是 1，余 1 是 i，余 2 是 −1，余 3 是 −i。
  • 用的时候：求 i2024 这种，先拿指数除以 4。
常用小结论：(1+i)2  =  2i，(1−i)2  =  −2i；(1+i)/(1−i)  =  i，(1−i)/(1+i)  =  −i
  • 大白话：见到这两种特殊形式直接写答案，不用现场算。
  • 用的时候：选择题里秒答；不熟就分子分母乘共轭推一遍。
平行四边形恒等式：|z1+z2|2 + |z1−z2|2  =  2(|z1|2 + |z2|2)
  • 大白话：两复数和的模平方加差的模平方，等于各自模平方和的 2 倍。
  • 用的时候：知道 |z1|、|z2| 及和（差）模之一时，可求另一个。

实系数二次方程的复根（了解）

ax2+bx+c = 0（实系数），Δ = b2−4ac：Δ<0 时有一对共轭复根 x  =  (−b ± √(−Δ)·i)/(2a)
  • 大白话：判别式小于 0 不是"没根"，而是没有实根、有一对互为共轭的复根。
  • 用的时候：照套求根公式，把 √Δ 换成 √(−Δ)·i；两根互为共轭。

复数范围内因式分解与单位根（苏州教研·专题53）

a2 + b2  =  (a + bi)(a − bi)（a、b 为实数）
  • 大白话：在实数里 a2+b2 不能再分解，到了复数里就能拆成一对共轭复数的乘积。
  • 用的时候：x2+4  =  (x+2i)(x−2i) 这类题直接套；因式分解范围从实数扩到复数。
  • 记忆要点：平方和  =  共轭两复数相乘，正好和 z·z  =  a2+b2 反过来用。
|z|  =  |z|
  • 大白话：一个复数和它的共轭，模是一样大的（它们关于实轴对称，到原点距离相同）。
  • 用的时候：求共轭的模可换成求原复数的模，省一步。
x3  =  1 的三个根（三次单位根）：1、ω、ω̄，其中 ω  =  −1/2 + (√3/2)i，ω̄  =  −1/2 − (√3/2)i
  • 公式：ω3 = 1，ω̄3 = 1；1 + ω + ω2 = 0；ω·ω̄ = 1；ω2 = ω̄，ω̄2 = ω。
  • 大白话：把单位圆三等分得到的三个复数，加起来正好归零，互相还是共轭。
  • 用的时候：见到 1+ω+ω2=0 直接代换；−1+√3 i = 2ω，这类提取因子题可秒杀。
  • 记忆要点：ω 是"逆时针转 120°"的单位复数，ω2 是"转 240°"，三个加起来 = 0。
数集包含链：N* ⫋ N ⫋ Z ⫋ Q ⫋ R ⫋ C
  • 大白话：自然数→整数→有理数→实数→复数，一层比一层大；注意实数里成立的运算性质（如"任何数平方非负"）到复数里不一定成立。
  • 用的时候：判断"能不能比大小"时心里有这条链——只有实数能比大小，复数不能。

11数列· 本章公式速查

口径与《高中数学常用公式·修订版》第八部分（数列）一致。

an 与 Sn 的关系

a1  =  S1；n ≥ 2 时 an  =  Sn − Sn−1
  • 大白话：前 n 项和减去前 n−1 项和，剩下的就是第 n 项。
  • 用的时候：大题第一步永远先写 n=1 单独验；n≥2 再作差，最后把 n=1 代回去看能不能并成一个式子。
  • 记忆要点：n=1 特殊，n≥2 作差。

等差数列

an  =  a1 + (n − 1)d（也可写成 an  =  am + (n − m)d）
  • 大白话：从第一项开始每项加一个 d，加到第 n 项。
  • 用的时候：知道任意一项都能当"新首项"跳着算；求基本量 a1、d 是万能钥匙。
  • 记忆要点：首项 +（项数−1） × 公差。
Sn  =  n(a1 + an)/2  =  na1 + n(n−1)d/2  =  (d/2)n2 + (a1 − d/2)n
  • 大白话：首末项配对相乘再除以 2；展开后是个过原点的二次函数。
  • 用的时候：给 a1、an、n 用第一式；给 a1、d、n 用第二式；讨论 Sn 最值时看第三式。
  • 记忆要点：高斯配对——(首+末)×项数÷2。
若 m+n  =  p+q，则 am + an  =  ap + a_q
  • 大白话：下标和相等，两项和就相等。
  • 用的时候：不求通项，直接整体代换；等差中项 2an = an−1 + an+1 是它的特例。
Sk，S2k − Sk，S3k − S2k，… 仍成等差数列
  • 大白话：把前 k 项、接下来 k 项、再接下来 k 项分别加起来，这几段和还是等差。
  • 用的时候：见到"前 k 项和 / 前 2k 项和"立刻想到分段和成等差。

等比数列

an  =  a1·qn−1
  • 大白话：从首项开始每项乘一个 q，乘到第 n 项。
  • 用的时候：知道任意两项先求 q；q≠0，各项也不为 0。
  • 记忆要点：首项 × 公比^(项数−1)。
Sn：q = 1 时 Sn  =  na1；q≠1 时 Sn  =  a1(1−qn)/(1−q)
  • 大白话：公比是参数时，先看 q 等不等于 1，两式完全不同。
  • 用的时候：q=1 别用分式（会除以 0）；这是最常见的丢分点。
  • 记忆要点：q 是字母必讨论，先判 1 再套式。
若 m+n  =  p+q，则 am·an  =  ap·a_q
  • 大白话：下标和相等，两项的"积"相等（注意是乘不是加）。
  • 用的时候：等比中项 an2 = an−1·an+1 是特例，开方有正负两个要取舍。
Sk，S2k − Sk，S3k − S2k，… 仍成等比数列
  • 大白话：分段和成等比；第 5~8 项和 = q4 × 前 4 项和。
  • 用的时候：等比前 4 项和与前 8 项和的题，就用 S8−S4 = q4·S4。

求和技巧

裂项：1/[n(n+1)]  =  1/n − 1/(n+1)；1/[(2n−1)(2n+1)]  =  ½[1/(2n−1) − 1/(2n+1)]
  • 大白话：把分母乘积拆成两项差，求和时中间两两抵消，只剩首尾。
  • 用的时候：第二个别忘了前面的系数 ½。
错位相减：通项是"等差  ×  等比"（如 n·2n）时用
  • 大白话：写一遍 Sn，两边乘公比得 qSn，错开一位相减，中间剩一个等比数列再求和。
  • 用的时候：相减后等比首项是第二项（q·a1），指数和项数要数清。
分组求和：把数列拆成几个等差、等比小组分别求和再相加
  • 大白话：杂数列不会算，拆开成熟悉的小块。

构造法求通项

an+1  =  p·an + q ⇒ 凑 an+1 + c  =  p(an + c)，其中 c  =  q/(p−1)
  • 大白话：加个常数把它变成等比数列先求，再减回来。
  • 用的时候：{an+c} 是公比 p 的等比数列；n=1 要验证。
  • 记忆要点：c = q/(p−1)，"凑等比"。

递推求通项的另外三招（苏州教研·专题34）

取倒数：an+1  =  q1an/(q2an+d2) ⇒ 1/an+1  =  (d2/q1)·(1/an) + q2/q1，转 an+1 = pan+q 型
  • 大白话：分式递推两边一倒，就变成熟悉的"加常数凑等比"。
  • 用的时候：分子分母都是 an 一次式时，先倒再凑。
取对数：an+1  =  c·anp ⇒ log_c an+1  =  p·log_c an + 1
  • 大白话：幂次递推取对数，乘法变加法、幂次变倍数。
  • 用的时候：后项是前项的幂次时，令 bn=log_c an 转标准型。
凑常数列：和/差/积/商四式（见 3.5.1）
  • 大白话：相邻两项加减乘除一个 f(n) 后相等，新数列就是常数列，直接等于首项。
  • 用的时候：an+1±f(n+1)=an±f(n)、f(n+1)an+1=f(n)an、an+1/f(n+1)=an/f(n)，四种信号一眼识别。

等差/等比的二级结论（苏州教研·专题32、33）

{Sn/n} 是公差为 d/2 的等差数列
  • 大白话：前 n 项和除以 n 排成一列，本身还是等差。
  • 用的时候：题目给 S2010/2010 − S2009/2009 = 2，立刻 d/2=2 ⇒ d=4。
am/bm  =  S_{2m−1}/T_{2m−1}（两等差第 m 项之比  =  前 2m−1 项和之比）
  • 大白话：两个等差数列，比第 m 项等于比它们前 2m−1 项的和。
  • 用的时候：已知 Sn/Tn 的表达式求 an/bn，直接把 n 换成 2n−1 代入。
{log_c bn} 等差（{bn} 等比且 bn>0）；项数 2n 时 S偶/S奇  =  q
  • 大白话：等比取对数变等差；偶数项每项都比前一个奇数项多乘一个 q。

自然数幂和与无穷等比（苏州教研·专题35）

12+22+…+n2  =  n(n+1)(2n+1)/6；13+23+…+n3  =  [n(n+1)/2]2
  • 大白话：平方和套公式；立方和等于"和的平方"。
  • 用的时候：见到 Σk2、Σk3 直接代，不要硬算。
无穷等比和：|q|<1 时 S  =  a1/(1−q)
  • 大白话：公比绝对值小于 1 时，无穷多项加起来收敛到一个定值。

数列放缩工具箱（苏州教研·专题36）

1/k2 < 1/[k(k−1)]  =  1/(k−1) − 1/k（k≥2）；1/k2 < ½(1/(k−1)−1/(k+1))
  • 大白话：见 1/k2 就想拆成相邻倒数差，求和时中间全消。
  • 用的时候：证 Sn<C 时，先把 C 拆成"前几项+裂项和"，反推通项该放大成什么；首项不吻合就延迟放缩。
1/√k < 2(√k−√(k−1))；k/(k+1)!  =  1/k! − 1/(k+1)!
  • 大白话：根号项乘共轭根式放缩；阶乘项直接裂项。
伪等差：an+1≥an+d ⇒ an≥a1+(n−1)d；伪等比：an+1≥q·an ⇒ an≥a1qn−1
  • 大白话：递推不等式累加/累乘，直接转成通项不等式。

数学归纳法两步（苏州教研·专题52）

① 奠基：验 n = n0 成立；② 递推：假设 n = k 成立，证 n = k+1 成立（必须用上归纳假设）
  • 大白话：第一张骨牌倒了 + 前一张倒后一张必倒 = 全部倒。
  • 用的时候：第二步证 a_{k+1} 时一定要把 ak 的归纳条件代进去；思路卡住用分析法。

12不等式与基本不等式· 本章公式速查

口径与《高中数学常用公式·修订版》第九部分（不等式）一致。

均值不等式（基本不等式）

√(ab) ≤ (a+b)/2 ≤ √[(a2+b2)/2]（a,b ≥ 0）
  • 大白话：两个正数的几何平均 ≤ 算术平均 ≤ 平方平均，一串从小到大。
  • 用的时候：高考最常用中间一段 √ab ≤ (a+b)/2；必须满足"一正二定三相等"。
  • 记忆要点：几何平均不超过算术平均。
三个变形：a+b ≥ 2√(ab)；ab ≤ [(a+b)/2]2；a2+b2 ≥ 2ab
  • 大白话：和与积互相挤——知道和求积用第二式，知道积求和用第一式。
  • 用的时候：第三条 a2+b2≥2ab 对任意实数都成立，不限正数；前两条要 a,b>0。

极值定理（求最值）

积定：xy  =  p（定值）⇒ x+y ≥ 2√p，x = y 时和最小为 2√p
  • 大白话：两个正数乘积固定，它们相等时加起来最小。
  • 用的时候："积定"求"和"的最小值；对勾函数 x+1/x≥2 就是它。
和定：x+y  =  s（定值）⇒ xy ≤ s2/4，x = y 时积最大为 s2/4
  • 大白话：两个正数加起来固定，它们相等时乘积最大。
  • 用的时候："和定"求"积"的最大值；用前先检查 a=b 能不能取到。
"1 的代换"：x+y = 1 时 1/x+1/y  =  (x+y)(1/x+1/y) ≥ 4
  • 大白话：见到"和为 1、求倒数和"，把 1 换成 x+y 乘进去展开。
  • 用的时候：展开后用 x/y+y/x ≥ 2；取等 x=y=1/2。

一元二次不等式

a>0 时：(x−x1)(x−x2)>0 ⇒ x<x1 或 x>x2；<0 ⇒ x1<x<x2
  • 大白话：开口向上，"大于取两边，小于取中间"。
  • 用的时候：先把 a 化成正数再因式分解；Δ<0 时 >0 解集是 R、<0 解集是空。

恒成立问题

ax2+bx+c ≥ 0 对一切 x 恒成立 ⇔ a>0 且 Δ  =  b2−4ac ≤ 0
  • 大白话：开口向上的抛物线全程贴在 x 轴上方或相切。
  • 用的时候：二次项含字母 k 时先讨论 k=0（变一次式），别直接套判别式。
分离参数：a ≤ f(x) 恒成立 ⇔ a ≤ f(x)_min；a ≥ f(x) 恒成立 ⇔ a ≥ f(x)_max
  • 大白话：要恒成立，参数就得不超过右边的最小值（或不小于最大值）。
  • 用的时候：分离后别忘了定义域对参数的限制。

比较大小与常用结论

作差法：a−b 的正负定大小；作商法：同正时 a/b 与 1 比
  • 大白话：比大小先作差，把结果因式分解再看每段正负。
对勾函数：x>0 时 x + 1/x ≥ 2（x = 1 取等）；x<0 时提负号得 ≤ −2
  • 大白话：正数和它倒数的和，最小值是 2。
绝对值：|x|<a（a>0）⇔ −a<x<a；|x|>a ⇔ x>a 或 x<−a
  • 大白话：小于夹中间，大于取两边。

三元均值与平方平均（苏州教研·专题37）

(a+b+c)/3 ≥ ∛(abc)（a,b,c>0）；(a2+b2)/2 ≥ ((a+b)/2)2
  • 大白话：三个正数的算术平均 ≥ 几何平均；平方的平均 ≥ 平均的平方。
  • 用的时候：三个正数和定求积最大、积定求和最小套第一式；已知 a+b 求 a2+b2 下界套第二式。
糖水不等式：a>b>0，m>0 ⇒ b/a < (b+m)/(a+m) < 1
  • 大白话：真分数越加越大，假分数越加越小；淡糖水加糖更甜。
  • 用的时候：比较 (a+m)/(b+m) 这类分数大小直接秒选。

绝对值与高次不等式工具（苏州教研·专题38）

|f(x)| < g(x) ⇔ −g(x)<f(x)<g(x)；|f(x)|>|g(x)| ⇔ f2(x)>g2(x)
  • 大白话：带 g(x) 的绝对值不等式，拆开或平方。
  • 用的时候：两边都是绝对值直接平方；一边是 g(x) 就拆成双向不等式。
数轴穿根法：一次因式乘积 >0，从右往左、奇穿偶切，上正下负
  • 大白话：根标在数轴上，波浪线穿过去，线上方的区间就是解。
  • 用的时候：每个因式 x 的系数先化成正；分式先移项通分再穿。
|x−a|+|x−b|（a<b）最小值  =  |a−b|
  • 大白话：数轴上一点到两定点距离之和，点在两定点之间时最小。

证明不等式的方法选择（苏州教研·专题40）

比较法（作差/作商）→ 综合法（由因导果）→ 分析法（执果索因，用⇔）→ 反证法 → 放缩法 → 换元法 → 构造法 → 数学归纳法
  • 大白话：证不等式八把刀，按题目形状挑。
  • 用的时候：思路卡壳用分析法倒推；证 n 有关命题用归纳法；函数型不等式构造差函数（学导数后用）；放缩不能过度、首项不吻合就延迟放。
含参讨论三条线：二次项系数 = 0、两根相等、Δ = 0
  • 大白话：参数临界值就是让"退化"发生的那些点。
  • 用的时候：讨论完写"综上所述"；已知解集反求参数时，端点代入方程。

13立体几何初步· 本章公式速查

口径与《高中数学常用公式·修订版》第四部分（立体几何）一致。

柱锥台球体积

柱体：V  =  S底·h（圆柱 V  =  πr2h）
  • 大白话：底面积乘高，柱体不乘 1/3。
  • 用的时候：柱和锥别混，锥体才要除以 3。
锥体：V  =  ⅓·S底·h（圆锥 V  =  ⅓πr2h）
  • 大白话：等底等高的柱，锥只占它的三分之一。
  • 用的时候：最容易漏的就是这个 1/3，写完先检查。
台体：V  =  ⅓(S上 + S下 + √(S上·S下))·h
  • 大白话：上下底面积和，再加个"上下底面积几何平均"，一起乘高除以 3。
  • 用的时候：中间那个 √(S上S下) 别漏；台体可看成锥截出来的。
球：V  =  (4/3)πR3，表面积 S  =  4πR2
  • 大白话：球的体积和表面积只跟半径有关。
  • 用的时候：表面积是 4πR2，别记成 πR2。

常见几何体表面积

圆柱侧面积 2πrh；圆锥侧面积 πrl（l 是母线长）
  • 大白话：侧面展开是个矩形 / 扇形，单独记。
  • 用的时候：表面积 = 侧面积 + 两个（或一个）底面积。
正方体棱长 a：体对角线 √3a，表面积 6a2，体积 a3
  • 大白话：六个正方形面，对角线跨三个棱。

外接球与体对角线

长方体体对角线 l  =  √(a2+b2+c2)；外接球直径  =  体对角线
  • 大白话：从一个顶点出发三条棱，勾股连套两次就是对角线。
  • 用的时候：墙角形三棱锥（三条棱两两垂直）补成长方体，R = ½√(a2+b2+c2)。
正方体：外接球直径  =  √3a；内切球直径  =  棱长 a
  • 大白话：外接球撑到对角，内切球贴到面。
  • 用的时候：外接球看对角线、内切球看棱长，别混。
正四面体（棱长 a）：高 h  =  √6/3·a，外接球半径 R  =  √6/4·a
  • 大白话：正四面体高约 0.816a，外接球半径是高的 3/4。
  • 用的时候：这是记牢的结论，小题直接用。

平行与垂直的判定（证明题）

线面平行：面外一条线 a∥面内一条线 b ⇒ a∥α（要 a⊄α）
  • 大白话：在面里找一条和它平行的线就行。
  • 用的时候：见到"两个中点"先想中位线；a 在面内就不能用。
面面平行：一个面内两条相交直线都平行于另一面 ⇒ 两面平行
  • 大白话：两条相交线都平行，整个面就平行。
线面垂直：一条线垂直于面内两条相交直线 ⇒ 线面垂直
  • 大白话：跟面里两条相交线都垂直，才算真立直。
  • 用的时候：只证一条不够，必须两条相交。
面面垂直：一个面过另一个面的一条垂线 ⇒ 两面垂直
  • 大白话：一个面里竖着一根垂直另一面的线，两面就垂直。

求距离

等体积法：h  =  3V/S底
  • 大白话：换个好算的顶点和底面，体积不变反解高。
  • 用的时候：求点到面的高，建系麻烦时用它。

补充二级结论（苏州教研·专题18/19）

球的截面：d2  =  R2 − r2（R 球半径，r 截面圆半径，d 球心到截面距离）
  • 大白话：截面离球心越远、截面圆越小，就是截面里的勾股。
  • 用的时候：球半径、截面圆半径、球心到截面距离知二求一。
展开图最短路径：侧面展开成平面后，两点间线段最短
  • 大白话：蚂蚁爬侧面，剪开平铺量直线。
  • 用的时候：绕侧面一周/几周的最短路程，展开后算勾股。
斜二测直观图面积：S′  =  S/(2√2)，即 S  =  2√2·S′
  • 大白话：直观图面积是原图的 1/(2√2)。
  • 用的时候：正反面积互算，乘或除 2√2。
三垂线定理：PA⊥α，AO⊥a ⇒ PO⊥a；逆定理：PO⊥a ⇒ AO⊥a
  • 大白话：斜线垂直面内直线 ⇔ 它的射影也垂直这条直线。
  • 用的时候：证线线垂直、找二面角平面角的快刀。
棱锥顶点在底面射影的位置（苏州教研·专题19）
  • 大白话：侧棱相等（或侧棱与底面所成角相等）→ 外心；各侧面与底面二面角相等（或顶点到底面各边等距）→ 内心；两组对棱垂直 / 三条侧棱两两垂直 → 垂心。
  • 用的时候：看到"侧棱相等"先想垂足是外心，是作高、定外接球心的依据。
多面体内切球半径：V  =  ⅓·S全·r ⇒ r  =  3V/S全
  • 大白话：从球心拆成一堆高为 r 的小棱锥，体积加起来解 r。
  • 用的时候：求三棱锥 / 多面体内切球半径专用。

14空间向量与立体几何· 本章公式速查

口径与《高中数学常用公式·修订版》第四部分（空间向量部分）一致。

空间向量坐标运算

加减与数乘：a±b = (x1±x2, y1±y2, z1±z2)；λa = (λx1, λy1, λz1)
  • 大白话：对应坐标分别加、减、乘。
  • 用的时候：先建系写对坐标，坐标错了后面全错。
数量积：a·b  =  x1x2 + y1y2 + z1z2
  • 大白话：对应坐标相乘再相加，结果是个数。
  • 用的时候：判断垂直就靠它——等于 0 就垂直。
模：|a|  =  √(x12 + y12 + z12)
  • 大白话：三个坐标平方加起来开根号，就是向量长度。
夹角：cosθ  =  a·b/(|a||b|)
  • 大白话：数量积除以两个模，就是夹角余弦。
垂直与平行：a⊥b ⇔ a·b = 0；a∥b ⇔ 对应坐标成比例
  • 大白话：垂直看数量积为 0，平行看坐标成倍。

法向量

法向量 n：垂直于面内两个不共线向量 u、v，即 n·u  =  0 且 n·v  =  0
  • 大白话：找一根垂直整个面的箭头，后面求角求距离全靠它。
  • 用的时候：在面内取两个不共线向量，列两个点积方程，令一个分量为 1 解出。

三类角（套公式）

线线角 θ：cosθ  =  |a·b|/(|a||b|)，θ ∈ [0, π/2]
  • 大白话：两条方向向量夹角取绝对值，只取锐角直角。
线面角 θ：sinθ  =  |a·n|/(|a||n|)，θ ∈ [0, π/2]
  • 大白话：斜线与法向量夹角的余角，所以用 sin 不是 cos。
  • 用的时候：这是最容易记混的一条，千万别写成 cos。
二面角 θ：cosθ  =  ±(n1·n2)/(|n1||n2|)，正负看锐钝
  • 大白话：两个面法向量的夹角（或补角）。
  • 用的时候：题目说锐角取正、钝角取负；没说先算绝对值再看图开口方向。

点到平面的距离

d  =  |AP·n|/|n|（A 是面上一点，n 是面法向量）
  • 大白话：连线 AP 在法方向上的投影长度。
  • 用的时候：AP 用"任意点 − 面上一点"，分母是法向量的模；算完用平面方程反代检验。

共面共线与投影（苏州教研·专题48）

四点共面：OP = x·OA+y·OB+z·OC ⇔ x+y+z = 1；三点共线：OP = x·OA+y·OB ⇔ x+y = 1
  • 大白话：系数加起来等于 1，P 就落在 A、B、C 确定的面（线）上。
  • 用的时候：证四点共面、求动点在面内的条件。
分点坐标：P = A+λ·AB ⇒ P(x1+λx2, y1+λy2, z1+λz2)
  • 大白话：沿方向向量走 λ 倍，每个分量加 λ 倍。
  • 用的时候：棱上按比例分点坐标，秒算。
空间两点距离：|AB|  =  √((x2−x1)2+(y2−y1)2+(z2−z1)2)
  • 大白话：坐标差平方和开根号，就是模公式的两点版。
面积射影定理：cosθ  =  S′/S（S 原面积，S′ 射影面积，θ 两面锐二面角）
  • 大白话：斜面积投影到另一个面，乘以 cosθ。
  • 用的时候：法向量不好求时，用射影面积比反求二面角。

15直线与圆· 本章公式速查

与《高中数学常用公式·修订版》第五部分"直线与圆"逐条核对一致。

斜率与倾斜角

斜率：k  =  (y2−y1)/(x2−x1)  =  tan α（α ≠ 90°）
  • 大白话：纵坐标差除以横坐标差，就是直线的陡缓。
  • 用的时候：α=90°（竖直直线）斜率不存在，别硬套；x1=x2 也不能用两点式。
  • 记忆要点：Δy 比 Δx。
平行 ⇔ k1 = k2（且截距不等）；垂直 ⇔ k1·k2 = −1
  • 大白话：平行就是斜率一样，垂直就是斜率互为负倒数。
  • 用的时候：平行要排除重合；竖直直线（斜率不存在）垂直的反而是水平线 k=0。

直线方程的五种形式

点斜式：y − y0  =  k(x − x0)
  • 大白话：知道斜率和一个点，直接写。
  • 用的时候：最常用的起手式。
斜截式：y  =  kx + b；一般式：Ax + By + C  =  0（k  =  −A/B）
  • 大白话：斜截式一眼看斜率纵截距；一般式统一做计算。
  • 用的时候：最后统一化到一般式，斜率就是 −A/B。
两点式：(y−y1)/(y2−y1)  =  (x−x1)/(x2−x1)；截距式：x/a + y/b  =  1
  • 大白话：两点直接写、知道横纵截距用截距式。
  • 用的时候：截距式要求 a、b 都不为 0，过原点或竖直直线用不了。

距离公式

两点距离：d  =  √[(x2−x1)2 + (y2−y1)2]
  • 大白话：横差纵差当直角边，勾股求斜边。
点到直线距离：d  =  |Ax0+By0+C|/√(A2+B2)
  • 大白话：点代入一般式左边取绝对值，除以法向量长度。
  • 用的时候：直线必须先化成 Ax+By+C=0；分子套绝对值、分母勾股。
两平行线距离：d  =  |C1−C2|/√(A2+B2)
  • 大白话：系数对齐后，常数项差的绝对值除以根号。
  • 用的时候：先把 x、y 系数化成完全相同，再 |C1−C2|。
到两平行线 ax+by+m = 0、ax+by+n = 0 等距的直线：ax+by+(m+n)/2  =  0
  • 大白话：两条平行线正中间那条线，常数项取平均。
  • 用的时候：求角平分线（与两已知平行线等距）直接套；系数要先对齐。

对称与反射

点关于点对称：P(x,y) 关于 Q(a,b) 的对称点 P′  =  (2a−x, 2b−y)
  • 大白话：Q 是 P、P′ 的中点，坐标对半再翻倍。
  • 用的时候：曲线关于点 (a,b) 中心对称，就是把式子里的 (x,y) 换成 (2a−x, 2b−y)。
光线经 x 轴（或 y 轴）反射：入射、反射光线的斜率互为相反数
  • 大白话：以坐标轴为镜面上下（左右）翻一下，倾斜角互补，斜率变号。
  • 用的时候：光线反射题把光源"镜像"到镜面另一侧，光线就拉直成直线距离。

圆的方程

标准方程：(x−a)2 + (y−b)2  =  r2，圆心 (a,b)，半径 r
  • 大白话：一眼看出圆心和半径。
一般方程：x2+y2+Dx+Ey+F = 0，圆心 (−D/2,−E/2)，r  =  ½√(D2+E2−4F)
  • 大白话：展开后的样子，配方才看得出圆心半径。
  • 用的时候：表示圆要 D2+E2−4F>0；等于 0 是一个点，小于 0 不是圆；没有 xy 项、x2y2 系数相等。
直径式：(x−x1)(x−x2) + (y−y1)(y−y2)  =  0（A(x1,y1)、B(x2,y2) 为直径两端点）
  • 大白话：已知直径两个端点，一步写出圆，不用求圆心半径。
  • 用的时候：原理是直径所对圆周角为直角（PA⊥PB）；题目说"对 AB 张直角"时立刻想到它。

直线与圆的位置关系

比 d 与 r：d<r 相交，d = r 相切，d>r 相离（d 为圆心到直线距离）
  • 大白话：量圆心到直线距离，跟半径比大小。
  • 用的时候：九成题先算 d 再比 r，不用真求交点。
弦长：|AB|  =  2√(r2 − d2)
  • 大白话：半弦、半径、垂距构成直角三角形，整条弦乘 2。
  • 用的时候：d 是圆心到直线距离，不是别的。
圆上点 (x1,y1) 处切线：(x1−a)(x−a) + (y1−b)(y−b)  =  r2
  • 大白话：切线垂直过切点的半径。
  • 用的时候：过圆外点求切线有两条，别漏斜率不存在的那条。
两圆公共弦：两圆一般式相减 (D1−D2)x+(E1−E2)y+(F1−F2) = 0
  • 大白话：两个圆方程一减，就得到它们公共弦（或公切线）所在的直线。
  • 用的时候：求两圆公共弦方程不用解交点，直接相减；相切时这条线就是公切线。
圆上到直线距离为 d′ 的点个数（圆心距 d，半径 r）

1 个：d = r+d′；2 个：r−d′<d<r+d′；3 个：d = r−d′；4 个：d<r−d′

  • 大白话：作两条平行直线距离 d′，数它们和圆交几个点；d 由大到小，个数从 1→2→3→4。
  • 用的时候：C1 那类"圆上到某直线距离等于定值的点有几个"直接套。

16圆锥曲线· 本章公式速查

与《高中数学常用公式·修订版》第六部分"圆锥曲线"逐条核对一致。

椭圆

|MF1| + |MF2|  =  2a（2a > |F1F2|  =  2c）
  • 大白话：椭圆上随便一点，到两个焦点的距离加起来永远等于 2a。
  • 用的时候：用定义求轨迹；必须 2a > 焦距，等号就退化成线段、小于就画不出图。
  • 记忆要点：到两焦点距离和  =  长轴长。
x2/a2 + y2/b2  =  1（焦点在 x 轴，a > b > 0）
  • 大白话：椭圆的标准长相，分母大的 a 在 x2 上就是焦点在 x 轴。
  • 用的时候：写方程前先看焦点在 x 轴还是 y 轴；哪个分母大，焦点就在那个轴上。
b2  =  a2 − c2（a 最大）
  • 大白话：短半轴 b、半焦距 c、长半轴 a 满足勾股，且 a 是三者里最大的。
  • 用的时候：知二求三天天用；椭圆是减号，最高频写成加号。
  • 记忆要点：椭圆 c2  =  a2 − b2（减）。
e  =  c/a（0 < e < 1）
  • 大白话：离心率衡量椭圆有多扁，越接近 1 越扁、越接近 0 越圆。
  • 用的时候：给 c 和 e 先求 a；e 是 a、b、c 知二求三的枢纽。
通径  =  2b2/a
  • 大白话：过焦点垂直长轴切出来的那条最短弦。
  • 用的时候：把 x = c 代回方程求 y 即得；小题当结论直接用。
焦点三角形面积 S  =  b2·tan(θ/2)（θ  =  ∠F1PF2）
  • 大白话：椭圆上一点跟两焦点围成的三角形，只看顶角就能算面积。
  • 用的时候：题里给 ∠F1PF2 又不需求 P 坐标时直接套；椭圆用 tan。
e  =  √(1 − (b/a)2)（椭圆离心率比值式）
  • 大白话：给了 b/a 直接平方算 e，不用先求 c。
  • 用的时候：选择题给"虚轴/实轴""b 与 a 的倍数"时秒算 e。
第二定义 |PF|/d  =  e；准线 x  =  ±a2/c（新教材作了解）
  • 大白话：椭圆上一点到焦点的距离，是它到对应准线距离的 e 倍。
  • 用的时候：把"到焦点距离"和"到准线距离"互相换，省得算坐标；准线在焦点外侧 a2/c 处。

双曲线

||MF1| − |MF2||  =  2a（2a < |F1F2|）
  • 大白话：双曲线上一点到两焦点距离之差的绝对值恒为 2a，所以有两支。
  • 用的时候：和椭圆就差一个字——"和"变"差"；必须 2a < 焦距。
x2/a2 − y2/b2  =  1（a > 0, b > 0）
  • 大白话：双曲线标准方程，中间是减号，中间是空的（|x| ≥ a）。
c2  =  a2 + b2（c 最大）
  • 大白话：双曲线里 a、b、c 也是勾股关系，但这次是加号，c 最大。
  • 用的时候：和椭圆反着写！这是本章第一高频坑。
  • 记忆要点：双曲线 c2  =  a2 + b2（加）。
渐近线 y  =  ±(b/a)x
  • 大白话：双曲线两头无限靠近但永远碰不到的两条直线。
  • 用的时候：焦点在 x 轴就是 b/a；别把 a、b 写反。
  • 记忆要点：令方程右边 1 变 0 即得渐近线。
e  =  c/a（e > 1）
  • 大白话：双曲线离心率必大于 1，越大开口越阔；e  =  √2 就是等轴双曲线。
通径  =  2b2/a；焦点三角形面积 S  =  b2·cot(θ/2)
  • 大白话：通径和椭圆同公式；焦点三角形面积把椭圆的 tan 换成 cot。
  • 用的时候：别记混——椭圆 tan、双曲线 cot。
e  =  √(1 + (b/a)2)（双曲线离心率比值式）
  • 大白话：给了 b/a 直接算 e；e = √2 就是等轴双曲线。
  • 用的时候：C1 那类"虚轴是实轴几倍"直接套；b/a = √7 ⇒ e = √(1+7) = 2√2。
准线 x  =  ±a2/c；同渐近线双曲线系 x2/a2 − y2/b2  =  λ
  • 大白话：准线位置和椭圆同公式；同渐近线的一族双曲线右边换成参数 λ。
  • 用的时候：求"与某双曲线共渐近线"的方程时设成 λ；第二定义 |PF|/d=e 同样适用。

抛物线

y2  =  2px（p > 0，开口向右）
  • 大白话：到焦点距离等于到准线距离的点的轨迹，标准式里一次项是谁焦点就在谁轴上。
  • 用的时候：先把方程写成 y2  =  2px 的样子读出 p。
焦点 F(p/2, 0)，准线 x  =  −p/2
  • 大白话：焦点在原点右边半个 p 处，准线在左边半个 p 处。
  • 用的时候：别把焦点记成 (p,0)，是 (p/2,0)；焦点到准线距离 = p。
通径  =  2p；离心率 e  =  1
  • 大白话：抛物线通径就是 2p；e 恒等于 1，正好卡在椭圆和双曲线中间。
焦点弦 x1x2  =  p2/4，y1y2  =  −p2
  • 大白话：过焦点的弦两端坐标乘积是固定的，小题直接套。
  • 用的时候：只对过焦点的弦成立；前面带个负号别漏。
焦半径（角度式）：|AF|  =  p/(1−cosθ)，|BF|  =  p/(1+cosθ)（θ 为焦点弦 AB 的倾斜角）
  • 大白话：焦点弦被焦点分成两段，各段长度用倾斜角 θ 直接写。
  • 用的时候：比 x1+p/2 更快；两段一长一短，cosθ 一减一加。
焦点弦长 |AB|  =  2p/sin2θ；S△AOB  =  p2/(2sinθ)；1/|AF| + 1/|BF|  =  2/p
  • 大白话：过焦点的弦长、它与原点围成三角形的面积，都只跟倾斜角 θ 有关。
  • 用的时候：θ=90°（通径）时弦最短 =2p；倒数和恒为 2/p，与弦怎么转无关。

直线与曲线联立

|AB|  =  √(1 + k2)·√[(x1+x2)2 − 4x1x2]
  • 大白话：用韦达定理写出来的弦长，不用真解出两个交点。
  • 用的时候：联立得一元二次方程后，先写 Δ > 0 再套；Δ ≤ 0 不能用。
点差法：椭圆 k·(y0/x0)  =  −b2/a2；双曲线  =  +b2/a2（中点 (x0, y0)）
  • 大白话：已知弦中点求斜率，两式一减直接出，省掉联立。
  • 用的时候：椭圆是负号、双曲线是正号；用完要代回验证 Δ > 0。

17计数原理（排列、组合、二项式定理）· 本章公式速查

排列组合部分：修订版手册未单列"排列组合"专章（其第十一部分为概率），本表按人教A版2019选必三第6章主线整理；排列数/组合数/二项式定理属常识性公式，口径与教材一致。

两大计数原理

分类加法：总数  =  n1 + n2 + … + nk
  • 大白话：一件事分几类办法，任选一类就完事，各类相加。
  • 用的时候：见到"要么…要么…"用加；各类要不重不漏。
分步乘法：总数  =  n1  ×  n2  ×  …  ×  nk
  • 大白话：一件事分几步，每步都做完才算完，步步相乘。
  • 用的时候：见到"先…再…""各选一个"用乘；少一步都不行。
  • 记忆要点："或"用加，"和/再"用乘。

排列

A(n, m)  =  n(n−1)…(n−m+1)  =  n! / (n−m)!
  • 大白话：从 n 个里挑 m 个还要排成队，有位置顺序就用排列。
  • 用的时候：见到"排队/分职务/排位置"用 A；m=n 时就是全排列。
全排列 A(n, n)  =  n!
  • 大白话：n 个不同元素全部排成一排，有 n 的阶乘种。
  • 用的时候：如 5 人一排 = 5! = 120。

组合

C(n, m)  =  A(n,m)/m!  =  n! / [m!(n−m)!]
  • 大白话：从 n 个里挑 m 个摆一堆、不分顺序，就用组合。
  • 用的时候：抽样/选人/连成线段这种不分先后的用 C；除以 m! 是因为同一组的 m! 种排列只算一次。
C(n, m)  =  C(n, n−m)（对称）
  • 大白话：挑出 m 个留下，等价于挑出 n−m 个不要。
  • 用的时候：m 很大时换成 n−m 好算（如 C(7,4) = C(7,3)）。
C(n, m)  =  C(n−1, m−1) + C(n−1, m)（递推）
  • 大白话：杨辉三角腰上的数等于它肩上两个数之和。
  • 用的时候：验算或推导性质时用。
m·C(n, m)  =  n·C(n−1, m−1)（苏州教研·专题54）
  • 大白话：从 n 人里选 m 人再指定其中 1 人当组长  =  先指定组长再从剩下 n−1 人里选 m−1 个组员。
  • 用的时候：带系数的组合数求和、化简时用；等价变形 (m/n)·C(n,m)  =  C(n−1,m−1)。
朱世杰恒等式：C(r, r) + C(r+1, r) + … + C(n, r)  =  C(n+1, r+1)（苏州教研·专题54）
  • 大白话：同一行（固定上标 r）的组合数从 r 一直加到 n，等于下一行错位一格的那个数。
  • 用的时候：一串组合数连加（上标相同、下标递增）直接合成一个组合数，不用逐项算。
  • 记忆要点：跟杨辉三角"肩上两数相加"是同一个道理的连加版本。

分组与分配技巧

捆绑法（相邻问题）：先捆整体再排，别忘内部排列
  • 大白话：要求挨着的几个人捆成一个大疙瘩，先算这个大疙瘩和别人一起排，再乘疙瘩内部的排法。
  • 用的时候：见到"必须相邻"就捆；捆完内部 k! 一定要乘。
插空法（不相邻问题）：先排其余，再把不相邻元素插空
  • 大白话：先把没要求的排好，它们之间（含两端）空出 n−k+1 个位置，把不相邻的插进去。
  • 用的时候：见到"不能相邻"就插；空位数 = 先排元素数 + 1。
平均分组除以组数阶乘：C(n,k)C(n−k,k)… / m!
  • 大白话：分成几个没名字的组时，同一种分法会被重复数 m! 遍，要除掉。
  • 用的时候：组没编号（平均分成 3 组）就除；组有名字（分给甲乙丙）就不除。
隔板法：n 个相同球分 k 盒、每盒至少 1 个  =  C(n−1, k−1)
  • 大白话：球排好，中间 n−1 个缝插 k−1 块板。
  • 用的时候：只对"球相同、每盒至少一个"用；要求"可以空盒"要先转化。
隔板法·允许空盒（非负整数解）：方程 x1+…+xk  =  n 的非负整数解个数  =  C(n+k−1, k−1)（苏州教研·专题54）
  • 大白话：允许某盒空着时，先给每盒"垫"1 个球变成每盒至少 1 个，再用隔板法——总数变成 n+k。
  • 用的时候：求"x1+…+xk  =  n"的正整数解用 C(n−1,k−1)；非负整数解（可以取 0）用 C(n+k−1,k−1)。
  • 记忆要点：正解垫 0、非负解垫 k，垫完都套"至少 1 个"的隔板公式。
多重排列（有相同元素）：n 个元素里有 m1 个相同、m2 个相同……排法  =  n! / (m1!·m2!·…·mk!)（苏州教研·专题54）
  • 大白话：先把所有不同元素全排 n!，再把每一组相同元素内部的 mi! 种"假不同"除掉。
  • 用的时候：如 2 红 3 黄 4 白同色不区分排成一列  =  9!/(2!·3!·4!)  =  1260。
  • 记忆要点：和平均分组除 m! 一个道理——相同元素之间交换不算新排法。
错位排列（n 封信全装错信封）：D2 = 1，D3 = 2，D4 = 9，D5 = 44（苏州教研·专题54）
  • 大白话：每个元素都不在自己原来位置上，n 不大时这几个数直接背。
  • 用的时候："每个人都不坐自己位置"这类题，n≤5 直接套；n 再大用递推 Dn  =  (n−1)(Dn−1+Dn−2)。
  • 实算复核：D4 = 4!(1−1+1/2!−1/3!+1/4!) = 24 × (9/24) = 9；D5 = 120 × (44/120) = 44。

二项式定理

(a + b)n  =  Σ C(n,k)·an−k·bk（共 n+1 项）
  • 大白话：把 (a+b) 的高次方展开，系数就是杨辉三角那排数。
通项 T₍k+1₎  =  C(n,k)·an−k·bk（k 从 0 开始）
  • 大白话：第 k+1 项长什么样，全靠这条写出来。
  • 用的时候：求指定项系数，先令 x 的幂等于目标解出 k，再代回算；求第 3 项对应 k = 2 不是 k = 3；实际系数还要乘 a、b 的数字幂和符号。
所有项系数之和  =  2n（令 a = b = 1）
  • 大白话：把 a、b 都代成 1，加起来就是全部系数和。
  • 用的时候：问"系数和"就令变量 x = 1；奇数项系数和  =  偶数项系数和  =  2n−1。
赋值法三公式：设 (ax+b)n  =  a0+a1x+…+anxn  =  f(x)（苏州教研·专题55）
  • 公式：a0  =  f(0)；a0+a1+…+an  =  f(1)；a0−a1+a2−…  =  f(−1)。
  • 大白话：常数项、全部系数和、正负交替系数和，分别靠代 0、代 1、代 −1 得到。
  • 用的时候：问"系数和""奇数项系数和""偶数项系数和"都用它，不用逐项展开。
|系数|之和的求法：|a0|+|a1|+…+|an|  =  (|a|x+|b|)n 展开式的系数和  =  f₍∣∣₎(1)（苏州教研·专题55）
  • 大白话：绝对值符号往往正负交替出现，干脆把 a、b 都换成正数再代 x = 1。
  • 用的时候：求各项系数绝对值之和，别先去展开去绝对值——直接写 (|a|x+|b|)n 再令 x = 1。
系数最大（小）项：设第 r 项系数 Ar 最大，解不等式组 Ar ≥ Ar−1 且 Ar ≥ Ar+1（苏州教研·专题55）
  • 大白话：系数最大那一项，一定比它左右邻居都大（或相等）。
  • 用的时候：列出相邻两项系数比 ≥1 的不等式组，解出整数 r；注意这是"项的系数"不是"二项式系数"。
两个二项式相乘的通项：(a+b)n·(c+d)m 展开式一般项  =  C(n,s)·an−sbs · C(m,t)·cm−tdt（苏州教研·专题55）
  • 大白话：第一个式子取第 s+1 项、第二个取第 t+1 项相乘，再合并同类项。
  • 用的时候：求 (a+b)n(c+d)m 展开式里某指定幂次的项，联立两个指数方程解 s、t。
求导法求和：1·C(n,1)+2·C(n,2)+…+n·C(n,n)  =  n·2n−1（苏州教研·专题55）
  • 公式：对 (1+x)n  =  1+C(n,1)x+…+C(n,n)xn 两边求导，再令 x = 1。
  • 大白话：给通项里多出来的那个 k 乘号，正好用"求导把幂次拉下来"消掉。
  • 实算复核（n = 3）：1·3+2·3+3·1  =  12；n·2n−1  =  3·4  =  12 ✓。
  • 记忆要点：带系数 k·C(n,k) 求和 → 求导；不带系数 → 直接令 x = 1。

18概率· 本章公式速查

与《高中数学常用公式·修订版》第十一部分"概率"核对一致；数字特征（期望/方差）口径与教材一致。

古典概型与事件关系

P(A)  =  A 包含的基本事件数 / 基本事件总数
  • 大白话：所有结果等可能时，概率就是"有利份数"除以"总份数"。
  • 用的时候：先数清总数；两枚骰子要区分顺序，(3,4) 和 (4,3) 是两个。
互斥加法 P(A∪B)  =  P(A) + P(B)
  • 大白话：两个事不能同时发生时，发生其一的概率就是相加。
  • 用的时候：互斥才加；不是互斥要减 P(AB)。
一般加法公式 P(A∪B)  =  P(A) + P(B) − P(A∩B)（苏州教研·专题25）
  • 大白话：两个事都可能发生时，"至少一个发生" =  各自概率相加再减掉"同时发生"被重复算的那一块。
  • 用的时候：题目没说互斥就套它；互斥时 P(A∩B) = 0，它就退化成 P(A)+P(B)。A∪B  =  至少一个发生，A∩B  =  同时发生。
概率为 0 不一定是不可能事件，概率为 1 也不一定是必然事件（苏州教研·专题25）
  • 大白话：几何概型里"恰好落在某一点"概率是 0，但这件事确实能发生；反过来"去掉一个点的区域"概率是 1，却不是全部。
  • 用的时候：别把"概率 0"直接等同于"不可能"；只有古典概型里两者才等价。
对立 P(A)  =  1 − P(A)
  • 大白话："不发生"的概率就是 1 减去发生的概率。
  • 用的时候：求"至少一个"正面难算时，转成求它的对立。

条件概率与独立

条件概率 P(A|B)  =  P(AB) / P(B)（P(B)>0）
  • 大白话：已知 B 发生后，样本空间缩小成 B，在 B 里数 AB 占多少。
  • 用的时候：分母是 P(B)，不是 P(A)；不放回抽样就是换样本空间重新数。
独立 P(AB)  =  P(A)·P(B)
  • 大白话：两件事互不影响，同时发生的概率就是各自概率相乘。
  • 用的时候：独立 ⇔ 此式成立；独立和互斥方向相反，互斥的事件一般不独立。
独立的传递性：若 A 与 B 独立，则 A 与 B、A 与 B、A 与 B 也都独立（苏州教研·专题56）
  • 大白话：A 发不发生跟 B 没关系，那 A 跟"B 不发生"同样没关系，反过来也一样。
  • 用的时候：题目给"A、B 独立"，求 P(A·B) 时直接写 P(A)·P(B) = P(A)(1−P(B))，不用重新证。
互斥条件概率：若 B、C 互斥，则 P(B∪C | A)  =  P(B|A) + P(C|A)（苏州教研·专题56）
  • 大白话：在 A 这个大前提下，B、C 不能同时发生，那"B 或 C 发生"的条件概率就是两个条件概率相加。
  • 用的时候：条件概率里遇到互斥事件求并，照样可以加。
概率运算四种类型口诀：加（互斥事件）、减（对立事件）、乘（独立事件）、除（古典/几何/条件概率）（苏州教研·专题56）
  • 大白话：见互斥用加法、见对立用 1−、见独立用乘法、见"数份数/已知条件"用除法。
  • 用的时候：列式前先给题目归个类，知道该用哪把刀。

期望与方差

E(X)  =  Σ xi·pi
  • 大白话：每个取值乘它的概率再加权，就是随机变量的"平均取值"。
  • 用的时候：列完分布列一定回头验算 Σpi=1。
D(X)  =  E(X2) − [E(X)]2
  • 大白话：描述随机变量围绕均值波动多大，平方消掉正负抵消。
  • 用的时候：用 E(X2)−[E(X)]2 比硬算离差平方快；先算 E(X2)=Σxi2pi。
E(aX+b)  =  aE(X)+b；D(aX+b)  =  a2D(X)
  • 大白话：期望跟着平移缩放一起变；方差只跟缩放、不跟平移（加 b 不变、乘 a 变 a2 倍）。
  • 用的时候：整体加一个常数，方差照写别加 b。

三个重要分布

二项分布 X~B(n,p)：E(X) = np，D(X) = np(1−p)
  • 大白话：n 次独立重复、每次成功率 p，命中次数就是二项分布。
  • 用的时候：独立+重复+概率不变才用它；有放回抽样。
两点分布（0-1 分布）：E(X) = p，D(X) = p(1−p)（苏州教研·专题56）
  • 大白话：只做一次试验、结果只有"成功 1 / 失败 0"两种，就是两点分布；它是 n = 1 的二项分布。
  • 用的时候：单次成败题直接套；D(X) = p(1−p) 和二项分布 n = 1 时一致。
超几何分布（不放回）：E(X)  =  n·M/N
  • 大白话：N 个里 M 个次品，抽 n 个，期望次品数就是 n·M/N。
  • 用的时候：不放回抽样是超几何不是二项；期望和二项同口径，但方差更小。
超几何/混合球速算期望（仅客观题）：m 白 n 红 p 黑共 m+n+p 个球，任取 k 个，其中白球数期望 E(X)  =  k·m/(m+n+p)（苏州教研·专题56）
  • 大白话：把球"打碎搅匀"，每个被取到的球里白球占比恒为 m/(m+n+p)，取 k 个就乘 k。
  • 用的时候：选择题快速出期望；解答题求分布列、方差时不能用它，要老实套超几何公式。
正态分布 X~N(μ,σ2)：μ±σ ≈ 0.683，μ±2σ ≈ 0.954，μ±3σ ≈ 0.997；P(Z<μ+σ) ≈ 0.8413
  • 大白话：钟形曲线关于 μ 对称，离 μ 几个 σ 就套对应比例。
  • 用的时候：求 P(X>a) 先看 a 离 μ 几个 σ，再用对称；a=μ+σ 时 P(X<μ+σ)=0.8413、P(X>μ+σ)=0.1587。
正态密度函数 φ(x)  =  1/(√(2π)·σ) · e^(−(x−μ)2/(2σ2))（苏州教研·专题56）
  • 大白话：这是那条钟形曲线的解析式；曲线与 x 轴围成的总面积  =  1，区间上的概率就是对应面积。
  • 用的时候：知道 μ = 均值、σ = 标准差即可，不必背解析式；样本里用 x 当 μ、用 √s（即 s）当 σ 把正态分布定下来。
3σ 原则（假设检验）：一次试验结果 a 落在 (μ−3σ, μ+3σ) 内就接受假设，落在外面就拒绝（苏州教研·专题56）
  • 大白话：正态变量几乎 99.7% 挤在 μ±3σ 里，跑出去属于小概率事件，一次就发生说明原假设可疑。
  • 用的时候：产品尺寸正常波动范围就是 (μ−3σ, μ+3σ)；出界即判异常。

几何概型

几何概型 P(A)  =  构成事件 A 的区域长度（面积/体积）÷ 试验全部结果的区域长度（面积/体积）（苏州教研·专题25）
  • 大白话：结果无限多又等可能时，概率不再是数份数，而是"长度比/面积比/体积比"。
  • 用的时候：一个变量在区间上取值 → 长度比；两个变量 (x,y) 在平面区域取值 → 面积比（先设全集 Ω、事件 A 再画图）；立体中取点 → 体积比。
  • 记忆要点：线段/圆周上动点用长度比；平面内动点用面积比；空间内动点用体积比。

全概率

全概率 P(A)  =  Σ P(Bi)·P(A|Bi)（Bi 互斥且覆盖全部）
  • 大白话：把 A 按它发生的几种前提拆开，各算各的再加权求和。
  • 用的时候：多阶段、"先选哪袋再抽一件"这种题用它；反过来"已知结果求原因"用贝叶斯，会套全概率即可。

19统计· 本章公式速查

与《高中数学常用公式·修订版》第十二部分"统计与统计案例"逐条核对一致。

抽样方法

分层抽样：每层抽取数  =  该层人数  ×  (样本量/总体量)
  • 大白话：总体分几层、层间差得多，就按比例从每层抽，让样本比例跟总体一致。
  • 用的时候：抽完各层相加必须等于样本总量；不等于就抽错了。
系统抽样间隔 k  =  N/n
  • 大白话：总体编号很多，每隔 k 个抽一个。
  • 用的时候：k 是总体量除以样本量；先随机定第一个，再等距往后数。
等概率抽样：无论哪种抽样，从 N 个元素中抽 n 个，每个元素被抽到的概率都是 p  =  n/N（苏州教研·专题24）
  • 大白话：简单随机、系统、分层，抽法不同，但"每个个体被抽中的机会"一律等于样本量除以总体量。
  • 用的时候：判断样本是否有代表性时，先看每个个体机会均等不均等；分层抽样是每层内等比例，整体仍 p = n/N。

数字特征

平均数 x  =  (1/n)Σxi（加权：Σwixi/Σwi）
  • 大白话：所有数加起来除以个数，就是数据的"中心"。
  • 用的时候：两组人数不等时合并要按加权平均，不能把两个平均分直接相加除 2。
方差 s2  =  (1/n)Σ(xi−x)2；标准差 s  =  √s2
  • 大白话：每个数离中心多远的平方平均，衡量数据"散得多开"；开根号还原单位。
  • 用的时候：方差是离差平方的平均；合并数据要重算，不能把两组方差相加。
平移缩放：数据 +a → 平均数 +a、方差不变；数据  × b → 平均数  × b、方差  × b2
  • 大白话：整体加一个数只平移不影响波动，整体乘一个数波动跟着放大 b2 倍。
  • 用的时候：问"每个数据加几/乘几后新方差"，记住方差里没有加的那个常数。

频率分布直方图

频率  =  (频率/组距)  ×  组距；每个矩形面积  =  频率
  • 大白话：纵轴是"频率/组距"不是频率，必须乘组距才是真频率；所有矩形面积加起来 = 1。
  • 用的时候：求某组人数 = 该组面积 × 总体数；直接拿纵轴数字当频率是命门级错误。
直方图各矩形：高之比  =  面积比  =  频率比  =  频数比（苏州教研·专题24）
  • 大白话：组距都一样时，柱子的高低直接反映了各组频率、频数的比例。
  • 用的时候：比较两组人数多少，直接比柱子高度即可，不用每组都乘组距算一遍。
用频率分布直方图估计"三数"（苏州教研·专题24）
  • 公式：众数 = 最高矩形中点的横坐标；中位数 = 累积面积达到 0.5 处的横坐标（常设未知数按面积列方程）；平均数 = Σ（各矩形中点横坐标 × 该矩形面积）。
  • 大白话：从直方图里反推这组数据的中心——最胖那根柱子的中点是众数，面积对半分那点是中位数，按面积加权的中点是平均数。
  • 用的时候：题目给直方图让估平均数，就把每根柱子中点乘它的面积再加起来；估中位数要"设未知数让左右面积各 0.5"列方程。
  • 记忆要点：众数看最高、中位数对半砍、平均数按面积加权。
两组数据比优劣：先比平均数（通常相当），再比方差（标准差），越小越集中、越稳定（苏州教研·专题24）
  • 大白话：两组平均分差不多时，谁方差小谁发挥稳定；评价数据好坏就这两步。
  • 用的时候：运动员得分、零件质量对比题都这么下结论。

回归分析

斜率 b  =  Σ(xi−x)(yi−y) / Σ(xi−x)2；截距 a  =  y − b·x
  • 大白话：最小二乘配出来的最贴散点的那条直线，斜率是"协方差除以 x 的方差"。
  • 用的时候：先算 x、y，再算 b，最后 a；斜率 b 和相关系数 r 一定同号。
回归直线必过样本中心 (x, y)
  • 大白话：这条直线一定穿过所有点的平均位置。
  • 用的时候：算完拿它代进去验证，是检查对错的照妖镜。
相关系数 r ∈ [−1,1]：|r|→1 线性越强；r>0 正相关、r<0 负相关
  • 大白话：衡量两个变量线性关系有多紧，越接近 ±1 越贴一条直线。
  • 用的时候：r 接近 0 几乎无线性关系；b 和 r 同号可快速自检。
相关系数 r 的计算公式：r  =  Σ(xi−x)(yi−y) / √[Σ(xi−x)2·Σ(yi−y)2]（苏州教研·专题57）
  • 大白话：分子就是回归斜率 b 乘的那个"协方差和"，分母把 x、y 各自波动归一化，结果落在 [−1,1]。
  • 用的时候：分子和求 b 时是同一个量，算过 b 就不用重算分子；|r|>0.75 就算有很强的线性相关。
  • 记忆要点：r 接近 1 正相关强、接近 −1 负相关强、接近 0 几乎无线性关系。
强相关门槛：|r| > 0.75 认为线性相关性很强（苏州教研·专题57）
  • 大白话：相关系数大过 0.75，就有把握说这两个变量线性关系紧密；越接近 0 越弱。
  • 用的时候：题目问"是否适合线性回归"，先看 |r| 过没过 0.75。
相关指数 R2  =  1 − Σ(yi−yi)2 / Σ(yi−y)2；一元线性模型中 R2  =  r2（苏州教研·专题57）
  • 大白话：R2 衡量回归直线解释了多少数据波动，越接近 1 说明模型越贴；只有一个解释变量时它正好等于 r 的平方。
  • 用的时候：R2 越大线性回归效果越好；残差平方和 Σ(yi−yi)2 越小，R2 越大。
残差平方和 Q  =  Σ(yi−yi)2  =  Σ(yi−bxi−a)2，最小二乘法就是取使 Q 最小的 b、a（苏州教研·专题57）
  • 大白话：每个真实点到回归直线的竖直偏差平方加起来，最小二乘法就是把这个总和压到最小。
  • 用的时候：理解回归直线"为什么最贴"就靠它；b、a 的公式正是 Q 取最小的解。

独立性检验（卡方）

χ2  =  n(ad − bc)2 / [(a+b)(c+d)(a+c)(b+d)]（2 × 2 列联表 a,b,c,d）
  • 大白话：两个变量有没有关系，算出 χ2 再和临界值比，越大越有把握说"有关"。
  • 用的时候：套公式时四个分母因子别漏乘、少写零；算完和临界值比。
临界值：3.841（95%）/ 6.635（99%）/ 10.828（99.9%，即 α = 0.001）
  • 大白话：χ2 超过哪个临界值，就对应那个把握度。
  • 用的时候：下结论写"有 X% 把握认为有关"，并补一句"这是统计相关，不等于因果"。
完整临界值梯度（苏州教研·专题57）：χ2>2.706 有 90% 把握；>3.841 有 95%；>6.635 有 99%；>10.828 有 99.9%；χ2<2.706 认为没有充分证据显示有关
  • 大白话：2.706 是"最低及格线"，过了它才敢说有九成把握；连它都不到，就当没关系。
  • 用的时候：题里若没给临界值，就按这四档对号入座；下结论前先看清 χ2 落在哪一档。
"有关"不等于"一个导致另一个"，"无关"也不等于"两事件互不影响"（苏州教研·专题57）
  • 大白话：独立性检验只说明两个分类变量在统计上有联系，不证明因果；算出"无关"也只是没有足够证据，不能断言它俩真没关系。
  • 用的时候：答题结尾那句"统计相关≠因果"不能省；别把检验结论说成"抽烟导致肺癌"。

函数

配方恒等式：x2+1/x2  =  (x+1/x)2 − 2；a2+b2+c2−ab−ac−bc  =  ½[(a−b)2+(a−c)2+(b−c)2]
  • 大白话：见到"平方和减两两乘积"，立刻想到它等于三对差的平方之和的一半，方便判号。
  • 用的时候：第二个式子把"a2+b2+c2 与 ab+bc+ca 谁大谁小"一眼看穿（差恒 ≥0）。
  • 记忆要点：a2±ab+b2 = (a±b/2)2 + ¾b2。
  • 出处：（苏州教研·专题B，原书p.5）
分子常数化：y  =  (ax−1)/(ax+1)  =  1 − 2/(ax+1)
  • 大白话：分子分母同结构时，把分子凑成分母，剩下一个常数，函数图像就一眼看穿。
  • 用的时候：形如 y=(mx+n)/(px+q) 的分式函数，先分离常数，再看它由反比例函数平移得到。
  • 记忆要点：分子常数化后，单调性、对称中心直接读。
  • 出处：（苏州教研·专题B，原书p.5）
有理化：1/(√a+√b)  =  (√a−√b)/(a−b)；√(n2+1) − n  =  1/(√(n2+1)+n)
  • 大白话：分母带根号就乘共轭式去根号；两个相近根号相减，倒过来变一个分式。
  • 用的时候：比较大小、求极限、裂项时，把"√(n2+1)−n"写成 1/(√(n2+1)+n) 方便放缩。
  • 记忆要点：差化和、和化差，符号相反那一项放分母。
  • 出处：（苏州教研·专题B，原书p.5）
双重根号化简：√(p±2√q)  =  √a ± √b（当 p = a+b 且 q = ab，a>b>0）
  • 大白话：根号套根号，若里面是 p±2√q，且能拆成两个数 a、b（和为 p、积为 q），就拆成 √a±√b。
  • 用的时候：先凑出"2√"，再把 p 拆成 a+b、q 拆成 ab。
  • 记忆要点：和=p、积=q，大根号套小根号就这么拆。
  • 出处：（苏州教研·专题9，原书p.39）
负指数化正：(ax+a−x)/(ax−a−x) 上下同乘 ax  =  (a2x+1)/(a2x−1)
  • 大白话：分子分母同时出现 ax 和 a−x，同乘一个 ax 全变成正指数。
  • 用的时候：研究指数型分式函数时，先把负指数消干净再讨论奇偶、单调。
  • 记忆要点：上下同乘 a 的正指数幂。
  • 出处：（苏州教研·专题B，原书p.5）
韦达定理与两根距离：x1+x2  =  −b/a，x1x2  =  c/a；|x1−x2|  =  √Δ / |a|
  • 大白话：二次方程两根的和、积有现成公式；两根在数轴上拉开多远，等于判别式开方再除以 |a|。
  • 用的时候：题里出现"两根之差""两交点水平距离"直接套 |x1−x2|=√Δ/|a|。
  • 记忆要点：和是 −b/a，积是 c/a，距离是 √Δ/|a|。
  • 出处：（苏州教研·专题B，原书p.5）
自对称充要条件：f(a+x) = f(a−x) ⇔ 关于直线 x = a 对称；f(a+x)+f(a−x) = 2b ⇔ 关于点 (a,b) 中心对称
  • 大白话：括号里"加 a 减 a"代入值相等 → 轴对称；加起来等于常数 2b → 中心对称。
  • 用的时候：看到这种 f(a+x) 与 f(a−x) 的等式，先判断它是对称轴还是对称中心。
  • 记忆要点：值相等→轴；值相加为定→中心。
  • 出处：（苏州教研·专题5/7，原书p.24、p.32）
对称图象零点之和：图象关于 x = a 对称且共有 n 个零点，则零点横坐标之和  =  n·a
  • 大白话：对称的零点成对出现，每对中点都是 a，n 个零点加起来就是 n 个 a。
  • 用的时候：求"所有零点之和"这类题，不用逐个解，用对称性直接乘。
  • 记忆要点：对称零点成对，中点都是对称轴。
  • 出处：（苏州教研·专题7，原书p.32）
单调性结构判定：f(x)+c、√f(x) 与 f 同单调；−f(x)、1/f(x) 与 f 反单调；增+增 = 增，正数增 × 增 = 增
  • 大白话：加常数、开根号不改变单调方向；加负号、取倒数方向反转；两个增函数相加仍增。
  • 用的时候：判断复合函数单调性时按这些规则拼，不必每次重新求导。
  • 记忆要点：正操作同调，负操作反调。
  • 出处：（苏州教研·专题6，原书p.27）
换元法要定新元范围：y  =  ax+b ± √(cx+d)，令 t  =  √(cx+d)
  • 大白话：带根号的一次式，设根号部分为 t，先写 t 的范围，再把函数化成关于 t 的二次式求值域。
  • 用的时候：必须求两次值域——先是新元 t 的范围，再是新函数的值域；漏掉 t≥0 最易错。
  • 记忆要点：换元必换范围。
  • 出处：（苏州教研·专题4，原书p.21）
反函数交点对称：a>1 时，ax  =  t−x 的根 x1 与 logax  =  t−x 的根 x2 满足 x1+x2  =  t
  • 大白话：指数与对数互为反函数、关于 y=x 对称；直线 y=t−x 也关于 y=x 对称，两交点中点在 y=x 上。
  • 用的时候：见到"ax=t−x"和"logax=t−x"两根之和，直接答 t，不必解方程。
  • 记忆要点：反函数+斜率 −1 的直线，交点关于 y=x 对称。
  • 出处：（苏州教研·专题11，原书p.43）
对数型复合函数定义域 / 值域为 R 的条件：f(x) = loga(ax2+bx+c)，Δ = b2−4ac
  • 大白话：定义域为 R 等价于真数恒正；值域为 R 等价于真数能取遍一切正数。
  • 用的时候：定义域为 R ⇔ a=b=0、c>0，或 a>0 且 Δ<0；值域为 R ⇔ a=0、b≠0，或 a>0 且 Δ≥0（两者方向相反，别记反）。
  • 记忆要点：恒正→Δ<0；取遍→Δ≥0。
  • 出处：（苏州教研·专题10，原书p.42）
分段函数单调衔接：f(x) = {f1(x), x≤a；f2(x), x>a} 在 R 上递增 ⇔ 每段各自增，且 f1(a) ≤ f2(a)
  • 大白话：两段各自递增还不够，接头处左边末端不能超过右边起点，否则在断点处"掉下去"。
  • 用的时候：含参分段函数论单调，除了各段单调，务必比接头点的值。
  • 记忆要点：段内单调 + 接头不倒挂。
  • 出处：（苏州教研·专题17，原书p.63）
抽象函数周期：f(x+a) = −f(x)、f(x+a) = 1/f(x)、f(x+a) = f(x−a) 均 ⇒ T = 2a
  • 大白话：解析式里隔一个 a 就翻号、取倒数、或平移复原，那么隔 2a 就回到自己。
  • 用的时候：f(x+a)+f(x−a)=b ⇒ T=4a；f(x+a)=1/(1−f(x)) ⇒ T=3a；两对称轴 x=a、x=b ⇒ T=2|a−b|；一轴一中心 ⇒ T=4|a−b|。
  • 记忆要点：翻号/取倒数→2a；轴+轴→2倍距，轴+心→4倍距。
  • 出处：（苏州教研·专题8，原书p.35~38）

导数

商值定号 ↔ 导数符号：[f(x1)−f(x2)]/(x1−x2) > 0 ⇔ f′(x) ≥ 0 恒成立（单调增）
  • 大白话：割线斜率恒正，就是函数单调增，等价于导数不小于 0。
  • 用的时候：题里给"任取 x1<x2 都有 f(x1)<f(x2)"这类条件，翻译成 f′≥0 再做。
  • 记忆要点：割线斜率的符号 = 单调性。
  • 出处：（苏州教研·专题6，原书p.27）
平均变化率  =  割线斜率：Δy/Δx  =  [f(x2)−f(x1)]/(x2−x1)
  • 大白话：函数在一段上的平均变化快慢，就是两点连线的斜率；导数是它取极限。
  • 用的时候：题目说"区间 [x1,x2] 上的平均变化率"，直接套这个式子。
  • 记忆要点：平均变化率就是割线斜率。
  • 出处：（苏州教研·专题49，原书p.160）
物理意义：瞬时速度 v  =  s′(t)；加速度 a  =  v′(t)  =  s″(t)
  • 大白话：路程对时间求导得速度，速度再求导得加速度。
  • 用的时候：物理背景的导数题，先把 s、v、a 的求导关系摆出来。
  • 记忆要点：s→v→a，逐阶求导。
  • 出处：（苏州教研·专题49，原书p.160）
三函数乘积求导：[f·g·h]′  =  f′gh + fg′h + fgh′
  • 大白话：三个函数相乘求导，轮流对其中一个求导、另外两个原样，三项相加。
  • 用的时候：乘积法则 [fg]′=f′g+fg′ 自然推广；遇到三个因子连乘就这么拆。
  • 记忆要点：轮着求导，三项齐。
  • 出处：（苏州教研·专题49，原书p.160）
切线平行 / 相同判定：平行 ⇔ f′(x0) = g′(x0) 且 f(x0)≠g(x0)；相同 ⇔ f′(x0) = g′(x0) 且 f(x0) = g(x0)
  • 大白话：斜率相等还不够——两条曲线在同一点切线重合，既要斜率同、又要函数值同。
  • 用的时候：判"公切线"时先求斜率相等的 x0，再看是否还需函数值相等。
  • 记忆要点：平行只要斜率同；相同要斜率+函数值都同。
  • 出处：（苏州教研·专题49，原书p.161）
二阶导数的意义：f′ 的正负看 f 增减；f″ 的正负看 f′ 增减（即曲线凹凸方向）
  • 大白话：一阶导数管函数升降，二阶导数管一阶导数怎么变，也就是曲线向上翘还是向下弯。
  • 用的时候：分界点、凹凸讨论时算 f″；f″ 的严格凹凸定义见 ②（选学，大题改用构造差函数）。
  • 记忆要点：一阶管升降，二阶管弯曲。
  • 出处：（苏州教研·专题49，原书p.161）
双函数 ∀∃ 最值组合（f 定义域 A，g 定义域 B）
  • 大白话：把"任意/存在"两两组合，翻译成 f 与 g 的最值关系。
  • 用的时候：∀x1∀x2 f≥g ⇔ f_min ≥ g_max；∀x1∃x2 f≥g ⇔ f_min ≥ g_min；∃x1∀x2 f≥g ⇔ f_max ≥ g_max；∃x1∃x2 f≥g ⇔ f_max ≥ g_min。
  • 记忆要点：两个任意→最小对最大；两个存在→最大对最小；混着就看谁在前。
  • 出处：（苏州教研·专题13，原书p.52）

向量

a+b+c = 0 时：移项平方或同乘其中一个向量，求模或夹角
  • 大白话：三个向量首尾相接和为零，把其中一个移到等号另一边，再两边点乘（平方）就能解出模长或夹角。
  • 用的时候：三角形里三个向量和为 0，求某边向量的模、某两边夹角，就"移项 + 平方"。
  • 记忆要点：和为零→移项→点乘。
  • 出处：（苏州教研·专题28，原书p.120）
同乘法解系数：AC⃗  =  x AB⃗ + y AD⃗ 时，两边分别点乘 AB⃗、AD⃗ 列方程组
  • 大白话：一个向量用两个基底表示，求系数 x、y，就把等式两边分别点乘两个基底，得到两个方程解二元一次组。
  • 用的时候：非坐标背景分解向量求系数时用；客观题也可取特殊多边形建系。
  • 记忆要点：点乘基底，两式解 x、y。
  • 出处：（苏州教研·专题28，原书p.120）

数列

除法裂项：(a−b)/(ab)  =  1/b − 1/a；(b+c)/a  =  b/a + c/a
  • 大白话：分子是两项之差、分母是两项之积，就能裂成两个分式相减，求和时逐项抵消。
  • 用的时候：1/[n(n+1)] = 1/n − 1/(n+1) 是它的特例；数列求和见差就想裂项。
  • 记忆要点：积在分母、差在分子 → 裂项相消。
  • 出处：（苏州教研·专题B，原书p.5）
高次放缩（1/k3 型）：1/k3 < 1/[(k−1)k(k+1)]  =  ½[1/((k−1)k) − 1/(k(k+1))]（k≥2）
  • 大白话：要证含 1/k3 的和不等式，先把它放大成可裂项的相邻两项差。
  • 用的时候：数列型不等式放缩求和时用，放缩后正好裂项相消。
  • 记忆要点：立方倒数 → 中间插 (k−1)、(k+1) 变连乘裂项。

2k−1 放缩：1/(2k−1) ≤ (1/3)·1/2^{k−2}（k≥2）
  • 大白话：分母 2k−1 比 2k 小一点，放缩成等比数列 1/2^{k−2} 就好求和。
  • 用的时候：证 1/(2−1)+1/(4−1)+… 这类和的上界，先放大成等比再求和。
  • 记忆要点：减 1 比不减 1 略大，按 1/3 系数放。

整数解配约数：F(m,n) = 0 化 (k1m+b1)(k2m+b2) = p，对 p 因数分解
  • 大白话：两个正整数满足的方程，整理成"两整数相乘等于常数 p"，就去分解 p 的约数。
  • 用的时候：数论小题、数列求正整数项时用；把方程凑乘积形式是关键一步。
  • 记忆要点：凑乘积 → 分解常数的约数。
  • 出处：（苏州教研·专题17，原书p.63）

不等式

a2+b2 ≥ 2|ab|；ab ≤ (a2+b2)/2
  • 大白话：两数平方和不小于两倍乘积的绝对值；乘积不超过平方和的一半。
  • 用的时候：不限正负（第一式带 |ab|），比基本不等式更通用。
  • 记忆要点：和平方 ≥ 2|积|。
  • 出处：（苏州教研·专题37，原书p.备用结论）
a>b>c 且 a+b+c = 0 ⇒ a>0 且 c<0
  • 大白话：三个数排好序、加起来是 0，最大的必为正、最小的必为负。
  • 用的时候：涉及 a+b+c=0 的符号判断题直接用。
  • 记忆要点：和为零排序，最大正、最小负。
  • 出处：（苏州教研·专题37，原书p.备用结论）
a,b,c>0 且 ab ≤ c2 ⇒ a≤c 或 b≤c 至少一个成立
  • 大白话：两正数乘积不超过第三个数平方，则至少有一个不超过第三个数。
  • 用的时候：反证常用——若两者都大于 c，乘积就超过 c2，矛盾。
  • 记忆要点：都大于 c → 积超 c2，故至少一个 ≤c。
  • 出处：（苏州教研·专题37，原书p.备用结论）
单调定义拆段：a<x<y<b ⇔ a<x<b 且 a<y<b 且 x<y
  • 大白话：要同时满足"x、y 都在区间内且 x 在 y 左边"，就拆成三条分别写。
  • 用的时候：用单调性定义证明时，规范地把 x、y 的关系拆开讨论。
  • 记忆要点：区间内 + 自带大小。
  • 出处：（苏州教研·专题37，原书p.备用结论）

立体几何

圆锥过顶点截面：S  =  ½·l2·sinθ（l 母线长，θ 两母线夹角），轴截面不一定最大
  • 大白话：过圆锥顶点的截面是等腰三角形，面积随两母线夹角 θ 增大而增大；θ 受圆锥顶角限制，所以最大截面未必是轴截面。

  • 记忆要点：S=½l2sinθ，θ 到不了 90° 就不是轴截面最大。
  • 出处：（苏州教研·专题18，原书p.67）
平面内切圆半径：多边形 S  =  ½·周长·r ⇒ r  =  2S/周长
  • 大白话：有内切圆的多边形，面积等于半周长乘内切圆半径，反过来就能解出 r。

  • 出处：（苏州教研·专题19，原书p.73）

抛物线点参数表示：直线 y = kx+m 交 y2 = 2px 于 A(y12/2p, y1)、B(y22/2p, y2)

概率统计

异面直线组数：n 个顶点几何体中，异面直线组数  =  3·(C(n,4) − m)
  • 大白话：每个四面体对应 3 组异面直线；m 是四点共面的组合数，要扣掉。
  • 用的时候：立方体、棱柱等数异面直线对数时用，先算四面体个数再乘 3。
  • 记忆要点：一个四面体 = 3 对异面直线。
  • 出处：（苏州教研·专题54，原书p.185）
圆内交点最多个数：圆上 n 个点连成的弦在圆内交点最多  =  C(n,4)
  • 大白话：每四个圆上的点确定一个圆内接四边形，两条对角线交一点，所以最多 C(n,4) 个交点。
  • 用的时候：数"圆内最多几个交点"，等价于数圆内接四边形个数。
  • 记忆要点：四点定一交点。
  • 出处：（苏州教研·专题54，原书p.185）
连号情形数：n 个连续号码中出现两组 m 个连号的情形数  =  C(n−2(m−1), 2)
  • 大白话：把两组 m 连号各捆成一个"大块"，剩下的位置数里选 2 个放这两大块。
  • 用的时候：排列组合里"连号"模型，先捆绑再插空。
  • 记忆要点：连号先捆绑。
  • 出处：（苏州教研·专题54，原书p.185）
抛掷 n 次硬币（或一次抛 n 枚）：基本事件总数  =  2n
  • 大白话：每次两个结果，n 次就是 n 个 2 相乘。
  • 用的时候：算概率时分母直接写 2n。
  • 记忆要点：每次 2 种，n 次 2n。
  • 出处：（苏州教研·专题25，原书p.109）
蒙特卡罗随机模拟：均匀随机数线性变换 Y  =  a + (b−a)X（X∈[0,1]）则 Y∈[a,b]
  • 大白话：把 [0,1] 上的均匀随机数缩放平移到 [a,b]；用"面积之比 = 质点数之比"估计面积或圆周率。
  • 用的时候：几何概型、随机模拟题里做区间变换。

复数

三次单位根 ω 的倍式：−1+√3 i  =  2ω，−1−√3 i  =  2ω̄，√3+i  =  −2iω，√3−i  =  2iω̄
  • 大白话：带 √3 的纯复数，常可凑成三次单位根 ω 的倍数，方便提公因式。
  • 用的时候：复数计算里出现这些数，认出是 ω 的倍式，乘除就变成指数运算。
  • 记忆要点：ω = (−1+√3 i)/2。
  • 出处：（苏州教研·专题53，原书p.184）
实数性质不可照搬到复数："任意数平方非负""|a|<|b| ⇒ a<b"在复数集不成立
  • 大白话：复数不能比大小，平方也可能是负数，实数集的老规矩别硬搬。
  • 用的时候：复数题里不写 a<b 这种大小关系，只算模、算实虚部。
  • 记忆要点：复数无大小，只比模。
  • 出处：（苏州教研·专题53，原书p.184）
