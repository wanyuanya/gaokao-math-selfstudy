## 〇、这套系统要解决什么

| 你吐槽的现状 | 本系统的解法 |
|---|---|
| 现在的教材东拼西凑，知识散乱 | 用**一条主线**串起全部内容：老教材讲"是什么、为什么"，新教材定"考什么、怎么考" |
| 课后作业、例题五花八门，深浅不一 | 每章统一模板：门槛自测 → 概念 → 方法卡 → 例题 → 分层练习，深浅由你控制 |
| 学习进度没有连续性，跳着学就卡住 | 8个阶段 + 每章前置门槛，学完一章才能解锁下一章，进度可自查 |
| 门槛太高，一步跟不上步步跟不上 | 每章开头给"门槛检测题"，过不了先补前置，不硬闯 |
| 老教材图文并茂、怕你看不懂，反而好懂 | **讲解主线用老教材**（2004课标版，讲得细、递进清楚），考试范围用新教材对齐 |

一句话：**用老教材学懂，用新教材对标，用真题验收。**

## 一、三层学习模型（每一章都按这个走）

```
第一层 概念层  看得懂   —— 用大白话 + 老教材图解理解定义、公式、图象
        ↓
第二层 方法层  会做题   —— 方法卡：拿到题先识别题型，再套固定步骤
        ↓
第三层 题战层  做得对   —— 教材例题 → 教材习题 → 真题分层（基础/中档/压轴）
```

学完一章的标准（出口检测）：**独立完成 1 道概念题 + 2 道中档题 + 1 道压轴题**，不再翻书。

## 二、全课程知识地图（9大板块）

高考数学全部内容归为 9 个板块，学完后你脑里就是这张图：

| # | 板块 | 新教材位置 | 老教材位置 | 高考分量（估算） |
|---|---|---|---|---|
| 1 | 集合、逻辑、不等式、复数 | 必修一§1-2 / 必修二§7 | 必修1、必修5 | ≈15分 |
| 2 | 函数（概念、性质、指对幂、三角函数） | 必修一§3-5 | 必修1、必修4 | ≈20分 |
| 3 | 导数及其应用 | 选必二§5 | 选修2-2 | ≈15-20分 |
| 4 | 数列 | 选必二§4 | 必修5 | ≈12-15分 |
| 5 | 平面向量 | 必修二§6 | 必修4 | ≈10分（多与三角/几何结合） |
| 6 | 立体几何与空间向量 | 必修二§8 / 选必一§1 | 必修2、选修2-1 | ≈20分 |
| 7 | 解析几何（直线圆、圆锥曲线） | 选必一§2-3 | 必修2、选修2-1 | ≈22-25分 |
| 8 | 概率与统计（计数原理、随机变量、统计） | 必修二§9-10 / 选必三 | 必修3、选修2-3 | ≈20分 |
| 9 | 数学建模与综合应用（新定义题） | 各章"探究"栏目 | 无对应 | 融入压轴（约10-17分） |

> 分量按 2020-2025 真题分布估算，每年略有浮动；解答题压轴通常落在**函数导数**与**解析几何**（轮流出新定义题）。

### 板块依赖关系（学之前必须已经会什么）

```
集合·不等式 ──→ 函数（定义域、值域要用不等式/集合）
函数 ──→ 导数（导数就是研究函数的工具）
三角 ──→ 解三角形、平面向量（向量用三角的坐标与角）
平面向量 ──→ 解析几何（向量工具）、立体几何（空间向量法）
数列（独立性强，但求和放缩常用不等式）   ← 可与函数导数并行学
立体几何基础 ──→ 空间向量建系法
计数原理 ──→ 概率统计
```

## 三、8 阶段连续进度表（主进度）

> 从零基础到高考，按周推进。每阶段有明确"出口"，过不了先复习，不赶进度。

| 阶段 | 名称 | 时间预算 | 学什么 | 出口检测（真题验证） |
|---|---|---|---|---|
| 0 | 初中衔接 | 2-3周 | 因式分解、一元二次方程与判别式、坐标系与一次函数、二次函数图象 | 能独立画二次函数图象并求最值 |
| 1 | 高一上：函数与不等式 | 14周 | 集合与逻辑、一元二次不等式、函数概念与性质、指对幂函数 | 用真题2020-2025中的集合/函数小题（第1-8题范围内） |
| 2 | 高一下：三角与向量 | 12周 | 三角函数、三角恒等变换、解三角形、平面向量 | 解答题第一道（三角/解三角形）能独立完成 |
| 3 | 高二上：数列与立体几何 | 12周 | 数列、立体几何初步、空间向量 | 数列解答题 + 立体几何解答题（建系法）能独立完成 |
| 4 | 高二下：解析几何与导数 | 14周 | 直线与圆、圆锥曲线、导数 | 解析几何解答题 + 导数解答题（第1-2问）能独立完成 |
| 5 | 高三一轮：概率统计收尾 | 10周 | 计数原理、随机变量分布、统计、复数、全体系串联 | 概率统计解答题 + 全卷限时模拟（90分钟） |
| 6 | 高三二轮：六大方法专题 | 8周 | 函数导数专题、三角向量专题、数列专题、立体几何专题、解析几何专题、概率统计专题 | 每专题压轴题独立完成 |
| 7 | 高三三轮：真题实战 | 6周 | 2020-2025新高考Ⅰ卷逐套限时训练 + 考前复盘 | 任意真题卷 ≥120分（目标分自定） |

> 若你已在校，把阶段对应到学期即可；若完全自学，阶段0-5约 1.5-2 年，留半年做二轮三轮。

## 四、每章统一学习模板（一章怎么学）

以任意一章为例（如"指数函数"）：

```
□ 门槛自测（5分钟）     —— 3道前置题，全对才继续（例：会不会算 2³×2⁴、画 y=x² 图象）
□ 概念理解（1-2天）     —— 老教材对应章节精读 + 新教材对照阅读，抄一遍定义与图象
□ 方法卡（1天）         —— 抄下本章"题型→步骤"方法卡（见第五节）
□ 例题跟练（2天）       —— 老教材例题逐题自己先做再看；错题标红
□ 分层练习（2天）       —— 基础题一批 + 中档题一批 + 压轴1题（从教材习题和新教材练习中选）
□ 出口检测（30分钟）    —— 1概念 + 2中档 + 1压轴，不翻书完成
```

**教材对照指引**：每章先在老教材找到对应节（老教材讲得细、有图），再回新教材看该节（新教材对应高考要求、例题更贴近新题型）。两本一起用，一章 = 老教材"学懂" + 新教材"对标"。

## 五、方法与公式索引（方法卡总表）

> 完整公式见《高中数学常用公式.pdf》；以下为"题型→方法"速查卡，配合方法手册使用。学完一章，从下表抄对应方法卡贴墙上。

### 板块1 集合·逻辑·不等式·复数
| 题型 | 方法 |
|---|---|
| 集合运算 | 数轴/韦恩图；注意空集、边界取等 |
| 充分必要条件 | 小范围 ⇒ 大范围；否定命题用"特例反证" |
| 一元二次不等式 | 因式分解→根→口诀"大于取两边，小于取中间" |
| 基本不等式 | 一正二定三相等；配凑常数、乘"1"法 |
| 复数 | 分母实数化；i⁴ⁿ 周期；共轭与模 |

### 板块2 函数
| 题型 | 方法 |
|---|---|
| 定义域 | 分母≠0、偶次根≥0、对数真数>0、底数>0且≠1 |
| 值域/最值 | 单调性法、换元法、判别式法、分离常数 |
| 单调性 | 定义法（作差变形）或求导；复合函数"同增异减" |
| 奇偶性 | 定义域对称 + f(-x) 与 f(x) 关系；奇×奇=偶等口诀 |
| 图象 | 平移/对称/翻折变换口诀；指对幂图象特征 |
| 零点 | 零点存在定理 + 单调性保证唯一；数形结合 |
| 指数对数 | 运算公式熟背；换底公式；比较大小用"中间值法" |

### 板块3 导数
| 题型 | 方法 |
|---|---|
| 切线 | 切点(x₀,f(x₀))处 f'(x₀)=斜率；过点求切线要设切点 |
| 单调区间 | 求导→f'(x)>0/<0 解不等式，注意定义域 |
| 极值最值 | 极值点：f'(x)变号；最值：极值+端点比较 |
| 恒成立/能成立 | 参变分离 → 求新函数最值；或分类讨论 |
| 零点个数 | 图象交点个数；单调性分段 + 端点符号 |
| 压轴技巧（选学） | 极值点偏移、同构、切线放缩（lnx≤x-1、eˣ≥x+1） |

### 板块4 数列
| 题型 | 方法 |
|---|---|
| 等差/等比判定 | 定义法（aₙ₊₁-aₙ=常数 / aₙ₊₁/aₙ=常数）；中项法 |
| 求通项 | 累加法/累乘法；Sₙ-Sₙ₋₁（n≥2）；构造等比（aₙ₊₁=paₙ+q） |
| 求和 | 公式法、错位相减（等差×等比）、裂项相消、分组求和 |
| 放缩证明 | 裂项放缩、等比放缩、先猜后证（数学归纳法） |

### 板块5 平面向量
| 题型 | 方法 |
|---|---|
| 坐标运算 | 建系→坐标化；模、夹角、垂直平行公式 |
| 数量积 | 定义式与坐标式；投影；几何意义 |
| 最值范围 | 极化恒等式、基底转化、坐标化 |
| 与三角结合 | 向量夹角=三角形内角；正弦定理面积公式联动 |

### 板块6 立体几何
| 题型 | 方法 |
|---|---|
| 平行垂直证明 | 线面平行：线线平行→线面平行；垂直：判定定理三件套 |
| 空间角/距离 | 首选建系法：建系→坐标→向量夹角公式 |
| 体积表面积 | 公式 + 等体积法（换顶点）；球：补形法/轴截面 |
| 动态问题 | 设参数→化为函数最值 |

### 板块7 解析几何
| 题型 | 方法 |
|---|---|
| 直线与圆 | 点到直线距离、圆心距与半径判别位置、切线弦长 |
| 圆锥曲线定义 | 椭圆/双曲线/抛物线第一定义 + 焦点弦性质 |
| 联立韦达 | 直线代入曲线→韦达→弦长/面积公式 |
| 中点弦 | 点差法 |
| 定点定值 | 先猜后证；设而不求 |
| 范围最值 | 判别式法/参数范围/函数最值 |
| 离心率 | 定义式 c/a + 几何条件化 |

### 板块8 概率统计
| 题型 | 方法 |
|---|---|
| 排列组合 | 分类分步；特殊元素优先；插空/捆绑；隔板法 |
| 二项式定理 | 通项 T_{k+1}；系数与二项式系数区分 |
| 概率计算 | 古典概型计数；条件概率；全概率公式；独立事件 |
| 分布列 | 二项分布 B(n,p)、超几何分布、正态分布；期望方差公式 |
| 统计 | 频率分布直方图、回归直线、独立性检验（卡方） |

### 板块9 新定义/综合（压轴）
| 题型 | 方法 |
|---|---|
| 新定义题 | 先读懂定义（翻译成大白话）→ 套定义验证简单情形 → 归纳规律 |
| 跨板块综合 | 识别主板块（通常是函数/数列/解析几何）→ 拆成小题逐个击破 |

## 六、真题对标（学到哪、做哪题）

**解答题五道常规布局（近6年稳定）**：三角/数列 → 立体几何 → 概率统计 → 解析几何 → 函数导数（或新定义压轴）。对应到进度表：
- 学完阶段2 → 练"三角/数列类"解答题
- 学完阶段3 → 练"立体几何类"解答题
- 学完阶段4 → 练"解析几何、导数类"解答题
- 学完阶段5 → 完整限时做真题卷

**小题（选择填空）覆盖全部板块**：学完一个板块，就把 2020-2025 六套卷中该板块的小题全找出来做一遍（真题PDF在手，按板块检索即可）。

> 具体到每年每题的板块归属，以你手头真题PDF为准（试卷开头选择题1-8常为集合、复数、函数、三角、向量、数列、立体几何、解析几何的基础题；多选题与填空分布逻辑题、导数、概率等）。

## 七、每周学习节奏与自检

```
每周（6天 × 1~1.5小时）：
  第1-3天  新学（概念 + 方法卡 + 例题）
  第4天    复练（重做本周错题）
  第5天    真题（本阶段对应板块真题 2-3 题）
  第6天    小结（整理方法卡 + 错题本 + 周出口自测）
  周日     休息 / 补缺
```

**错题本四栏法**：抄题 → 我错在哪（一句话）→ 正确方法 → 同类题重做日期。每周日重做本周错题，全对才算清空。

**进度看板**：打印第五节"方法卡总表"，每掌握一个方法卡打勾；一张表就是你的整个复习地图。

## 八、素材使用指南（对接 book-to-skill / cangjie-skill）

你已确认技能由你自行安装使用，以下是喂料建议：

1. **喂什么**：优先喂结构化、文本可提取的 PDF —— 教材5册 + 老教材（讲解最系统）+ 方法手册 + 课程标准 + 真题（真题文本已含公式）。
2. **按什么顺序**：先喂**老教材必修1-5**（建立完整知识骨架），再喂**新教材5册**（对齐高考范围），最后喂**方法手册+课程标准+真题**（补充方法与验收标准）。
3. **建议切分**：一次喂一册或一个板块，避免单次输入过大导致蒸馏失真；每个技能产物命名建议带板块名（如 `gaokao-math-functions`）。
4. **蒸馏产物定位**：让生成的技能"讲解概念"用老教材语言（图文并茂、循序渐进），"出题验收"用真题风格（新高考题型）。
5. **版权提醒**：教材为版权内容，蒸馏产物仅供个人自用，勿公开分发（book-to-skill 的发布流程对第三方版权书籍默认要求私有仓库）。
