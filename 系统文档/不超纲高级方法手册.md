## 一、函数与导数（压轴主战场，约占高考压轴70%）

### 1.1 同构思想 —— 把"两个变量"变"一个函数"
**适用信号**：不等式或方程两侧结构一模一样，只是变量不同（如 x·eˣ 与 lnx·x 同型、x+lnx 与 eˣ+x 同型）。
**操作步骤**：
1. 把式子变形，让两侧都长成 f(外层) 和 f(内层) 的形式；
2. 判断 f 的单调性（先求导确认）；
3. 由 f(A) ≤ f(B) 且 f 单调 → 推出 A ≤ B（单调增）或 A ≥ B（单调减），把超越式化成普通式。
**常用同构模板**：x·eˣ ↔ lnx·x（即 x·eˣ = e^(x+lnx)，与 x+lnx 同构）；x/eˣ ↔ lnx/x；x-lnx ↔ eˣ-x。
**例题**：2022新高考Ⅰ卷第22题、第7题（0.1e^0.1 与 ln0.9 比较大小，同构+放缩）。配套讲义《2022新高考I卷函数压轴多角度解析_同构》。
**课标依据**：函数单调性定义与复合函数单调性（必修一第三章）。✓ 不超纲。
**注意**：同构的关键是"脱壳"后别忘定义域；构造失败就换另一个同构式。

### 1.2 极值点偏移 —— 压轴出现率最高的一类
**适用信号**：f(x₁)=f(x₂)，x₀ 是极值点，要证 x₁+x₂ > 或 < 2x₀（或 x₁x₂ 与 x₀² 比大小）。
**操作步骤（对称化构造法）**：
1. 不妨设 x₁<x₀<x₂；
2. 构造函数 F(x)=f(x)-f(2x₀-x)（把 x₂ 对称到 2x₀-x₂ 一侧）；
3. 证明 F(x) 在 (x₁,x₀) 定号（求导），推出 f(x₁) 与 f(2x₀-x₂) 的大小关系；
4. 利用 f(x₁)=f(x₂) 与单调性，得出 x₂ 与 2x₀-x₁ 的关系 → 结论。
**变体**：比值代换法（令 t=x₁/x₂，把双变量化成单变量 t），适用于对称化做不动的题。
**例题**：2022新高考Ⅰ卷压轴（导数双零点）。配套《导数综合讲义_极值点偏移隐零点凹凸反转》第10.8讲、《极值点偏移与拐点偏移讲义》见素材清单链接。
**课标依据**：导数与极值最值（选必二第五章）。✓ 不超纲。
**注意**：极值点偏移本质是"图象不对称"，先画草图判断偏向哪边再选证法。

### 1.3 隐零点 —— "设而不求"的巅峰应用
**适用信号**：求导后 f'(x)=0 的根解不出来，但知道它存在（零点存在定理）。
**操作步骤**：
1. 设隐零点 x₀（x₀ 满足 f'(x₀)=0，写"由零点存在定理，存在唯一 x₀∈(a,b) 使 f'(x₀)=0"）；
2. 把 f'(x₀)=0 这个等式**反代回原函数**（消掉 eˣ 或 lnx 项，把超越式化成代数式）；
3. 研究 F(x₀)（原函数在极值点取值）时，利用第2步的等式化简；
4. 估值时用放缩（见1.4）夹出 x₀ 的范围。
**课标依据**：零点存在定理+导数（必修一第四章、选必二第五章）。✓ 不超纲。
**例题**：历年导数恒成立压轴（如"求 a 使 f(x)≥0 恒成立，其中 f 含 eˣ、lnx 且不可解"）。配套《隐零点的替代以及放缩法(北京考试报)》。
**注意**：隐零点的核心是"等式代换"，不是真的求出 x₀。

### 1.4 切线放缩（超越不等式族）—— 比较大小与证明的利器
**核心不等式（先背会，用前能证）**：
- eˣ ≥ x+1（x=0 取等）→ 变式：eˣ ≥ ex（x=1 取等）、eˣ ≥ 1+x+x²/2（x≥0）
- lnx ≤ x-1（x=1 取等）→ 变式：lnx ≤ x/e（x=e 取等）、1-1/x ≤ lnx（x=1 取等）、ln(1+x) ≤ x
**适用信号**：含 eˣ、lnx 的不等式证明、比较大小、隐零点估值、恒成立求参。
**操作步骤**：
1. 识别超越项（eˣ、lnx、xˣ 等）；
2. 用放缩把它"砍"成多项式/简单式（eˣ → x+1，lnx → x-1）；
3. 砍完后解普通不等式；若放缩过松（太粗），换更紧的放缩（如 eˣ ≥ 1+x+x²/2）。
**例题**：2022新高考Ⅰ卷第7题比较 a=0.1e^0.1、b=1/9、c=-ln0.9：放缩 e^0.1>1.1? 或 0.1e^0.1 与 1/9——答案 c<a<b。配套《函数比较大小_切线放缩(gdedu)》、《导数证明不等式策略_切线放缩(oajrc)》。
**课标依据**：切线是导数的几何意义（选必二），不等式可用导数证明。✓ 不超纲（但要写证明）。
**红线**：**在答题卡上直接用"lnx≤x-1"当已知结论而不证明，可能被扣过程分**；务必用一句"（可由导数证明）"或当场证一遍（构造 g(x)=lnx-x+1 求导）。

### 1.5 必要性探路（端点效应）—— 恒成立求参的"先猜后证"
**适用信号**：恒成立求参数范围（f(x)≥0 对 x∈D 恒成立，求 a）。
**操作步骤**：
1. **必要性**：取特殊点（通常是端点或极限点）代入，得到 a 的必要范围（如取 x=0 得 a≥2）；
2. **充分性**：证明 a 取该范围时确实恒成立（放缩/最值法）；
3. 合并得答案。
**选学·验证用**：洛必达法则（lim 型极限）可直接算出端点极限得到临界值——**超纲**，只用于"猜答案"，大题证明仍走第2步。
**例题**：2022新高考Ⅰ卷压轴第2问（a 的最小值问题，先猜 a=2 再证）。
**课标依据**：不等式恒成立转化为最值（选必二）。✓ 不超纲。
**注意**：取点要"够用"，一次取不到就多取几个特值缩小范围。

### 1.6 双变量问题
**适用信号**：x₁、x₂ 两个变量同时出现（零点、切线、极值相关问题）。
**三种主流操作**：
- **主元法**：固定 x₁，把 x₂ 看成 x₁ 的函数/变量，单变量化；
- **比值换元**：令 t=x₁/x₂（或 x₂/x₁），全部用 t 表示；
- **和积换元**：令 u=x₁+x₂、v=x₁·x₂，用 u、v 消元（常配合极值点偏移）。
**课标依据**：函数与导数综合。✓ 不超纲。

### 1.7 小题：比较大小的构造模型速查
- f(x) 与 x 的关系：出现 xf'(x)-f(x) → 构造 F=f(x)/x；出现 xf'(x)+f(x) → F=x·f(x)
- f(x) 与 eˣ：f'(x)-f(x) → F=f(x)/eˣ；f'(x)+f(x) → F=f(x)·eˣ
- 大小比较：先看能否用中间值（0、1、e、1/2），再看能否构造同型函数，最后放缩/泰勒近似（选学·验证用）。
**例题**：2022新高考Ⅰ卷第7题；2023新高考Ⅰ卷比较大小题。

## 二、解析几何（压轴第二主战场）

### 2.1 齐次化 —— 斜率之和/积问题的"降计算"神技
**适用信号**：题目涉及从同一点 P 出发的两条直线，求/证 k₁+k₂ 或 k₁·k₂ 为定值。
**操作步骤**：
1. 若 P 不在原点，先**平移坐标系**（把 P 移到原点；曲线方程同步平移）；
2. 直线写成 mx+ny=1 的形式（过原点的直线）；
3. 联立曲线方程，把一次项乘 (mx+ny)，常数项乘 (mx+ny)²，凑成关于 (y/x) 的齐次方程；
4. 令 t=y/x（即斜率 k），得一元二次方程，k₁+k₂、k₁·k₂ 直接由韦达定理给出——无需联立消元算到底。
**例题**：2024年新高考多套卷"过定点 P 的两条直线斜率之积为定值"类题。配套《齐次化妙解圆锥曲线(zizzs)》46页详解。
**课标依据**：直线与圆锥曲线位置关系（选必一）、韦达定理。✓ 不超纲（属于计算技巧，非新知识）。
**注意**：平移后要记得"还原"结论；斜率不存在的情形单独讨论。

### 2.2 点差法 —— 中点弦与第三定义
**适用信号**：弦的中点已知/要求中点；两交点与中心（原点）连线斜率关系。
**操作步骤（中点弦）**：
1. 设交点 A(x₁,y₁)、B(x₂,y₂)，代入曲线方程；
2. 两式相减，因式分解出 (x₁-x₂) 与 (y₁-y₂)；
3. 除以 (x₁-x₂)，得到弦斜率 k 与中点坐标 (x₀,y₀) 的关系（椭圆：k·(y₀/x₀) = -b²/a² 型）。
**第三定义（可直接用的小题结论）**：椭圆上两点与中心连线的斜率之积 = -b²/a²；双曲线 = b²/a²；圆 = -1。
**课标依据**：曲线方程、斜率公式。✓ 不超纲。
**注意**：点差法结果只给"关系"，代入验证是否满足判别式 Δ>0 是惯例步骤。

### 2.3 二级结论速查表（小题直接用、大题可快速推导）
| 板块 | 结论 |
|---|---|
| 椭圆 | 通径长 2b²/a；焦点三角形面积 S=b²·tan(θ/2)（θ为两焦点半径夹角）；焦半径 r₁=a+ex₀、r₂=a-ex₀ |
| 双曲线 | 焦点三角形面积 S=b²·cot(θ/2)；渐近线 y=±(b/a)x |
| 抛物线 y²=2px | 焦点弦 AB：x₁x₂=p²/4、y₁y₂=-p²；弦长 |AB|=2p/sin²α（α为倾斜角）；以焦点弦为直径的圆与准线相切 |
| 通法 | 过圆锥曲线焦点的弦，焦点弦两端点"焦半径+准线距离"互换 |

**课标依据**：均为定义、方程、焦半径定义的直接推论。大题中直接使用建议加一句推导。
**选学·验证用**：极点极线理论（可"秒杀"定点定值问题，超纲，只用来猜答案与检验）。

### 2.4 设而不求的整体操作规范
- **设直线**：过定点 (m,0) 设 x=ty+m（避免讨论斜率不存在；t 为斜率的倒数）；一般直线 y=kx+b。
- **联立消元**：消 y 得关于 x 的二次方程 → 判别式 Δ>0、韦达 x₁+x₂、x₁x₂。
- **整体代换**：弦长 |AB|=√(1+k²)·√((x₁+x₂)²-4x₁x₂)；面积 S=½·|AB|·d（点到直线距离）；向量 OA·OB=x₁x₂+y₁y₂。
- **目标导向**：把要求证的式子全部用 x₁+x₂、x₁x₂、k 表示，别中途解出 x 的值。

## 三、数列（压轴常客，方法最"套路化"）

### 3.1 递推求通项——三大构造模板
| 递推形式 | 方法 |
|---|---|
| aₙ₊₁ = p·aₙ + q | 构造 aₙ₊₁+c = p(aₙ+c)，c=q/(p-1)，转等比 |
| aₙ₊₁ = p·aₙ + f(n) | 累加/待定系数（两边同除 pⁿ⁺¹ 转累加） |
| aₙ₊₂ = p·aₙ₊₁ + q·aₙ | **特征根法**：解 x²=px+q，两根 α≠β 则 aₙ=Aαⁿ+Bβⁿ；α=β 则 aₙ=(A+Bn)αⁿ，A、B 由 a₁、a₂ 定 |
| aₙ₊₁ = (paₙ+q)/(raₙ+s) | **不动点法**：解 x=(px+q)/(rx+s)，两根 α≠β 则 (aₙ-α)/(aₙ-β) 成等比 |
| aₙ₊₁ = aₙ + g(aₙ)（特殊） | 先猜后证 + 数学归纳法 |

**课标依据**：等差等比定义、递推（选必二第四章）。特征根/不动点的**结论**教材未直接给出，解答时建议：先"观察+猜想"，再用数学归纳法证明（完全课标内）；或写出结论并注明可验证。
**注意**：特征根法结论可以直接用于**小题**（填空选择），解答题用它算出答案后补归纳法证明最稳妥。

### 3.2 错位相减"免计算"公式（自检神器）
等差×等比求和 Sₙ 的结果必能写成 **Sₙ=(An+B)·qⁿ - B** 的形式。
用法：先随便算 S₁、S₂，反解 A、B，直接写出 Sₙ——再用普通错位相减法验证一遍（或用 n=1、2 代入验证）。
**课标依据**：错位相减（选必二）。✓ 公式形态是推导的必然结果，非新知识。

### 3.3 裂项放缩库
- 1/(n(n+1)) = 1/n - 1/(n+1)；1/(n(n+2)) = ½(1/n - 1/(n+2))
- 1/n² < 1/(n(n-1)) = 1/(n-1) - 1/n（n≥2）
- 1/√n = 2/(√n+√n) < 2/(√n+√(n-1)) = 2(√n-√(n-1))（分母有理化）
- 2ⁿ/(2ⁿ-1)² < 1/(2ⁿ-1) - 1/(2ⁿ⁺¹-1)
**用法**：要证 Tₙ < 某个值，先把目标值"拆"成可裂项的形式，再反向选择放缩——**目标驱动**，不是碰运气。

### 3.4 数列不等式证明流程
1. 先求 Tₙ 或放缩后的和（明确目标常数 C）；
2. 选择裂项/等比放缩使和式恰好 ≤ C；
3. 首项不符时"从第二项起放缩"（保留前几项精确值）；
4. 证明单调性后再放缩（若 Tₙ 递增，只需证 Tₙ 的上界）。

## 四、不等式（跨板块工具）

### 4.1 基本不等式"三件套"技巧
- **1的代换**：已知 x+y=1，求 1/x+1/y 最小 → 乘 (x+y)；
- **和积转化**：已知 x+y=S、xy=P 的关系，用 S²≥4P 搭桥；
- **换元化齐次**：a/b 型的式子令 t=a/b 消元。
**课标依据**：基本不等式（必修一第二章）。✓

### 4.2 绝对值三角不等式
||a|-|b|| ≤ |a±b| ≤ |a|+|b|。用于含绝对值函数的最值、恒成立问题（比分类讨论快）。
**课标依据**：选修（新教材选必一"不等式选讲"已删，但绝对值性质属必修基础；小题可用，大题若用需一句话说明）。

### 4.3 切线不等式族（与1.4联动）
lnx≤x-1、eˣ≥x+1、sinx≤x（x≥0）等——证明题里"构造差函数求导"即可证，全部课标内。

### 4.4 选学·验证用（超纲标注）
柯西不等式、琴生不等式、排序不等式——仅用于小题秒杀或验证，**不在答题卡上直接引用**。

## 五、三角与解三角形

### 5.1 辅助角公式（合一变形）
asinx + bcosx = √(a²+b²)·sin(x+φ)，其中 tanφ=b/a。
用于求最值、周期、单调区间；求最值时直接看振幅。
**课标依据**：两角和差公式逆用（必修一）。✓

### 5.2 解三角形"隐藏公式"速查
- **射影定理**：a=bcosC+ccosB（可秒解"边角关系"题）；
- **中线长**：mₐ² = (2b²+2c²-a²)/4（向量或余弦定理推）；
- **角平分线**：BD/DC = AB/AC；角平分线长 l² = bc[1-(a²/(b+c)²)]（选学）；
- **面积**：S=½absinC；海伦公式（选学）。
**课标依据**：正弦余弦定理（必修二）。✓

### 5.3 三角形最值套路
1. 边角互换（正弦定理把边换成角）；
2. 统一成单变量（一角）；
3. 辅助角/基本不等式/二次函数求最值。
经典：周长最值（边角互换后辅助角）、面积最值（基本不等式）。

## 六、概率统计（新高考压轴新贵）

### 6.1 条件概率与全概率（新教材已入教材，务必熟练）
P(A|B)=P(AB)/P(B)；全概率 P(A)=ΣP(Bᵢ)P(A|Bᵢ)。用于"多阶段随机过程"题。

### 6.2 期望的线性性
E(aX+bY+c)=aE(X)+bE(Y)+c；E(X+Y)=E(X)+E(Y)（不要求独立）。
用于"求期望不用列全分布列"的题（如多个随机变量的和）。

### 6.3 递推思想（马尔可夫链模型）—— 近两年高考压轴热点
**适用信号**：有状态转移的过程（传球、抽球、传染、走格），问"第 n 步处于某状态的概率"。
**操作步骤**：
1. 设 Pₙ = 第 n 步处于目标状态的概率；
2. 找转移关系：Pₙ = f(Pₙ₋₁)（由第 n-1 步的状态转移而来）；
3. 得到一阶递推，用"构造等比"解出 Pₙ 通项（联动3.1方法）；
4. 再求期望等。
**例题**：2023年新高考（各省联考/真题的传球模型）；配套讲义见《导数综合讲义》第10.10讲前的概率专题或素材清单中二轮概率讲义链接。
**课标依据**：条件概率+递推数列（选必二、选必三）。✓ 不超纲——这正是"数列与概率交叉"的高考热点。

### 6.4 分布模型公式速记
二项分布 B(n,p)：E=np、D=np(1-p)；超几何（不放回抽取）：E=nM/N；正态：对称性、3σ原则。均值方差公式熟背，压轴问"方差大小比较"常用"方差刻画波动"直觉+公式。

## 七、立体几何

### 7.1 空间向量建系法（选必一，大题主力）
流程：建系（优先找三条两两垂直的线）→ 写坐标 → 求法向量（叉积或解方程）→ 套公式：
- 线面角：sinθ = |cos<n,v>|；二面角：cosθ = |cos<n₁,n₂>|（注意锐钝判断）；点到面距离 d=|PA·n|/|n|。
**课标依据**：空间向量（选必一）。✓
**注意**：二面角锐钝判断靠"观察法向量方向"，别丢符号。

### 7.2 外接球"补形模型"速查
| 几何体 | 模型 | 半径 |
|---|---|---|
| 长方体/墙角三棱锥 | 补成长方体 | R=½√(a²+b²+c²) |
| 正四面体边长 a | 内嵌正方体 | R=a√6/4 |
| 直棱柱底面外接圆半径 r | 轴截面 | R²=r²+(h/2)² |
| 对棱相等三棱锥 | 补成长方体 | 同上 |
**课标依据**：球的表面积体积+长方体对角线（必修二）。✓

### 7.3 等体积法
换顶点求高/体积（三棱锥），避免建系算距离的繁琐；截面问题画"过已知点的截面"按"延长交棱"操作。
