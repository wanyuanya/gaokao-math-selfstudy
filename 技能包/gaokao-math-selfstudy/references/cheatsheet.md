# 决策规则速查 — 高中数学自学系统（新高考Ⅰ卷）

| 能力 | 一句话规则 |
|---|---|
| 自学进度规划 | 先定位第一个过不去的阶段，再按该阶段任务+每周节奏生成周计划 |
| 单章学习执行 | 门槛自测→概念理解→方法卡→例题跟练→分层练习→出口检测，任一环节不过不进入下一章 |
| 压轴题方法选择 | 先识别板块与题型信号，再查方法卡，按步骤执行并做红线检查 |
| 超纲判定 | 查课标依据→查"选学·验证用"红线→按题型分流，超纲结论只用于小题与验证 |
| 公式速查 | 按 15 板块匹配公式，输出公式本体+变量+适用条件+使用红线 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
