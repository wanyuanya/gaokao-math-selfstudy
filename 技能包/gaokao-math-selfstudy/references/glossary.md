# GLOSSARY — 高中数学自学系统共享术语词典

> 阶段 3 产出。全书共享术语；下游所有能力卡以本词典为术语基准，不使用字典义。

| 术语 | 本书用法 | 与常识/字典义差异 | 下游能力 |
|---|---|---|---|
| 同构 | 不等式/方程两侧结构相同，构造 f(外层)/f(内层) 用单调性"脱壳" | ≠ 换元变形；要求两侧是同一函数 f 作用不同内层 | method-select |
| 极值点偏移 | f(x₁)=f(x₂) 但零点关于极值点不对称，证 x₁+x₂ 与 2x₀ 大小 | ≠ 普通对称；需构造对称差函数判符号 | method-select |
| 隐零点 | f'(x)=0 的根解不出但存在，设 x₀ 后用等式代换 | ≠ 零点不存在；设而不求 | method-select |
| 切线放缩 | 切线不等式 lnx≤x-1、eˣ≥x+1、sinx≤x（x≥0），构造差函数求导可证 | ≠ 超纲；实为课标内可直接用 | method-select / boundary-check |
| 齐次化 | 平移坐标系把斜率和/积问题凑成齐次方程，韦达直接出结论 | ≠ 普通联立；计算技巧非新知识 | method-select |
| 点差法 | 设点作差建立弦中点与斜率关系，不解交点 | ≠ 解交点；需验 Δ 与斜率存在性 | method-select |
| 必要性探路 | 恒成立题先代端点/临界值缩参数范围，再证充分 | ≠ 分类讨论硬解 | method-select |
| 特征根法 | aₙ₊₂=paₙ₊₁+qaₙ 解 x²=px+q 得通项 | 结论教材未直接给出；小题可用、大题需补证 | method-select / boundary-check |
| 不动点法 | 分式递推解 x=(px+q)/(rx+s)，两根时 (aₙ-α)/(aₙ-β) 成等比 | 同上，结论可用大题需证明 | method-select |
| 马尔可夫链递推 | 状态转移过程（传球/抽球/传染/走格）设 Pₙ=f(Pₙ₋₁) 解一阶递推 | ≠ 古典概型枚举；数列×概率交叉热点 | method-select |
| 选学·验证用 | 超纲项标记，只用于猜答案与检验，不上答题卡 | 使用边界由课标依据决定 | boundary-check |
| 出口检测 | 一章学完标准：不翻书完成 1 概念+2 中档+1 压轴 | ≠ 单元测验；过关才解锁下一章 | study-plan / chapter-flow |
| 方法卡 | "题型→步骤"速查条目，掌握一条打勾一条 | ≠ 笔记；照做的操作卡 | study-plan / chapter-flow / method-select |
| 门槛自测 | 每章 3 道前置题全对才继续 | 防断层机制 | chapter-flow |
