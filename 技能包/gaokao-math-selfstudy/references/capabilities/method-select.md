# 压轴题方法选择（method-select）

## R — Reading（原文）

> "方法以'题型→方法'速查卡配合方法手册使用。学完一章，从下表抄对应方法卡贴墙上。"
> ——《高中数学自学系统.md》五、方法与公式索引
>
> "方法手册每条方法按'适用信号→操作步骤→例题→课标依据→红线'组织。拿到题先识别题型，再套固定步骤。"
> ——《不超纲高级方法手册.md》前言与各章

## I — Interpretation（自述）

遇到题目先判定所属板块与题型信号，再查该板块方法卡选择匹配方法，按步骤执行，最后做红线检查。方法库覆盖八大板块：函数导数（同构、极值点偏移、隐零点、切线放缩、必要性探路、凹凸反转等）、解析几何（齐次化、点差法、定比点差、二级结论）、数列（构造等比、特征根、不动点、错位相减自检、裂项放缩）、不等式（1代换、切线不等式族）、三角解三角形（辅助角、射影定理、最值套路）、概率统计（条件概率、期望线性性、马尔可夫递推）、立体几何（建系法、补形法、等体积法）、通用应试（特殊值、端点验证、数形结合、先猜后证）。选择逻辑=识别题型（板块+信号）→ 查方法卡 → 按步骤执行 → 红线检查（是否超纲、条件是否满足）。

## A1 — Application Example（书中案例）

**worked_example（来自方法手册·1.3/1.4，2022 新高考Ⅰ卷函数压轴）**：题目含"比较大小"与"函数零点+不等式"信号 → 识别为导数板块 → 方法卡命中"切线放缩（lnx≤x-1、eˣ≥x+1，构造差函数求导可证，课标内）"与"同构（两侧构造同形函数，用单调性脱壳）" → 执行：比较大小题构造差函数或用切线不等式放缩；压轴题同构后由单调性比较内层 → 红线检查：切线放缩课标内可直接用；同构注意定义域。真题采用上述方法可解（完整解答见《2022新高考I卷函数压轴多角度解析》讲义）。素材未附完整题面。
**信号映射（2022 年真题显式化）**："两零点 x₁、x₂" → 首选极值点偏移路径（对称差函数 F(x)=f(x)-f(2x₀-x) 判 x₁+x₂ 与 2x₀ 大小；大题需构造差函数并讨论单调性，结论可小题直接用）；"零点+恒成立/求参数范围" → 隐零点代换或必要性探路；"比较大小" → 切线放缩族。信号→方法映射在 18 卡索引中逐条可查。

## A2 — Future Trigger（何时用）

**用户会在什么情境下遇到这类问题？**
1. 做题卡住，问"这道题用什么方法/怎么入手"
2. 备考二轮，问"导数压轴有哪些方法""圆锥曲线定点定值怎么做"
3. 学完一章，问"这一板块有哪些方法"
4. 考前突击，问"高考压轴常考哪些方法"

**语言信号**：这题怎么做/用什么方法/压轴/同构/偏移/隐零点/齐次化/点差法/放缩/建系/马尔可夫/方法卡/怎么入手；"which method / how to solve / derivative trick / conic shortcut"

**与相邻能力区分**：本卡管"选什么方法+步骤执行"；boundary-check 管"方法能不能在大题用"（近邻负例：用户问'超纲吗'→ boundary-check；问'用什么'→ 本卡）；formula-lookup 管"查公式"；study-plan/chapter-flow 管学习进度。

## E — Execution（可执行步骤）

**输入契约**：题目文本（必填）；可选：题目所属板块判断、是否大题/小题。

**步骤**：
1. 识别板块与题型信号：按题面特征归入八大板块之一，记录信号词（如"两零点""恒成立""过定点斜率积""第n次传球"）→ 完成标准：输出板块名+信号列表；无法归入任何板块→提示用户补充题目信息（不静默猜）。
2. 查方法卡：在本卡方法索引中匹配候选方法（见下），命中 1-3 条 → 完成标准：输出候选方法名+适用信号核对。
3. 执行：按方法步骤操作（如同构：构造 f→判单调→脱壳；齐次化：平移→联立→韦达）→ 完成标准：得到结果或明确卡点（卡点→换候选方法）。
4. 红线检查：查该方法的课标依据；带"选学·验证用"标记的方法在大题中禁止直接引用 → 完成标准：输出红线判定（可/不可，替代方案）。
5. 判停点：方法执行后结果与题目要求矛盾（如放缩方向反、Δ<0）→ 回到步骤 2 换方法，并对照反例清单排查。

**方法索引（18 卡）**：
- 导数：同构（两侧同形→单调脱壳）；极值点偏移（对称差函数判 x₁+x₂ 与 2x₀）；隐零点（设 x₀ 等式代换）；切线放缩（lnx≤x-1、eˣ≥x+1）；必要性探路（端点缩范围再证充分）；凹凸反转/双变量消元（讲义扩展）
- 解析几何：齐次化（平移系凑齐次方程）；点差法（弦中点）；二级结论（焦点三角形/通径/焦半径）；定点定值（先猜后证+设而不求）
- 数列：构造等比（aₙ₊₁=paₙ+q）；特征根/不动点（结论可用，大题补证）；错位相减自检（Sₙ=(An+B)qⁿ-B）；目标驱动放缩
- 三角：辅助角合一；射影定理/中线长；最值三步（边角互换→单变量→求最值）
- 概率：条件概率/全概率；期望线性性；马尔可夫递推（Pₙ=f(Pₙ₋₁)）
- 立体：建系法（坐标+法向量）；补形法（外接球）；等体积法
- 通用：特殊值排除、端点验证、数形结合、先猜后证

**输出契约**：板块+题型信号、选中方法+适用性核对、执行结果、红线判定与替代方案。

## B — Boundary（边界）

**不要用**：用户问的是概念理解或章节学习（→ chapter-flow）；用户问公式（→ formula-lookup）；用户问"是否超纲"（→ boundary-check）；用户只需直接答案的简单计算题（无需路由，直接算）。

**书中警告的失败模式**：无脑套模板不识别题型（ce09）——先识别信号再选方法；同构忘定义域（ce02）、联立忘验 Δ（ce03）、放缩方向反（ce04）、二面角丢符号（ce05）、错位相减算错（ce06，用自检公式）、特殊值当证明（ce07）、二级结论误用（ce08）；方法执行后必须做红线检查。
