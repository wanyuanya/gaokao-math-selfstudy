# 高中数学自学系统（新高考Ⅰ卷）

> 一套人人看得懂、门槛清晰、进度连续的高中数学自学系统。
> 用**老教材学懂**（2004 课标版图文并茂、讲得细），用**新教材对标**（人教A版2019，新高考Ⅰ卷考点范围），用**真题验收**（2020–2025 新高考Ⅰ卷）。

## 快速开始

1. 打开 `电子书\高中数学自学系统电子版.html` —— 19 章 + 导读的单文件电子书，浏览器直接看，带全文搜索、字号调节、衬线/黑体切换、夜读模式。
2. 按 00 章导读的"六步闭环"学每一章：**门槛自测 → 学习目标 → 正文讲解 → A/B/C 分层习题 → 公式速查 → 高级方法 → 答案**。
3. 不会做/看不懂？每章顶部有配套资料直达 + "看不懂怎么办"指引。
4. 想让 AI 助手按同一套方法答疑/出题？安装 `技能包\gaokao-math-selfstudy\`（见 `系统文档\技能包安装说明.md`）。

## 学习方法（一句话）

**一条主线**：19 章按依赖关系排好，每章告诉你"学之前必须会什么、学完能干什么、怎么证明过关"。
**门槛控制**：每章入口有门槛自测（不过关先补前置），出口有检测（过关才解锁下一章）。
**三层递进**：看得懂（老教材图解）→ 会做题（方法卡）→ 做得对（真题分层）。
