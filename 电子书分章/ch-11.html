本章本质核心：数列的本质是"按规则一个接一个排下去的一列数"——它就是定义在正整数上的函数 an = f(n)。等差（相邻两项差固定）和等比（相邻两项比固定）是最简单的两种规则；本章所有内容（通项公式、前 n 项和 Sn、由 Sn 求 an、裂项/错位相减求和、由递推求通项、放缩证不等式），都是围绕"规则与项的关系"展开的变体。

为什么有用想通"数列是定义在正整数上的函数、规则决定一切"，等差等比的通项求和、由 Sn 求 an、递推构造就都能现场推；高考固定的数列解答题第二题，套路就是定规则、求基本量、再求和或放缩，想通原理比死记公式稳。

3.1 数列的概念

引入：你每月往银行存一笔钱，本息按月份滚存下来，第 1 个月 100、第 2 个月 101、第 3 个月 102.01……这就是一列"按月份排好的数"。古印度那个著名的兔子问题——一对兔子每月生一对、新生兔子下月又开始生——数出来也是一串数：1，1，2，3，5，8，13……（斐波那契数列）。生活里只要"按次序一个个数下去"，背后就是数列。

定义：按照一定次序排列的一列数叫做数列，记作 a1，a2，a3，…，an，…。其中 an 叫这个数列的第 n 项（也叫通项）。如果第 n 项和 n 之间能用一个式子 an = f(n) 写出来，这个式子就叫通项公式。

注意两件事：

  1. 数列的"项数 n"只能取正整数 1，2，3，…，所以它其实是一个定义在正整数上的函数 an = f(n)。
  2. "次序"很重要：1，2，3 和 3，2，1 是两个不同的数列。

直观理解：把 (n, an) 当成点画在坐标系里，数列就是一堆"排成一列、横坐标跳着走"的散点——不会连成一条连续曲线，因为 n 只能取整数。后面 3.2、3.3 你会看到：等差的点排在一条直线上，等比的点趴在一条指数曲线上。

Sn 与 an 的关系（必背，大题第一步）：前 n 项和 Sn  =  a1+a2+…+an。那么：

  • 当 n = 1 时，a1  =  S1；
  • 当 n≥2 时，an  =  Sn − Sn−1。

道理很朴素：Sn 是前 n 项加起来，Sn−1 是前 n−1 项加起来，一减就只剩第 n 项。但 n = 1 时 S0 没定义，所以第一段必须单独验。

计算流程（已知 Sn 求 an）：

  1. 先写 n = 1：a1  =  S1；
  2. 再写 n≥2：an  =  Sn − Sn−1；
  3. 把 n = 1 代进第 2 步的式子检验：能对上，就合并成一个式子；对不上，就分段写。

例题跟讲例题：已知数列前 n 项和 Sn  =  n2+n，求通项 an。 解：n = 1 时 a1 = S1 = 2。n≥2 时 an = Sn−Sn−1 = (n2+n)−[(n−1)2+(n−1)] = n2+n−(n2−n) = 2n。把 n = 1 代入 2n 得 2，正好等于 a1，所以合起来 an = 2n。

小结：数列就是"编号排队的数"；见到 Sn 求 an，永远 n = 1 单独验、n≥2 作差。

编者注·本质回扣：数列这个名字听着新，本质就是"编号排队的一列数"，把第 n 项写成 an 就是一个定义在正整数上的函数——和你在第 02 章学的函数是同一回事，只是自变量 n 只能取 1,2,3…，图像是散点而不是连续曲线。Sn 与 an 的关系更朴素：Sn 是前 n 项一锅端的和，Sn−1 是前 n−1 项的和，两者一减自然只剩第 n 项；只是 n = 1 时 S0 没定义，所以必须单独验 a1 = S1。记住"作差出通项"，这就是已知 Sn 求 an 的全部道理。

3.1.1 数列的单调性、周期性与最大(小)项 （苏州教研·专题31）

单调性怎么判：数列 {an} 递增 ⇔ an+1 > an 恒成立；递减 ⇔ an+1 < an 恒成立。判断手段两种：

  • 作差：算 an+1 − an 的正负；
  • 作商：各项为正时，算 an+1/an 与 1 比。

重要提醒（苏州书原话）：不能对函数 an = f(n)，n∈N* 直接求导！要研究单调性，得先引进对应函数 y = f(x)，x∈[1,+∞)，对它求导，再回到数列上。

最大(小)项怎么找：若第 n 项是最大项，它必须同时不比左右邻居小：an ≥ an−1 且 an ≥ an+1（最小项把不等号反过来）。

这就是苏州书说的"∨ 字形模型"（最小项是倒过来的 ∧ 字形）。解这个不等式组，n 取正整数的那几项就是候选最大项。

周期性：若 an+t  =  an，则 {an} 的周期为 T。客观题里给了递推又求不出通项，先猜它是不是周期数列。

应用题模型（苏州书·专题31）：

  • 分期付款（复利）：贷款 A 元，n 次还清，每期利率 r，每次还款 x。 x  =  A·r·(1+r)n / [(1+r)n − 1] 大白话：分期去付款，到期算总账——我付银行息，银行付我息，借还两相等。
  • 零存整取（单利）：每期存 p 元，每期利率 r，n 期后本利和 Sn  =  p·[n + n(n−1)/2·r]（这是等差数列求和模型）。

3.2 等差数列（公差 d）

引入：把钢管堆成梯形，最上层 5 根，往下每层多 1 根：5，6，7，8，9……相邻两层的差总是 1。再比如上衣尺码 S、M、L、XL 之间的号差。这种"后一项减前一项等于同一个常数"的数列，就是等差数列。

定义：如果一个数列从第 2 项起，每一项与它前一项的差都等于同一个常数 d，即 an+1 − an  =  d，这个数列就叫等差数列，常数 d 叫公差。

通项公式：an  =  a1 + (n − 1)d。 怎么来的？用累加法：a2−a1 = d，a3−a2 = d，…，an−an−1 = d，左边一加一减全抵消，剩 an−a1 = (n−1)d，移项就是公式。

几何意义：把 an = a1+(n−1)d 写成 an = dn+(a1−d)，这是关于 n 的一次函数。所以等差的散点 (n,an) 全在一条斜率为 d 的直线上（见下图，蓝点）。

前 n 项和：Sn  =  n(a1 + an)/2  =  na1 + n(n−1)d/2。 高斯小时候算 1+2+…+100，思路就是"首末配对"：(1+100)、(2+99)……每对都 101，共 50 对，得 5050。搬到一般等差上就是"首项加末项乘项数除以 2"。

它的几何意义：把 Sn = na1+n(n−1)d/2 整理成 Sn  =  (d/2)n2 + (a1 − d/2)n，这是关于 n 的二次函数，而且常数项是 0（过原点）。d>0 时开口向上，Sn 的散点趴在一条抛物线上（见下图）。

常用性质（都能由通项推出来，别死背）：

  • 若 m+n = p+q，则 am + an  =  ap + a_q。理由：am+an = 2a1+(m+n−2)d，右边 = 2a1+(p+q−2)d，由 m+n = p+q 相等。
  • 等差中项：相邻三项中 2an  =  an−1 + an+1。
  • 推广：an  =  am + (n−m)d（知道任意一项都能当"新首项"）。
  • 分段和：Sk，S2k−Sk，S3k−S2k，… 仍成等差数列。

两个好用的二级结论（苏州教研·专题32）：

{Sn/n} 是等差数列：由 Sn = na1+n(n−1)d/2 两边除以 n，得 Sn/n  =  a1+(n−1)·d/2，即 {Sn/n} 本身就是公差为 d/2 的等差数列。题目给你一组"Sn/n 的差"，立刻反推公差 d。

am/bm  =  S_{2m−1}/T_{2m−1}（两等差数列第 m 项之比  =  前 2m−1 项和之比）：设 {an}、{bn} 前 n 项和分别为 Sn、Tn。因为 S_{2m−1} = (2m−1)(a1+a_{2m−1})/2 = (2m−1)·am（等差中项 a1+a_{2m−1} = 2am），同理 T_{2m−1} = (2m−1)·bm，两式一除，(2m−1) 约掉，得 am/bm  =  S_{2m−1}/T_{2m−1}。

【跟讲例题（苏州教研·专题32，原书p.130）】：等差数列 {an}、{bn} 的前 n 项和分别为 Sn、Tn，且 Sn/Tn  =  (7n+45)/(n+3)，求 an/bn 为整数时 n 的值。 解：an/bn  =  S_{2n−1}/T_{2n−1}  =  [7(2n−1)+45]/[(2n−1)+3]  =  (14n+38)/(2n+2)  =  (7n+19)/(n+1)  =  7 + 12/(n+1)。要 an/bn 为偶数（整数），需 12/(n+1) 为整数，即 n+1 是 12 的正约数：n+1∈{1,2,3,4,6,12}，n∈N* 且对应值为偶数。代回检验：n = 1 时 7+6 = 13（奇），n = 2 时 7+4 = 11（奇），n = 3 时 7+3 = 10（偶✓），n = 5 时 7+2 = 9（奇），n = 11 时 7+1 = 8（偶✓）。故 n = 3 或 n = 11。（此即苏州书 B 组第 1(1) 题，答案 3 或 11。）

其他小结论（苏州教研·专题32）：

  • 等差数列判定四法：①定义 an+1−an = d；②等差中项 2an = an−1+an+1；③an = kn+b（一次式）；④Sn = An2+Bn（常数项为 0 的二次式）。
  • 若 {an} 等差，则 {c^an}（c>0，c≠1）是等比数列。
  • 从等差数列中按"序号成等差"抽取若干项，抽出的项仍成等差数列。

例题跟讲例题：等差数列中 a3 = 7，a7 = 19，求 a10。 解：a7−a3 = 4d = 12 ⇒ d = 3；a3 = a1+2d ⇒ a1 = 1。a10 = a1+9d = 1+27 = 28。 要点：等差问题永远抓住 a1 和 d 两个"基本量"，把已知条件翻译成关于它们的方程。

小结：等差 = "差固定"，通项一次、求和二次，两基本量 a1、d 走天下。

3.3 等比数列（公比 q）

引入：一张纸对折 1 次变 2 层，对折 2 次变 4 层，对折 3 次变 8 层……层数是 1，2，4，8，16……每折一次就乘 2。银行复利也是：利息滚进本金再生利息，每年本金都乘上 (1+利率)。这种"后一项除以前一项等于同一个常数"的数列叫等比数列。

定义：如果一个数列从第 2 项起，每一项与它前一项的比都等于同一个非零常数 q，即 an+1/an  =  q，这个数列就叫等比数列，q 叫公比（规定 q≠0，各项也不为 0）。

通项公式：an  =  a1·qn−1。 推导类似累乘：a2/a1 = q，a3/a2 = q，…，an/an−1 = q，左边全约掉只剩 an/a1 = qn−1。

前 n 项和：

  • 当 q = 1 时，每一项都等于 a1，所以 Sn  =  n·a1；
  • 当 q≠1 时，Sn  =  a1(1 − qn)/(1 − q)  =  a1(qn − 1)/(q − 1)。

公式怎么来的？写一遍：Sn = a1+a1q+…+a1qn−1，两边乘 q 得 qSn = a1q+…+a1qn，两式一减（错位相减），中间全消，Sn−qSn = a1−a1qn，解出 Sn。q 是参数时一定要先讨论 q = 1 还是 q≠1，这是最常见的丢分点。

常用性质：

  • 若 m+n = p+q，则 am·an  =  ap·a_q（注意这里是"乘"不是"加"）。
  • 等比中项：an2  =  an−1·an+1，但开方有正负两个，要按题目条件取舍。
  • 当 |q|<1 且 n 无限增大时，qn→0，an→0，Sn→a1/(1−q)。

补充结论（苏州教研·专题33）：

  • {log_c bn} 是等差数列：若 {bn}（bn>0）是等比数列，则取以 c 为底的对数后 {log_c bn} 就是等差数列（乘法变加法）。这是"等比↔等差"互相转化的桥梁。
  • 奇偶项和之比：项数为 2n 时，S偶/S奇  =  q（因为 a2 = q·a1，a4 = q·a3，… 全部提一个 q）；项数为 2n−1 时，(S奇−a1)/S偶  =  q。
  • 连续 m 项的积仍成等比：设 Tn = a1·a2·…·an，则 Tm，T2m/Tm，T3m/T2m，… 仍成等比数列。
  • 注意：q = −1 时，"连续 m 项和成等比"要求 m 必须是奇数（否则分段和为 0）。
  • 等比数列判定四法：①定义 an+1/an = q；②等比中项 an2 = an−1an+1≠0；③an = p·qn；④Sn = A(1−qn)。

例题跟讲例题：等比数列 a1 = 3，q = 2，求前 6 项和。 解：q≠1，S6 = 3·(26−1)/(2−1) = 3·63 = 189。 要点：先确认 q≠1 再套公式；本题 a1 = 3 别代成 1。

小结：等比 = "比固定"，通项指数式，求和务必分 q = 1。

编者注·本质回扣：等差和等比其实是一对"兄弟规则"：等差是相邻两项"差固定"（每次加同一个 d），等比是相邻两项"比固定"（每次乘同一个 q）。差固定时通项是 n 的一次式、前 n 项和是过原点的二次式；比固定时通项是指数式、前 n 项和要用错位相减推出来，并且 q = 1 时所有项都一样、公式得另写。它们的基本量都只有两个（等差是 a1 和 d，等比是 a1 和 q），做题就是把已知条件翻译成关于这两个基本量的方程——这就是"基本量法"为什么走天下。

3.4 数列求和的三种常用方法

大题第二问十有八九让你"求前 n 项和"，但给你的数列既不是等差也不是等比。这时用下面三招。

1. 裂项相消：当通项是"两项乘积作分母"时，把一项拆成两项之差，求和时中间全部抵消。

  • 1/[n(n+1)]  =  1/n − 1/(n+1)
  • 1/[(2n−1)(2n+1)]  =  ½[1/(2n−1) − 1/(2n+1)]（注意前面那个 ½）

2. 错位相减：当通项是"等差  ×  等比"（比如 an = (2n−1)·3n）时，先写 Sn，再两边乘公比 q 得 qSn，两式错开一位相减，中间剩一个等比数列，套等比求和公式。

3. 分组求和：把数列拆成几个等差、等比小组，分别求和再相加。

例题跟讲例题：求 1/(1·3)+1/(3·5)+…+1/[(2n−1)(2n+1)]。 解：每一项  =  ½[1/(2k−1) − 1/(2k+1)]。 原式  =  ½[(1−1/3)+(1/3−1/5)+…+(1/(2n−1)−1/(2n+1))]  =  ½[1 − 1/(2n+1)]  =  n/(2n+1)。 要点：中间项两两抵消，只剩首尾；别忘了系数 ½。

小结：裂项看"分母乘积"，错位看"等差 × 等比"，分组看"能拆成常见数列"。

补充求和招法（苏州教研·专题35）：

  • 倒序相加法：适合"首末等距两项之和为常数"的数列（如 ak = Cnk）。把 Sn 正着写一遍、倒着写一遍，两式相加，对应项配对。
  • 并项法：相邻若干项的和恰好是常数/特殊数列，如 an = (−1)n(4n−1)，两项一并就是 −4。
  • 奇偶讨论法：an = (−1)n−1(2n−1)2 这类带 (−1)n 的，先算偶数项和 S_{2n} = f(n)，再算奇数项 S_{2n−1} = S_{2n−2}+a_{2n−1}。先偶后奇（偶数项好配对）。
  • 分段讨论法：如 an = |2n−29|，前若干项负、后面正，要分段去掉绝对值再求和。

必背的三个自然数幂和公式（苏州教研·专题35）：

1+2+3+…+n  =  n(n+1)/2

12+22+32+…+n2  =  n(n+1)(2n+1)/6

13+23+33+…+n3  =  [n(n+1)/2]2

  • 大白话立方和等于"和的平方"，这个最惊艳——13+23+33=36=(1+2+3)2。
  • 用的时候：见到 Σk2、Σk3 直接套公式，不要硬算。

无穷等比数列的和：当 |q|<1 时，S  =  lim Sn  =  a1/(1−q)。

3.5 由递推关系求通项（构造法入门）

很多大题不给通项，只给相邻两项的关系 an+1 = f(an)。最常见的一类是 an+1  =  p·an + q（p、q 为常数）。 思路：凑一个等比。设 an+1 + c  =  p(an + c)，展开得 an+1  =  p·an + (p−1)c，对比原式得 (p−1)c  =  q，即 c  =  q/(p−1)。于是 {an+c} 是公比为 p 的等比数列，先求它再还原出 an。

例题跟讲例题：a1 = 1，an+1 = 2an+1，求 an。 解：p = 2，q = 1，c = 1/(2−1) = 1。于是 an+1+1 = 2(an+1)，即 {an+1} 是首项 a1+1 = 2、公比 2 的等比数列，an+1 = 2·2n−1 = 2n，所以 an = 2n−1。

小结：见到 an+1 = p·an+q，就"加个常数凑等比"；更全的构造模板见章末"高级方法·进阶"。

3.5.1 取倒数、取对数、凑常数列（苏州教研·专题34）

上面 3.5 是最基础的"加常数凑等比"。苏州书专题34 还总结了另外几招，见到对应信号直接用。

招一：取倒数（分式递推）

信号：an+1  =  q1an/(q2an+d2) 这种分子分母都是 an 一次式的分式。

操作：两边同时取倒数， 1/an+1  =  (d2/q1)·(1/an) + q2/q1 这就变成了 an+1 = pan+q 的标准型（只是把 an 换成了 1/an），再用"加常数凑等比"。

记住它之前先看懂它：取倒数不是玄学——原式分子分母都含 an，一倒之后右边拆成"常数 × (1/an) + 另一个常数"，正好变回你已经会的 an+1 = pan+q 标准型，只是主角从 an 换成了 1/an，照着凑等比就行。

招二：取对数（指数递推）

信号：an+1  =  c·anp（后项是前项的 p 次幂再乘常数）。

操作：两边取以 c 为底的对数， log_c an+1  =  p·log_c an + 1 令 bn = log_c an，则 bn+1 = p·bn+1，又是标准型。乘法/幂次问题，取对数就降成了加法问题。

招三：凑常数列（和差积商四式）

苏州书总结得很漂亮——若相邻两项加一个、减一个、乘一个、除一个关于 n 的式子后相等，那这个新数列就是常数列（后一项等于前一项），直接等于首项。

  • 和型：an+1+f(n+1) = an+f(n) ⇒ {an+f(n)} 是常数列；
  • 差型：an+1−f(n+1) = an−f(n) ⇒ {an−f(n)} 是常数列；
  • 积型：f(n+1)·an+1 = f(n)·an ⇒ {f(n)·an} 是常数列；
  • 商型：an+1/f(n+1) = an/f(n) ⇒ {an/f(n)} 是常数列。

常数列一旦看出来，通项立刻写出（等于首项），省掉累加/累乘。

招四：an 与 Sn 混合式，两式相减

题目给 F(an, Sn)=0 时，先写 n=1 求出 a1；再把 n 换成 n−1 得 F(an−1, Sn−1)=0，两式相减，消掉 Sn，得到只含 an、an−1 的递推。注意 n≥2，最后一定要回验 n=1。

【跟讲例题（苏州教研·专题34，原书p.132）】：设数列 {an} 的前 n 项和为 Sn，已知 Sn  =  2an − 2n+1（n∈N*）。（1）求 {an/2n} 的通项公式；（2）证明（见 3.6 节放缩例题）。 解（1）：n = 1 时 a1 = S1 = 2a1−4 ⇒ a1 = 4。 n≥2 时，写 Sn−1 = 2an−1−2n，两式相减： an  =  Sn−Sn−1  =  2an−2an−1−2n，整理得 an  =  2an−1 + 2n。 两边同除以 2n：an/2n  =  an−1/2n−1 + 1。令 bn = an/2n，则 bn = bn−1+1，即 {bn} 是公差为 1 的等差数列，首项 b1 = a1/2 = 2。 故 bn  =  2+(n−1)  =  n+1，即 an/2n  =  n+1（代回 n = 1 检验：a1/2 = 2 = 1+1 ✓）。 要点：见到 Sn 与 an 混在一起，永远"两式相减消 Sn"；除完 2n 后露出一个公差为 1 的等差，这就是苏州书说的"除幂数化等差"。

3.6 数列型不等式的证明——放缩套路（苏州教研·专题36）

大题第二问最常考：证明 a1+a2+…+an 小于某个常数。通项求不出精确和时，标准动作是先放缩、再求和。

总流程（苏州书原话整理）：

  1. 目标常数 C 是什么形状？ - 若 C  =  a1/(1−q)，就猜通项放大后是个等比数列 an ≤ a1·qn−1； - 若 C  =  f(n+1)−f(1)，就猜通项 an ≤ f(n+1)−f(n)（裂项）。
  2. 选好放缩方向后，首项不吻合就延迟放缩——从第 2 项甚至第 4 项才开始放，前几项精确保留。
  3. 放缩不能过度：放太大直接超过 C，证不出来。

放缩工具箱（苏州教研·专题36，必存）：

1/k2 < 1/(k2−1)  =  ½(1/(k−1) − 1/(k+1))（k≥2）

1/k2 < 1/[k(k−1)]  =  1/(k−1) − 1/k（k≥2）

1/k2 > 1/[k(k+1)]  =  1/k − 1/(k+1)（反向用）

1/√k < 2(√k − √(k−1))；1/√k > 2(√(k+1) − √k)（分母有理化放缩）

k/(k+1)!  =  1/k! − 1/(k+1)!（阶乘裂项）

  • 大白话见 1/k2 就想拆成两个相邻倒数差；见 1/√k 就想乘共轭根式。
  • 用的时候：证明 Sn < C 时，先把 C 拆成"前几项 + 一个裂项和"，再反推通项该放大成什么。

伪等差 / 伪等比（苏州书·专题36）：

  • 若 an+1 ≥ an+d，则累加得 an ≥ a1+(n−1)d（不等号方向跟着）；
  • 若正项数列 an+1 ≥ q·an，则累乘得 an ≥ a1·qn−1。

这两条把"递推不等式"直接转成了通项不等式，是放缩的跳板。

【跟讲例题（苏州教研·专题34 例3，原书p.134）】：已知数列 {an} 满足 a1 = 2，an+1  =  ½an2 + 2an，求证：1/a1 + 1/a2 + … + 1/an < 3/4。 证明：由 a1 = 2>0 及递推式知 an>0 且 an+1>an，故 an≥2。 于是 an+1  =  ½an2+2an  =  an(½an+2) ≥ an(½·2+2)  =  3an（把 an≥2 代入括号）。 类比等比数列累乘：an ≥ a1·3n−1  =  2·3n−1，故 1/an ≤ ½·(1/3)n−1。 求和：Σ_{k = 1}^{n} 1/ak ≤ ½[1+⅓+(⅓)2+…+(⅓)n−1]  =  ½·[1−(1/3)n]/(1−1/3)  =  ½·(3/2)·[1−(1/3)n]  =  3/4·[1−(1/3)n] < 3/4。证毕。 要点：目标常数 3/4 正是 ½/(1−⅓) = 3/4——"先算目标常数对应的等比首项与公比，再反推该把通项放大成什么"。这就是苏州书说的"由 3/4 = ½/(1−q) 猜出 q = 1/3"。

3.7 数学归纳法（苏州教研·专题52；新教材选必二 4.4）

与正整数 n 有关的命题，当你"观察+猜想"出结论后，用数学归纳法严格证明。两步缺一不可：

  1. 归纳奠基：证明 n 取第一个值 n0（通常 n0 = 1）时结论成立；
  2. 归纳递推：假设 n = k（k≥n0）时结论成立，以此为条件，证明 n = k+1 时结论也成立。

两步走完，就断定命题对从 n0 开始的所有正整数都成立。

  • 大白话第一步验"第一张多米诺骨牌倒了"，第二步证"前一张倒了后一张一定倒"。
  • 用的时候：第二步必须用上归纳假设 ak 成立这个条件，不能空证 a_{k+1}。苏州书提醒："由 n = k 推 n = k+1 这一步，可用分析法（执果索因）找思路。"
  • 注意：并非所有与正整数有关的命题都能直接用数学归纳法；它和放缩法、分析法常搭配使用。

④ 例题详解（先做再看）

例题例 1（等差数列基本量）：等差数列 {an}，a3  =  7，a7  =  15，求通项与前 10 项和。

自己做：先求 a1 和 d。

解：a7 − a3  =  4d  =  8 ⇒ d  =  2；a3  =  a1 + 2d ⇒ a1  =  3。an  =  3 + 2(n − 1)  =  2n + 1。 S10  =  10(a1 + a10)/2  =  10(3 + 21)/2  =  120。 要点："基本量法"：任何等差数列都由 a1、d 两个基本量确定。

例题例 2（等比数列求和）：求 1 + 2 + 4 + … + 29 的值。

自己做：q ≠ 1 用公式。

解：a1  =  1，q  =  2，n  =  10。S10  =  1·(210 − 1)/(2 − 1)  =  1024 − 1  =  1023。 要点：先判断 q 是否等于 1 再选公式。

例题例 3（裂项相消）：求数列 1/(1·2) + 1/(2·3) + … + 1/[n(n+1)] 的和。

自己做：每项拆成两个分数的差。

解：1/[k(k+1)]  =  1/k − 1/(k+1)。 原式  =  (1 − 1/2) + (1/2 − 1/3) + … + (1/n − 1/(n+1))  =  1 − 1/(n+1)  =  n/(n+1)。 要点：中间项全部抵消，只剩首尾——这是裂项的招牌特征。

例题例 4（错位相减）：求数列 {n·2n} 的前 n 项和。

自己做：写出 Sn 与 2Sn 再相减。

解：Sn  =  1·2 + 2·4 + 3·8 + … + n·2n 2Sn  =  1·4 + 2·8 + … + (n−1)·2n + n·2n+1 相减：−Sn  =  2 + (4 + 8 + … + 2n) − n·2n+1  =  2 + 22(2n−1 − 1)/(2 − 1) − n·2n+1  =  2 + 2n+1 − 4 − n·2n+1  =  2n+1(1 − n) − 2 故 Sn  =  (n − 1)·2n+1 + 2。

记住它之前先看懂它：错位相减的精髓就一个"错"字——qSn 比 Sn 整体向右挪了一项，两式一减，中间那一长串 2·4、4·8…全部成对抵消，只剩最前面的首项和最后面的尾项，中间恰好露出一个干净的等比数列再求和。 要点：错位相减只适合"等差  ×  等比"；相减后中间的等比部分整体求和。

例题例 5（递推裂项相消，苏州教研·专题36 B组第7题，原书p.138）：已知数列 {an} 满足 a1 = √2，an+1  =  an2 + an，记 bn  =  1/(1+an)，Sn 为数列 {bn} 的前 n 项和。求证：Sn + 1/an+1  =  √2/2。

自己做：把递推式两边取倒数，看能不能裂项。

解：由 an+1  =  an(an+1)，两边取倒数： 1/an+1  =  1/[an(an+1)]  =  1/an − 1/(an+1)（裂项）。 移项得 1/(an+1)  =  1/an − 1/an+1，即 bn  =  1/an − 1/an+1。 对 k = 1,2,…,n 求和： Sn  =  (1/a1−1/a2)+(1/a2−1/a3)+…+(1/an−1/an+1)  =  1/a1 − 1/an+1。 故 Sn + 1/an+1  =  1/a1  =  1/√2  =  √2/2。证毕。 要点：见到 an+1  =  an(an+c) 型递推，两边取倒数必出裂项；这是递推与裂项相消的经典接口。

an 与 Sn 的关系

a1  =  S1；n ≥ 2 时 an  =  Sn − Sn−1

  • 大白话前 n 项和减去前 n−1 项和，剩下的就是第 n 项。
  • 用的时候：大题第一步永远先写 n=1 单独验；n≥2 再作差，最后把 n=1 代回去看能不能并成一个式子。
  • 记忆要点：n=1 特殊，n≥2 作差。

等差数列

an  =  a1 + (n − 1)d（也可写成 an  =  am + (n − m)d）

  • 大白话从第一项开始每项加一个 d，加到第 n 项。
  • 用的时候：知道任意一项都能当"新首项"跳着算；求基本量 a1、d 是万能钥匙。
  • 记忆要点：首项 +（项数−1） × 公差。

Sn  =  n(a1 + an)/2  =  na1 + n(n−1)d/2  =  (d/2)n2 + (a1 − d/2)n

  • 大白话首末项配对相乘再除以 2；展开后是个过原点的二次函数。
  • 用的时候：给 a1、an、n 用第一式；给 a1、d、n 用第二式；讨论 Sn 最值时看第三式。
  • 记忆要点：高斯配对——(首+末)×项数÷2。

若 m+n  =  p+q，则 am + an  =  ap + a_q

  • 大白话下标和相等，两项和就相等。
  • 用的时候：不求通项，直接整体代换；等差中项 2an = an−1 + an+1 是它的特例。

Sk，S2k − Sk，S3k − S2k，… 仍成等差数列

  • 大白话把前 k 项、接下来 k 项、再接下来 k 项分别加起来，这几段和还是等差。
  • 用的时候：见到"前 k 项和 / 前 2k 项和"立刻想到分段和成等差。

等比数列

an  =  a1·qn−1

  • 大白话从首项开始每项乘一个 q，乘到第 n 项。
  • 用的时候：知道任意两项先求 q；q≠0，各项也不为 0。
  • 记忆要点：首项 × 公比^(项数−1)。

Sn：q = 1 时 Sn  =  na1；q≠1 时 Sn  =  a1(1−qn)/(1−q)

  • 大白话公比是参数时，先看 q 等不等于 1，两式完全不同。
  • 用的时候：q=1 别用分式（会除以 0）；这是最常见的丢分点。
  • 记忆要点：q 是字母必讨论，先判 1 再套式。

若 m+n  =  p+q，则 am·an  =  ap·a_q

  • 大白话下标和相等，两项的"积"相等（注意是乘不是加）。
  • 用的时候：等比中项 an2 = an−1·an+1 是特例，开方有正负两个要取舍。

Sk，S2k − Sk，S3k − S2k，… 仍成等比数列

  • 大白话分段和成等比；第 5~8 项和 = q4 × 前 4 项和。
  • 用的时候：等比前 4 项和与前 8 项和的题，就用 S8−S4 = q4·S4。

求和技巧

裂项：1/[n(n+1)]  =  1/n − 1/(n+1)；1/[(2n−1)(2n+1)]  =  ½[1/(2n−1) − 1/(2n+1)]

  • 大白话把分母乘积拆成两项差，求和时中间两两抵消，只剩首尾。
  • 用的时候：第二个别忘了前面的系数 ½。

错位相减：通项是"等差  ×  等比"（如 n·2n）时用

  • 大白话写一遍 Sn，两边乘公比得 qSn，错开一位相减，中间剩一个等比数列再求和。
  • 用的时候：相减后等比首项是第二项（q·a1），指数和项数要数清。

分组求和：把数列拆成几个等差、等比小组分别求和再相加

  • 大白话杂数列不会算，拆开成熟悉的小块。

构造法求通项

an+1  =  p·an + q ⇒ 凑 an+1 + c  =  p(an + c)，其中 c  =  q/(p−1)

  • 大白话加个常数把它变成等比数列先求，再减回来。
  • 用的时候：{an+c} 是公比 p 的等比数列；n=1 要验证。
  • 记忆要点：c = q/(p−1)，"凑等比"。

递推求通项的另外三招（苏州教研·专题34）

取倒数：an+1  =  q1an/(q2an+d2) ⇒ 1/an+1  =  (d2/q1)·(1/an) + q2/q1，转 an+1 = pan+q 型

  • 大白话分式递推两边一倒，就变成熟悉的"加常数凑等比"。
  • 用的时候：分子分母都是 an 一次式时，先倒再凑。

取对数：an+1  =  c·anp ⇒ log_c an+1  =  p·log_c an + 1

  • 大白话幂次递推取对数，乘法变加法、幂次变倍数。
  • 用的时候：后项是前项的幂次时，令 bn=log_c an 转标准型。

凑常数列：和/差/积/商四式（见 3.5.1）

  • 大白话相邻两项加减乘除一个 f(n) 后相等，新数列就是常数列，直接等于首项。
  • 用的时候：an+1±f(n+1)=an±f(n)、f(n+1)an+1=f(n)an、an+1/f(n+1)=an/f(n)，四种信号一眼识别。

等差/等比的二级结论（苏州教研·专题32、33）

{Sn/n} 是公差为 d/2 的等差数列

  • 大白话前 n 项和除以 n 排成一列，本身还是等差。
  • 用的时候：题目给 S2010/2010 − S2009/2009 = 2，立刻 d/2=2 ⇒ d=4。

am/bm  =  S_{2m−1}/T_{2m−1}（两等差第 m 项之比  =  前 2m−1 项和之比）

  • 大白话两个等差数列，比第 m 项等于比它们前 2m−1 项的和。
  • 用的时候：已知 Sn/Tn 的表达式求 an/bn，直接把 n 换成 2n−1 代入。

{log_c bn} 等差（{bn} 等比且 bn>0）；项数 2n 时 S偶/S奇  =  q

  • 大白话等比取对数变等差；偶数项每项都比前一个奇数项多乘一个 q。

自然数幂和与无穷等比（苏州教研·专题35）

12+22+…+n2  =  n(n+1)(2n+1)/6；13+23+…+n3  =  [n(n+1)/2]2

  • 大白话平方和套公式；立方和等于"和的平方"。
  • 用的时候：见到 Σk2、Σk3 直接代，不要硬算。

无穷等比和：|q|<1 时 S  =  a1/(1−q)

  • 大白话公比绝对值小于 1 时，无穷多项加起来收敛到一个定值。

数列放缩工具箱（苏州教研·专题36）

1/k2 < 1/[k(k−1)]  =  1/(k−1) − 1/k（k≥2）；1/k2 < ½(1/(k−1)−1/(k+1))

  • 大白话见 1/k2 就想拆成相邻倒数差，求和时中间全消。
  • 用的时候：证 Sn<C 时，先把 C 拆成"前几项+裂项和"，反推通项该放大成什么；首项不吻合就延迟放缩。

1/√k < 2(√k−√(k−1))；k/(k+1)!  =  1/k! − 1/(k+1)!

  • 大白话根号项乘共轭根式放缩；阶乘项直接裂项。

伪等差：an+1≥an+d ⇒ an≥a1+(n−1)d；伪等比：an+1≥q·an ⇒ an≥a1qn−1

  • 大白话递推不等式累加/累乘，直接转成通项不等式。

数学归纳法两步（苏州教研·专题52）

① 奠基：验 n = n0 成立；② 递推：假设 n = k 成立，证 n = k+1 成立（必须用上归纳假设）

  • 大白话第一张骨牌倒了 + 前一张倒后一张必倒 = 全部倒。
  • 用的时候：第二步证 a_{k+1} 时一定要把 ak 的归纳条件代进去；思路卡住用分析法。

进阶 1：递推求通项——三大构造模板

适用信号：题目给的是 an+1 与 an 的关系式，要你求通项。 操作步骤：

  1. an+1 = p·an+q 型：凑 an+1+c = p(an+c)，c = q/(p−1)，转等比；
  2. an+1−an = f(n) 型：用累加法，an = a1+Σf(k)；
  3. an+1/an = f(n) 型：用累乘法。 例题：a1 = 1，an+1 = 2an+3 ⇒ c = 3，{an+3} 等比，an+3 = 4·2n−1，an = 2n+1−3。 课标依据/红线：构造法本身是等差等比定义的直接运用，✓ 不超纲（高考可放心用）。

进阶 2：错位相减"免计算"自检

适用信号：等差 × 等比求和 Sn = (An+B)·qn−B。 操作步骤：先算 S1、S2 两个具体值，反解出 A、B，直接写出结果，再用错位相减或代入 n = 1、2 验证。 例题：{n·2n}，S1 = 2，S2 = 2+8 = 10。设 Sn = (An+B)2n−B：n = 1→2(A+B)−B = 2A+B = 2；n = 2→4(2A+B)−B = 8A+3B = 10。解得 A = 2，B = −2，故 Sn = (2n−2)2n+2 = (n−1)2n+1+2（与 ④ 例 4 一致）。 课标依据/红线：只是"先猜后算"的验算技巧，✓ 不超纲。

进阶 3：裂项放缩库

适用信号：要证 Tn 小于某个常数。 常用放缩：1/n2<1/[n(n−1)] = 1/(n−1)−1/n（n≥2）；1/√n<2(√n−√(n−1))。 操作步骤：先把目标常数"拆"成可裂项的形式，再反向选择放缩；首项不符就"从第二项起放缩"。 课标依据/红线：裂项本身不超纲；但把它用来证明"数列不等式小于某定值"时，解答里要把放缩的每一步写清楚，✓ 不超纲。

进阶 4：特征根法（选学·超纲红线）

适用信号：an+2 = p·an+1+q·an 型二阶递推。 操作步骤：解特征方程 x2 = px+q，两根 α≠β 则 an = Aαn+Bβn。 课标依据/红线：超纲红线（考试禁用，只用于理解/自检）——教材没有这个结论。解答题里若想用，应改成"观察猜想 + 数学归纳法证明"才算课标内；本题型新高考已很少直接考。

3.1 递推求通项——三大构造模板

大白话·本质一句话：递推模板 = 给你 an+1 和 an 的关系式，就像认锁配钥匙——看到哪种长相的递推，就套哪种固定动作（凑等比/累加/特征根/不动点），把"绕来绕去的关系"掰成一个能直接写通项的等比或等差。（与本章前述 3.5、3.5.1、进阶 1、进阶 4 联动）

递推形式 方法
an+1  =  p·an + q 构造 an+1+c  =  p(an+c)，c = q/(p-1)，转等比
an+1  =  p·an + f(n) 累加/待定系数（两边同除 pn+1 转累加）
an+2  =  p·an+1 + q·an 特征根法：解 x2 = px+q，两根 α≠β 则 an = Aαn+Bβn；α = β 则 an = (A+Bn)αn，A、B 由 a1、a2 定
an+1  =  (pan+q)/(ran+s) 不动点法：解 x = (px+q)/(rx+s)，两根 α≠β 则 (an-α)/(an-β) 成等比
an+1  =  an + g(an)（特殊） 先猜后证 + 数学归纳法

课标依据：等差等比定义、递推（选必二第四章）。特征根/不动点的结论教材未直接给出，解答时建议：先"观察+猜想"，再用数学归纳法证明（完全课标内）；或写出结论并注明可验证。

注意：特征根法结论可以直接用于小题（填空选择），解答题用它算出答案后补归纳法证明最稳妥。

（高级方法手册·3.1）

3.2 错位相减"免计算"公式（自检神器）

大白话·本质一句话：错位相减的答案一定长成 (An+B)·qn−B 这个固定模样，所以先拿 n = 1、n = 2 两个小情况算出 A、B，直接拼出整个公式，再回头用错位相减验算——等于先看答案长什么样再倒推，省掉一整页展开。（与本章前述 ④例 4、进阶 2 联动）

等差 × 等比求和 Sn 的结果必能写成 Sn = (An+B)·qn - B 的形式。

用法：先随便算 S1、S2，反解 A、B，直接写出 Sn——再用普通错位相减法验证一遍（或用 n = 1、2 代入验证）。

课标依据：错位相减（选必二）。✓ 公式形态是推导的必然结果，非新知识。

3.3 裂项放缩库

大白话·本质一句话：裂项 = 把一项拆成两项之差，让加减互相抵消，像多米诺骨牌一块一块倒下去，最后只剩头和尾；放缩就是把不好算的项放大/缩小成"能裂项"的模样。（与本章前述 3.4、3.6 放缩工具箱、④例 5、进阶 3 联动）

  • 1/(n(n+1))  =  1/n - 1/(n+1)；1/(n(n+2))  =  ½(1/n - 1/(n+2))
  • 1/n2 < 1/(n(n-1))  =  1/(n-1) - 1/n（n≥2）
  • 1/√n  =  2/(√n+√n) < 2/(√n+√(n-1))  =  2(√n-√(n-1))（分母有理化）
  • 2n/(2n-1)2 < 1/(2n-1) - 1/(2n+1-1)

用法：要证 Tn < 某个值，先把目标值"拆"成可裂项的形式，再反向选择放缩——目标驱动，不是碰运气。

（高级方法手册·3.3）

3.4 数列不等式证明流程

大白话·本质一句话：证 Sn < C 就像瞄靶心——先看清目标常数 C 是"等比和"还是"裂项和"的样子，再反推该把每一项放缩成什么形状；首项对不上就从第二项开始放，宁可放得紧也别放过头。（与本章前述 3.6 总流程、放缩例题、④例 5 联动）

  1. 先求 Tn 或放缩后的和（明确目标常数 C）；
  2. 选择裂项/等比放缩使和式恰好 ≤ C；
  3. 首项不符时"从第二项起放缩"（保留前几项精确值）；
  4. 证明单调性后再放缩（若 Tn 递增，只需证 Tn 的上界）。

一通百通

这一章的"通用骨架"是：① 先认清规则——是等差（差固定）还是等比（比固定），或题目只给了递推 → ② 抓住两个基本量（等差 a1、d；等比 a1、q），把条件翻译成它们的方程 → ③ 已知 Sn 就作差求 an（n=1 单独验）→ ④ 求和看信号：分母乘积用裂项、等差×等比用错位相减、能拆就分组；证不等式就先放缩再求和。高考数列解答题不管怎么变，本质都是"先定规则、再求基本量、后求和/放缩"。会做一道数列大题，就会做所有数列大题；这套"规则—基本量—求和"的骨架，和第 12 章不等式求最值、放缩常常搭手出现。

跨章结合

  • 数列递推 ⇔ 第 04 章函数的应用与方程：递推式 an+1=f(an) 本质就是同一个函数 f 反复作用在首项上——求通项、看它收不收敛、有没有最大项，背后是函数迭代和函数单调性的思想（苏州教研·专题31 也提醒：研究数列单调性要先引进对应连续函数 y=f(x) 再求导，不能直接对 an=f(n) 求导）。想通这一层，数列和函数就不是两块知识。（综合原理说明，非真题）
  • 数列求和与放缩 ⇔ 第 05 章导数、第 12 章不等式：数列大题第二问"证 Sn 小于某个常数"，动作是先放缩成等比或裂项再求和，和第 12 章基本不等式求最值、第 05 章用导数证不等式是同一套"放缩—夹逼"思路。例如 2025 新高考Ⅰ卷解答第 16 题第 (1) 问，由相邻两项的关系证一个新数列为等差数列，靠的就是"作差看是不是常数"——这正是本章 an+1−an=d 的判定动作在大题里的原样复用。

本章与前后章

数列前接第 02 章（函数与基本运算）——它本质就是定义在正整数上的函数，通项 an=f(n)、前 n 项和都是函数思想的离散版本。它向后直接接第 12 章不等式：数列大题第二问"证 Sn 小于某个常数"就是放缩法，和基本不等式、最值问题是同一类；同时数列里的函数思想（单调性、最值、对应函数求导）也回头强化第 02 章。学完它，你手里有了一套处理"离散变化"的工具。

高考怎么考

新高考Ⅰ卷里数列固定出解答题第二题附近（第 17–19 题区间），通常两问：第一问求通项或证等差等比（如 2025 新高考Ⅰ卷解答第 16 题第 (1) 问，由递推证 {n·an} 为等差数列），第二问求和或证不等式；小题里也常插一道（如 2025 卷填空第 13 题，等比前 4 项和 4、前 8 项和 68 求公比）。难度中档、是必须拿下的大题，考的就是"基本量法 + 三种求和 + 放缩"这套固定动作。
