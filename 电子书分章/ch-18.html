公式速查：修订版 第11部分（概率）

本章本质核心：概率的本质是"随机事件的面积/份额"——一件事发生的可能性大小，就是它在全部可能结果里占的那一份。古典概型是"公平地数个数"（有利份数/总份数），几何概型是"比面积（长度、体积）"，条件概率是"把已知条件当作新的全部、在缩小的范围里重新数份额"；期望 E(X) = Σxipi 则是"按每份的概率加权求平均"。本章互斥、独立、二项/超几何/正态分布、全概率，全是这一个"算份额"原理的变体。

为什么有用学了它，"某件事发生的可能性多大""这个方案平均收益多少、稳不稳"这类题就能落地——古典概型数份数、独立重复套二项、不放回用超几何，想通"概率 = 份额"，分布列和期望就是份额的加总，而不是背出来的表格。

3.1 古典概型

引入：掷一枚均匀骰子，掷出 3 点的概率是多少？6 个面朝上的可能性一样大，3 只是其中 1 种，所以 1/6。这就是最朴素的概率——"公平"地数份数。

正式定义：古典概型要求所有基本事件等可能且有限。此时

P(A)  =  A 包含的基本事件数 / 基本事件总数

计数工具：枚举、树状图、排列组合（回 17 章）。

事件关系：

  • 互斥：A、B 不能同时发生。P(A∪B)  =  P(A) + P(B)。
  • 对立：A 不发生就是 B（A∪B  =  全部，A∩B  =  空）。P(A)  =  1 − P(A)。

例题跟讲例题：

例 3.1-a：同时掷两枚骰子，点数和为 7 的概率。 解：总数 6 × 6 = 36。和为 7：(1,6)(2,5)(3,4)(4,3)(5,2)(6,1) 共 6 种。P  =  6/36  =  1/6。 要点：两枚骰子不同，(3,4) 和 (4,3) 要分开数。

小结：古典概型就是"公平份数除法"。

编者注·本质回扣：古典概型为什么非要"等可能"三个字？说白了，只有当每种结果机会均等时，"份数比"才等于"概率"。掷硬币正反各占一半、骰子六面一样重，这时数个数才作数；要是骰子被做了手脚，六个面不等重，数 1/6 就骗人了。所以分母（总基本事件数）要靠 17 章排列组合老老实实数清，分子（有利事件数）同样不能漏——两枚骰子 (3,4) 和 (4,3) 算两种，就是因为它们是两个等可能的基本结果。概率本质上就是"公平份额"这把尺子。

3.2 条件概率与独立事件

引入：袋里 3 红 2 白。"随手摸一个是红球"概率 3/5。但如果已知第一个摸出的是红球，再摸第二个，这时袋里变成 2 红 2 白，"第二个是红球"概率就变成 2/4  =  1/2。"已知条件变了，样本空间就变了"——这就是条件概率。

条件概率：在 B 已发生条件下 A 发生的概率：

P(A | B)  =  P(AB) / P(B)（P(B) > 0）

含义：把 B 当作新的"全部"，在 B 里面数 AB。

独立事件：A 的发生不影响 B。

P(AB)  =  P(A)·P(B)（独立 ⇔ 此式成立）

独立 vs 互斥：互斥说"不能同时发生"（P(AB) = 0）；独立说"互不影响"（P(AB) = P(A)P(B)）。方向相反——互斥的事件一般不独立。举个数：P(A) = 0.5、P(B) = 0.5 若互斥，则 P(AB) = 0，而 P(A)P(B) = 0.25≠0，所以它俩不独立；若独立，P(AB) = 0.25>0，说明能同时发生，就不互斥。

例题跟讲例题：

例 3.2-a：袋 3 红 2 白不放回连取 2 个。已知第一个是红球，求第二个也是红球。 解：第一红后剩 2 红 2 白，P(第二红|第一红)  =  2/4  =  1/2。 要点：条件概率  =  换个样本空间重新数。

小结：条件概率是"在已经缩小的范围里数"，独立是"两个事件井水不犯河水"。

3.3 离散型随机变量（分布列、期望、方差）

引入：投篮命中次数是个"随机数"——可能 0 次、1 次、2 次……把每个可能值和它的概率列成一张表，就是分布列；再算个"平均命中次数"，就是期望。

分布列：X 取 x1,…,xn 的概率 p1,…,pn。要求 pi ≥ 0 且 Σpi  =  1。

期望（均值）：E(X)  =  Σ xi·pi（概率加权平均）。 方差：D(X)  =  Σ(xi−E(X))2pi  =  E(X2) − [E(X)]2（描述波动大小）。

记住它之前先看懂它：E(X) 就是"按概率加权的平均分"——概率大的取值在平均里分量重；D(X) 是"围绕这个平均分晃悠多大"，先算每个值离均值的平方、再按概率加权，所以是平方量纲。别把这两行当新符号死背，它们就是"加权平均"和"波动大小"两件事的算式。

性质（为什么 b 不影响方差）：E(aX+b)  =  aE(X)+b 很直观——每个数据平移 b，均值也平移 b。但 D(aX+b) = a2D(X)：整体加 b 只是把整条分布平移，数据之间的"离散程度"没变，所以方差里没有 b；整体乘 a 把波动放大 a2 倍，所以乘 a2。

例题跟讲例题：

例 3.3-a：X 分布列 P(X = 0) = 0.3, P(X = 1) = 0.5, P(X = 2) = 0.2，求 E(X)、D(X)。 解：E  =  0·0.3+1·0.5+2·0.2  =  0.9。 E(X2)  =  0·0.3+1·0.5+4·0.2  =  1.3。D  =  1.3 − 0.92  =  1.3 − 0.81  =  0.49。 要点：D  =  E(X2)−[E(X)]2 比直接算离差平方快。

小结：期望是"加权平均"，方差是"波动大小"。

编者注·本质回扣：期望 E(X) = Σxipi 看着是新公式，本质就是"按份额加权的平均数"。普通平均数是每个数权重相同（各占 1/n），期望是每个取值按它出现的概率 pi 加权——出现概率大的值，在"长期平均"里分量就重。这正是"概率 = 份额"的延续：pi 就是这个取值在全部可能里占的份额，把每个取值乘它的份额再相加，就得到随机变量的长期平均值。方差则是再算一次"围绕这个平均波动多大"，所以决策题先比期望（看平均收益）、期望相同再比方差（看稳不稳）。

3.4 三个重要分布

① 二项分布 X ~ B(n, p)：n 次独立重复试验，每次成功概率 p。

  • P(X = k)  =  C(n,k)·pk·(1−p)n−k
  • E(X)  =  np，D(X)  =  np(1−p)

② 超几何分布：N 个中有 M 个次品，抽 n 个（不放回），次品数 X：

  • P(X = k)  =  C(M,k)C(N−M,n−k)/C(N,n)
  • E(X)  =  n·M/N

③ 正态分布 X ~ N(μ, σ2)：连续型，中间高两边低的钟形曲线。

  • 关于 x  =  μ 对称；
  • P(μ−σ<X<μ+σ) ≈ 0.683，μ±2σ ≈ 0.954，μ±3σ ≈ 0.997。
  • 用法：求 P(X>a) 时，先看 a 离 μ 几个 σ，再用"对称+查表"。比如 a = μ+σ，则 P(X>μ+σ) = 1−0.8413 = 0.1587（因为 P(X<μ+σ) = 0.8413）。

记住它之前先看懂它：这三个分布别当三张孤立的表背——先看"取法"：独立重复、每次概率不变就是二项（投 n 次平均中 np 次）；一把抓出来不放回就是超几何（抽 n 个平均摊到 n·M/N 个次品）；无数个小误差加起来、连续取值的钟形就是正态。认出取法，公式自己就对上号。

例题跟讲例题：

例 3.4-a：投篮命中率 0.6，独立投 3 次，求恰好命中 2 次的概率与期望。 解：X~B(3,0.6)。P(X = 2) = C(3,2)·0.62·0.4  =  3·0.36·0.4  =  0.432。E(X) = np = 1.8。 要点：独立重复+概率不变 → 二项分布，期望直接 np。

小结：二项（有放回/独立重复）、超几何（不放回）、正态（连续钟形），三套模型认清楚。

辨析·有放回 vs 不放回（高考常考，一步一验）：袋中 3 红 2 白（共 5 个），从中取 3 个，记其中红球数为 X。

  • 若有放回：每次取到红球概率恒为 3/5，独立重复 3 次，X ~ B(3, 3/5)。E(X) = 3 × 0.6 = 1.8，D(X) = 3 × 0.6 × 0.4 = 0.72。
  • 若不放回：这是超几何分布（N = 5, M = 3, n = 3）。E(X) = n·M/N = 3 × 3/5 = 1.8，D(X) = n·(M/N)·(1−M/N)·(N−n)/(N−1) = 3 × 0.6 × 0.4 × 2/4 = 0.36。
  • 关键结论：两种取法期望相同（都是 1.8），但方差不同——有放回的方差 0.72 是不放回 0.36 的两倍。道理：不放回时每次取完不放，后面结果和前面有"反向锁定"关系，波动被压缩了。所以题目里"有放回/不放回"四个字，决定了用二项还是超几何，也决定了方差的答案。

3.5 高考大题结构（新情境）

给实际情境（比赛/质检/射击），三步走：

  1. 明确定义 X → 列全部取值；
  2. 算每个概率（古典/二项/超几何）→ 列表；
  3. 求 E(X)/D(X) → 比较方案做决策。

决策题逻辑：先比期望（谁大谁好）；期望相等再比方差（方差小的稳）。列完分布列一定回头验算 Σp = 1，这是送分的检查动作。

3.6 全概率公式（多阶段随机过程）

引入：生病可能由 A、B、C 三种原因引起，已知各原因概率和各原因下得病概率，求总得病概率——这就是全概率。

全概率公式：若 B1、B2、…、Bn 互斥且覆盖全部，则

P(A)  =  Σ P(Bi)·P(A|Bi)

道理：把 A 拆成"在每种情况下发生"的概率之和。

例题跟讲例题：

例 3.6-a：甲袋合格率 0.9、乙袋合格率 0.6，随机选一袋（各 1/2）抽一件，求抽到合格品概率。 解：P = ½·0.9 + ½·0.6 = 0.75。 要点：分情况（选哪袋），各算各的再加起来。

小结：全概率就是"分情况算概率再加权"。进阶/选学：反过来"已知结果求原因"的概率叫贝叶斯公式 P(Bk|A) = P(Bk)P(A|Bk)/ΣP(Bi)P(A|Bi)，它在医学检测、垃圾邮件过滤里天天用，新教材把它并入条件概率处理，会套全概率公式即可。

④ 例题详解（先做再看）

例题例 1（古典概型）：同时掷两枚骰子，求点数之和为 7 的概率。

自己做：总数 36，数一数和为 7 的。

解：基本事件总数 6 × 6  =  36。和为 7：(1,6)(2,5)(3,4)(4,3)(5,2)(6,1) 共 6 种。 P  =  6/36  =  1/6。 要点：总数先算清楚；两枚骰子不同，别漏 (3,4) 和 (4,3)。

例题例 2（条件概率）：袋中 3 红 2 白，不放回连取 2 个。已知第一个是红球，求第二个也是红球的概率。

自己做：条件概率，在"第一红"条件下算。

解：第一红后袋中剩 2 红 2 白。P(第二红 | 第一红)  =  2/4  =  1/2。 要点：条件概率  =  换样本空间（发生条件后重新数）；不放回是"抽签原理"来源。

例题例 3（二项分布）：投篮命中率 0.6，独立投 3 次，求恰好命中 2 次的概率与期望。

自己做：二项分布直接套。

解：X ~ B(3, 0.6)。P(X  =  2)  =  C(3,2)·0.62·0.4  =  3·0.36·0.4  =  0.432。 E(X)  =  np  =  3·0.6  =  1.8。 要点：独立重复 + 固定概率 → 二项分布；期望直接 np 不用列分布列。

例题例 4（期望决策）：两种方案收益分别为：A 稳得 100；B 有 0.5 概率得 200、0.5 概率得 0。选哪个？

自己做：比期望。

解：E(A)  =  100；E(B)  =  0.5·200 + 0.5·0  =  100。期望相同。 风险不同：A 无风险。若考虑方差：D(B)  =  0.5·1002 + 0.5·1002  =  10000 远大于 0。 要点：期望相同看方差/风险，这是高考"决策"题的完整逻辑。

例题例 5（全概率 + 超几何，别误当二项）（苏州教研·专题57，原书p.193）：某商店储存的 50 个灯泡中，甲厂占 60%、乙厂占 40%，甲厂一等品率 90%，乙厂一等品率 80%。(1) 随机抽 1 个，它是甲厂一等品的概率；(2) 随机抽 2 个，记其中"甲厂一等品"个数为 X，求分布列与 E(X)。

自己做：先算清楚两类灯泡各有几个。

解：甲厂灯泡 50 × 60%  =  30 个，其中一等品 30 × 90%  =  27 个；乙厂 20 个，其中一等品 16 个。

(1) 抽到甲厂一等品  =  27/50  =  0.54。

(2) 从 50 个里不放回抽 2 个，"甲厂一等品"共 27 个、非甲厂一等品共 23 个。这是超几何分布（不放回，每次抽中概率在变），不能套二项分布：

  • P(X = 0)  =  C(23,2)/C(50,2)  =  253/1225
  • P(X = 1)  =  C(27,1)·C(23,1)/C(50,2)  =  621/1225
  • P(X = 2)  =  C(27,2)/C(50,2)  =  351/1225

E(X)  =  (0·253 + 1·621 + 2·351)/1225  =  1323/1225  =  27/25  =  1.08（也可用超几何期望 n·M/N  =  2 × 27/50  =  27/25 验证）。

要点：不放回抽 → 超几何，不是二项；"每次抽中概率相等"才是二项，这里抽走一个总数就少一个。（对应《高级方法手册》6.1 全概率、6.4 分布模型。）

例题例 6（二项分布建模）（苏州教研·专题57，原书p.193）：A、B 两种药做对比，每个试验组 4 只小白鼠，2 只服 A、2 只服 B，服 A 有效概率 2/3、服 B 有效概率 1/2。一组中"A 有效只数 > B 有效只数"称甲类组。(1) 求一个试验组为甲类组的概率；(2) 观察 3 个试验组，记甲类组个数为 X，求分布列与 E(X)。

自己做：先把"A 有效只数""B 有效只数"各自的概率列出来。

解：设 k_A、k_B 分别为服 A、服 B 有效的只数。 P(k_A = 0) = (1/3)2 = 1/9，P(k_A = 1) = C(2,1)(2/3)(1/3) = 4/9，P(k_A = 2) = (2/3)2 = 4/9。 P(k_B = 0) = (1/2)2 = 1/4，P(k_B = 1) = C(2,1)(1/2)(1/2) = 1/2，P(k_B = 2) = (1/2)2 = 1/4。

(1) 甲类组  =  k_A > k_B：  =  k_A = 1,k_B = 0：(4/9)(1/4)  =  1/9 + k_A = 2,k_B = 0：(4/9)(1/4)  =  1/9 + k_A = 2,k_B = 1：(4/9)(1/2)  =  2/9 合计  =  4/9。

(2) 每个试验组"是否甲类组"独立重复、成功概率恒为 4/9，故 X ~ B(3, 4/9)：

  • P(X = 0)  =  C(3,0)(4/9)0(5/9)3  =  125/729
  • P(X = 1)  =  C(3,1)(4/9)(5/9)2  =  300/729
  • P(X = 2)  =  C(3,2)(4/9)2(5/9)  =  240/729
  • P(X = 3)  =  C(3,3)(4/9)3  =  64/729

E(X)  =  np  =  3 × (4/9)  =  4/3。

要点："每组独立、成功概率恒定"→ 二项分布；先把底层小概率（4/9）算准，再套二项分布列。（对应《高级方法手册》6.4 分布模型。）

⑥ 常见坑清单

  • 互斥 ≠ 独立：互斥事件 P(AB)  =  0，独立事件 P(AB)  =  P(A)P(B)——两个概念方向相反。
  • 条件概率 P(A|B) 分母是 P(B)，不是无条件概率。
  • 二项分布条件：独立 + 重复 + 概率不变；"不放回抽样"不是二项分布（是超几何）。
  • 分布列概率和必须为 1：算完检查，验算一步防错。
  • 期望的线性性质 E(aX+b)  =  aE(X) + b，方差 D(aX+b)  =  a2D(X)（b 不加）。
  • 决策题：期望相等时比方差（风险），别只停在期望。

与《高中数学常用公式·修订版》第十一部分"概率"核对一致；数字特征（期望/方差）口径与教材一致。

古典概型与事件关系

P(A)  =  A 包含的基本事件数 / 基本事件总数

  • 大白话所有结果等可能时，概率就是"有利份数"除以"总份数"。
  • 用的时候：先数清总数；两枚骰子要区分顺序，(3,4) 和 (4,3) 是两个。

互斥加法 P(A∪B)  =  P(A) + P(B)

  • 大白话两个事不能同时发生时，发生其一的概率就是相加。
  • 用的时候：互斥才加；不是互斥要减 P(AB)。

一般加法公式 P(A∪B)  =  P(A) + P(B) − P(A∩B)（苏州教研·专题25）

  • 大白话两个事都可能发生时，"至少一个发生" =  各自概率相加再减掉"同时发生"被重复算的那一块。
  • 用的时候：题目没说互斥就套它；互斥时 P(A∩B) = 0，它就退化成 P(A)+P(B)。A∪B  =  至少一个发生，A∩B  =  同时发生。

概率为 0 不一定是不可能事件，概率为 1 也不一定是必然事件（苏州教研·专题25）

  • 大白话几何概型里"恰好落在某一点"概率是 0，但这件事确实能发生；反过来"去掉一个点的区域"概率是 1，却不是全部。
  • 用的时候：别把"概率 0"直接等同于"不可能"；只有古典概型里两者才等价。

对立 P(A)  =  1 − P(A)

  • 大白话"不发生"的概率就是 1 减去发生的概率。
  • 用的时候：求"至少一个"正面难算时，转成求它的对立。

条件概率与独立

条件概率 P(A|B)  =  P(AB) / P(B)（P(B)>0）

  • 大白话已知 B 发生后，样本空间缩小成 B，在 B 里数 AB 占多少。
  • 用的时候：分母是 P(B)，不是 P(A)；不放回抽样就是换样本空间重新数。

独立 P(AB)  =  P(A)·P(B)

  • 大白话两件事互不影响，同时发生的概率就是各自概率相乘。
  • 用的时候：独立 ⇔ 此式成立；独立和互斥方向相反，互斥的事件一般不独立。

独立的传递性：若 A 与 B 独立，则 A 与 B、A 与 B、A 与 B 也都独立（苏州教研·专题56）

  • 大白话A 发不发生跟 B 没关系，那 A 跟"B 不发生"同样没关系，反过来也一样。
  • 用的时候：题目给"A、B 独立"，求 P(A·B) 时直接写 P(A)·P(B) = P(A)(1−P(B))，不用重新证。

互斥条件概率：若 B、C 互斥，则 P(B∪C | A)  =  P(B|A) + P(C|A)（苏州教研·专题56）

  • 大白话在 A 这个大前提下，B、C 不能同时发生，那"B 或 C 发生"的条件概率就是两个条件概率相加。
  • 用的时候：条件概率里遇到互斥事件求并，照样可以加。

概率运算四种类型口诀：加（互斥事件）、减（对立事件）、乘（独立事件）、除（古典/几何/条件概率）（苏州教研·专题56）

  • 大白话见互斥用加法、见对立用 1−、见独立用乘法、见"数份数/已知条件"用除法。
  • 用的时候：列式前先给题目归个类，知道该用哪把刀。

期望与方差

E(X)  =  Σ xi·pi

  • 大白话每个取值乘它的概率再加权，就是随机变量的"平均取值"。
  • 用的时候：列完分布列一定回头验算 Σpi=1。

D(X)  =  E(X2) − [E(X)]2

  • 大白话描述随机变量围绕均值波动多大，平方消掉正负抵消。
  • 用的时候：用 E(X2)−[E(X)]2 比硬算离差平方快；先算 E(X2)=Σxi2pi。

E(aX+b)  =  aE(X)+b；D(aX+b)  =  a2D(X)

  • 大白话期望跟着平移缩放一起变；方差只跟缩放、不跟平移（加 b 不变、乘 a 变 a2 倍）。
  • 用的时候：整体加一个常数，方差照写别加 b。

三个重要分布

二项分布 X~B(n,p)：E(X) = np，D(X) = np(1−p)

  • 大白话n 次独立重复、每次成功率 p，命中次数就是二项分布。
  • 用的时候：独立+重复+概率不变才用它；有放回抽样。

两点分布（0-1 分布）：E(X) = p，D(X) = p(1−p)（苏州教研·专题56）

  • 大白话只做一次试验、结果只有"成功 1 / 失败 0"两种，就是两点分布；它是 n = 1 的二项分布。
  • 用的时候：单次成败题直接套；D(X) = p(1−p) 和二项分布 n = 1 时一致。

超几何分布（不放回）：E(X)  =  n·M/N

  • 大白话N 个里 M 个次品，抽 n 个，期望次品数就是 n·M/N。
  • 用的时候：不放回抽样是超几何不是二项；期望和二项同口径，但方差更小。

超几何/混合球速算期望（仅客观题）：m 白 n 红 p 黑共 m+n+p 个球，任取 k 个，其中白球数期望 E(X)  =  k·m/(m+n+p)（苏州教研·专题56）

  • 大白话把球"打碎搅匀"，每个被取到的球里白球占比恒为 m/(m+n+p)，取 k 个就乘 k。
  • 用的时候：选择题快速出期望；解答题求分布列、方差时不能用它，要老实套超几何公式。

正态分布 X~N(μ,σ2)：μ±σ ≈ 0.683，μ±2σ ≈ 0.954，μ±3σ ≈ 0.997；P(Z<μ+σ) ≈ 0.8413

  • 大白话钟形曲线关于 μ 对称，离 μ 几个 σ 就套对应比例。
  • 用的时候：求 P(X>a) 先看 a 离 μ 几个 σ，再用对称；a=μ+σ 时 P(X<μ+σ)=0.8413、P(X>μ+σ)=0.1587。

正态密度函数 φ(x)  =  1/(√(2π)·σ) · e^(−(x−μ)2/(2σ2))（苏州教研·专题56）

  • 大白话这是那条钟形曲线的解析式；曲线与 x 轴围成的总面积  =  1，区间上的概率就是对应面积。
  • 用的时候：知道 μ = 均值、σ = 标准差即可，不必背解析式；样本里用 x 当 μ、用 √s（即 s）当 σ 把正态分布定下来。

3σ 原则（假设检验）：一次试验结果 a 落在 (μ−3σ, μ+3σ) 内就接受假设，落在外面就拒绝（苏州教研·专题56）

  • 大白话正态变量几乎 99.7% 挤在 μ±3σ 里，跑出去属于小概率事件，一次就发生说明原假设可疑。
  • 用的时候：产品尺寸正常波动范围就是 (μ−3σ, μ+3σ)；出界即判异常。

几何概型

几何概型 P(A)  =  构成事件 A 的区域长度（面积/体积）÷ 试验全部结果的区域长度（面积/体积）（苏州教研·专题25）

  • 大白话结果无限多又等可能时，概率不再是数份数，而是"长度比/面积比/体积比"。
  • 用的时候：一个变量在区间上取值 → 长度比；两个变量 (x,y) 在平面区域取值 → 面积比（先设全集 Ω、事件 A 再画图）；立体中取点 → 体积比。
  • 记忆要点：线段/圆周上动点用长度比；平面内动点用面积比；空间内动点用体积比。

全概率

全概率 P(A)  =  Σ P(Bi)·P(A|Bi)（Bi 互斥且覆盖全部）

  • 大白话把 A 按它发生的几种前提拆开，各算各的再加权求和。
  • 用的时候：多阶段、"先选哪袋再抽一件"这种题用它；反过来"已知结果求原因"用贝叶斯，会套全概率即可。

6.1 条件概率与全概率

大白话·本质一句话：条件概率就是"知道了一部分消息后重新数份额"——分母从整个样本空间缩小到已知条件那一块；全概率则是把一件事按它发生的几种前提拆开，各算各的份额再加权。

手册原文：P(A|B)=P(AB)/P(B)；全概率 P(A)=ΣP(Bi)P(A|Bi)。用于"多阶段随机过程"题。（新教材已入教材，务必熟练。）

课标依据：条件概率与全概率公式（选必三第 7 章）。✓ 不超纲。

联动本章：3.2 节例 3.2-a（袋中不放回取球）是条件概率最朴素的版本——"第一红"这个消息把分母从 5 个球缩到 4 个球；3.6 节例 3.6-a（选袋抽合格品）是全概率；例 5（灯泡）先分"甲厂/乙厂"两块算一等品份额，E(X)=27/25=1.08。

（高级方法手册·6.1）

6.2 期望的线性性

大白话·本质一句话：期望就是"加权平均数"，而平均数可以拆开算再相加——不管两个随机变量独立不独立，E(X+Y) 永远等于 E(X)+E(Y)，省得去列那长长的分布列。

手册原文：E(aX+bY+c)=aE(X)+bE(Y)+c；E(X+Y)=E(X)+E(Y)（不要求独立）。用于"求期望不用列全分布列"的题（如多个随机变量的和）。

课标依据：期望的线性性质（选必三）。✓ 不超纲。

联动本章：C2（2025 新高考Ⅰ卷第 14 题）设 Ii=第 i 号球至少被取到一次，X=ΣIi，E(X)=ΣE(Ii)=5·[1−(4/5)3]=61/25，正是靠这条"拆成指示变量相加"省去枚举所有情况。

（高级方法手册·6.2）

6.3 递推思想（马尔可夫链模型）—— 近两年高考压轴热点

大白话·本质一句话：马尔可夫递推就是"只盯着下一步从哪来"——第 n 步在某状态的概率只由第 n−1 步的状态决定，写成 Pn=f(Pn−1) 的递推式，再当数列题解出通项。

手册原文：

  • 适用信号：有状态转移的过程（传球、抽球、传染、走格），问"第 n 步处于某状态的概率"。
  • 操作步骤： 1. 设 Pn = 第 n 步处于目标状态的概率； 2. 找转移关系：Pn = f(Pn−1)（由第 n−1 步的状态转移而来）； 3. 得到一阶递推，用"构造等比"解出 Pn 通项（联动数列递推求通项方法）； 4. 再求期望等。
  • 例题：2023 年新高考及各省联考的传球模型、抽球模型。
  • 课标依据：条件概率 + 递推数列（选必二、选必三）。✓ 不超纲——这正是"数列与概率交叉"的高考热点。

6.4 分布模型公式速记

大白话·本质一句话：先认出这是哪一号分布——独立重复、有放回是二项；一把抓出来不放回是超几何；无数小因素加起来的连续钟形是正态——再各背一口期望方差口诀，不用每次现推。

一通百通

这一章的"通用骨架"是四步：① 定随机变量 X 及其全部取值 → ② 判断用哪个模型（古典数份数、独立重复用二项、不放回用超几何、连续钟形用正态）→ ③ 算每个取值的概率并列表（回头验算 Σpi=1）→ ④ 求 E(X)/D(X) 做决策（先比期望，期望相同再比方差）。条件概率和全概率只是在第②步里"换个样本空间重新数份额"。会解一道概率解答题，就会解所有概率题——灯泡、小白鼠、投篮、质检，骨子里都是"列分布列→求期望→比方案"。这套骨架下一章统计里"用样本频率估计概率"还会接上。

跨章结合

  • 第 17 章计数 + 本章概率 → 古典概型/超几何的"数份求概率"：袋中取球、卡片比大小这类题，第一步永远是用排列组合数清"总情况数"和"有利情况数"，再相除得概率。本章例 5（灯泡，苏州教研·专题57，原书p.193）先数清 50 个灯泡里甲厂一等品 27 个，再用超几何 C(27,k)C(23,2−k)/C(50,2) 列分布列；例 6（小白鼠）先把底层"A 有效只数>B 有效只数"的概率 4/9 算准，再套二项分布。计数不准，后面概率全盘皆错。
  • 本章概率 + 第 19 章统计 → 用样本估计总体概率与正态定参：本章 C1（2024 新高考Ⅰ卷第 9 题多选）就是把第 19 章的样本均值 x=2.1、样本标准差 s 当作正态分布的 μ、σ，把出口后亩收入 Y 定成 N(x,s2) 再套 3σ 比例判断——这正是"统计给参数、概率算区间"的握手处。

本章与前后章

概率（18）前面接第 17 章计数原理——古典概型的分子分母全靠排列组合去数，不会计数就列不出分布列；它后面接第 19 章统计——统计里"用样本频率估计总体概率""正态分布用样本均值 x、样本标准差 s 来定 μ、σ"，正是概率思想往"由样本推断总体"的延伸。本章例题 5（灯泡，E(X)=27/25=1.08）、例题 6（小白鼠，E(X)=4/3）就是全概率、二项分布的综合演练，把"算份额"这条主线走通，概率统计板块就立住了。

高考怎么考

新高考Ⅰ卷里概率是解答题主力（2023 起位置常在第 18–19 题区间），题型固定：新情境（比赛/质检/射击/药物对比）下列分布列、求期望方差、做方案决策；小题则考正态分布（如 2024 新高考Ⅰ卷第 9 题多选，本章 C1 已收录）、条件概率、古典概型计数（2024、2025 第 14 题，本章 C2、C3 已收录）。难度中档偏上，得分关键是"先判准模型（有放回二项、不放回超几何）、再列全分布列并验算 Σp=1"。它与 17 章计数、19 章统计共同构成概率统计解答题的完整链条。
