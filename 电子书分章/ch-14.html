公式速查：修订版 第4部分（立体几何）

本章本质核心：空间向量的本质是"给空间装上坐标"——把第 13 章那些靠眼睛看、靠辅助线想的几何关系，统统翻译成数字（坐标）运算。建系之后，一条线是什么就变成一个方向向量，一个面是什么就变成一个法向量；而"角"和"距离"看着是几何量，其实都是内积 a·b 的副产品——夹角靠 cosθ=内积/(模×模)，垂直靠内积=0，距离靠连线在法方向上的投影。本章全部题型（三类角、点到面距离、建系大题）都是这一个原理的变体。

为什么有用学了这章，立体几何解答题就从"靠灵感想辅助线"变成"照流程算坐标"——只要图形里有现成的墙角（三条两两垂直的棱），建系之后线线角、线面角、二面角和点到面距离都能按公式稳定算出来。想通"几何问题=坐标运算、角=内积"，法向量和那几个公式就是顺手推出来的，不必死背；这正是把立体几何大题变成可控拿分点的关键。

3.1 空间向量的坐标运算

引入：平面向量是带箭头的二维箭头，空间向量就是三维箭头——左右（x）、前后（y）、上下（z）三个方向都能动。建一个空间直角坐标系后，向量就从两个数变成三个数。

坐标运算：设 a=(x1,y1,z1)，b=(x2,y2,z2)：

  • 加减：a±b=(x1±x2, y1±y2, z1±z2)；
  • 数乘：λa=(λx1, λy1, λz1)；
  • 数量积 a·b = x1x2 + y1y2 + z1z2；
  • 模 |a|=√(x12+y12+z12)；
  • 夹角 cosθ = a·b/(|a||b|)；
  • 垂直 a⊥b ⇔ a·b=0；平行 ⇔ 对应坐标成比例。

建系原则：找三条两两垂直的棱作 x、y、z 轴。正方体、长方体、有"墙角"的直角棱锥最好建系；没有现成垂直就先作辅助线。大题里建完系要写一句"以 O 为原点，……为 x、y、z 轴建立空间直角坐标系"。

一个常见误判：三条轴必须两两垂直，不能凭直觉把"看起来垂直"就当垂直。若题目只给 PA⊥底面，就以 PA 为 z 轴、底面上两条互相垂直的方向为 x、y 轴；底面没有现成直角时，要先证明一对垂直再建系。

例题跟讲例题：a=(1,2,2)，求 |a|；a=(1,0,0) 与 b=(0,1,0) 的夹角。 解：|a|=√(1+4+4)=3；a·b=0 ⇒ cosθ=0 ⇒ θ=90°。

再跟一道（建系写坐标）：正方体棱长 1，以 A 为原点、AB 为 x 轴、AD 为 y 轴、AA1 为 z 轴，写出八个顶点坐标。 解：A(0,0,0)、B(1,0,0)、D(0,1,0)、A1(0,0,1)、C(1,1,0)、B1(1,0,1)、D1(0,1,1)、C1(1,1,1)。写坐标是建系法的第一步，每个点都要核对一遍，坐标错了后面全错。

空间向量基本定理与基底（苏州教研·专题48）：如果三个向量 a、b、c 不共面，那么空间任一向量 p 都能唯一写成 p = x·a + y·b + z·c。 这组不共面的 {a,b,c} 叫空间的一组基底。大白话：三维空间里随便挑三根不共面的箭头当"方向标"，任何向量都能拿它们拼出来——这就是建坐标系的老祖宗。

共线、共面向量定理（苏州教研·专题48）：

  • 共线：b≠0 时，a∥b ⇔ 存在实数 λ 使 a = λb；
  • 共面：a、b 不共线时，p 与 a、b 共面 ⇔ p = x·a + y·b。

四点共面 / 三点共线的充要条件（苏州教研·专题48）：对空间任一点 O 和不共线三点 A、B、C—— P、A、B、C 四点共面 ⇔ OP = x·OA + y·OB + z·OC，且 x+y+z = 1； 特别地，A、P、B 三点共线 ⇔ OP = x·OA + y·OB，且 x+y = 1。

  • 大白话用从 O 出发的向量表示 P，系数加起来等于 1，P 就落在 A、B、C 确定的平面（或直线）上。
  • 用的时候：证四点共面、求动点在面内的条件，小题直接套。

分点坐标公式（苏州教研·专题48）：若 A(x1,y1,z1)，向量 AB=(x2,y2,z2)，且 AP=λ·AB，则 P=A+λ·AB，即 P(x1+λx2, y1+λy2, z1+λz2)。

  • 大白话沿 AB 方向走 λ 倍，坐标每个分量都加 λ 倍的方向分量。
  • 用的时候：求棱上按比例分点的坐标，比硬算快。

3.2 法向量（最核心操作）

引入：描述一个平面"朝哪个方向立着"，最方便的是找一根垂直于它的箭头——法向量。有了法向量，后面所有的角和距离都能算。

定义：垂直于平面 α 的向量 n 叫平面 α 的法向量，即 n 与 α 内任意向量的数量积都是 0。

求法（大题标准三步）：

  1. 在平面内取两个不共线向量 u、v（用点的坐标相减得到）；
  2. 设 n=(x,y,z)，列方程组 n·u=0 且 n·v=0；
  3. 令某个分量为 1，解出另外两个，得到一个具体的法向量（法向量不唯一，差倍数都行）。

记住它之前先看懂它：法向量就是"垂直整个面的那根箭头"——面里随便两个不共线的方向 u、v 都躺在面上，n 要垂直整个面就得同时垂直 u 和 v，也就是 n·u=0 且 n·v=0；解这两个方程就是在找那根箭头，令一个分量为 1 只是为了把无穷多个平行箭头里挑一个整数的。

例题跟讲例题：平面过 A(1,0,0)、B(0,1,0)、C(0,0,1)，求法向量。 解：AB=(−1,1,0)，AC=(−1,0,1)。设 n=(x,y,z)：−x+y=0，−x+z=0 ⇒ y=x=z，取 n=(1,1,1)。

再跟一道（正方体里求法向量）：求正方体中平面 A1BD 的法向量（棱长 1，A 为原点）。 解：A1(0,0,1)、B(1,0,0)、D(0,1,0)。A1B=(1,0,−1)，A1D=(0,1,−1)。设 n=(x,y,z)：x−z=0，y−z=0 ⇒ x=y=z，取 n=(1,1,1)。可见换一个面，只要按"取两个不共线向量、列两个点积方程"这套流程，总能求出法向量。

用方向向量、法向量判断位置关系（苏州教研·专题48）：设直线 l、m 的方向向量为 a、b，平面 α、β 的法向量为 u、v，则——

要证 向量等价条件
l∥m a∥b，即 a=λb
l⊥m a⊥b，即 a·b=0
l∥α a⊥u，即 a·u=0
l⊥α a∥u，即 a=λu
α∥β u∥v，即 u=λv
α⊥β u⊥v，即 u·v=0

大白话线线关系看方向向量，线面关系看方向向量与法向量，面面关系看法向量之间。证平行就"方向成倍数"，证垂直就"数量积为 0"。

编者注·本质回扣：法向量为什么被称作"钥匙"？因为它把"一个平面朝哪个方向立着"这件难事，浓缩成了一根箭头。你看那张位置关系表：证线线平行或垂直，只要看两个方向向量成不成倍数、内积是不是 0；证线面、面面关系，本质也是方向向量与法向量、法向量与法向量之间做同样两件事。说白了，第 13 章要靠眼睛判断"这两个面平不平行、垂不垂直"，到这里全部降级成"算两组坐标成不成比例、点积等不等于 0"。这就是装上坐标的好处：几何判断变成了算术。

3.3 三类角（用向量求）

引入：异面直线的夹角、线和面的夹角、两个面的夹角，肉眼不好量，但都能翻译成向量夹角，套公式算。

所求 公式 注意
线线角 θ cosθ=|a·b|/(|a||b|) 取绝对值，θ∈[0,π/2]
线面角 θ sinθ=|a·n|/(|a||n|) 是 sin 不是 cos
二面角 θ cosθ=±(n1·n2)/(|n1||n2|) 正负看锐钝

记住它之前先看懂它：这三行公式别看花眼——它们都是"两个向量夹角 cosθ=a·b/(|a||b|)"这一颗种子长出来的：线线角直接取绝对值；二面角是两个法向量的夹角（或其补角）；线面角因为和法向量夹角差了个余角，才把 cos 换成 sin。

为什么线面角用 sin 线面角是斜线与它在面内射影的夹角，而斜线与法向量的夹角正好是它的余角，所以套进去得到 sinθ。这是最容易记混的一条。

例题跟讲例题：正方体棱长 1，求直线 A1B 与底面 ABCD 所成角的正弦值。 解：建系 A(0,0,0)、A1(0,0,1)、B(1,0,0)，方向向量 A1B=(1,0,−1)，底面法向量 n=(0,0,1)。sinθ=|−1|/(√2×1)=√2/2。

再跟一道（二面角）：正方体中二面角 D−A1A−B（即两个相邻面 ABB1A1 与 ADD1A1 的夹角）是多少度？ 解：棱是 AA1。面 ABB1A1 的法向量可取 (0,1,0)，面 ADD1A1 的法向量可取 (1,0,0)。cosθ=|0|/... 两者点积为 0，故二面角为 90°（本来就是相邻两面，互相垂直）。这道小题提醒：二面角 = 两个面法向量的夹角（或其补角）。

3.4 点到平面的距离

引入：求一个点离一个平面多远，几何上要"过点作面的垂线"，建系后就变成投影。

公式：点 P 到过点 A、法向量为 n 的平面的距离， d = |AP·n| / |n|。 道理：AP 在法方向上的投影长度就是点到面的垂距。

例题跟讲例题：求原点到平面 x+y+z=1 的距离。 解：面上取 A(1,0,0)，法向量 n=(1,1,1)，AP=(−1,0,0)（取 P=原点）。d=|−1|/√3=√3/3。

再跟一道（正方体里算距离）：棱长 1 的正方体中，求点 C1 到平面 A1BD 的距离。 解：面 A1BD 法向量 n=(1,1,1)（见 3.2 例题），面上取 A1(0,0,1)，点 C1(1,1,1)，A1C1=(1,1,0)。d=|1+1+0|/√3=2√3/3。算完可反代：正方体被平面 A1BD 切下的小三棱锥体积用等体积法也能得到同一结果，可交叉验算。

面积射影定理（苏州教研·专题48）：一个平面多边形面积为 S，它在另一个平面上的射影面积为 S′，两个平面所成的锐二面角为 θ，则 cosθ = S′ / S。

  • 大白话一个面斜着"投影"到另一个面上，面积被 cosθ 打了个折。
  • 用的时候：两条法向量不好找、二面角算不动时，算一下射影面积比反求 cosθ；也常用于"斜立锥体侧面投影"小题。

3.5 大题完整模板（建系法）

五步走：

  1. 建系，写出关键点坐标（先证三轴两两垂直）；
  2. 求所需向量：直线方向向量、平面法向量；
  3. 代入公式求角或距离；
  4. 二面角要判断锐角还是钝角，决定 cos 的正负；
  5. 下结论，线面角记得"公式结果是 sinθ"。

两个最常见失分点：一是坐标写错（尤其带分数的点），每个点算完都反推一遍棱长；二是线面角公式里写成 cos，记住"线面角用 sin"。二面角若题目说"锐角"就取正，说"钝角"就取负；没说就先算绝对值，再看图形是开口朝哪边。

小结：空间向量把立体几何大题变成"算坐标、套公式"的体力活；法向量是钥匙，线面角别写成 cos。

编者注·本质回扣：回头看三类角和距离那几个公式，别把它们当四条孤立结论死背，它们其实都是内积 a·b=|a||b|cosθ 这一个式子的变形：线线角、二面角直接就是两个方向（或法）向量的夹角；线面角因为和法向量的夹角正好差一个余角，才把 cos 换成 sin；点到面距离就是连线在法方向上的投影长度。所以建系五步里真正的"发动机"只有一个——数量积。你记住了内积这一颗种子，三类角和距离公式就能自己长出来，不必逐条硬背；这也是本章本质核心"角与距离都是内积的副产品"的落点。

④ 例题详解（先做再看）

例题例 1（求法向量）：平面 α 过点 A(1, 0, 0)、B(0, 1, 0)、C(0, 0, 1)，求 α 的一个法向量。

自己做：取两个向量，列方程组。

解：AB = (−1, 1, 0)，AC = (−1, 0, 1)。设 n = (x, y, z)： n·AB = −x + y = 0；n·AC = −x + z = 0 ⇒ y = x，z = x。取 x = 1 ⇒ n = (1, 1, 1)。 要点：令一个分量为 1 得整数解；法向量不唯一，方向相反也行。

例题例 2（线面角）：正方体 ABCD−A1B1C1D1 棱长为 1，求直线 A1B 与平面 ABCD 所成角的正弦值。

自己做：A1B 的方向向量，底面法向量是 (0, 0, 1)。

解：建系 A(0,0,0)，A1(0,0,1)，B(1,0,0)。A1B = (1, 0, −1)，底法向量 n = (0, 0, 1)。 sin θ = |A1B·n|/(|A1B||n|) = |−1|/(√2×1) = √2/2。 要点：线面角公式里是 sin，很多同学错写成 cos。

例题例 3（点到面距离）：上题中求点 A1 到平面 BCD1 的距离。

自己做：先求平面法向量，再套距离公式。

解：B(1,0,0)、C(1,1,0)、D1(0,1,1)。BC = (0,1,0)，BD1 = (−1,1,1)。 设 n = (x,y,z)：n·BC = y = 0；n·BD1 = −x + y + z = 0 ⇒ z = x。取 x = 1 ⇒ n = (1, 0, 1)。 取平面上点 B：BA1 = (−1, 0, 1)。d = |BA1·n|/|n| = |−1 + 1|/√2 = 0。 咦？A1 在平面 BCD1 上？检查：A1(0,0,1)，平面 BCD1 过 B(1,0,0) 法向 (1,0,1)：平面方程 x + z = 1，A1 代入 0 + 1 = 1 成立，确实在平面上。距离为 0 合理（此题作为"检查法"示范）。 换个距离题：求点 A1 到平面 BCC1 的距离：平面 BCC1 即 x = 1 面，法向 (1,0,0)，A1(0,0,1) 代入 d = |0 − 1| = 1。 要点：算完用平面方程反代检验，距离为 0 说明点在面上（正常）。

例题例 4（建系综合：线线角、线面角、体积）（苏州教研·专题19，原书p.76）：四边形 ABCD 为矩形，PD⊥平面 ABCD，PD=DC=2，BC=√2，E 是 PC 的中点。求：(1) 异面直线 AD 与 BE 所成角；(2) BE 与平面 PCD 所成角；(3) 三棱锥 P−BDE 的体积。

自己做：PD⊥底面，以 D 为原点建系。

解：以 D 为原点，DA 为 x 轴、DC 为 y 轴、DP 为 z 轴。由 PD=DC=2、BC=AD=√2，得 D(0,0,0)、A(√2,0,0)、C(0,2,0)、B(√2,2,0)、P(0,0,2)；E 为 PC 中点，E(0,1,1)。

(1) AD 方向向量取 (1,0,0)，BE=E−B=(−√2,−1,1)，|BE|=√(2+1+1)=2。 cosθ=|(1,0,0)×(−√2,−1,1)|/(1×2)=√2/2 ⇒ θ=45°。

(2) 平面 PCD 上 P、C、D 的 x 坐标都是 0，即该平面为 x=0，法向量 n=(1,0,0)。 sinθ=|BE·n|/(|BE||n|)=√2/2 ⇒ θ=45°。

(3) 换顶点求体积（等体积法）：V(P−BDE)=V(B−PDE)。面 PDE 即 x=0，△PDE 中 PD=2（在 z 轴上），E 到 z 轴距离为 1，故 S△PDE=½·2×1=1；点 B 到面 PDE（x=0）的距离 = √2。 V=⅓·1·√2=√2/3。

要点：建系后每个坐标逐点核对；平面 PCD 三个点 x 都为 0，一眼看出法向量 (1,0,0)；体积换个好算的底面（△PDE 在坐标面内，面积好算）。

  3. 向量 a = (1, 0, 0) 与 b = (0, 1, 0) 的夹角是多少？

11.【考点：建系求二面角】（2024 新高考Ⅰ卷·解答第 17 题第 (2) 问）四棱锥 P−ABCD 中，PA⊥底面 ABCD，PA=AC=2，BC=1，AB=√3。若 AD⊥DC，且二面角 A−CP−D 的正弦值为 √42/7，求 AD。

⑥ 常见坑清单

  • 线面角用 sin、线线角用 cos（带绝对值），公式别串。
  • 法向量方程组：取两个不共线向量；共线会解不出唯一方向。
  • 二面角 cos 的正负：看两个法向量是"同向进"还是"反向进"，大题写清锐/钝角。
  • 建系要证明三条轴两两垂直（大题要写一句话），别默认垂直。
  • 距离公式：AP 用"任意点 − 平面上的点"，分母是法向量模。
  • 坐标写错是最常见失分点：每个点坐标算完检查一遍再代入。

本章公式速查表

口径与《高中数学常用公式·修订版》第四部分（空间向量部分）一致。

空间向量坐标运算

加减与数乘：a±b=(x1±x2, y1±y2, z1±z2)；λa=(λx1, λy1, λz1)

  • 大白话对应坐标分别加、减、乘。
  • 用的时候：先建系写对坐标，坐标错了后面全错。

数量积：a·b = x1x2 + y1y2 + z1z2

  • 大白话对应坐标相乘再相加，结果是个数。
  • 用的时候：判断垂直就靠它——等于 0 就垂直。

模：|a| = √(x12 + y12 + z12)

  • 大白话三个坐标平方加起来开根号，就是向量长度。

夹角：cosθ  =  a·b/(|a||b|)

  • 大白话数量积除以两个模，就是夹角余弦。

垂直与平行：a⊥b ⇔ a·b = 0；a∥b ⇔ 对应坐标成比例

  • 大白话垂直看数量积为 0，平行看坐标成倍。

法向量

法向量 n：垂直于面内两个不共线向量 u、v，即 n·u  =  0 且 n·v  =  0

  • 大白话找一根垂直整个面的箭头，后面求角求距离全靠它。
  • 用的时候：在面内取两个不共线向量，列两个点积方程，令一个分量为 1 解出。

三类角（套公式）

线线角 θ：cosθ  =  |a·b|/(|a||b|)，θ ∈ [0, π/2]

  • 大白话两条方向向量夹角取绝对值，只取锐角直角。

线面角 θ：sinθ  =  |a·n|/(|a||n|)，θ ∈ [0, π/2]

  • 大白话斜线与法向量夹角的余角，所以用 sin 不是 cos。
  • 用的时候：这是最容易记混的一条，千万别写成 cos。

二面角 θ：cosθ = ±(n1·n2)/(|n1||n2|)，正负看锐钝

  • 大白话两个面法向量的夹角（或补角）。
  • 用的时候：题目说锐角取正、钝角取负；没说先算绝对值再看图开口方向。

点到平面的距离

d  =  |AP·n|/|n|（A 是面上一点，n 是面法向量）

  • 大白话连线 AP 在法方向上的投影长度。
  • 用的时候：AP 用"任意点 − 面上一点"，分母是法向量的模；算完用平面方程反代检验。

共面共线与投影（苏州教研·专题48）

四点共面：OP = x·OA+y·OB+z·OC ⇔ x+y+z = 1；三点共线：OP = x·OA+y·OB ⇔ x+y = 1

  • 大白话系数加起来等于 1，P 就落在 A、B、C 确定的面（线）上。
  • 用的时候：证四点共面、求动点在面内的条件。

分点坐标：P=A+λ·AB ⇒ P(x1+λx2, y1+λy2, z1+λz2)

  • 大白话沿方向向量走 λ 倍，每个分量加 λ 倍。
  • 用的时候：棱上按比例分点坐标，秒算。

空间两点距离：|AB| = √((x2−x1)2+(y2−y1)2+(z2−z1)2)

  • 大白话坐标差平方和开根号，就是模公式的两点版。

面积射影定理：cosθ  =  S′/S（S 原面积，S′ 射影面积，θ 两面锐二面角）

  • 大白话斜面积投影到另一个面，乘以 cosθ。
  • 用的时候：法向量不好求时，用射影面积比反求二面角。

进阶 1：空间向量建系法（大题主力）

7.1 空间向量建系法（选必一，大题主力）

大白话·本质一句话：建系法就是"给空间装上坐标"——把靠眼睛想辅助线变成照流程算坐标：找到三条两两垂直的棱当轴，写坐标、求法向量，角和距离全是内积的副产品。

手册原文：流程：建系（优先找三条两两垂直的线）→ 写坐标 → 求法向量（叉积或解方程）→ 套公式：

  • 线面角：sinθ = |cos<n,v>|；二面角：cosθ = |cos<n1,n2>|（注意锐钝判断）；点到面距离 d=|PA·n|/|n|。

课标依据：空间向量（选必一）。✓

注意：二面角锐钝判断靠"观察法向量方向"，别丢符号。

联动本章：详见 3.5 五步模板与本章例 4（建系综合，45°/45°/√2/3）；C 组第 11 题（2024 新高考Ⅰ卷解答第 17 题第 (2) 问）是建系法主场。

（高级方法手册·7.1）

7.2 外接球补形模型速查

大白话·本质一句话：补形就是"把歪着放的四面体塞进一个长方体里"——一旦补成长方体，外接球直径立刻变成长方体的体对角线，半径就是对角线的一半。

手册原文：

几何体 模型 半径
长方体/墙角三棱锥 补成长方体 R=½√(a2+b2+c2)
正四面体边长 a 内嵌正方体 R=a√6/4
直棱柱底面外接圆半径 r 轴截面 R2=r2+(h/2)2
对棱相等三棱锥 补成长方体 同上

课标依据：球的表面积体积 + 长方体对角线（必修二）。✓

跨章联动：本表与第 13 章"立体几何初步"中外接球既有内容配套——第 13 章讲球的概念、截面与表面积体积，这里给"补形"速查模型；遇墙角三棱锥（三条侧棱两两垂直）直接套 R=½√(a2+b2+c2)，对棱相等的三棱锥也补成长方体。

（高级方法手册·7.2）

7.3 等体积法

大白话·本质一句话：等体积法就是"同一个三棱锥换个顶点当尖"——三棱锥四个面都能当底，体积不变，高和底面积来回倒腾，哪条高好算就换哪个顶点。

手册原文：换顶点求高/体积（三棱锥），避免建系算距离的繁琐；截面问题画"过已知点的截面"按"延长交棱"操作。

课标依据：三棱锥体积公式 V=⅓·S·h（必修二）。✓

联动本章：例 4 第 (3) 问求三棱锥 P−BDE 体积，正是换顶点 V(P−BDE)=V(B−PDE)，把底面换到坐标面 PDE 上，S△PDE=1、高=√2，得 V=√2/3；3.4 节点 C1 到平面 A1BD 的距离（d=2√3/3）也可用等体积法交叉验算。

课后习题答案

自测答案：1. AB = (−1, 0, 1)，AC = (0, −1, 1)；n·AB = −x + z = 0，n·AC = −y + z = 0 ⇒ x = y = z，取 (1, 1, 1)；2. √(1+4+4) = 3；3. cos θ = 0 ⇒ θ = 90°；4. sin；5. 点与面上任一点连线在法向量方向上的投影绝对值（|AP·n|/|n|）。

A 组答案

A 组

  1. |a|=√(4+9+36)=7。
  2. a·b=1×2+(−2)(−1)+2×0=2+2+0=4。
  3. AB=(−1,2,0)，AC=(−1,0,3)。设 n·AB=−x+2y=0，n·AC=−x+3z=0，得 y=x/2，z=x/3，取 x=6 得 n=(6,3,2)。
  4. cosθ=|1+0+0|/(√2·√2)=1/2。
  5. sinθ=|a·n|/(|a||n|)，a 为斜线方向向量，n 为平面法向量。
  6. 平面 2x+2y+z−6=0，d=|0+0+0−6|/√(4+4+1)=6/3=2。

B 组答案

B 组

  1. 建系 A(0,0,0)、B(1,0,0)、D(0,1,0)、D1(0,1,1)。BD1=(−1,1,1)，底面法向量 n=(0,0,1)。sinθ=|1|/(√3×1)=√3/3。
  2. cosθ=|n1·n2|/(|n1||n2|)=1/(√2·√2)=1/2。
  3. 面 A1BD：A1(0,0,1)、B(1,0,0)、D(0,1,0)。A1B=(1,0,−1)，A1D=(0,1,−1)，法向量 n=(1,1,1)。取 A1 为面上点，AA1=(0,0,1)。d=|0+0+1|/√3=√3/3。
  4. A1C=(1,1,−1)，底面法向量 n=(0,0,1)。线面角 sinθ=1/√3，则 tanθ=sin/√(1−sin2)=(1/√3)/√(2/3)=√2/2。

C 组答案

C 组

  1. 建系 A(0,0,0)、C(2,0,0)、P(0,0,2)；由 AB=√3、BC=1 得 B(3/2,√3/2,0)。设 D=(u,v,0)，由 AD⊥DC 得 u2+v2=2u。平面 ACP 即 y=0，法向量 n1=(0,1,0)。平面 DCP 的法向量 n2=CP×CD=(−2v, 2u−4, −2v)。由 sin(二面角)=√42/7 得 |cos<n1,n2>|=√7/7，即 (2−u)/√(2v2+(2−u)2)=√7/7。平方化简得 v2=3(2−u)2，结合 v2=2u−u2 解得 u=3/2（舍去退化 u=2），v=√3/2。于是 AD=√(u2+v2)=√(9/4+3/4)=√3。

一通百通

遇到立体几何解答题，本质都是"建系→写坐标→求法向量→用内积套公式"这一条流水线：先找三条两两垂直的棱建系（大题要写一句垂直依据），把每个点坐标写对——错一个坐标全题崩；要角就取方向向量或法向量，线线角、二面角用 cos，线面角用 sin；要距离就套 d=|AP·n|/|n|。会这五步，第 13 章那些靠辅助线、靠灵感的难题，到这里都退化成算坐标。这套"几何问题坐标化、坐标问题内积化"的骨架，和后面解析几何（15、16 章）是同一个思想。

跨章结合

  • 本章坐标运算 × 第 09 章平面向量：本章的加减、数乘、数量积、模、夹角公式，一个符号都没改，只是把坐标从二维 (x,y) 升到三维 (x,y,z)。所以平面向量（09 章）学扎实了，空间向量等于白送；门槛自测第 1 题就是在考你这条迁移。（综合原理说明，非真题）
