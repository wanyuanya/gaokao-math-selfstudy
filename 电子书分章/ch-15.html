公式速查：修订版 第5部分（直线与圆）

本章本质核心：直线与圆是解析几何的第一步——给"几何图形"装上"方程"这台计算器。从此平行、垂直、距离、相切、相交，这些靠眼睛看的几何关系，全部变成坐标代数运算：平行比斜率 k1 = k2、垂直看 k1k2 = −1，距离套 |Ax0+By0+C|/√(A2+B2)，圆与直线的位置关系就比"圆心到直线距离 d"和"半径 r"两个数。本章所有题型都是这一个原理的变体；而圆的"圆心 (a,b)+半径 r"是最短的信息包，记住它，标准方程、弦长、切线全从这两个数长出来。

为什么有用想通了"几何关系 = 代数运算"这一步，导航算路程、铺管线找最短距离、判断一条路会不会碰到某个圆，全都变成套公式的代数题；考试里那些"距离、位置、切线"小题，也就不再靠目测，而是算一个 d、比一次 r 就定案。原理想通了，公式是顺带的事，不用死背。

3.1 直线的倾斜角与斜率

引入：你站在坡上，坡有陡有缓。坡越陡，往上爬越费劲；数学上用一个数把"陡的程度"量化出来，这个数就是斜率。爬楼时每往前走 1 米、高度抬升多少，斜率就是"上升量 ÷ 前进量"。路是水平的（不升不降），斜率就是 0；路竖起来（没法往前走了），这个比值就没法写了——也就是"斜率不存在"。

正式定义（人教A版口径）：

  • 倾斜角 α：当直线 l 与 x 轴相交时，取 x 轴为基准，x 轴正向与直线 l 向上方向之间所成的角 α 叫做直线 l 的倾斜角。规定 α ∈ [0, π)。与 x 轴平行或重合时 α  =  0。
  • 斜率 k：当 α ≠ 90° 时，k  =  tan α。
  • 过两点 P1(x1, y1)、P2(x2, y2) 的斜率（x1 ≠ x2）：

k  =  (y2 − y1) / (x2 − x1)  =  Δy / Δx

直观理解（看图）：

斜率 k 就是"Δy 比 Δx"。k  =  0 是水平线；k > 0 直线往上翘；k 越大翘得越陡；α  =  90° 时直线垂直于 x 轴，Δx  =  0，分母为 0，斜率不存在（这条直线不能写成 y  =  kx + b）。

性质（逐条验证）：

  1. k 的正负：k > 0 ⇔ α 是锐角（直线从左下到右上）；k < 0 ⇔ α 是钝角（从左上到右下）。验证：tan 在 (0, π/2) 为正、(π/2, π) 为负，正好对应。
  2. k 的大小：在 α ∈ [0, π/2)，α 越大 k 越大、线越陡。
  3. 倾斜角相同的两条直线互相平行。

两直线平行与垂直（斜率都存在时）：

  • 平行 ⇔ k1  =  k2（且不重合）。道理：倾斜角一样才平行。
  • 垂直 ⇔ k1·k2  =  −1。道理：垂直就是方向转 90°，倾斜角相差 90°，正切值正好互为负倒数。

斜率不存在 / 一般式时的补充判定（苏州教研·专题20）：

  • 一般式判垂直：两直线 l1:A1x+B1y+C1 = 0、l2:A2x+B2y+C2 = 0，则 l1⊥l2 ⇔ A1A2 + B1B2  =  0。不用先求斜率，竖直直线也成立，比 k1k2 = −1 更通用。
  • 方向向量：斜率为 k 的直线，一个方向向量是 (1, k)；写成一般式 Ax+By+C = 0 时，它的一个方向向量是 (B, −A)。反过来，方向向量 u⃗ = (m, n) 对应的斜率 k  =  n/m（m≠0）。

计算流程（求斜率）：

  1. 若已知两点 → 套 k  =  (y2−y1)/(x2−x1)；
  2. 若已知倾斜角 α → k  =  tan α（先确认 α ≠ 90°）；
  3. 若直线方程已给出（如 Ax+By+C = 0）→ 先化成 y  =  kx+b，看 x 的系数。

例题跟讲例题：

例 3.1-a：已知直线过 A(2, 3)、B(5, 9)，求斜率和倾斜角。 解：k  =  (9−3)/(5−2)  =  6/3  =  2。因为 k  =  2 > 0，倾斜角 α 满足 tan α  =  2，是个锐角。 要点：Δy 是"后减前"，x、y 要按同一点顺序减，别一个从 A 减 B、一个从 B 减 A。

例 3.1-b：直线过 P(1, 2)，且与斜率为 −1/3 的直线垂直，求它的斜率。 解：垂直 ⇒ k·(−1/3)  =  −1 ⇒ k  =  3。 要点：垂直就是负倒数，"乘起来等于 −1"。

常见陷阱：

  • 斜率不存在（竖直直线 x  =  常数）时，别硬套 k1k2  =  −1；此时与之垂直的反而是水平线（k  =  0）。
  • 平行要同时排除"重合"：k1  =  k2 还不够，得截距不同。

小结：斜率 k  =  Δy/Δx 是描述直线"陡和向哪歪"的数；平行看 k 等不等，垂直看乘积等不等于 −1。

3.2 直线方程的五种形式（会互化）

引入：要把一条直线"写死"在纸上，需要几个条件？给你一个点和一个方向，直线就唯一确定了；给你两个点，也唯一确定。不同的已知条件，对应不同写法。就像你介绍一个人，可以说"他是张三的爸爸"，也可以说"他身高 1 米八"——指的是同一个人，只是角度不同。

五种形式（黑体为必背）：

形式 方程 什么时候用
点斜式 y − y0  =  k(x − x0) 知道斜率 k + 一点 (x0, y0)
斜截式 y  =  kx + b 知道斜率 k + 纵截距 b
两点式 (y−y1)/(y2−y1)  =  (x−x1)/(x2−x1) 知道两点
截距式 x/a + y/b  =  1 知道横截距 a、纵截距 b
一般式 Ax + By + C  =  0（A、B 不同时为 0） 最通用，统一计算

互化流程（编号步骤）：

  1. 点斜式展开 → 斜截式（解出 y）；
  2. 斜截式移项 → 一般式（全部挪到左边）；
  3. 一般式求斜率：把 y 解出来，k  =  −A/B（B ≠ 0）。

性质/验证：截距式里 a 是直线与 x 轴交点的横坐标（令 y  =  0），b 是与 y 轴交点纵坐标（令 x  =  0）。截距式要求 a、b 都不为 0——过原点的直线或垂直坐标轴的直线不能用截距式。

例题跟讲例题：

例 3.2-a：已知直线过点 (2, −1)，斜率为 3，写出点斜式、斜截式、一般式。 解：点斜式 y − (−1)  =  3(x − 2)，即 y + 1  =  3(x − 2)。 斜截式：y  =  3x − 7。一般式：3x − y − 7  =  0。 要点：三种写法同一条直线，互相推。

例 3.2-b：直线过 (1, 0) 和 (0, 2)，写截距式。 解：横截距 a  =  1（与 x 轴交于 (1,0)），纵截距 b  =  2。截距式 x/1 + y/2  =  1。 要点：截距是坐标值，可正可负，不是距离。

常见陷阱：

  • 斜率不存在的直线是 x  =  x0（竖直），它写不进 y  =  kx + b，别漏。
  • "截距"不是"距离"：截距可负，距离恒正。

小结：见到已知条件，选最顺手的形式起手，最后统一化到一般式做计算。

3.3 距离公式（必背）

引入：平面上两点隔多远？点到一条直线"最近"是多近？这两个问题天天用——导航算路程、建管线算最短距离。勾股定理是它们的老祖宗。

公式：

  1. 两点距离：P1(x1,y1)、P2(x2,y2) d  =  √[(x2−x1)2 + (y2−y1)2]（勾股：横差、纵差为两条直角边）

  2. 点到直线距离：点 P(x0, y0) 到直线 Ax + By + C  =  0 d  =  |Ax0 + By0 + C| / √(A2 + B2)

  3. 两平行线距离：Ax + By + C1  =  0 与 Ax + By + C2  =  0 d  =  |C1 − C2| / √(A2 + B2)（任取一条上一点，套点到直线距离）

推导/验证（点到直线距离为什么长这样）：把点代入左边 Ax0+By0+C，它的绝对值衡量"离直线有多远"，再除以 √(A2+B2) 归一化。直觉上：直线法向量就是 (A, B)，长度 √(A2+B2)，点到直线距离就是沿法向量方向量过去，所以要除以这个长度。分子套绝对值，因为距离不能为负。

计算流程：

  1. 点到直线距离：先把直线化成 Ax+By+C = 0（A、B、C 同号移项无所谓，但必须等于 0）；
  2. 把点坐标代入分子，套绝对值；
  3. 分母 √(A2+B2)；
  4. 两平行线：先保证 x、y 系数完全一样（不一样就乘倍数化一致），再 |C1−C2|。

例题跟讲例题：

例 3.3-a：求原点 (0,0) 到直线 3x + 4y − 10  =  0 的距离。 解：d  =  |0 + 0 − 10| / √(9+16)  =  10/5  =  2。 要点：分子代入 0，常数项别丢；分母 32+42 = 25 开根号是 5（勾股数）。

例 3.3-b：求平行线 2x + y + 1  =  0 与 2x + y − 5  =  0 的距离。 解：系数一致（都是 2,1），d  =  |1 −(−5)|/√(4+1)  =  6/√5  =  6√5/5。 要点：C1、C2 一正一负，相减变相加，别漏绝对值里的符号。

常见陷阱：

  • 套点到直线距离前，直线必须是" =  0"的形式；y  =  x + 1 要先写成 x − y + 1  =  0。
  • 两平行线距离公式要求 x、y 系数完全相同，一个是 2x、另一个是 4x 时先把后者除以 2。

小结：距离就三条公式，核心是"点到直线先化一般式、分子绝对值、分母勾股"。

3.4 圆的方程

引入：圆是"到定点距离等于定长的所有点"。定点是圆心，定长是半径。把这句话翻译成坐标方程，就是圆的方程。

正式定义：平面上到定点 C(a, b) 的距离等于定长 r 的点的轨迹叫圆。

  • 标准方程：(x − a)2 + (y − b)2  =  r2，圆心 C(a, b)，半径 r。
  • 一般方程：x2 + y2 + Dx + Ey + F  =  0。

配方可得：圆心 (−D/2, −E/2)，半径 r  =  ½√(D2 + E2 − 4F)。

直观理解：标准方程一眼看出圆心半径；一般方程是展开后的样子，需要配方才看得出来。

性质/验证：

  1. 一般方程表示圆的条件：D2 + E2 − 4F > 0。等于 0 时半径 0，只是一个点；小于 0 时没有实数点，根本不是圆。
  2. 一般方程没有 xy 项，且 x2、y2 系数相等（都是 1）——这是判断"这个二次方程是不是圆"的眼。
  3. 直径式方程（苏州教研·专题22）：若 A(x1,y1)、B(x2,y2) 是圆的一条直径两端点，则圆可直接写成 (x−x1)(x−x2) + (y−y1)(y−y2)  =  0。道理：圆上任一点 P 对直径 AB 张直角（直径所对圆周角是 90°），即 PA⃗·PB⃗  =  0。

计算流程（一般式 ↔ 标准式）：

  1. 一般式化标准式：对 x、y 分别配方（x2+Dx 配成 (x+D/2)2 − D2/4）；
  2. 标准式展开 → 一般式（展开平方、合并常数）。

例题跟讲例题：

例 3.4-a：求圆 x2 + y2 − 4x + 6y − 3  =  0 的圆心和半径。 解：配方：(x2−4x) + (y2+6y)  =  3 → (x−2)2 − 4 + (y+3)2 − 9  =  3 → (x−2)2 + (y+3)2  =  16。 圆心 (2, −3)，半径 r  =  4。 要点：配方时左边配了多少，右边就加多少；D = −4、E = 6、F = −3，r = ½√(16+36+12) = ½√64 = 4。

常见陷阱：

  • 半径公式里是 √(D2+E2−4F)，别漏那个 −4F；F 是负的，−4F 反而变大。

小结：标准方程看一眼就知道圆心半径；一般方程配方还原。

编者注·本质回扣：为什么圆非要在"标准式"和"一般式"之间来回配方？说白了，标准方程 (x−a)2+(y−b)2 = r2 一眼就读出圆心和半径，这是几何信息最紧凑的"信息包"；而题目给你的往往是展开后的一般式 x2+y2+Dx+Ey+F = 0，看不出圆心在哪。配方不是白做的功夫，它就是把"展开后被打乱的几何信息"重新装回圆心半径这个最短信息包——后面算 d、比 r、求弦长，靠的全是这个 (a,b) 和 r。所以见到圆的方程，第一反应永远是"先把它变回圆心+半径"。

3.5 直线与圆的位置关系

引入：拿一个圆环（圆）往一条直线上放——要么不挨（相离），要么正好碰一下（相切），要么穿过去（相交，切出一条弦）。怎么判断？量一量"圆心到直线的距离 d"和"半径 r"谁大谁小就行，根本不用把交点算出来。

判定（核心：比 d 和 r）：

设圆心到直线距离为 d，半径为 r。

关系 条件 交点
相离 d > r 0 个
相切 d  =  r 1 个（切点）
相交 d < r 2 个（弦）

弦长公式：相交时，弦长 |AB|  =  2√(r2 − d2)。道理：半条弦、半径、圆心到直线垂线构成直角三角形，半弦  =  √(r2−d2)，整条弦乘 2。

切线求法：

  • 切点 (x1, y1) 在圆上时：切线方程 (x1−a)(x−a) + (y1−b)(y−b)  =  r2（记住"半径垂直切线"）。
  • 过圆外一点求切线：设斜率 k，写成点斜式，令圆心到它距离  =  r，解出 k。有两条，注意 k 不存在（竖直切线）的那条别漏。

计算流程（直线与圆位置问题）：

  1. 写出圆心 (a,b) 和半径 r；
  2. 用点到直线距离公式算 d；
  3. 比 d 与 r：>、 = 、< 定关系；
  4. 相交再用弦长公式 2√(r2−d2)。

例题跟讲例题：

例 3.5-a：判断直线 3x + 4y + 5  =  0 与圆 x2 + y2  =  4 的位置关系。 解：圆心 (0,0)，r  =  2。d  =  |0+0+5|/√(9+16)  =  5/5  =  1。 d  =  1 < r  =  2 ⇒ 相交。弦长  =  2√(4 − 1)  =  2√3。 要点：先 d 后 r，一步定关系。

例 3.5-b：求过圆 x2+y2  =  4 上点 (1, √3) 的切线方程。 解：半径斜率  =  √3/1  =  √3，切线垂直半径 ⇒ 切线斜率  =  −1/√3。 点斜式：y − √3  =  (−1/√3)(x − 1)，整理 x + √3 y − 4  =  0。 要点：切线⊥过切点的半径，这是求切线斜率的钥匙。

常见陷阱：

  • 弦长公式里的 d 是圆心到直线距离，不是"弦到圆心的距离"（其实就是一个东西，但别拿弦长的一半来代）。
  • 过圆外点切线有两条，解 k 的二次方程通常两个根；还要单独想有没有竖直切线。

小结：直线圆问题，九成是"算 d、比 r"，弦长、切线都从这个判定长出来。

编者注·本质回扣：为什么判断直线和圆"相离、相切、相交"不用真的去解交点？这正是解析几何的精髓——把"两条曲线交几个点"这种几何问题，翻译成"比两个数的大小"这个代数问题。圆心到直线距离 d 是算出来的，半径 r 是现成的，d 比 r 大就是不挨、相等就是相切、小就是穿过去。弦长 2√(r2−d2)、切线 d = r，也都是同一个"d 与 r 比大小"长出来的副产品。会算这一个 d，整章的位置关系题就都通了——这就是"给几何装上方程"的第一次实战。

3.6 圆与圆的位置关系（选学拓展）

两个圆放一起，看圆心距 d 和两半径 R、r（设 R ≥ r）：

  • d > R+r：外离（互不搭界）；
  • d  =  R+r：外切（外挨一下）；
  • R−r < d < R+r：相交（两个交点）；
  • d  =  R−r：内切；
  • d < R−r：内含。

判断方法和直线圆一模一样——量"圆心距"比"半径和差"。

公共弦所在直线（苏州教研·专题22）：两圆一般式 C1:x2+y2+D1x+E1y+F1 = 0、C2:x2+y2+D2x+E2y+F2 = 0 相交时，把两式相减：

(D1−D2)x + (E1−E2)y + (F1−F2)  =  0

  • 大白话相减消掉了 x2、y2，剩下的一次方程过两个交点，就是公共弦（相交时）、公切线（相切时）所在直线。

小结：圆与圆还是"距离比半径"，只是把"到直线距离"换成"圆心距"。

④ 例题详解（先做再看）

例题例 1（垂直斜率）：直线 l1：2x + y − 1  =  0，求与 l1 垂直且过点 (1, 2) 的直线方程。

自己做：先求斜率，用点斜式。

解：l1 斜率 k1  =  −2；垂直 ⇒ k2  =  1/2。点斜式：y − 2  =  (1/2)(x − 1)，即 x − 2y + 3  =  0。 要点：垂直斜率互为负倒数（k1k2  =  −1）。

例题例 2（点到直线距离）：求点 (2, 1) 到直线 3x − 4y + 5  =  0 的距离。

自己做：套公式。

解：d  =  |3·2 − 4·1 + 5| / √(9 + 16)  =  |6 − 4 + 5|/5  =  7/5。 要点：绝对值在分子、根号在分母；A2 + B2 别算错。

例题例 3（直线与圆）：圆 x2 + y2  =  4 与直线 y  =  x + b 相切，求 b。

自己做：圆心 (0,0) 到直线距离  =  半径 2。

解：直线 x − y + b  =  0，d  =  |0 − 0 + b|/√2  =  |b|/√2  =  2 ⇒ |b|  =  2√2 ⇒ b  =  ±2√2。 要点：相切 ⇔ d  =  r；"相离/相交/相切"一律先算 d。

⑥ 常见坑清单

  • 斜率不存在（垂直 x 轴）时公式失效，别硬套 k1k2  =  −1。
  • 一般式距离公式：Ax + By + C  =  0 形式，先化成这个形式再用。
  • 圆的一般方程 D2 + E2 − 4F > 0 才是圆；等于 0 是一个点。
  • 切线过圆外点有两条，用 d  =  r 解斜率时别漏 k 不存在的那条。
  • 弦长公式 2√(r2 − d2)：d 是圆心到直线距离，不是弦到圆心的距离。

本章公式速查表

与《高中数学常用公式·修订版》第五部分"直线与圆"逐条核对一致。

斜率与倾斜角

斜率：k  =  (y2−y1)/(x2−x1)  =  tan α（α ≠ 90°）

  • 大白话纵坐标差除以横坐标差，就是直线的陡缓。
  • 用的时候：α=90°（竖直直线）斜率不存在，别硬套；x1=x2 也不能用两点式。
  • 记忆要点：Δy 比 Δx。

平行 ⇔ k1 = k2（且截距不等）；垂直 ⇔ k1·k2 = −1

  • 大白话平行就是斜率一样，垂直就是斜率互为负倒数。
  • 用的时候：平行要排除重合；竖直直线（斜率不存在）垂直的反而是水平线 k=0。

直线方程的五种形式

点斜式：y − y0  =  k(x − x0)

  • 大白话知道斜率和一个点，直接写。
  • 用的时候：最常用的起手式。

斜截式：y  =  kx + b；一般式：Ax + By + C  =  0（k  =  −A/B）

  • 大白话斜截式一眼看斜率纵截距；一般式统一做计算。
  • 用的时候：最后统一化到一般式，斜率就是 −A/B。

两点式：(y−y1)/(y2−y1)  =  (x−x1)/(x2−x1)；截距式：x/a + y/b  =  1

  • 大白话两点直接写、知道横纵截距用截距式。
  • 用的时候：截距式要求 a、b 都不为 0，过原点或竖直直线用不了。

距离公式

两点距离：d  =  √[(x2−x1)2 + (y2−y1)2]

  • 大白话横差纵差当直角边，勾股求斜边。

点到直线距离：d  =  |Ax0+By0+C|/√(A2+B2)

  • 大白话点代入一般式左边取绝对值，除以法向量长度。
  • 用的时候：直线必须先化成 Ax+By+C=0；分子套绝对值、分母勾股。

两平行线距离：d  =  |C1−C2|/√(A2+B2)

  • 大白话系数对齐后，常数项差的绝对值除以根号。
  • 用的时候：先把 x、y 系数化成完全相同，再 |C1−C2|。

到两平行线 ax+by+m = 0、ax+by+n = 0 等距的直线：ax+by+(m+n)/2  =  0

  • 大白话两条平行线正中间那条线，常数项取平均。
  • 用的时候：求角平分线（与两已知平行线等距）直接套；系数要先对齐。

对称与反射

点关于点对称：P(x,y) 关于 Q(a,b) 的对称点 P′  =  (2a−x, 2b−y)

  • 大白话Q 是 P、P′ 的中点，坐标对半再翻倍。
  • 用的时候：曲线关于点 (a,b) 中心对称，就是把式子里的 (x,y) 换成 (2a−x, 2b−y)。

光线经 x 轴（或 y 轴）反射：入射、反射光线的斜率互为相反数

  • 大白话以坐标轴为镜面上下（左右）翻一下，倾斜角互补，斜率变号。
  • 用的时候：光线反射题把光源"镜像"到镜面另一侧，光线就拉直成直线距离。

圆的方程

标准方程：(x−a)2 + (y−b)2  =  r2，圆心 (a,b)，半径 r

  • 大白话一眼看出圆心和半径。

一般方程：x2+y2+Dx+Ey+F = 0，圆心 (−D/2,−E/2)，r  =  ½√(D2+E2−4F)

  • 大白话展开后的样子，配方才看得出圆心半径。
  • 用的时候：表示圆要 D2+E2−4F>0；等于 0 是一个点，小于 0 不是圆；没有 xy 项、x2y2 系数相等。

直径式：(x−x1)(x−x2) + (y−y1)(y−y2)  =  0（A(x1,y1)、B(x2,y2) 为直径两端点）

  • 大白话已知直径两个端点，一步写出圆，不用求圆心半径。
  • 用的时候：原理是直径所对圆周角为直角（PA⊥PB）；题目说"对 AB 张直角"时立刻想到它。

直线与圆的位置关系

比 d 与 r：d<r 相交，d = r 相切，d>r 相离（d 为圆心到直线距离）

  • 大白话量圆心到直线距离，跟半径比大小。
  • 用的时候：九成题先算 d 再比 r，不用真求交点。

弦长：|AB|  =  2√(r2 − d2)

  • 大白话半弦、半径、垂距构成直角三角形，整条弦乘 2。
  • 用的时候：d 是圆心到直线距离，不是别的。

圆上点 (x1,y1) 处切线：(x1−a)(x−a) + (y1−b)(y−b)  =  r2

  • 大白话切线垂直过切点的半径。
  • 用的时候：过圆外点求切线有两条，别漏斜率不存在的那条。

两圆公共弦：两圆一般式相减 (D1−D2)x+(E1−E2)y+(F1−F2) = 0

  • 大白话两个圆方程一减，就得到它们公共弦（或公切线）所在的直线。
  • 用的时候：求两圆公共弦方程不用解交点，直接相减；相切时这条线就是公切线。

圆上到直线距离为 d′ 的点个数（圆心距 d，半径 r）

1 个：d = r+d′；2 个：r−d′<d<r+d′；3 个：d = r−d′；4 个：d<r−d′

  • 大白话作两条平行直线距离 d′，数它们和圆交几个点；d 由大到小，个数从 1→2→3→4。
  • 用的时候：C1 那类"圆上到某直线距离等于定值的点有几个"直接套。

高级方法·进阶

本章主线方法（算 d、比 r、配方、点斜式）已被新教材完整覆盖，不超纲高级方法手册中无"直线与圆"的专属进阶节。下面两条是本章内可以让你算得更快的"小经验"，均在课标范围内。

进阶 1：圆上到定直线距离为定值的点个数（适用信号→步骤→例）

  • 适用信号：题目说"圆上到某直线距离等于 m 的点有几个"。
  • 操作步骤：①算圆心到直线距离 d；②圆上点到直线距离范围是 [|d−r|, d+r]；③作两条与已知直线平行、距离 m 的直线，数它们和圆交几个点。
  • 例：2025 新高考Ⅰ卷第 7 题（C1）。圆心到直线距离 d = 2，半径 r。距离为 1 的点：r 太小（<1）时圆离直线最近处都大于 1，0 个；1 < r < 3 时恰有 2 个；r 太大时变成 4 个。故"恰 2 个"⇔ 1 < r < 3，选 B。不超纲（高考可放心用）。

把这道题推广成一般结论（苏州教研·专题22，原书p.90）：半径 r 的圆上，到直线 l 距离为定值 d′ 的点有几个，由圆心到直线距离 d 决定——

恰有 1 个：d  =  r + d′；恰有 2 个：r − d′ < d < r + d′；恰有 3 个：d  =  r − d′；恰有 4 个：d < r − d′。

  • 大白话作两条与 l 平行、距离 d′ 的直线，数它们和圆交几个点。d 大时圆离 l 远，先在外圈切出 1~2 个；d 小到跨过圆心后，内圈也冒出来，变成 3~4 个。
  • 用的时候：C1 那道题 d=2、d′=1，"恰 2 个"即 r−1 < 2 < r+1，解得 1 < r < 3，选 B——和正文结论完全一致。

进阶 2：设而不求代平方（适用信号→步骤→例）

  • 适用信号：过圆外点引切线，求切线长。
  • 操作步骤：切线长 = √(点到圆心距离2 − r2)，根本不用先求切点。
  • 例：点 P 到圆心距离 L，切线长 = √(L2−r2)（勾股，半径⊥切线）。不超纲。

进阶 3：几何意义转化——"斜率型"与"距离型"最值（苏州教研·专题20）

  • 适用信号：求 (y−b)/(x−a)、√((x−a)2+(y−b)2) 这类式子的最值或范围。
  • 操作步骤：把代数式"翻译"成几何，别硬求函数最值——
  • 斜率型：(y−b)/(x−a) 就是动点 P(x,y) 与定点 Q(a,b) 连线的斜率 k_PQ；特别地 y/x 就是 k_PO（O 为原点）。
  • 距离型：√((x−a)2+(y−b)2) 就是 P(x,y) 到定点 Q(a,b) 的距离；它的平方就是距离平方。
  • 例：（苏州教研·专题20，原书p.85）已知点 M(a,b) 在直线 3x + 4y − 15 = 0 上，求 √(a2+b2) 的最小值。 解：√(a2+b2) = √((a−0)2+(b−0)2) 就是原点 O 到 M(a,b) 的距离 |OM|。M 在直线上动，|OM| 的最小值就是原点到该直线的距离：d = |0+0−15|/√(32+42) = 15/5 = 3。
  • ✓ 不超纲（就是斜率公式、点到直线距离公式的"几何读法"）。

课后习题答案

自测答案：1. k = (5−1)/(3−1) = 2；2. y = (2/3)x + 2，k = 2/3；3. |−2|/√2 = √2；4. 圆心 (1, −2)，半径 3；5. d = |0−0|/√2 = 0 < 1 ⇒ 相交（且过圆心，是直径）。

A 组答案

A1. k = (−4−2)/(3−(−1)) = −6/4 = −3/2。 A2. k = tan 120° = −tan 60° = −√3；k < 0，直线从左上向右下倾斜。 A3. 斜截式 y = −2x + 3；一般式 2x + y − 3 = 0。 A4. 原直线斜率 k = −3/4，平行斜率相同。过 (2,−1)：y+1 = (−3/4)(x−2)，整理 3x + 4y − 2 = 0。 A5. d = |3·3 − 4·4 + 1|/√(9+16) = |9−16+1|/5 = |−6|/5 = 6/5。 A6. 标准方程 (x+1)2 + (y−2)2 = 9；展开 x2+2x+1+y2−4y+4=9，一般式 x2 + y2 + 2x − 4y − 4 = 0。

B 组答案

B7. 系数一致，d = |(−2)−8|/√(9+16) = 10/5 = 2。 B8. 圆心 (0,0)，d = |0+0−1|/√2 = 1/√2。弦长 = 2√(9 − 1/2) = 2√(17/2) = √34 ≈ 5.83。 B9. 设切线 y = kx + 4，圆心 (0,0) 到它距离 = |4|/√(k2+1) = r = 2 ⇒ √(k2+1) = 2 ⇒ k2 = 3 ⇒ k = ±√3。切线：y = √3 x + 4 和 y = −√3 x + 4。（本题无竖直切线漏网。） B10. 圆心 (1,2) 到直线 x − y + b = 0 距离 d = |1−2+b|/√2 = |b−1|/√2。相交 ⇔ d < 2 ⇒ |b−1| < 2√2 ⇒ 1−2√2 < b < 1+2√2。

C 组答案

C1. B。圆心到直线距离 d = 2；圆上点到直线距离范围 [|2−r|, 2+r]。距离恰为 1 时：r<1 → 0 个；1<r<3 → 2 个；r>3 → 4 个。"恰 2 个"⇔ 1 < r < 3。 C2.（思想题）面积 = ½·弦长·d（d 为第三个顶点到直线的距离），弦长用 2√(r2−d2) 或联立求得。本章只需掌握"点到直线距离是面积的一条高"。 C3. 设切线 y = kx（过原点），圆 (x−2)2+y2=1 圆心 (2,0)、r=1。d = |2k|/√(k2+1) = 1 ⇒ 4k2 = k2+1 ⇒ k2 = 1/3 ⇒ k = ±√3/3。切线：y = (√3/3)x 和 y = −(√3/3)x。

一通百通

直线与圆这一类题，通用骨架就三步：① 把图形"翻译"成方程（直线写一般式 Ax+By+C=0，圆配方读出圆心 (a,b) 和半径 r）→ ② 把几何关系翻译成代数（平行/垂直比斜率，距离套 |Ax0+By0+C|/√(A2+B2)，位置关系比 d 和 r）→ ③ 按代数结果直接下结论。九成的直线圆题不用真解交点：算一个 d、比一次 r，相离/相切/相交、弦长、切线全出来。会做这一道骨架题 = 会做这一整类；这套"先翻译、再代数、后下结论"的打法，到第 16 章圆锥曲线联立大题还会原样复用，只是把"圆"换成"椭圆、双曲线、抛物线"。

跨章结合

  • 本章"点到直线距离" + 第 08 章解三角形"面积=½·底·高"：直线与曲线围成的三角形，面积常常就是"½·弦长·第三个顶点到这条弦所在直线的距离"——本章 3.3 的距离公式就是这条高。本章 C2 已点明：面积 = ½·弦长·d，"点到直线距离"是本章工具（该题型在第 16 章详解）。（综合原理说明，非新数值题）
  • 本章"算 d、比 r" + 第 02 章"二次方程判别式 Δ"：直线和圆联立消元后，判别式的正负其实就是 d 与 r 大小关系的代数化身——Δ>0 相交（此时 d<r）、Δ=0 相切（d=r）、Δ<0 相离（d>r）。换成圆锥曲线后这套"联立看 Δ"的流程直接复用。既有真题即本章 C1（2025 新高考Ⅰ卷第 7 题，圆上到直线距离为定值的点有几个，答案选 B，即 1<r<3），本质就是本章距离公式的活用。

本章与前后章

本章前接第 02 章（函数与方程：点斜式 y=kx+b 就是一次函数，方程与不等式的代数运算是本章地基），是解析几何的开门第一课；后接第 16 章圆锥曲线——椭圆、双曲线、抛物线的联立、弦长、距离判定，用的全是本章的"一般式、点到直线距离、联立消元"这套工具。学完这章，你手里有了三件通用武器：斜率判方向、距离算远近、d 比 r 判位置，它们是后面所有解析几何大题的地基。

高考怎么考

直线与圆在新高考Ⅰ卷里是小题常客，多年落在选择题第 5~8 题区间（如 2025 新高考Ⅰ卷第 7 题即本章 C1，考"圆上到直线距离为定值的点有几个"，答案选 B，即 1<r<3），考法集中在：斜率与平行垂直判定、点到直线/平行线距离、直线与圆位置关系与弦长、过圆外点求切线。难度中等偏易、3 分钟一道，几乎不单独出大题；但它是圆锥曲线大题的"工具间"——压轴题里的弦长、点到直线距离、联立判别，背后都站着本章的公式。想通了"几何变代数"，这几分是稳拿的送分题。
