本章本质核心：集合是把对象按确定标准"装进一个筐"的容器语言，逻辑是判断一句话成不成立的校验规则——它们自己几乎不单独考，却是全书所有"解集、定义域、值域、取值范围"的书写语言。本章全部内容（三性、运算、包含、充分必要、量词否定）都是这一个原理的变体：先把话翻译成"谁在哪个筐里"，再用筐的关系（包含、交并、补）回答一切问题。

为什么有用集合是全书所有"答案"的标准写法——从第 2 章起，函数定义域、值域、不等式解集、参数的取值范围，高考卷面上全要用集合或区间表达；逻辑（充分必要、量词否定）是"恒成立""存在""至少有一个"这类高级题目的翻译工具。学通本章，你不是多会了两个小知识点，而是拿到了读题和写答案的底层语法。

3.1 集合的含义与表示

先讲个生活例子。 你书包里有什么？"语文书、数学书、水杯、钥匙"——把这几样确定的东西放在一起，就是一个整体。数学上把这样的整体叫集合，里面每一样东西叫这个集合的一个元素。再比如"咱们班所有女生"也是一个集合，"身高超过 180cm 的同学"也是。

那"班里个子高的同学"呢？这就含糊了——175cm 算不算高？没有硬标准，谁也说不清一个同学到底在不在里面。这种标准不明确的一堆东西，不能叫集合。这就是下面第一条性质的来历。

一般地，我们把一些能够确定的、不同的对象看成一个整体，就说这个整体是由这些对象的全体构成的集合（简称集），集合中的每个对象叫做这个集合的元素。（人教A版口径）

元素的三个性质——判断"一堆东西算不算一个集合"，就拿这三把尺子量：

  1. 确定性：任何一个对象，要么在这个集合里，要么不在，不含糊。"好看的人"不是集合，"身高 ≥ 180cm 的人"才是集合。
  2. 互异性：集合里的元素互不相同。写 {1, 1, 2} 是不规范的，两个 1 是同一个元素，应写成 {1, 2}。
  3. 无序性：{1, 2} 和 {2, 1} 是同一个集合，顺序无所谓。

元素与集合的关系：一个对象 a 在集合 A 里，说"a 属于 A"，记作 a ∈ A；不在就说"a 不属于 A"，记作 a ∉ A。∈ 和 ∉ 是一对反义词，二选一。

常用数集（必须背熟，后面每章都用）：

记号 含义 例子
N 自然数集（含 0） 0, 1, 2, 3, …
N* 或 N+ 正整数集（不含 0） 1, 2, 3, …
Z 整数集 …, −2, −1, 0, 1, 2, …
Q 有理数集 能写成分数 p/q 的数
R 实数集 数轴上所有的数

注意：新教材（人教A版2019）里 0 是自然数，所以 N 从 0 开始；N* 才从 1 开始。这是和老教材一个容易混的点。

集合的三种表示方法：

  • 列举法：把元素一一列出来，写在大括号里，如 {1, 2, 3}。元素少的时候好用。
  • 描述法：写清楚"这个集合里的元素满足什么条件"，格式是 {代表元素 | 条件}。例如 {x | x2 − 1  =  0} 读成"满足 x2 − 1  =  0 的所有 x 构成的集合"，它就是方程 x2−1 = 0 的解集。竖线左边写"是谁"，右边写"要满足什么"。
  • 图示法：用一条封闭曲线（圆圈）圈住元素，叫 Venn 图，后面讲运算时大量用。

【跟讲例题 3.1-1】 用适当的方法表示："大于 −3 且小于 5 的所有整数"。 解：先把这些整数逐个列出来：−2, −1, 0, 1, 2, 3, 4。元素不多，用列举法写成 {−2, −1, 0, 1, 2, 3, 4}。 也可以用描述法写成 {x ∈ Z | −3 < x < 5}。两种写法都对，结果是同一个集合。

【跟讲例题 3.1-2】 判断：集合 {x | x 是好人} 是不是一个集合？ 解：不是。"好人"没有客观标准，张三觉得好、李四觉得不好，确定性这一条就过不了关。换成"考试及格（≥60 分）的同学"，有硬标准，才是集合。

本节易错点：描述法竖线两边别写反——{x | x > 2} 里 x 是被描述的对象，不是把"x>2"整个塞进去。

小结：集合就是"标准明确的一堆东西"；元素要么在里面要么不在；常用数集 N、Z、Q、R 要张口就来。

编者注·本质回扣：集合的本质是"容器"而不是"内容"——学 3.1 时你可能觉得这些定义没什么用，但集合的价值在于它是全书的书写语言：从下一章开始，函数的定义域、值域、方程解集、不等式解集，全都要用集合来"装"。现在把确定性、互异性、无序性三把尺子练熟，后面写解集才不写错；这也是本章本质核心说的"谁在哪个筐里"——先把筐的规矩定好，全书才装得下。

3.2 集合间的基本关系

生活类比：你的文具盒 A 里有"铅笔、橡皮"，你的笔袋 B 里有"铅笔、橡皮、尺子"。你会发现：A 里的每一样东西，B 里都有。这种"A 整个装进 B 里"的关系，就是数学上说的包含。

定义（以新教材口径）：

  • 子集：如果集合 A 的任意一个元素都是集合 B 的元素，就说 A 是 B 的子集，记作 A ⊆ B（或 B ⊇ A），读作"A 包含于 B"。
  • 真子集：如果 A ⊆ B，并且 B 中至少有一个元素不在 A 中，就说 A 是 B 的真子集，记作 A ⫋ B。
  • 集合相等：如果 A ⊆ B 且 B ⊆ A，那 A 和 B 的元素一模一样，记作 A  =  B。
  • 空集：不含任何元素的集合叫空集，记作 ∅。规定：空集是任何集合的子集，即 ∅ ⊆ A 对任意 A 都成立。

几条核心结论（会推导，别死背）：

  1. 任何集合是它自己的子集：A ⊆ A。——因为 A 的元素当然都在 A 里。
  2. 传递性：A ⊆ B 且 B ⊆ C ⇒ A ⊆ C。——就像"你包含在年级里，年级包含在学校里，你当然在学校里"。

  3. 含 n 个元素的集合，子集共有 2n 个，真子集 2n−1 个，非空真子集 2n−2 个。 这个 2n 是怎么来的？拿集合 {a, b, c} 来说，写它的一个子集时，对每个元素都有"带它玩"或"不带它玩"两种选择：a 有 2 种、b 有 2 种、c 有 2 种，搭配起来就是 2 × 2 × 2  =  23  =  8 种。其中"全都不带"就是 ∅，"全都带"就是它自己。去掉空集得真子集 2n−1 个；再去掉它自己，得非空真子集 2n−2 个。

  4. 空集陷阱：∅ 是任何集合的子集。问"某集合的所有子集"时，第一个就要写 ∅，最后别忘了它自己。

【跟讲例题 3.2-1】 写出 {1, 2} 的所有子集，并指出真子集。 解：按"从少到多"列：∅、{1}、{2}、{1,2}，共 22  =  4 个。真子集是前 3 个（去掉 {1,2} 本身）：∅、{1}、{2}，共 22−1  =  3 个。 要点：先写空集，再写单元素集，再写双元素集，按这个顺序想就不会漏。

【跟讲例题 3.2-2】 {0} 和 ∅ 是不是一回事？ 解：不是。∅ 里一个元素都没有；{0} 里有一个元素 0。打个比方：∅ 是空口袋，{0} 是口袋里装着一个 0。写子集时把这两个搞混，是经典失分点。

小结：A⊆B 就是"A 全装在 B 里"；n 个元素有 2n 个子集；空集是常客，别漏。

3.3 集合的基本运算

生活例子：高一（1）班参加数学兴趣小组的同学构成集合 A，参加物理兴趣小组的构成集合 B。那么"既参加数学又参加物理"的同学是谁？是 A 和 B 重叠的那部分——这就是交集。"参加数学或物理（至少一个）"的同学呢？是两个小组合起来的全部——这就是并集。

正式定义：

  • 交集 A ∩ B  =  {x | x ∈ A 且 x ∈ B}。两个集合公共的那部分。
  • 并集 A ∪ B  =  {x | x ∈ A 或 x ∈ B}。两个集合合起来的全部（重叠处只算一次）。
  • 补集：先约定一个"大背景"叫全集 U（我们讨论的所有对象都在 U 里）。U 中不属于 A 的元素构成的集合叫 A 在 U 中的补集，记作 ∁u A  =  {x | x ∈ U 且 x ∉ A}。

三种运算的直观图（重叠 = 交，合起来 = 并，背景里扣掉 = 补）：

数集运算画数轴：当集合是区间（不等式解集）时，把它们画在数轴上最快——交集取"两段重叠的公共部分"，并集取"两段盖住的全部"，补集取"剩下的部分"。实心点表示端点取得到，空心圈表示取不到。

运算律（用熟）：

  • 交换律：A ∩ B  =  B ∩ A，A ∪ B  =  B ∪ A。
  • 分配律：A ∩ (B ∪ C)  =  (A ∩ B) ∪ (A ∩ C)；A ∪ (B ∩ C)  =  (A ∪ B) ∩ (A ∪ C)。
  • 德摩根律：∁u(A ∩ B)  =  (∁uA) ∪ (∁uB)，∁u(A ∪ B)  =  (∁uA) ∩ (∁uB)。记口诀："交的补  =  补的并，并的补  =  补的交"，括号一拆，∩ 和 ∪ 对调。

计数公式（容斥原理）：|A ∪ B|  =  |A| + |B| − |A ∩ B|。意思是：两个集合的总个数，先各算各的，重叠部分被算了两次，要减掉一次。

运算结果与包含关系的互推（苏州教研·专题1）——看到运算结果"等于谁"，立刻反推"谁装谁"：

A ∪ B  =  B ⇔ A ⊆ B；A ∩ B  =  A ⇔ A ⊆ B

  • 大白话并完之后还是 B，说明 A 整个被 B 包住了（A⊆B）；交完之后剩下 A，也是 A⊆B。
  • 用的时候：题目给 "A∪B=B" 或 "A∩B=A"，先翻译成 "A⊆B" 再动手，别上来就硬算。

补集思想（正难则反，苏州教研·专题1 补充）：正面分类太繁时，先求反面（补集）的结果，再从全集里扣掉。解决"否定型"或"正面较繁"的问题特别管用。

看清集合的代表元素（苏州教研·专题1 补充）：描述法里竖线左边写什么，决定这个集合到底是什么——

  • {x | f(x) = 0} 是方程的解集；{x | f(x)>0} 是不等式的解集；
  • {x | y = f(x)} 是函数的定义域；{y | y = f(x)} 是函数的值域。

同样是 x、y，左边是 x 还是 y，意义完全不同；先看代表元素，再进一步化简。

做题流程（数集运算）：

  1. 把每个集合先化简成区间（解不等式）。
  2. 画数轴，标出端点、注意开闭。
  3. 交 = 公共段、并 = 合并段、补 = 剩余段，照着图写出结果。

【跟讲例题 3.3-1】 设 A  =  {x | −1 < x ≤ 3}，B  =  {x | 1 ≤ x < 5}，求 A ∩ B、A ∪ B。 解：画数轴。A 是 (−1, 3]，B 是 [1, 5)。

  • A∩B：两段重叠的部分是 [1, 3]（左端点 1 在 B 里取得到，右端点 3 在 A 里取得到）。
  • A∪B：合起来从 −1 到 5，即 (−1, 5)（−1 取不到、5 取不到）。

【跟讲例题 3.3-2】 设 U  =  {1,2,3,4,5}，A  =  {1,3,5}，求 ∁uA。 解：全集里去掉 A 的元素，剩下 {2, 4}。所以 ∁uA  =  {2, 4}。

小结：交是"且"、并是"或"、补是"去掉"；数集运算务必画数轴，盯紧端点开还是闭。

3.4 常用逻辑用语

先搞清楚什么叫命题。 "今天下雨了""2+3 = 5""x2<0"——能判断对错的陈述句叫命题。判断为真的是真命题，判断为假的是假命题。"你好吗？"不是命题（没法判断对错）。

本章最重要的考点：充分条件与必要条件。 设 p、q 是两个命题。

  • 若 p ⇒ q（p 成立一定能推出 q 成立），就说 p 是 q 的充分条件，q 是 p 的必要条件。
  • 四种情况（设 p、q 各对应一个实数集合 A、B）：
关系 集合关系 说法
p ⇒ q，但 q ⇏ p A ⫋ B（A 是 B 的真子集） p 是 q 的充分不必要条件
q ⇒ p，但 p ⇏ q B ⫋ A p 是 q 的必要不充分条件
p ⇒ q 且 q ⇒ p A  =  B p 是 q 的充要条件
互相都推不出 A、B 互不包含 既不充分也不必要

秒杀技巧——集合包含法：把 p、q 各翻译成一个数集 A、B。若 A ⊆ B，那"落在 A 里"一定"落在 B 里"，即 p ⇒ q（p 充分、q 必要）。小集合推大集合。

全称量词与存在量词：

  • 全称命题：对所有 x ∈ M 都成立，记作 "∀x ∈ M, p(x)"。∀ 读"任意"。
  • 存在命题：存在 x ∈ M 使 p(x) 成立，记作 "∃x ∈ M, p(x)"。∃ 读"存在"。
  • 否定规则（必背）：否定一个含量词的命题，量词互换（∀ ↔ ∃），再把结论否定，条件 M 不动。
  • ¬(∀x ∈ M, p(x))  =  ∃x ∈ M, ¬p(x)
  • ¬(∃x ∈ M, p(x))  =  ∀x ∈ M, ¬p(x)

常见词语的否定（苏州教研·专题42，必背）——否定一句话时，下面这些"对义词"要成对换：

原词 它的否定 原词 它的否定
是 不是 都是 不都是
大于 不大于 小于 不小于
p 或 q ¬p 且 ¬q p 且 q ¬p 或 ¬q
至少有一个 一个也没有 至多有一个 至少有两个
至少有 n 个 至多有 n−1 个 至多有 n 个 至少有 n+1 个

大白话"都"的否定是"不都"（存在一个不是），不是"都不"；"或"变"且"、"且"变"或"。这跟量词否定是一个路数：把"全部成立"翻成"存在一个例外"。另外分清两件事：命题的否定只否结论；否命题要把条件和结论一起否掉，全称/特称命题没有否命题。

【跟讲例题 3.4-1】 "x > 2" 是 "x > 1" 的什么条件？ 解：设 A  =  {x | x>2}，B  =  {x | x>1}。A ⫋ B（小集合在大集合里）。

  • x>2 一定有 x>1（小推大，充分）✓
  • 但 x>1 不一定 x>2（比如 x = 1.5），反过来推不出。 所以 "x>2" 是 "x>1" 的充分不必要条件。

【跟讲例题 3.4-2】 写出命题 "∀x ∈ R, x2 + 1 > 0" 的否定。 解：量词 ∀ 换成 ∃，结论 "x2+1>0" 否定成 "x2+1≤0"，条件 R 不动。 否定为：∃x ∈ R, x2 + 1 ≤ 0。（原命题真，它的否定假，符合预期。）

易错点：充要条件的方向别读反——"p 是 q 的充分条件"  =  "p ⇒ q"，箭头从 p 指向 q。"p 的充分条件是 q" 才是 q ⇒ p，两句话主宾颠倒，方向相反。

小结：充分/必要就看"谁推得出谁"；用集合包含（小推大）最快；量词否定只换量词+否结论。

编者注·本质回扣：逻辑这一节看着像新东西，本质还是"筐"：充分必要条件就是两个集合谁包含谁（小筐在大筐里，落进小筐必落进大筐），量词否定就是把"全部/存在"翻成"有没有例外"。所以 3.1 到 3.4 是一条线——一切问题都翻译成集合，再用包含、交并、补来回答。记住这条线，第 2 章"函数定义域"、第 12 章"不等式解集"里你再见到集合，就知道它只是同一原理换了身衣服。

3.5 数形结合：集合题的解题总纲

前面讲的都是"算"，这一小节把"画图"这件事钉死。高考集合题年年出在第 1 题，1 分钟内必须拿下，靠的就是数形结合。

两类图，对号入座：

  • 数集（不等式解集、区间） → 画数轴。端点该实就实、该空就空，重叠 = 交、合并 = 并。
  • 抽象集合（不知道具体元素，只知道 A、B、C 之间的包含关系） → 画 Venn 图，把文字关系转成圆圈的大小和重叠。

操作步骤：① 先把每个集合化到最简（解不等式、列举元素）；② 选图（数轴 or Venn）；③ 在图上把答案区域涂出来；④ 翻译成区间或列举写回去，最后核对端点开闭。

【跟讲例题 3.5-1】 设全集 U  =  R，A  =  {x | x < 1}，B  =  {x | x ≥ −2}，求 (∁uA) ∩ B。 解：先求补：∁uA  =  {x | x ≥ 1}。再和 B  =  {x | x ≥ −2} 取交：两段 [1, +∞) 与 [−2, +∞) 的公共部分是 [1, +∞)。 数轴上一画就明白：补集是 1 右边（含 1），B 是 −2 右边，公共的当然是更靠右的 [1, +∞)。

【跟讲例题 3.5-2】（苏州教研·专题1，原书p.10） 设全集 U  =  {x | 0 < x < 10，x ∈ N*}，若 A ∩ B  =  {2, 3}，A ∩ (∁uB)  =  {1, 5, 7}，(∁uA) ∩ (∁uB)  =  {6, 9}，求集合 B。

解：U  =  {1, 2, 3, 4, 5, 6, 7, 8, 9}。画 Venn 图，把已知一块块填进去： - A ∩ B  =  {2, 3} → 2、3 在 A、B 的公共圈里； - A ∩ (∁uB)  =  {1, 5, 7} → 1、5、7 在 A 里、不在 B； - (∁uA) ∩ (∁uB)  =  {6, 9} → 6、9 在圈外（A、B 都不在）。 剩下 4、8 没地方去：它们不在 A（否则会落到上面两格），又不在圈外，只能"在 B、不在 A"。 所以 B  =  {2, 3, 4, 8}。 要点：抽象集合关系别空想，画个 Venn 图把已知分区填好，剩下的元素自然归位——这就是数形结合的威力。

小结：集合题"能画就不算"，数轴和 Venn 图就是你的两把尺子。

④ 例题详解（先做再看）

例题例 1（教材必修1 第1章例题）：写出集合 {a, b} 的所有子集，并指出哪些是真子集。

自己做：别漏 ∅。

解：所有子集为 ∅、{a}、{b}、{a, b}，共 4  =  22 个。 真子集为 ∅、{a}、{b}，共 3  =  22 − 1 个。 要点：先写 ∅，再写单元素集，再写双元素集，顺序想清楚就不会漏。

例题例 2（2021 新高考Ⅰ卷 T1，真题）：设集合 A  =  {x | −2 < x < 4}，B  =  {2, 3, 4, 5}，则 A ∩ B  =  （　）

A. {2}　B. {2, 3}　C. {3, 4}　D. {2, 3, 4}

自己做：B 是具体集合，逐个看哪些元素落在 A 的开区间里。

解：A  =  (−2, 4)，B 中的元素逐个检查：2 ∈ (−2, 4) ✓；3 ∈ (−2, 4) ✓；4 ∉ (−2, 4)（开区间不含 4）；5 ∉。故 A ∩ B  =  {2, 3}，选 B。 要点：开区间端点取不到，这是集合题第一陷阱。

例题例 3（充要条件判断）：设 x ∈ R，判断"x > 2"是"x > 1"的什么条件。

自己做：画数轴看两个集合的包含关系。

解：设 A  =  {x | x > 2}，B  =  {x | x > 1}，A ⊂ B。

  • x > 2 ⇒ x > 1 成立（充分）；
  • x > 1 ⇏ x > 2（如 x  =  1.5）。 故"x > 2"是"x > 1"的充分不必要条件。 要点：充分性看"小集合 ⇒ 大集合"，必要性反过来看。

例题例 4（苏州教研·专题1，原书p.9）：设 A  =  {x | x2 − 2x − 3  =  0}，B  =  {x | ax  =  1}，若 B ⊆ A，求实数 a。

自己做：先把 A 解出来；别忘了 B 可能是空集。

解：A  =  {x | (x−3)(x+1) = 0}  =  {−1, 3}。分两种情况：

  • 当 a  =  0 时，方程 ax  =  1 即 0  =  1，无解，B  =  ∅。空集是任何集合的子集，满足 B ⊆ A。
  • 当 a ≠ 0 时，B  =  {1/a}。要 B ⊆ A，需 1/a  =  3 或 1/a  =  −1，得 a  =  1/3 或 a  =  −1。

综上，a  =  0，或 a  =  1/3，或 a  =  −1。 要点：含参集合 B ⊆ A 时，第一件事就是讨论"B 会不会是空集"（这里 a = 0 时 B 自动为空）——漏掉这一支几乎必扣分。

⑥ 常见坑清单（错一次记一次）

  • 空集 ∅ 不是 {0}：∅ 不含任何元素，{0} 含一个元素 0。
  • ∅ ⊆ A 恒成立，写子集时漏 ∅ 是高频失分点。
  • 开闭区间端点：x < 4 不含 4；x ≤ 4 含 4。
  • 充要条件方向反：p 是 q 的充分条件 ⇔ p ⇒ q（p 在前）。"谁是谁的"顺序别搞反。
  • 量词否定只换量词+否结论，不要否定原命题的条件。

本章公式速查表

与《高中数学常用公式·修订版》第一部分（集合）、第十四部分（常用逻辑用语）核对一致。

元素与集合的关系

a ∈ A（a 属于 A）

  • 大白话a 这个东西，A 这个口袋里有它。
  • 用的时候：判断某个对象在不在集合里；在就写 ∈，不在就写 ∉，二选一，别空着。

a ∉ A（a 不属于 A）

  • 大白话A 这个口袋里没有 a。
  • 用的时候：和 ∈ 配套，注意常用数集 N 含 0、N* 不含 0。

集合间的关系

A ⊆ B（A 包含于 B）

  • 大白话A 里的每样东西 B 里都有，A 整个装进 B 里。
  • 用的时候：判断包含关系；别忘 ∅ ⊆ A 恒成立，写子集先写空集。
  • 记忆要点：⊆ 开口朝向"装得多"的那个大集合。

A  =  B（A 等于 B）

  • 大白话A 和 B 元素一模一样。
  • 用的时候：要证 A = B，得两边互相 ⊆，即 A⊆B 且 B⊆A。

∅ ⊆ A（空集是任何集合的子集）

  • 大白话空口袋能装进任何口袋。
  • 用的时候：问"某集合的所有子集"，第一个就写 ∅，最后别忘了它自己；{0} ≠ ∅。

含 n 个元素 ⇒ 子集 2n、真子集 2n−1、非空真子集 2n−2

  • 大白话每个元素"带不带"两种选择，n 个元素就是 2 的 n 次方。
  • 用的时候：{1,2,3} 有 8 个子集、7 个真子集；先写 ∅ 再逐个加。
  • 记忆要点：去掉空集减 1，再去掉它自己再减 1。

若 A ⊆ B ⊆ C，A 有 m 个元素、C 有 n 个元素（n>m），则这样的 B 有 2n−m 个（苏州教研·专题1 补充）

  • 大白话A 的元素必须全进 B，C 比 A 多出的 (n−m) 个元素每个"带不带进 B"都行，共 2n−m 种。
  • 用的时候：如 {1,2}⊆B⊆{1,2,3,4,5}，多出 3 个元素，B 有 23  =  8 个。
  • 记忆要点：夹在中间的 B，自由度全在"A 没有、C 有"的那批元素上。

集合的基本运算

A ∩ B  =  {x | x ∈ A 且 x ∈ B}（交集）

  • 大白话两个集合重叠的那部分，"既在 A 又在 B"。
  • 用的时候：数集运算画数轴取公共段；盯紧端点该闭还是该开。

A ∪ B  =  {x | x ∈ A 或 x ∈ B}（并集）

  • 大白话两个集合合起来的全部，重叠处只算一次。
  • 用的时候：画数轴取两段盖住的全部；"或"是至少满足一个。

∁uA  =  {x | x ∈ U 且 x ∉ A}（A 在全集 U 中的补集）

  • 大白话从大背景 U 里把 A 扣掉，剩下的就是补集。
  • 用的时候：先写清楚全集 U 是什么；补集  =  数轴上"剩下的部分"。

运算律与计数

德摩根律：∁u(A∩B)  =  (∁uA)∪(∁uB)，∁u(A∪B)  =  (∁uA)∩(∁uB)

  • 大白话交的补 = 补的并，并的补 = 补的交，括号一拆 ∩ 和 ∪ 对调。
  • 用的时候：见到"补的交并"想拆开，或反过来合并。
  • 记忆要点："交补变并、并补变交"。

|A∪B|  =  |A| + |B| − |A∩B|（容斥计数）

  • 大白话两个集合总个数，重叠部分被算了两次，要减掉一次。
  • 用的时候：数元素个数、做概率题常用。

A ∪ B  =  B ⇔ A ⊆ B；A ∩ B  =  A ⇔ A ⊆ B（运算结果反推包含，苏州教研·专题1）

  • 大白话并完还是 B、交完剩 A，都说明 A 整个被 B 装着。
  • 用的时候：题目给运算等式，先翻译成包含关系再动手，别硬算。
  • 记忆要点："谁被吸收了，谁就是小的那个。"

充分与必要条件

A ⊆ B ⇒ "A 的条件"是"B 的条件"的充分条件（小推大）

  • 大白话落在小集合里，一定落在大集合里。
  • 用的时候：把两个命题翻成数集，小集合推大集合就是充分；A=B 才充要。
  • 记忆要点："谁是谁的充分条件"，箭头从 p 指向 q，别读反主宾。

量词与命题否定

¬(∀x∈M, p(x))  =  ∃x∈M, ¬p(x)

  • 大白话"所有 x 都成立"的否定是"存在某个 x 不成立"。
  • 用的时候：量词 ∀ 换成 ∃，结论否定，条件 M 不动。

¬(∃x∈M, p(x))  =  ∀x∈M, ¬p(x)

  • 大白话"存在某个 x 成立"的否定是"所有 x 都不成立"。
  • 用的时候：∃ 换成 ∀，再否定结论；别去动条件 M。
  • 记忆要点："换量词 + 否结论"，两步就够。

常见词语否定：都→不都；或⇔且互换；至少一个→一个也没有（苏州教研·专题42）

  • 大白话"都是"的否定是"不都是"（存在一个不是），不是"都不是"；"p或q"的否定是"¬p且¬q"。
  • 用的时候：否定命题先换量词、再对词；"至少有一个"否定成"一个也没有"，"至多有一个"否定成"至少有两个"。
  • 记忆要点：全称特称互换 + 连接词或且互换。

高级方法·进阶

本章对应方法手册：无直接对应章节（集合与逻辑是全书最基础的工具章，《不超纲高级方法手册》没有专门收录压轴方法）。这里只补两个把本章用"快"的小技巧，都是课标内、高考可放心用的：

进阶 1：充要条件的"集合包含法"（不超纲，高考可放心用）

  • 适用信号：题目给两个命题 p、q，问谁是谁的什么条件。
  • 操作步骤：① 把 p、q 各自翻译成实数集合 A、B；② 画数轴比 A、B 的包含关系；③ A ⊆ B ⇒ p 充分、q 必要；A = B ⇒ 充要。
  • 例："x>2"是"x>1"的什么条件？A=(2,+∞)⊆B=(1,+∞)，故 p 充分不必要。
  • 依据：充分条件的集合刻画（课标内）。✓ 不超纲。

进阶 2：含参子集问题的"空集先行"讨论（不超纲，高考可放心用）

  • 适用信号：B ⊆ A，且 B 是含参数 m 的区间。
  • 操作步骤：① 先单独讨论 B = ∅ 的情形（即"左端点 > 右端点"），这是最容易漏的；② 再讨论 B ≠ ∅，把两个端点的不等式列出来；③ 合并两种情况。
  • 依据：空集是任何集合的子集（课标内）。✓ 不超纲。
  • 注意：考试若漏掉 B=∅ 这一支，本题几乎必扣分，务必写出来。

课后习题答案

自测答案：1. {x | x ∈ N*，且 x < 5}（或 {1, 2, 3, 4}）；2. 子集 8 个（23）、真子集 7 个；3. A ∩ B  =  {2}、A ∪ B  =  {1, 2, 3}、∁uA  =  {3, 4, 5}；4. 充分不必要条件（a  =  0 ⇒ ab  =  0，反例 b  =  0、a  =  1）；5. ∃x ∈ R，x2 < 0。

A 组答案

A 组

  1. C。只有 C 有确定标准（x2=4 的解是 ±2，确定）；A、B、D 标准不明确，不满足确定性。
  2. 0 ∈ N；−3 ∉ N（N 不含负整数）；√2 ∉ Q（无理数）；π ∈ R。
  3. {x ∈ Z | −2 ≤ x < 3} = {−2, −1, 0, 1, 2}。
  4. n=3：子集 23=8 个；真子集 23−1=7 个；非空真子集 23−2=6 个。
  5. A∩B = {2, 4}；A∪B = {1, 2, 3, 4, 6}。
  6. U={1,2,3,4,5,6} 去掉 A={2,4,6}，∁uA = {1, 3, 5}。

B 组答案

B 组

  1. A=[−1,3)，B=(1,+∞)。 - A∩B = (1, 3)（重叠段）。 - A∪B = [−1, +∞)（合起来，−1 含、3 不含、向右无限）。 - ∁ᴿA = (−∞, −1) ∪ [3, +∞)；与 B=(1,+∞) 取交 = [3, +∞)。

  2. B⊆A。分两种情况： - B = ∅：m+1 > 2m−1 ⇒ m < 2。此时 B⊆A 恒成立。 - B ≠ ∅：需 m+1 ≤ 2m−1（即 m≥2），且 m+1 ≥ −1、2m−1 ≤ 3。解得 m≥2 且 m≥−2 且 m≤2，即 m=2。 合并：m < 2 或 m = 2，即 m ≤ 2。

  3. x=1 ⇒ x2−1=0（充分）；但 x2−1=0 ⇒ x=±1，不一定 x=1（必要不成立）。故 "x=1" 是 "x2−1=0" 的充分不必要条件。

  4. 否定：∀x ∈ R, x2 + 2x + 3 > 0。原命题：x2+2x+3 = (x+1)2+2 ≥ 2 > 0 恒成立，所以原命题 "∃…≤0" 是假命题（恒大于 0，不存在 ≤0 的）。

C 组答案

C 组

  1. A = {x | −5 < x3 < 5}，即 −∛5 < x < ∛5，∛5 ≈ 1.71，故 A ≈ (−1.71, 1.71)。B={−3,−1,0,2,3} 中落在 (−1.71,1.71) 的只有 −1、0。A∩B = {−1, 0}，选 A。
  2. U = {1,2,3,4,5,6,7,8}（小于 9 的正整数，共 8 个）。A={1,3,5}。∁uA = {2,4,6,7,8}，共 5 个元素，选 C。
  3. A⊆B 意味着 0 和 −a 都必须在 B={1, a−2, 2a−2} 中。逐一代入选项：
    • a=1：A={0,−1}，B={1,−1,0}，0∈B、−1∈B，成立。
    • a=2：B={1,0,2}，−2∉B，不成立；a=2/3 时 0∉B；a=−1 时 0∉B。 故 a=1，选 B。

一通百通

这一章的"通用骨架"只有四步：① 问对象是谁（元素还是集合？）→ ② 问关系是什么（属于/包含/相等/运算？）→ ③ 翻译（画数轴或 Venn，把文字变成图形）→ ④ 按图回答。高考集合题年年出现在第 1 题，本质全是这一套：看清对象 → 定关系 → 画图 → 读数。会解一道集合题，就会解所有集合题；这套"先翻译再画图"的骨架，后面解不等式、解函数定义域、解圆锥曲线取值范围，还会一再出现。

跨章结合

本章的原理和后面这些章碰在一起，就会长出高考里反复出现的典型问题： - 集合运算 ⇔ 02 章函数的定义域/值域：求两个函数定义域的交并补，几乎年年以"集合小题"形式出现（2023/2025 卷 T2 就是集合运算与不等式解集的结合，见本章 C 组真题）； - 充分必要条件 ⇔ 12 章不等式恒成立 / 16 章参数范围：把"p 是 q 的什么条件"翻译成"两个集合谁包含谁"，本质和"参数取什么值时不等式恒成立"是同一个"小推大"思维（综合原理说明，非真题）。 记住这两条结合点，你在 02、12、16 章再见到集合，就知道它只是换了身衣服的同一个工具。

本章与前后章

集合与逻辑是全书的第一站：它前面接初中的数系、方程与不等式（门槛自测已帮你确认），后面接第 2 章函数——函数的定义域、值域、单调区间全部用集合与区间书写；第 12 章不等式的解集、第 16 章圆锥曲线的参数的取值范围，也都是集合运算的化装舞会。充分必要条件这套"小推大"逻辑，更是后面"恒成立"类问题的底层思维。学完这一章，你手里有了全书第一件工具：一套把"自然语言"翻译成"集合语言"的能力。

高考怎么考

新高考Ⅰ卷里集合几乎锁定第 1 题（2020–2024 卷 T1、2023/2025 卷 T2），考法高度套路化：交并补运算（常与一元二次不等式、指对数函数值域结合）、子集个数、充分必要条件判断（翻译成集合包含最快）；常用逻辑偶尔混进多选题的选项判断。难度低、位置固定、必须 1 分钟内拿下——它考的不是集合本身，而是你"翻译+画图"的熟练度，为全卷节省时间。
