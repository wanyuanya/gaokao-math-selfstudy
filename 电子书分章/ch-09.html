公式速查：修订版 第7部分（平面向量）

本章本质核心：向量的本质是"既有大小又有方向的箭头"——它不关心起点在哪，可以随便平移；所有运算都是这支箭头的几何动作：加减是把箭头首尾相接或共起点合并（平移），数乘是拉长/压短/反向，数量积 a·b 是"把 b 投影到 a 方向上再乘 a 的模"（投影）。本章全部题型（共线、垂直、夹角、求模、投影、建系解几何）都是这一个原理的变体。

为什么有用想通"向量=可平移的箭头、点积=投影"，你就不用背一堆几何二级结论——垂直、夹角、求模、投影、三点共线全都能现场推出来；后面立体几何建系求角和距离，靠的也是这一套，学一次用两章。

② 学习目标

  • 理解向量的概念（大小 + 方向）与表示
  • 掌握向量加法（三角形/平行四边形法则）、减法、数乘

  • 掌握数量积（点乘）的定义、坐标公式及其应用（垂直、夹角、投影）
  • 会用向量解决平面几何问题（基底法、坐标法）

③ 正文讲解

先想一个生活场景。你推箱子，用多大力（大小）、朝哪个方向推（方向），两个信息缺一不可——只说"用 50 牛的力"不说方向，箱子动不了。这种"既有大小、又有方向"的量，就是向量。本章地图：

3.1 向量的基本概念

定义：既有大小又有方向的量叫向量，记 a（粗体）或 AB（上面带箭头）。向量的大小叫模，记作 |a|。

几个要分清的词：

  • 零向量 0：模为 0，方向任意（相当于"没移动"）。
  • 单位向量：模为 1 的向量。
  • 相等向量：大小相等且方向相同，与起点在哪无关——向量可以随便平移。
  • 共线向量（平行向量）：方向相同或相反；规定零向量与任何向量共线。

和数量的区别：向量不能比较大小（"a > b"没意义），只能比模长 |a| > |b|。

单位向量的用处：和 a 同方向的单位向量是 a/|a|（把 a 除以它的模）。以后题目说"沿 a 方向走一个单位"，写的就是这个。

例题跟讲例题 3.1-1：把一个向量 AB 平移到 A′B′，它变了吗？ 解：平移不改变大小和方向，所以 AB = A′B′（相等向量）。 要点：向量只看大小方向，不看位置。

3.2 线性运算

加法——三角形法则与平行四边形法则：

  • 三角形法则：把 b 的起点接到 a 的终点上，从 a 的起点指向 b 的终点就是 a+b（首尾相接）。
  • 平行四边形法则：a、b 共起点，以它们为邻边作平行四边形，对角线就是 a+b。

减法：a − b = a + (−b)。几何上让 a、b 共起点，从 b 的终点指向 a 的终点的向量就是 a−b。

数乘 λa：长度变成 |λ|·|a|；λ>0 方向不变，λ<0 方向反向，λ=0 得零向量。

坐标运算（建系后一切变算术）：设 a = (x1, y1)，b = (x2, y2)，则

  • a + b = (x1+x2, y1+y2)
  • a − b = (x1−x2, y1−y2)
  • λa = (λx1, λy1)

共线定理（核心）：b 与 a（a ≠ 0）共线 ⇔ 存在唯一实数 λ 使 b = λa。 坐标形式：a = (x1,y1)、b = (x2,y2) 共线 ⇔ x1y2 − x2y1 = 0（交叉相乘差为 0）。

中点公式：A(x1,y1)、B(x2,y2) 的中点 M = ((x1+x2)/2, (y1+y2)/2)。

例题跟讲例题 3.2-1：已知 a = (1, 2)，b = (3, −1)，求 a+b、2a−b。 解：a+b = (1+3, 2+(−1)) = (4, 1)；2a−b = (2,4)−(3,−1) = (−1, 5)。 要点：坐标逐项加减，别漏负号。

例题跟讲例题 3.2-2：已知 a = (2, −3)，b = (x, 6) 且 a∥b，求 x。 解：共线条件 x1y2−x2y1 = 0：2×6 − (−3)x = 0 → 12+3x = 0 → x = −4。 要点：共线用"交叉相乘差为 0"。

陷阱：共线是 x1y2−x2y1=0，垂直是 x1x2+y1y2=0，这两个公式最容易用反。

编者注·本质回扣：这一节的加减数乘，本质上都是在"搬箭头"。加法把两个箭头首尾接起来，得到的是从起点到终点那支合成箭头；减法 a−b 是让两支箭头共起点，从 b 的头指向 a 的头——所以它其实就是"a 加一个反向的 b"；数乘 λa 只是把这支箭头拉长或压短，λ 负了就掉头。一旦建了坐标系，这些几何动作全部翻译成坐标逐项加减乘，所以你会觉得"向量运算像算术"，本质就是几何被坐标化了。

3.3 平面向量基本定理与基底

问题：平面上向量无穷多，能不能用两个固定向量把它们都表示出来？能，这就是基本定理。

定理：如果 e1、e2 是同一平面内两个不共线的向量，那么对这个平面内任一向量 a，存在唯一一对实数 λ、μ，使 a = λe1 + μe2。不共线的 e1、e2 叫这组向量的基底。

直觉：把平面想象成地面，e1、e2 是两个不重合的方向轴；任何一步 a，都能拆成"沿 e1 走 λ、沿 e2 走 μ"。

例题跟讲例题 3.3-1：已知 e1、e2 不共线，a = 2e1 − e2，b = e1 + 3e2，求 a+b。 解：a+b = (2+1)e1 + (−1+3)e2 = 3e1 + 2e2。 要点：基底相同时，系数直接加减。

3.4 数量积（点乘，最重要）

物理引入：一个力 F 拉物体走位移 s，做的功 W = |F||s|cosθ——既不是 F 也不是 s，而是"两个向量模相乘再乘夹角余弦"。这种运算就是数量积。

定义（人教A版口径）：a · b = |a||b| cos θ，θ 是 a、b 的夹角（0 ≤ θ ≤ π）。零向量与任一向量数量积为 0。结果是一个数，不是向量。

坐标公式：a = (x1,y1)、b = (x2,y2) ⇒ a · b = x1x2 + y1y2（对应坐标相乘再相加）。

四条必背结论：

  • a ⊥ b ⇔ a·b = 0 ⇔ x1x2 + y1y2 = 0；
  • |a|2 = a·a = x12 + y12（求模）；
  • cos θ = (a·b)/(|a||b|)（求夹角）；
  • b 在 a 方向上的投影 = |b| cosθ = (a·b)/|a|。

运算律：交换律 a·b = b·a；分配律 a·(b+c) = a·b+a·c；数乘结合 (λa)·b = λ(a·b)。注意：数量积没有消去律——a·b = a·c 推不出 b = c。

投影到底是什么？ 把 b 的终点"垂直投影"到 a 所在直线上，得到的那段带方向的长度就是投影。夹角 θ 是锐角时投影为正，钝角时为负，直角时为零（这正是垂直 ⇔ 数量积为 0 的几何来源）。数量积 a·b = |a|×(b 在 a 上的投影)，所以它也可以理解为"a 的模乘 b 的投影"。

补·投影向量（人教A版必修第二册 p.108–109；课标必修"了解平面向量投影的概念以及投影向量的意义"）：上面说的投影"长度"是一个带符号的数（投影数量）；新教材还要求区分一个"向量"——把 b 垂直投影到 a 所在直线上得到的那个带方向的向量，叫 b 在 a 上的投影向量。设 e 是与 a 同向的单位向量、θ 为 a 与 b 的夹角，则

b 在 a 上的投影向量 = |b| cosθ · e = [(a·b)/|a|2] · a

  • 大白话投影数量是"带符号的长度"（一个数），投影向量是"沿 a 方向趴下来的那个向量"（一个向量）；后者就是把前者乘上 a 方向的单位向量。
  • 用的时候：坐标里 a=(x1,y1)、b=(x2,y2) 时，投影向量 = [(x1x2+y1y2)/(x12+y12)]·(x1,y1)。它和投影数量的关系是：投影数量 = 投影向量在 a 方向上的坐标。

例题跟讲例题 3.4-1：已知 |a| = 2，|b| = 3，a·b = 3，求夹角 θ。 解：cosθ = (a·b)/(|a||b|) = 3/(2×3) = 1/2，θ∈[0,π]，故 θ = 60°。 要点：夹角公式就是"数量积 ÷ 两模乘积"。

例题跟讲例题 3.4-2：已知 a = (1,2)，b = (x,−1)，且 a⊥b，求 x。 解：垂直 ⇔ a·b = 0：1·x + 2×(−1) = 0 → x − 2 = 0 → x = 2。 要点：垂直看点积是否为 0。

例题跟讲例题 3.4-3：已知 |a| = 3，|b| = 4，a·b = −6，求 |a+b|。 解：先平方：|a+b|2 = |a|2 + 2a·b + |b|2 = 9 + 2×(−6) + 16 = 13，故 |a+b| = √13。 要点：求模先平方，用 |a±b|2 = |a|2 ± 2a·b + |b|2，别直接把模相加。

陷阱：夹角范围是 [0,π]，cosθ 为负说明夹角是钝角（>90°）。

编者注·本质回扣：数量积看着是个新运算，本质就是"投影"。a·b = |a| 乘上 b 在 a 方向上的投影长度：两支箭头方向一致时投影最长、点积最大；垂直时 b 在 a 上趴不下来、投影为 0，所以垂直等价于点积为 0；方向相反时投影变负、点积为负。坐标公式 x1x2+y1y2 只是这套投影几何建系后的算术化身。记住"点积=投影"，垂直、夹角、求模这一串结论就全挂回同一根线上了。

3.5 两套解题思路

  1. 坐标法（推荐）：能建系就建系，把点放坐标系里，向量写成坐标，全部变成加减乘除。
  2. 基底法：选两个不共线向量作基底，其它向量全用基底表示，再列方程求解。

高考高频考点：数量积求夹角、垂直/平行条件、求模（配 |a±b|2 展开）、平面几何题用向量翻译。这四类几乎覆盖了新高考向量小题的全部出法。

3.6 坐标法实战：把几何题翻译成算术

很多同学怕"向量解几何"，其实套路很固定——建系、写坐标、算。

操作步骤：

  1. 找图里的直角关系或对称中心，把它放原点；
  2. 把各关键点写成坐标（不知道的设成未知数）；
  3. 把题目条件（垂直、中点、等长）翻译成向量等式；
  4. 解出未知数，回答问题。

例题跟讲例题 3.6-1：已知 A(1,0)、B(3,2)，点 P 满足 P 是 AB 中点，且 Q 满足 P 是 Q 的坐标原点对称点，求 Q。 解：P = ((1+3)/2, (0+2)/2) = (2,1)。P 关于原点对称的 Q = (−2,−1)。 要点：中点公式、对称点，都是坐标套公式。

例题跟讲例题 3.6-2：已知 A(0,0)、B(4,0)、C(2,3)，求 AB 边上中线的长。 解：AB 中点 M = (2,0)。中线是 CM = √((2−2)2+(3−0)2) = 3。 要点：先求中点，再用两点距离公式。

3.7 三点共线的向量判定（小题秒判）

结论：P、A、B 三点共线 ⇔ 存在实数 x、y，使 OP = x·OA + y·OB，且 x + y = 1（O 是任取的原点）。

怎么理解：在直线 AB 上，P 的位置可以看作 A、B 的"加权平均"。x=y=1/2 时 P 就是中点；x=1,y=0 时 P=A；x=0,y=1 时 P=B。只要 x+y=1，P 就被"摁"在直线 AB 上。

例题跟讲例题 3.7-1：已知 OP = 2·OA − OB，判断 P 是否在直线 AB 上。 解：系数 2 + (−1) = 1，满足 x+y=1，所以 P 在直线 AB 上。一步到位，不用算坐标。 要点：见到 OP = x·OA + y·OB，先加系数看是否等于 1；等于 1 就三点共线，不等于 1 就不共线，这是小题里最快的判断法。

例题跟讲例题 3.7-2：已知 A(1,2)、B(3,4)，且 OP = (1/2)·OA + (1/2)·OB，求 P 并说明它是谁。 解：P = ((1+3)/2, (2+4)/2) = (2,3)。系数和 = 1/2+1/2 = 1，P 在 AB 上；正好是 AB 的中点。 要点：系数都等于 1/2 就是中点。

小结：向量是"带方向的量"；加减数乘管线性运算，坐标化后变成算术；数量积 a·b 是把"垂直、夹角、模"翻译成代数的钥匙。

④ 例题详解（先做再看）

例题例 1（坐标运算）：已知 a = (1, 2)，b = (3, −1)。 (1) 求 a + b、2a − b；(2) 求 a · b；(3) 判断 a 与 b 是否垂直。

自己做：坐标逐项算。

解：(1) a + b = (4, 1)；2a − b = (2, 4) − (3, −1) = (−1, 5)。 (2) a · b = 1×3 + 2×(−1) = 1。 (3) a · b = 1 ≠ 0 ⇒ 不垂直。 要点：数量积是数不是向量；垂直看数量积是否为 0。

例题例 2（夹角）：已知 |a| = 2，|b| = 3，a · b = 3，求 a 与 b 的夹角 θ。

自己做：cos θ = a·b/(|a||b|)。

解：cos θ = 3/(2×3) = 1/2，θ ∈ [0, π] ⇒ θ = 60°。 要点：夹角公式 = 数量积 ÷ 模的乘积，结果是角度（弧度 π/3）。

例题例 3（共线）：已知 a = (2, −3)，b = (x, 6)，且 a ∥ b，求 x。

自己做：用 x1y2 − x2y1 = 0。

解：2×6 − (−3)·x = 0 ⇒ 12 + 3x = 0 ⇒ x = −4。 要点：平行用叉积式（x1y2 − x2y1 = 0），垂直用点积式（x1x2 + y1y2 = 0），别混。

例题例 4（数量积最值 + 基本不等式，苏州教研·专题28，原书p.122 C组）：已知圆 O 半径为 1，PA、PB 为圆 O 的两条切线，A、B 为切点，求 PA·PB 的最小值。

自己做：设半张角 θ，把数量积表示成 θ 的函数，再求最小。

解：设 ∠APO = θ（则 ∠APB = 2θ）。在 Rt△PAO 中 OA=1 是半径，sinθ = OA/PO = 1/|PO|，故 |PO| = 1/sinθ；切线长 |PA|=|PB| = √(|PO|2−1) = cotθ。 PA·PB = |PA||PB|·cos∠APB = cot2θ · cos2θ。 令 u = sin2θ ∈ (0,1]，则 cot2θ = (1−u)/u，cos2θ = 1−2u： PA·PB = (1−u)(1−2u)/u = 2u + 1/u − 3。 由基本不等式 2u + 1/u ≥ 2√(2u·(1/u)) = 2√2，当且仅当 2u = 1/u 即 u = 1/√2 时取等。 故 PA·PB 的最小值 = 2√2 − 3。 要点：切线（或任意两线段）的数量积最值，先把夹角设成单变量、把模也用它表示，再用基本不等式求最值；这是"数量积+基本不等式"的标准搭配。

11.【考点：向量垂直+坐标运算】（2024 新高考Ⅰ卷·第 3 题）已知向量 a = (0, 1)，b = (2, x)，若 b ⊥ (b − 4a)，则 x =（　） A. −2　　B. −1　　C. 1　　D. 2

⑥ 常见坑清单

  • 向量有方向，比较大小只比模；a ≥ b 这种写法不存在。
  • 共线 ⇔ x1y2 − x2y1 = 0；垂直 ⇔ x1x2 + y1y2 = 0。两个公式交叉使用是最高频错误。
  • a · b = 0 包含 a = 0 或 b = 0 或垂直三种可能，做题要看清条件。
  • 数量积没有消去律：a·b = a·c 不能推出 b = c。
  • 求 |a + b|：先平方（|a+b|2 = |a|2 + 2a·b + |b|2）再开方，别直接"加模"。
  • 夹角范围 [0, π]：cos θ 为负说明夹角为钝角。

向量的坐标运算

a=(x1,y1)，b=(x2,y2)：a±b = (x1±x2, y1±y2)，λa = (λx1, λy1)

  • 大白话建系之后，向量加减数乘就是坐标逐项加减乘。
  • 用的时候：能建系就建系，把几何题全变成算术；别漏负号。

与 a 同向的单位向量：a/|a|

  • 大白话把一个向量除以它的长度，就得到方向相同、长度为 1 的向量。
  • 用的时候：题目说"沿 a 方向走一个单位"就写它。

共线与垂直（最容易用反的一对）

共线（平行）：a∥b ⇔ b = λa ⇔ x1y2 − x2y1 = 0

  • 大白话两个向量平行，就是坐标交叉相乘再相减等于 0。
  • 用的时候：求平行用这条"叉积式"；别和下面垂直那条混。

垂直：a⊥b（a、b 非零）⇔ a·b = 0 ⇔ x1x2 + y1y2 = 0

  • 大白话两个向量垂直，就是对应坐标相乘再相加等于 0。
  • 用的时候：求垂直用这条"点积式"；共线用减、垂直用加，千万别交叉用。

数量积（点乘）

a·b = |a||b|cosθ = x1x2 + y1y2

  • 大白话点乘 = 两模相乘再乘夹角余弦；坐标里就是对应坐标相乘再相加。
  • 用的时候：结果是一个数（不是向量）；零向量和任何向量点乘为 0。

求模：|a|2 = a·a = x12 + y12

  • 大白话向量自己点乘自己，就是坐标平方和，等于模的平方。
  • 用的时候：求模先平方再开方。

|a±b|2 = |a|2 ± 2a·b + |b|2

  • 大白话和（差）的模平方，像完全平方公式那样展开。
  • 用的时候：求 |a+b|、|a−b| 先平方，别直接把模相加。

夹角：cosθ  =  (a·b)/(|a||b|)

  • 大白话夹角余弦 = 点积除以两模乘积。
  • 用的时候：夹角范围是 [0,π]；cosθ 为负说明夹角是钝角。

投影：b 在 a 方向上的投影数量  =  |b|cosθ  =  (a·b)/|a|

  • 大白话把 b 垂直投影到 a 所在直线上，那段带方向的长度就是投影。
  • 用的时候：锐角投影为正、钝角为负、直角为 0。

距离与中点

两点距离：d_AB = √((x2−x1)2 + (y2−y1)2)

  • 大白话两点横纵坐标差的平方和开根号，就是勾股定理。
  • 用的时候：向量里求线段长，本质就是两点距离。

中点：M = ((x1+x2)/2, (y1+y2)/2)

  • 大白话中点坐标就是两端点坐标的平均。
  • 用的时候：见到中线、中点直接套。

三点共线的向量判定

P、A、B 三点共线 ⇔ OP  =  x·OA + y·OB 且 x + y  =  1

  • 大白话P 能写成 OA、OB 的加权平均，且权重加起来正好是 1，P 就被摁在直线 AB 上。
  • 用的时候：见到 OP = x·OA + y·OB，先加系数看是不是 1，是就共线，小题秒判。

三角形与向量的二级结论（苏州教研·专题28）

中线向量定理：D 为 BC 边中点 ⇔ AD  =  ½(AB + AC)（即 AB + AC  =  2 AD）

  • 大白话从顶点指向底边中点的向量，等于两条邻边向量和的一半。
  • 用的时候：见到三角形中线，直接用它把中线向量拆成两边向量；和"三点共线 x+y=1"配合做基底题。

重心：P 为 △ABC 重心 ⇔ PA + PB + PC = 0；重心坐标 = ((x1+x2+x3)/3, (y1+y2+y3)/3)；使 PA2+PB2+PC2 最小的点就是重心

  • 大白话重心是三条中线交点（分中线 2:1），它到三顶点向量和为零、坐标是三顶点平均、到三顶点距离平方和最小。
  • 用的时候：见到 PA+PB+PC=0 立刻认重心；给三顶点坐标求重心直接取平均。

角平分线方向向量：AD 平分 ∠A（D 在 BC 上）⇔ AD 方向  =  AB/|AB| + AC/|AC|（两个单位向量相加）

  • 大白话角平分线方向，就是把两条邻边各自取单位向量再相加。
  • 用的时候：要写角平分线的方向向量，别瞎设，直接用"两个单位向量的和"。

极化恒等式（平行四边形对角线平方和）：|a+b|2 + |a−b|2 = 2(|a|2 + |b|2)；从而 a·b = (|a+b|2 − |a−b|2)/4

  • 大白话两向量和与差的模平方相加，等于模平方和的两倍；反解出数量积就是"和模平方减差模平方再除以 4"。
  • 用的时候：已知"中线"或"共起点两向量"的和模、差模（如三角形两边中线），用它一步求数量积，省得展开。

外心数量积结论：O 为 △ABC 外心，则 AO·BC = ½(b2 − c2)（b=|AC|、c=|AB|）

  • 大白话外心到 A 的向量，点乘 BC 边向量，等于两边平方差的一半。
  • 用的时候：题目出现"外心 + 数量积"，直接套这个秒出（由 AO·BC = (AD+DO)·BC，DO⊥BC 消掉，再展开即得）。

夹角锐/钝角判定：a·b>0 且 a 不平行于 b ⇔ 夹角锐角；a·b<0 且不平行 ⇔ 钝角

  • 大白话点积为正只是锐角的必要条件，还要排除两向量同向（点积正但夹角 0°）的情况。
  • 用的时候：题目说"夹角为锐角"列不等式，除了 a·b>0，记得再加"不共线"，否则会把 0° 角也算进去。

定比分点公式：P 在 P1P2 上且 P1P = λ·PP2，则 P = ((x1+λx2)/(1+λ), (y1+λy2)/(1+λ))；λ=1 即中点

  • 大白话分点坐标是两端点坐标按 λ 的"加权混合"，权重在两端点间按 λ 分配。
  • 用的时候：已知分点比 λ，直接套；λ=1 退化成中点公式。

课后习题答案

自测答案：1. a + b = (3, 1)，a − b = (−1, 3)；2. 共线（1×4 − 2×2 = 0，b = 2a）；3. 1·x + 2×(−1) = 0 ⇒ x = 2；4. cos θ = 0 ⇒ θ = 90°（π/2）；5. |a+b|2 = 9 + 2×(−6) + 16 = 13，|a + b| = √13。

A 组答案

A 组

  1. a+b = (2−1, 3+4) = (1, 7)；a−b = (2+1, 3−4) = (3, −1)；2a−3b = (4,6)−(−3,12) = (7, −6)。
  2. |a| = √(9+16) = 5；2a = (6, 8)，|2a| = 10。
  3. 共线：2×(−3) − 6x = 0 → −6−6x = 0 → x = −1。
  4. a·b = 1×4 + (−2)×3 = 4−6 = −2；≠0，不垂直。
  5. M = ((1+5)/2, (2+6)/2) = (3, 4)。
  6. cosθ = (1/2)/(1×1) = 1/2，θ∈[0,π]，θ = 60°（π/3）。

B 组答案

B 组

  1. a+2b = (1+2x, 0)，a−b = (1−x, 3)。垂直：(1+2x)(1−x) + 0×3 = 0 → 1+x−2x2 = 0 → 2x2−x−1 = 0 → (2x+1)(x−1) = 0，x = −1/2 或 1。
  2. |a−2b|2 = |a|2 − 4a·b + 4|b|2 = 4 − 4×1 + 4×1 = 4，|a−2b| = 2。
  3. AC = AB+AD = a+b；BD = AD−AB = b−a。
  4. 投影 = (a·b)/|a| = (4×1+0×1)/4 = 1。

C 组答案

C 组 11.【2024·第3题】b−4a = (2, x)−(0,4) = (2, x−4)。b⊥(b−4a) ⇒ b·(b−4a) = 0：2×2 + x(x−4) = 0 → x2−4x+4 = 0 → (x−2)2 = 0 → x = 2，选 D。

一通百通

这一章的"通用骨架"是：① 看见向量先想成一支可平移的箭头 → ② 能建系就建系，把箭头写成坐标 → ③ 线性问题用坐标加减、共线用 x1y2−x2y1=0 → ④ 涉及垂直/夹角/求模/投影就点积 a·b = x1x2+y1y2。高考向量小题不管怎么包装，本质都是"把几何条件翻译成坐标或点积，再做算术"。会解一道向量小题，就会解所有向量小题；这套"建系坐标化 + 点积翻译几何"的骨架，到第 14 章空间向量还会原样搬到三维里复用。

跨章结合

  • 向量数量积 ⇔ 第 14 章空间向量与立体几何：本章的数量积 a·b=x1x2+y1y2、求模 |a|2=a·a、垂直 ⇔ 点积为 0，搬到三维就是 x1x2+y1y2+z1z2——立体几何里建系后求线线角、线面角、点到面距离，全是这一套二维点积的三维版。想通"点积=投影"，第 14 章那些角和距离公式就不是新东西，而是同一原理多写一个坐标。（综合原理说明，非真题）
  • 向量线性运算 ⇔ 第 15 章直线与圆：直线的方向向量、斜率 k，本质就是"一支箭头的坐标比"；两点决定直线，用的也是向量 AB=(x2−x1, y2−y1)。你在本章练熟的坐标加减、中点公式，到解析几何里写直线方程、算点线距离时会一再出现。（综合原理说明，非真题）

本章与前后章

平面向量前接第 02 章（函数与坐标）和第 06 章（三角函数的夹角与直角三角形）——向量的坐标来自坐标系，夹角公式来自 cosθ；它本身是个"几何→代数"的转换器，向后直接喂给第 14 章空间向量与立体几何：把向量从二维搬到三维、建系求线面角和距离，靠的就是本章这套线性运算和数量积。同时向量也是后面解析几何（15、16 章）里"翻译几何条件"的常用语言。

高考怎么考

新高考Ⅰ卷里向量固定在小题区间（选择题 3–7 题附近），年年一两道，考法高度套路：数量积求夹角、垂直条件、求模（先平方用 |a±b|2 展开）、共线判定，以及坐标法解平面几何。真题如 2024 新高考Ⅰ卷第 3 题（向量垂直+坐标运算，答案 x=2 选 D）就是典型。难度中档、位置靠前，考的不是新结论，而是你"建系、写坐标、点积翻译"这一步熟不熟。
