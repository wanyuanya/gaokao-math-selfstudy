本章本质核心：函数应用的本质是"两次翻译"——先把一个现实问题（或一个带参数的方程、不等式）翻译成"函数的零点、恒成立或最值"，再把算出来的函数结论翻译回题目要的答案。本章从零点存在定理、二分法、零点个数，到恒成立、根的分布、增长模型，全都是这一个原理的变体：先把问题建成 y = f(x)，再靠图象和最值说话。

为什么有用想通了"问题 → 函数 → 结论 → 答案"这条翻译链，你就不必死记"恒成立看 max/min""二分法砍一半"——遇到任何带参数的方程、不等式、利润最值题，都能自己推出该看哪个最值、根大概落在哪，而不是套模板碰运气。

3.1 方程的根与函数的零点

先解决一个老问题。 你会解 x−1 = 0（根 x = 1），会解 x2−3x+2 = 0（根 x = 1,2）。但 x3−x−1 = 0 怎么解？没有求根公式。这时候换个思路：解方程 f(x) = 0，就是找函数 y = f(x) 的图象和 x 轴的交点。

定义：使 f(x) = 0 的实数 x 叫做函数 y = f(x) 的零点。 换句话说：方程 f(x) = 0 有实数根 ⇔ 函数 y = f(x) 有零点 ⇔ 图象与 x 轴有交点。（三件事说的是一回事）

【跟讲例题 3.1-1】 求 f(x) = x2−3x+2 的零点。 解：令 x2−3x+2 = 0，(x−1)(x−2) = 0，x = 1 或 x = 2。零点是 1 和 2。（注意：零点是数 x，不是点 (x,0)。）

小结：零点  =  方程的实根  =  图象与 x 轴交点的横坐标。注意零点是一个数 x，不是一个点。

3.2 零点存在定理

问题来了：我怎么知道一个函数"在某个区间里一定有零点"，而不用真的解出来？

零点存在定理：如果函数 y = f(x) 在区间 [a, b] 上的图象是一条连续不断的曲线，并且 f(a)·f(b) < 0（两端一正一负），那么函数 y = f(x) 在区间 (a, b) 内至少有一个零点，即至少存在一个 c∈(a,b) 使 f(c) = 0。

为什么是这样 图象从 x 轴上方（f(a)>0）连续走到下方（f(b)<0），中间必然至少穿过 x 轴一次。直觉就像走楼梯从楼上到楼下，中间一定过了某个楼层。

注意三个前提：

  1. 图象要连续不断（有断点不成立）；
  2. f(a)·f(b)<0 是充分条件，不是必要——两端同号也可能有零点（比如抛物线顶点正好在 x 轴上）；
  3. 定理只保证"至少一个"，不保证只有一个。

为什么要强调"连续"？ 举个反例：分段函数 f(x) = 1/x，取 a = −1、b = 1，f(a) = −1、f(b) = 1，乘积<0，但 f 在 x = 0 处断开（无定义），它根本不穿过 x 轴——1/x = 0 无解。可见"连续不断"是定理的命门，少了它就不能乱用。

【跟讲例题 3.2-1】 f(x) = lnx+x−2 在区间 (1,2) 内有没有零点？ 解：f(1) = ln1+1−2 = −1<0；f(2) = ln2+2−2 = ln2>0。f(1)·f(2)<0，且 f 连续，故 (1,2) 内至少有一个零点。

小结：两端异号 + 连续 ⇒ 区间内至少一个零点；这是"定性判断有没有根"的利器。

编者注·本质回扣：这条"两端异号就有根"的定理，本质上就是本章主线"两次翻译"的第一步——把"这个方程到底有没有解"这种硬算不出来的问题，翻译成"图象连不连续、两端是不是一正一负"这个看得见的问题。为什么死咬"连续不断"？因为一断，曲线就可能在 x 轴上方直接跳走、根本不穿轴（前面 1/x 的反例就是这个意思）。为什么只说"至少一个"不说"只有一个"？因为一条曲线可以上下穿好几次。记住它只负责"定性地告诉你根在不在里面"，到底有几个、精确值多少，是后面数个数和二分法去补的活。

3.3 二分法

零点存在定理只告诉我们"根在里面"，但到底是多少？ 二分法就是一个笨办法但很可靠的逼近法。

流程（每次把区间对半砍）：

  1. 取区间中点 c = (a+b)/2，算 f(c)。
  2. 若 f(c) = 0，c 就是根；否则看 f(a) 和 f(c) 异号 → 根在 (a,c)；f(c) 和 f(b) 异号 → 根在 (c,b)。
  3. 新区间长度是原来的一半。重复，直到区间足够小（达到精度要求）。

【跟讲例题 3.3-1】 用二分法估计 x3−x−1 = 0 在 (1,2) 的根（f(1) = −1<0，f(2) = 5>0）。 解：中点 1.5，f(1.5) = 3.375−1.5−1 = 0.875>0，根在 (1,1.5)。 中点 1.25，f(1.25) = 1.95−1.25−1 = −0.30<0，根在 (1.25,1.5)。 中点 1.375，……如此反复，区间越来越小，就逼近了真根  ≈ 1.325。

小结：二分法  =  反复取中点、看符号、砍一半；不用会求根公式也能把根算到任意精度。

精度怎么定：题目往往要求"精确到 0.1"。做法是一直砍到区间长度 <0.2（这样区间中点到两端误差都 <0.1）。砍 n 次后区间长度是 (b−a)/2n，想精确到 ε，就砍到 (b−a)/2n<ε 为止。这是计算机求根的经典算法，你手机上的某些数值求解背后就是它。

3.4 零点个数判断

知道"有零点"后，常问"到底有几个"。 方法：

  1. 算特殊点的函数值：看 f 在哪些点变号，每变号一次至少一个零点。
  2. 结合单调性：若函数在区间上单调，则变号区间里恰好一个零点（单调把"至少一个"升级成"恰一个"）。
  3. 画图象：看曲线和 x 轴交几次。

【跟讲例题 3.4-1】 f(x) = 2x+x−3 有几个零点？ 解：f(0) = 1+0−3 = −2<0；f(1) = 2+1−3 = 0（x = 1 是零点）；f(2) = 4+2−3 = 3>0。又 f(x) = 2x+x−3 是增函数（2x 增、x 增，加起来增）。单调函数一旦变号就只有一个零点，故 f 只有一个零点 x = 1。

小结：零点个数  =  变号次数  ×  单调性；单调+变号 ⇒ 恰一个零点。

3.5 三种函数增长模型

生活里到处是增长：存钱的利息（指数）、匀速走路（线性）、经验积累越到后面越慢（对数）。数学上把它们分开看。

模型 形式 增长特点
指数模型 y = a·bx（b>1） 开头慢，后来爆炸，最终最快
线性模型 y = kx+b 匀速，恒定斜率
对数模型 y = lgx / lnx 越涨越慢，后劲不足
幂模型 y = xn（n>0） 介于线性和指数之间

关键结论：在 x 足够大时，指数函数 y = ax（a>1）会最终超过任何幂函数和对数函数。这就是"指数爆炸"——别被它开头慢骗了。

一个生活对照：线性模型像领死工资，每年涨得一样多；对数模型像学新东西，刚开始进步飞快，到后来瓶颈了、涨不动；指数模型像利滚利，基数越大滚得越快。理解了这三种曲线的"脾气"，遇到应用题里的"细胞分裂、复利、传染病扩散"就能立刻反应过来该用哪种模型。

【跟讲例题 3.5-1】 y = 2x 与 y = x2，当 x 很大时谁更大？ 解：x = 10 时，2x = 1024，x2 = 100，2x 反超。x 再大，指数增长甩开平方增长。

指数增长模型（苏州教研·专题16，原书p.60）：原有量为 N，每次增长率为 p，经过 x 次增长后

y  =  N(1+p)x（x∈N）

  • 大白话利滚利、细胞分裂都是这个式子；反过来 p<0 就是衰减（半衰期）。
  • 复利问题、半衰期问题都套它。如半衰期 P = P0e^(−kt) 也是指数衰减。

解应用题四步（苏州教研·专题16，原书p.60）：审题（找等量关系）→ 建模（设变量、注明实际定义域）→ 解模（求最值/解不等式）→ 回归（答案说回实际问题）。数量关系多时，先分类列式，哪怕算不完也能拿步骤分。

【跟讲例题 3.5-2（苏州教研·专题16，原书p.61）】 某商品进货价 14 元/件，售价 15 元时每天卖 500 件；每涨价 1 元，日销量少 20 件。定价多少时日利润最高？ 解：设涨价 x 元，则售价 (15+x) 元，单件利润 (15+x−14)  =  (1+x) 元，日销量 (500−20x) 件。 日利润 P  =  (1+x)(500−20x)  =  −20x2 + 480x + 500。这是开口向下的二次函数，顶点 x  =  −480/(2 × (−20))  =  12。 此时定价  =  15+12  =  27 元，日利润 P  =  (1+12)(500−240)  =  13 × 260  =  3380 元。 要点："涨价多少、少卖几件"这类利润题，永远是建一个二次函数，顶点即最值。

小结：短期看幂/线性，长期看指数；指数模型"笑到最后"；应用题四步走，利润题建二次函数。

3.6 恒成立与能成立（压轴常客，多思多悟）

这是高考"每次必考"的一类题（苏州教研·专题13，原书p.52，原话"重点掌握！每次必考！"）。一句话：求参数范围，先想"恒成立⇔最值"。

四条核心转化（配合 y = f(x) 的图象，一眼就懂）：设 f(x) 在某区间上有最大值 max、最小值 min。

  • λ ≥ f(x) 恒成立（λ 始终压在 f(x) 上方）⇔ λ ≥ f(x)max；
  • λ ≤ f(x) 恒成立（λ 始终贴在 f(x) 下方）⇔ λ ≤ f(x)min；
  • λ ≥ f(x) 有解（只要存在一个 x 让 λ≥f(x)）⇔ λ ≥ f(x)min；
  • λ ≤ f(x) 有解（只要存在一个 x 让 λ≤f(x)）⇔ λ ≤ f(x)max。

大白话"恒成立"看的是离得最远那个最值（上方就压最高、下方就托最低）；"能成立/有解"看的是离得最近那个最值（上方只要够到最低、下方只要够到最高）。注意等号端点要不要取，单独检验。

主力方法：分离参数。把 λ 单独挪到一边：如 λf(x) = g(x) ⇒ λ  =  g(x)/f(x)，问题就变成"求右边那个函数的最值/值域"。若参数拆不开，才用"含参转化法"（按参数讨论）。

两类常见的恒成立（苏州教研·专题13补充，原书p.53）：

  • 一次函数 f(x) = kx+b 在区间 [m,n] 上恒正 ⇔ f(m)>0 且 f(n)>0（一次函数笔直，两头正中间必正）；
  • 二次函数 f(x) = ax2+bx+c 在 R 上恒正 ⇔ a>0 且 Δ = b2−4ac<0（开口向上且与 x 轴不相交）；恒负则 a<0 且 Δ<0。

【跟讲例题 3.6-1（苏州教研·专题13，原书p.54）】 已知 f(x) = x2−x+1，若在区间 [−1,1] 上不等式 f(x)>2x+m 恒成立，求 m 的范围。 解：分离参数。f(x)>2x+m ⇔ m < x2−3x+1。令 g(x) = x2−3x+1，要 m 小于 g(x) 在 [−1,1] 上的最小值（恒成立看最低）。g(x) 对称轴 x = 3/2，在 [−1,1] 上单调递减（导数 2x−3<0），最小值 g(1) = 1−3+1 = −1。故 m < −1。

【跟讲例题 3.6-2（苏州教研·专题13，原书p.54）】 不等式 x2+ax+1 ≥ 0 对任意 x∈(0, 1/2] 恒成立，求 a 的最小值。 解：分离参数：a ≥ −(x+1/x)。要 a 大于等于 −(x+1/x) 在 (0,1/2] 上的最大值。x+1/x 在 (0,1/2] 递减，故 −(x+1/x) 在该区间递增，最大值在 x = 1/2：−(1/2+2)  =  −5/2。故 a ≥ −5/2，a 的最小值为 −5/2。

【跟讲例题 3.6-3（苏州教研·专题13，原书p.54）】 |x+1|+|2x−1|−m ≥ 0 对 x∈R 恒成立，求 m 的范围。 解：分离参数 m ≤ |x+1|+|2x−1|。记 g(x) = |x+1|+|2x−1|，关键点点 x = −1、x = 1/2 分段讨论：x≤−1 时 g = −3x（递减），−1≤x≤1/2 时 g = −x+2，x≥1/2 时 g = 3x（递增）。g(x) 在 x = 1/2 处取最小值 g(1/2) = |3/2|+0 = 3/2。恒成立要求 m ≤ 这个最小值，故 m ≤ 3/2。

小结：恒成立看最值（上方压 max、下方托 min）；分离参数是主力；一次函数区间恒正看两头，二次函数 R 上恒正看 a>0 且 Δ<0。

编者注·本质回扣：这四条转化看着像要背的口诀，本质还是本章"靠最值说话"那条主线。为什么"恒成立"非得去翻最大值、最小值？因为"恒成立"就是参数 λ 要压得住（或托得住）函数 f(x) 的全部取值——它得比 f 最高的那个还高、或比最低的那个还低，自然就落到 max、min 头上。"能成立/有解"宽松得多：只要够着一次就行，所以看的是离得最近的那个最值。分离参数不过是把 λ 单独拎到一边，让右边变成一个纯粹求最值的函数。说白了，这四条不是四个结论，而是"翻译回最值"这一个动作的四种说法。

3.7 二次方程根的分布（数形结合经典）

"方程 ax2+bx+c = 0 的根落在哪个区间"这类题，苏州书给了一句口诀（专题15，原书p.57）：两根在同一区间，三抓——一抓判别式 Δ、二抓对称轴 −b/2a、三抓区间端点函数值；两根不在同一区间，一抓——只抓端点函数值符号。

设 a>0，f(x) = ax2+bx+c，两根 x1≤x2。

情形一：两根落在同一区间（三抓）：

  • 两根都小于 m（x1,x2∈(−∞,m)）⇔ Δ≥0，−b/2a<m，f(m)>0；
  • 两根都大于 m（x1,x2∈(m,+∞)）⇔ Δ≥0，−b/2a>m，f(m)>0；
  • 两根都落在 (m,n) 内 ⇔ Δ≥0，m<−b/2a<n，f(m)>0，f(n)>0。

情形二：两根分居两侧（一抓端点值）：

  • 一根大于 m、一根小于 m（x1<m<x2）⇔ f(m)<0（开口向上，m 点在 x 轴下方，必夹在两根之间）。

【跟讲例题 3.7-1（苏州教研·专题15，原书p.58）】 已知方程 x2+λx+3λ−9 = 0 的一根比 1 大、另一根比 1 小，求 λ 的范围。 解：这是"一根大于 m、一根小于 m"的情形（m = 1），直接用一抓：令 f(x) = x2+λx+3λ−9，条件即 f(1)<0。 f(1) = 1+λ+3λ−9 = 4λ−8<0 ⇒ λ<2。 要点：开口向上的抛物线，要 1 夹在两根中间，只要 f(1) 掉到 x 轴下方即可，Δ 都不用算。

小结：同区间三抓（Δ、对称轴、端点值），异区间一抓（端点值符号）；画抛物线脑子里过一遍，符号就不会反。

④ 例题详解（先做再看）

例题例 1（零点存在定理）：函数 f(x)  =  x3 + x − 1 在下列哪个区间内必有零点？ A. (0, 1)　B. (1, 2)　C. (2, 3)　D. (3, 4)

自己做：算端点值，找符号相反的区间。

解：f(0)  =  −1 < 0；f(1)  =  1 > 0。f(0)·f(1) < 0 且 f 连续 ⇒ 零点在 (0, 1)，选 A。 要点：逐个端点试符号，异号区间即答案；x3 这种多项式恒连续，不用写证明。

例题例 2（零点个数）：求方程 2x + x − 2  =  0 的实数根的个数。

自己做：拆成两个函数看交点。

解：2x  =  2 − x。左侧 y  =  2x 递增，右侧 y  =  2 − x 递减，两图象至多一个交点。取两点试高低：x  =  0 时，20  =  1，2 − 0  =  2，左 1 < 右 2（右高）；x  =  1 时，21  =  2，2 − 1  =  1，左 2 > 右 1（左高）。一增一减，高低在 (0,1) 间翻转一次，故必有一个交点。实数根个数为 1。 要点："一增一减"或"一增一平"用交点数秒杀；一增一增要小心。

例题例 3（二分法）：用二分法求 f(x)  =  x3 − 2 在区间 (1, 2) 内的零点近似值（精确到 0.25）。

自己做：走三步。

解：f(1)  =  −1 < 0，f(2)  =  6 > 0。 第一次：c  =  1.5，f(1.5)  =  1.375 > 0 → 零点在 (1, 1.5)； 第二次：c  =  1.25，f(1.25)  =  −0.047 < 0 → 零点在 (1.25, 1.5)； 第三次：c  =  1.375，f(1.375)  ≈  0.6 > 0 → 零点在 (1.25, 1.375)，区间长 0.125 < 0.25。 取近似值 1.25（或 1.3）。要点：每次只看 f(中点) 符号，区间一分为二。

⑥ 常见坑清单

  • 零点存在定理只说"至少一个"，只有加单调性才能说"恰一个"。
  • f(a)·f(b) < 0 是充分条件不是必要条件——别用"端点同号"判定"没有零点"。
  • 零点  =  横坐标（数），不是交点坐标（点）。
  • 拆函数求交点时注意：两边函数都单调且方向相反 → 恰一个；方向相同 → 可能 0/1/2 个，逐个检验。
  • 二分法收敛：每次都把区间长度减半。

零点的概念

零点  =  使 f(x) = 0 的实数 x

  • 大白话函数图象和 x 轴交点的横坐标，就是方程 f(x)=0 的根。
  • 用的时候：零点是一个数 x，不是一个点 (x,0)；求零点就是解方程。

三件事一回事：有实根 ⇔ 有零点 ⇔ 图象交 x 轴

  • 大白话解方程、找零点、看图象和 x 轴交几次，说的是同一件事。
  • 用的时候：不会解方程就画图，看曲线和 x 轴交几次。

零点存在定理

f 连续，且 f(a)·f(b)<0 ⇒ (a,b) 内至少一个零点

  • 大白话图象从 x 轴上方连续走到下方，中间必然至少穿过一次。
  • 用的时候：两个前提——图象要连续、两端一正一负；它只是充分条件，同号也可能有零点。
  • 记忆要点：定理只保"至少一个"，不保"只有一个"。

二分法

取中点 c = (a+b)/2，看 f(c) 与哪端异号，把区间砍一半

  • 大白话每次取区间中点，根据中点值符号，保留根所在的那一半。
  • 用的时候：f(c)=0 直接得根；否则 f(a) 与 f(c) 异号就缩到 (a,c)。

砍 n 次后区间长度  =  (b−a)/2n

  • 大白话每砍一次区间减半，越缩越接近真根。
  • 用的时候：想精确到 ε，就砍到 (b−a)/2n<ε 为止。

零点个数判断

单调 + 变号 ⇒ 恰一个零点

  • 大白话函数一路单调，又在区间两端变号，那中间一定穿过且只穿过 x 轴一次。
  • 用的时候：零点定理只说"至少一个"，加上单调性才升级成"恰一个"。

增长模型

指数模型 y = a·bx（b>1）：长期最快，指数爆炸

  • 大白话开头慢，后来越涨越猛，最终压倒一切幂函数和对数函数。
  • 用的时候：细胞分裂、复利、传染病扩散，长期都归指数模型。

对数模型 y = lnx/lgx：越涨越慢

  • 大白话一开始快，后来后劲不足、涨不动。
  • 用的时候：学新东西的边际递减，就是这个脾气。

x 足够大时：指数 > 幂 > 线性 > 对数

  • 大白话时间拉长，指数模型笑到最后。
  • 用的时候：别被指数开头慢骗了，长期必看指数。

指数增长模型 y = N(1+p)x（复利/细胞分裂/半衰期）（苏州教研·专题16）

  • 大白话原有量 N，每次乘 (1+p)，利滚利；p<0 就是衰减（半衰期）。
  • 用的时候：复利、人口增长、放射性衰减都套它；应用题四步"审题→建模→解模→回归"。

恒成立与能成立（苏州教研·专题13）

λ≥f(x) 恒成立⇔λ≥f(x)max；λ≤f(x) 恒成立⇔λ≤f(x)min；λ≥f(x) 有解⇔λ≥f(x)min；λ≤f(x) 有解⇔λ≤f(x)max

  • 大白话恒成立看"离得最远"的最值，能成立看"离得最近"的最值。
  • 用的时候：优先分离参数 λ=g(x)/f(x)，再求 g(x)/f(x) 的最值；一次函数区间恒正看 f(m)>0、f(n)>0；二次函数 R 上恒正看 a>0 且 Δ<0。
  • 记忆要点："恒压最高、恒托最低；够到最低、够到最高"，端点等号单独验。

二次方程根的分布（苏州教研·专题15）

同区间三抓：Δ≥0、对称轴 −b/2a 落在区间内、两端 f 值同号（>0）；异区间一抓：x1<m<x2 ⇔ f(m)<0

  • 大白话两根挤在一个区间里，要同时满足"有根、对称轴在里面、两头都在 x 轴上方"；两根分居 m 两侧，只要 f(m)<0 即可。
  • 用的时候：开口向上 a>0；先画抛物线，再写不等式组；一根大于 m 一根小于 m 时，直接 f(m)<0，Δ 都不用算。
  • 记忆要点："同区间三抓（Δ、轴、端点），异区间一抓（端点符号）"。

高级方法·进阶

本章对应方法手册：无直接对应压轴章节（零点、二分法、增长模型是教材主线，《不超纲高级方法手册》的"函数与导数"方法要等第 05 章导数）。这里给两个课标内、可放心用的小技巧：

进阶 1：数形结合数零点（不超纲，高考可放心用）

  • 适用信号：f(x)=g(x)−h(x) 型方程，问有几个解。
  • 操作步骤：把方程拆成 y=g(x) 与 y=h(x) 两条熟悉的曲线，画在同一张图上，交点个数就是解的个数。
  • 例：2x=x+1 拆成 y=2x 与 y=x+1，画出来交于 (0,1)、(1,2) 两点，故 2 个解。
  • 依据：函数图象与方程解的关系（课标内）。✓ 不超纲。

进阶 2：端点效应初体验（不超纲）

  • 适用信号：零点存在定理配合"端点函数值变号"，快速锁定根的大致范围。
  • 操作步骤：多算几个整数点的函数值，看符号在哪两个点之间翻转，根就在那个区间。
  • 依据：零点存在定理（课标内）。✓ 不超纲（严格的"必要性探路"在第05章）。

进阶 3：中心对称函数——最大值加最小值等于 2b（不超纲）（苏州教研·专题12，原书p.48）

  • 结论：若 f(a+x)+f(a−x)=2b，则 y=f(x) 的图象关于点 (a,b) 成中心对称；此时 f(x) 的最大值 M 与最小值 N 满足 M+N=2b。
  • 操作信号：看到"f(x)=奇函数部分 + 常数"（如 f(x)=ax7+bx5+c∛x+2），或求一串成对函数值的和，先凑 f(−x)+f(x)。
  • 例（苏州教研·专题12，原书p.49）：f(x)=ax7+bx5+c∛x+2，f(−5)=7，求 f(5)。解：奇部分记 g(x)=ax7+bx5+c∛x（奇函数，g(−x)=−g(x)），f(x)=g(x)+2。f(−5)=g(−5)+2=−g(5)+2=7 ⇒ g(5)=−5，故 f(5)=g(5)+2=−3。
  • 依据：奇函数定义与中心对称（课标内）。✓ 不超纲。

进阶 4：抽象函数模型"对号入座"（不超纲）（苏州教研·专题12，原书p.48）

  • 信号：给一个运算等式，让你判断性质/求函数值。把它对号到一个熟悉的具体函数：
  • f(x+y)=f(x)+f(y) ⇒ 一次函数模型（如 f(x)=kx）；
  • f(x+y)=f(x)·f(y) ⇒ 指数函数模型（如 f(x)=ax）；
  • f(xy)=f(x)+f(y) ⇒ 对数函数模型（如 f(x)=logax）；
  • f(xy)=f(x)·f(y) ⇒ 幂函数模型（如 f(x)=xα）。
  • 操作：对号入座后，赋值法（令 x=0、y=0、y=−x）求 f(0)、证奇偶、判单调。
  • 依据：基本初等函数的运算律（课标内）。✓ 不超纲。

A 组答案

A 组

  1. x2−5x+6=(x−2)(x−3)=0，零点为 2 和 3。
  2. f(1)=1−2−1=−2<0；f(2)=8−4−1=3>0。f 连续，f(1)·f(2)<0，故 (1,2) 内有零点。
  3. f(1)·f(e)<0 且连续，故 (1,e) 内至少有一个零点。
  4. f(1.5)>0 而 f(1)<0，根在异号的那一端，即 (1,1.5)。
  5. B。y=2·1.1x 底数 1.1>1，是指数爆炸增长。
  6. f(x)=x−lnx。f'(x) 这里先不正式用；直接看：f(1)=1>0，f(e)=e−1≈1.72>0，且 x→0+ 时 −lnx→+∞，函数在 x=1 附近取最小值 f(1)=1>0。最小值 >0，故没有零点，零点个数 0。

B 组答案

B 组

  1. f(x)=3x+x−3。f(x) 是增函数（3x 增、x 增）。f(0)=1+0−3=−2<0；f(1)=3+1−3=1>0。单调 + 变号 ⇒ 在 (0,1) 内恰一个零点，全 R 上仅此一个。
  2. f(1)=−1<0，f(2)=1>0，零点在 (1,2)。取中点 1.5，f(1.5)=2^1.5−3=2.828−3=−0.172<0，与 f(2) 异号，零点缩到 (1.5,2)。
  3. 长期看指数最快、线性次之、对数最慢：1.01x > 100x > lnx。（注意短期 100x 可能领先，但 x→∞ 时指数反超。）
  4. 画 y=2x 与 y=x+1：交于 (0,1)（20=1=0+1）和 (1,2)（21=2=1+1）。两条线交于 2 点，故方程 2x=x+1 有 2 个解。

C 组答案

C 组

  1. f(x)=x3−x+1。 - C：f(x)+f(−x)=(x3−x+1)+(−x3+x+1)=2，即 f(−x)=2−f(x)，图象关于点 (0,1) 对称。C 正确。 - B：f(−2)=−8+2+1=−5<0，f(−1)=−1+1+1=1>0，在 (−2,−1) 有一个零点；f(0)=1>0，局部最低点（x=1/√3≈0.577 代入 f≈0.62>0）为正，故 x>−1 时不再变号，只有 1 个零点而非 3 个。B 错误。 - A、D 两问要用到导数（第05章正式讲）：f'(x)=3x2−1=0 有两个解 → 两个极值点（A 正确）；斜率 2 对应 f'(x)=2⇒x=±1，代入得切线分别为 y=2x−1、y=2x+3，都不是 y=2x（D 错误）。 综上正确选项为 AC。

一通百通

这一章的"通用骨架"三步：① 把题目翻译成一个函数 y=f(x)（解方程就令 f(x)=0，不等式就移项成一边）→ ② 看图象、算最值：用两端符号定"有没有"、用单调定"有几个"、用最值定参数范围 → ③ 把函数结论翻译回题目要的答案。不管零点存在定理、二分法、零点个数，还是恒成立、根的分布、利润最值，骨子里都是这三步：先建模、再看图求最值、最后回译。会做一道零点题，就会做所有"方程—函数—图象"的题；这套"先翻译、再看图、后回译"的骨架，下一章用导数求函数最值时还会原样复用。

跨章结合

  • 零点存在定理 × 05 章导数（隐零点）：本章 3.2 教你"两端异号就有根"，3.4 教你"单调 + 变号就恰一个"；到了 05 章导数压轴，f′(x)=0 的根常常解不出显式，这时正是回头用本章这两条——先证 f′ 在区间两端变号、再证它单调，就敢把这个零点设为 x0"设而不求"、整体代换。05 章例 6（苏州教研·专题51·例21，求 k_max=3）就是这么干的：x0∈(2,3) 解不出来，但靠零点存在定理确认它唯一存在，再用 p(x0)=0 整体代换。本章的零点工具，正是导数压轴"隐零点"的地基。
  • 恒成立转最值 × 12 章基本不等式：本章 3.6 把"恒成立"翻译成求最值；分离参数后那个新函数的最值，有时不必求导，用 12 章的基本不等式（如 x+1/x ≥ 2）一步就能估出来——本章例 3.6-2 里那个 −(x+1/x) 的最值，本质就是对勾函数、基本不等式的变形。两章一碰，恒成立题就多了一条"不求导也能出最值"的快路。（此点为综合原理说明，非真题。）

本章与前后章

这一章是函数主线的"第一次实战"：它前面接 第 02 章函数概念与性质（单调、最值、图象）和 第 03 章指对幂函数（增长模型、算函数值）——没有前两章的图象和基本函数，这章连 f(a)、f(b) 都算不出来；它后面直接通向 第 05 章导数：这章靠"单调性 + 变号"数零点、靠"最值"做恒成立，可一旦函数复杂到看不出单调、求不出最值，就得请导数当新工具。学完这章，你手里多了一套"把现实问题翻译成函数、再翻译回答案"的本事，它正是下一章求导、求极值、解压轴的地基。

高考怎么考

这一章在新高考Ⅰ卷里通常以小题出现：零点存在定理判断根所在区间、零点个数（常和函数图象交点、单调性结合）、二分法近似解，多落在选择题中后段；恒成立、根的分布这类更像"工具"，往往嵌进函数与导数解答题的第一问，而不是单独成题（本章 C 组收录的 2022 新高考Ⅰ卷第 10 题多选，就把零点个数、对称中心和切线揉在一起考）。难度以中档为主，不偏不怪——它真正的分量不在这几道小题，而在于给第 05 章导数压轴备好"数零点、求最值"这两块基本功。
