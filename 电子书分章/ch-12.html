本章本质核心：不等式的本质就是"比较大小"——本章从头到尾都在回答同一个问题："谁大谁小、大多少"。解一元二次不等式（ax2+bx+c>0），是在问"x 取哪些值时左边比 0 大"；基本不等式 √(ab)≤(a+b)/2，是在规定"和与积谁不超过谁"；求最值、恒成立、证明不等式，本质都是把"谁大谁小"用代数式说清楚。本章所有题型（解不等式、套基本不等式、求最值、证不等式）都是这一个原理的变体。

为什么有用想通了"比较大小"这件事，你就能独立解决两类高考高频题——求最值（用料最省、围面最大这类优化问题的数学内核就是"和定积最大、积定和最小"）和恒成立求参数。不用背套路，遇到任何"给条件求最大/最小"的题，认准谁是固定的"和"、谁是固定的"积"，自己就能把最值推出来。

3.1 一元二次不等式（ax2 + bx + c > 0，先让 a > 0）

引入：投篮时球的轨迹是一条抛物线，问"球什么时候在篮筐高度以上"，就是在解一个二次不等式。二次函数、二次方程、二次不等式其实是同一条抛物线的三件事：方程看"和 x 轴交点在哪"，不等式看"抛物线在 x 轴上方还是下方"。

定义：只含一个未知数，并且未知数最高次数是 2 的整式不等式，叫一元二次不等式，标准形 ax2+bx+c>0（或 <0），a≠0。

求解步骤（编号，照做不会错）：

  1. 化正：a<0 时两边同乘 −1，不等号反向，先把开口变成向上；
  2. 求根：因式分解或求根公式，得两根 x1 ≤ x2（Δ<0 就没有实根）；
  3. 看图写解：开口向上时，"大于取两边，小于取中间"： - ax2+bx+c > 0 ⇒ x<x1 或 x>x2； - ax2+bx+c < 0 ⇒ x1<x<x2。

几何意义：开口向上的抛物线，在两根之间图像落在 x 轴下方（y<0），两根之外落在上方（y>0）。Δ<0 时抛物线整段都在 x 轴上方，所以 ax2+bx+c>0 的解集是全体实数 R。

例题跟讲例题：解 x2 − 5x + 6 < 0。 解：分解 (x−2)(x−3)<0，开口向上，"小于取中间"，解集 2<x<3，写成区间 (2,3)。

再跟一道（Δ = 0 的情形）：解 x2 − 4x + 4 > 0。 解：分解 (x−2)2>0。开口向上且正好与 x 轴相切于 x = 2，除了切点本身，其余地方都在 x 轴上方。所以解集是 x≠2 的全体实数（写成 (−∞,2)∪(2,+∞)）。如果题目改成 (x−2)2≥0，那解集就是全体实数 R；改成 (x−2)2≤0，则只有 x = 2 一个点。

常见陷阱：a<0 忘了先变号；Δ<0 时把解集写成空集（开口向上时应是 R）。

高次/分式不等式——数轴穿根法（苏州教研·专题38）

遇到 (x−x1)(x−x2)…(x−xn)>0 这种一次因式乘积，或 f(x)/g(x)>0 这种分式，不用每个区间讨论，画一条波浪线就行：

  1. 把所有根 x1≤x2≤…≤xn 标在数轴上（每个因式 x 的系数必须先化成正）；
  2. 从最右端根的上方开始，从右往左画波浪线：奇数次根穿过数轴，偶数次根碰一下就弹回（不穿过）；
  3. 线在数轴上方的区间就是 >0 的解集，下方就是 <0 的解集。

苏州书顺口溜："原式化为标准形，数轴上面标出根，奇穿偶切画曲线，上正下负解集明。"分式不等式 f(x)/g(x)>h(x) 先移项通分，化成一个分式再穿根。

绝对值不等式互化（苏州教研·专题38）：

|f(x)| < g(x) ⇔ −g(x) < f(x) < g(x)（g(x) 必须 >0）

|f(x)| > g(x) ⇔ f(x) > g(x) 或 f(x) < −g(x)

|f(x)| > |g(x)| ⇔ f2(x) > g2(x)（两边都是绝对值，直接平方）

|x−a|+|x−b|（a<b）的几何意义：数轴上点 x 到 a、b 两点的距离之和。最小值就是 |a−b|（x 在 a、b 之间时取得）；x 在 a 左边或 b 右边每往外移 Δx，距离和就增加 2Δx。解这类题三种办法：零点分段去绝对值、画函数图像、用几何意义。

3.2 基本不等式（核心，高考必考）

引入：用一根长固定的绳子围矩形菜园，围成正方形时面积最大——这是古人就知道的事实。为什么？因为"和一定时，两数越接近乘积越大"，这背后就是基本不等式。

定义：对任意两个正数 a、b，有 √(ab) ≤ (a+b)/2，等号当且仅当 a = b 时成立。 其中 (a+b)/2 叫 a、b 的算术平均数，√(ab) 叫几何平均数。一句话：两个正数的几何平均不超过它们的算术平均。

怎么证：因为 a、b>0，对 √a−√b 平方得 (√a−√b)2≥0，展开 a+b−2√(ab)≥0，移项即 √(ab)≤(a+b)/2；a = b 时等号成立。

几何解释（半圆模型）：把线段 AB 长 a+b 放在直径上，C 点把直径分成 a 和 b 两段，过 C 作直径的垂线交半圆于 D，则 CD = √(ab)（由射影定理），而半圆半径是 (a+b)/2。垂线永远不超过半径，所以 √(ab)≤(a+b)/2。

三个常用变形（务必滚瓜烂熟）：

记住它之前先看懂它：这三条其实是同一个不等式 √ab ≤ (a+b)/2 换个写法——第一条是"两边乘 2"，第二条是"两边平方"，第三条是把 a、b 换成 √a、√b 得到的、连正数条件都放宽了。理解了它们是一回事，就不用背三张表。

  1. a+b ≥ 2√(ab)（和 ≥ 两倍根号积）
  2. ab ≤ [(a+b)/2]2（积 ≤ 半和的平方）
  3. a2+b2 ≥ 2ab（这条对任意实数都成立，不限正数）

求最值三条件（口诀：一正、二定、三相等）：

  • 一正：各项必须是正数，否则不等式不成立；
  • 二定：求和的最小值，就要"积为定值"；求积的最大值，就要"和为定值"；
  • 三相等：一定要能取到 a = b，否则这个最值是假的。

两个方向：

  • 积 xy = p（定值）⇒ x+y ≥ 2√p，x = y 时和最小为 2√p；
  • 和 x+y = s（定值）⇒ xy ≤ s2/4，x = y 时积最大为 s2/4。

对勾函数：x>0 时 x+1/x ≥ 2√(x·1/x) = 2，x = 1 取等；x<0 时提负号，x+1/x ≤ −2。

例题跟讲例题：x>0，求 x+4/x 的最小值。 解：x·(4/x) = 4 为定值，x+4/x ≥ 2√4 = 4，当 x = 4/x 即 x = 2 时取等。三条件：x>0（正）✓、积定 4 ✓、x = 2 可取 ✓。

再跟一道（高考最热的"1 的代换"）：已知 x>0，y>0，x+y = 1，求 1/x+1/y 的最小值。 解：把"1"换成 x+y 乘进去：1/x+1/y = (x+y)(1/x+1/y) = 1+x/y+y/x+1 = 2+(x/y+y/x) ≥ 2+2 = 4，当 x/y = y/x 即 x = y = 1/2 时取等。这招叫"1 的代换"，见到"和为 1、求倒数和"就用它。

小结：基本不等式就是"和与积互相挤"；用前先查一正二定三相等。

编者注·本质回扣：基本不等式为什么长这样？它其实就是本质核心"比较大小"里最常用的一把尺：两个正数的和与积，谁也不能同时无限占优——和一定时积有顶（围菜园正方形最大），积一定时和有底。所谓"一正二定三相等"，说白了就是先确认这把尺能用（各项为正）、再看准固定的是和还是积、最后保证等号真能取到。你看到的"1 的代换"、对勾函数 x+1/x≥2，都不是新公式，只是把这把尺换个场景再量一遍而已。

三元均值与平方平均（苏州教研·专题37）：

(a+b+c)/3 ≥ ∛(abc)（a,b,c>0），等号当 a = b = c 时成立

  • 大白话三个正数的算术平均不小于几何平均，是二元基本不等式的推广。
  • 用的时候：见到三个正数的和求积的最大值，或积求和的最小值，直接套。

(a2+b2)/2 ≥ ((a+b)/2)2（任意实数 a,b）

  • 大白话平方的平均不小于平均的平方。
  • 用的时候：已知 a+b 求 a2+b2 的下界，或反过来；这是柯西不等式的二维特例。

糖水不等式推广（苏州教研·专题37）：若 a>b>0，m>0，n>0，则

b/a < (b+m)/(a+m) < 1 < (a+n)/(b+n) < a/b

  • 大白话真分数越加越大，假分数越加越小。一杯淡糖水（b/a）再加点糖（m）反而更甜；一杯浓糖水（a/b）再加点水（n）反而更淡。
  • 用的时候：比较两个形如 (a+m)/(b+m) 的分数大小，直接用这个结论秒选。

混合浓度不等式：A 杯浓度 a%、B 杯浓度 b%（a>b），各取 x、y 克混合，则混合浓度介于两者之间：b < (ax+by)/(x+y) < a。

3.3 恒成立问题

引入："不管 x 取什么值，这个式子都 ≥0"——比如"对所有实数 x，x2+ax+4≥0 恒成立，求 a"。这类题的套路是：把恒成立翻译成最值。

两条主路：

  1. 分离参数：a ≤ f(x) 对一切 x 恒成立 ⇔ a ≤ f(x) 的最小值；a ≥ f(x) 恒成立 ⇔ a ≥ f(x) 的最大值。
  2. 判别式法（二次型）：开口向上的二次函数 ax2+bx+c≥0 恒成立 ⇔ 判别式 Δ≤0（图像整段在 x 轴上方或相切）。

例题跟讲例题：对 ∀x∈R，x2+ax+4≥0 恒成立，求 a。 解：开口向上，只需 Δ = a2−16≤0 ⇒ −4≤a≤4。

再跟一道（分离参数）：若 x>0 时，a ≤ x + 1/x 恒成立，求 a 的最大值。 解：要 a 不超过右边的一切取值，只要 a 不超过右边的最小值。x+1/x≥2，最小值为 2，所以 a≤2，a 的最大值是 2。这就是"恒成立 → 求最值"的标准动作。

常见陷阱：x2 系数含字母 k 时，必须先讨论 k = 0（变成一次式），不能直接套判别式。

3.4 不等式的性质与比较大小

引入：等式两边随便加减乘除同一个数（除数非零）都不变号，但不等式"娇气"——两边乘负数要变号。这一节把这些脾气说清楚。

基本性质（由浅入深）：

记住它之前先看懂它：这一串性质不是死规矩，而是"大小关系在加减乘除下怎么跟着变"——加同一个数两边同步平移，方向不变；乘正数是均匀拉伸，方向不变；乘负数是把数轴整个翻过来，方向必然颠倒。盯住"这一步操作有没有把数轴翻面"，就不用逐条背。

  • 传递性：a>b，b>c ⇒ a>c；
  • 可加性：a>b ⇒ a+c>b+c；同向可加：a>b，c>d ⇒ a+c>b+d；
  • 乘正数不变号：a>b，c>0 ⇒ ac>bc；乘负数变号：a>b，c<0 ⇒ ac<bc；
  • 同正可乘：a>b>0，c>d>0 ⇒ ac>bd；
  • 同方可开方：a>b>0 ⇒ an>bn，n√a>n√b。

比较大小两招：作差法（a−b 的正负定大小）、作商法（同正时 a/b 与 1 比）。

例题跟讲例题：比较 (a+1)(a−5) 与 (a+2)(a−4) 的大小。 解：作差 (a+1)(a−5)−(a+2)(a−4) = (a2−4a−5)−(a2−2a−8) = −2a+3。a<3/2 时差为正，前者大；a = 3/2 相等；a>3/2 后者大。

再跟一道（糖水不等式直觉）：比较 a/b 与 (a+m)/(b+m)（0<a<b，m>0）。 解：作差 a/b−(a+m)/(b+m) = [a(b+m)−b(a+m)]/[b(b+m)] = (am−bm)/[b(b+m)] = m(a−b)/[b(b+m)]<0。所以 a/b<(a+m)/(b+m)。生活直觉：一杯淡糖水再加点糖反而更甜，就是这个道理。

小结：不等式两边乘除要盯符号；比大小先作差，定号看因式。

编者注·本质回扣：作差法 a−b 其实就是把"谁大谁小"这句话翻成一个数：差为正前者大、差为负后者小、差为零相等。你也许会问，为什么不等式两边乘负数要变号？本质还是"比较"——乘一个负数相当于把数轴方向整个反过来，原来靠左的变得更小、靠右的变得更大，大小关系自然跟着颠倒。所以这一节列的那些性质，不是要你死背的死规矩，而是"大小关系在加减乘除、平方开方这些操作下怎么跟着变"的一本账；做题时盯住符号，就是盯住这本账有没有记反。

3.5 证明不等式的常用方法（苏州教研·专题40）

证明题拿到手，先挑方法。苏州书总结了七把"刀"：

1. 比较法（最常用）：作差 a−b，变形（因式分解/配方/通分），定号；两个正数也可作商 a/b 与 1 比。苏州书提醒：两个正数作差有困难时，可改比平方差；无理数比大小，分子/分母有理化是常用手段。

2. 综合法：由因导果——从已知条件出发，用定理、公式一步步推出结论。书写顺、看着像"标准答案"。

3. 分析法：执果索因——从要证的结论倒推，找它成立的充分条件，直到归结为已知或显然成立。苏州书要求：书写尽量用"⇔"符号，每一步都是等价变形。思路卡壳时用分析法找路，找到后再用综合法写出来。

4. 反证法：正难则反——假设结论不成立，推出矛盾（与已知/假设/定理矛盾），从而断定原结论成立。三步：反设、归谬、结论。

5. 放缩法：把不等式一侧适当放大或缩小。常用技巧（苏州书原话）： - 添加或舍去一些项，如 √(n2+1) > √n2  =  |n|；√(n(n+1)) < √(n2+n+¼)  =  n+½； - 分子或分母单独放大/缩小； - 用均值不等式放缩，如 √(lg3·lg5) < (lg3+lg5)/2  =  lg√15 < lg4； - 对应项一一放大，如 Ank ≤ nk。

放缩的分寸：不能过度、不能过早——放太大直接超过目标，证不出来；首项不吻合就从第二项起放。

6. 换元法：减少变量，化难为易。苏州书给的常用模板： - 已知 x2+y2 = a2，设 x = a·cosθ，y = a·sinθ（三角换元）； - 已知 a2≤x2+y2≤b2，设 x = r·cosθ，y = r·sinθ（a≤r≤b）； - 椭圆 x2/a2+y2/b2 = 1 同理设 x = a·cosθ，y = b·sinθ。

7. 构造法：构造方程（判别式法）、构造数列、构造向量、构造辅助函数。函数型不等式通常构造差函数 F(x) = f(x)−g(x)，再用单调性证明（这要学了导数才用得上）。

8. 数学归纳法：与正整数 n 有关的不等式，两步走（奠基+递推），第二步常用分析法找思路。

【跟讲例题（苏州教研·专题40，原书p.143）】：设数列 {an} 满足 an+1  =  an2 − n·an + 1，n∈N*。当 a1≥3 时，证明：① an≥n+2；② 1/(1+a1)+1/(1+a2)+…+1/(1+an) < 1/2。 证明①（数学归纳法）： n = 1 时，a1≥3 = 1+2，成立。 假设 n = k 时 ak≥k+2，则 ak+1  =  ak(ak−k)+1 ≥ (k+2)·[(k+2)−k]+1  =  (k+2)·2+1  =  2k+5  =  (k+1)+2+(k+2) ≥ (k+1)+2。 故 n = k+1 时也成立。由归纳法，an≥n+2 对所有 n 成立。 证明②（放缩法）：由 an≥n+2 得 an−n≥2，于是 an+1+1  =  an(an−n)+2 ≥ 2an+2  =  2(an+1)。 累乘：an+1 ≥ (a1+1)·2n−1 ≥ 4·2n−1  =  2n+1，故 1/(1+an) ≤ 1/2n+1。 求和：Σ_{k = 1}^{n} 1/(1+ak) ≤ 1/4+1/8+…+1/2n+1  =  (1/4)·[1−(1/2)n]/(1−1/2)  =  (1/2)·[1−(1/2)n] < 1/2。证毕。 要点：归纳法证"下界"→ 用下界做放缩的跳板 → 转等比求和。这是苏州书说的"数列不等式证明"标准流水线。

3.6 含参数不等式的讨论标准（苏州教研·专题39）

解含字母参数的不等式 ax2+bx+c>0，什么时候需要分类讨论？苏州书给了三条"讨论标准"：

  1. 二次项系数含字母：先令它 = 0（退化为一次式），这是第一个分界；
  2. 能因式分解的题型：令各因式的根相等 x1 = x2，解出参数值；
  3. 不能因式分解的题型：令判别式 Δ = 0，解出参数值。

讨论完一定要写"综上所述，原不等式的解集是……"（分类整合思想）。

反用：如果不等式的解集已经给你了，那解集的端点值一定是对应方程 ax2+bx+c = 0 的根——可以直接代进去求参数。

④ 例题详解（先做再看）

例题例 1（二次不等式）：解不等式 x2 − 5x + 6 < 0。

自己做：因式分解 → 小于取中间。

解：x2 − 5x + 6  =  (x − 2)(x − 3) < 0，开口向上，"小于取中间"：2 < x < 3。 要点：先看开口，再写区间；解集写成区间形式 (2, 3)。

例题例 2（基本不等式求最值，高考经典）：已知 x > 0，y > 0，且 x + y  =  1，求 1/x + 1/y 的最小值。

自己做：把 1 换成 x + y（"1 的代换"）。

解：1/x + 1/y  =  (x + y)/(xy)  =  1/(xy)。由 xy ≤ [(x+y)/2]2  =  1/4 ⇒ 1/(xy) ≥ 4。 或用"1 的代换"：1/x + 1/y  =  (x+y)(1/x + 1/y)  =  2 + x/y + y/x ≥ 2 + 2  =  4。 取等 x  =  y  =  1/2。最小值 4。 要点："积定求和最小"方向：xy 有上界 ⇒ 1/x + 1/y 有下界；"1 的代换"是最高频技巧。

例题例 3（恒成立）：若对 ∀x ∈ R，x2 + ax + 4 ≥ 0 恒成立，求 a 的范围。

自己做：开口向上，判别式 ≤ 0。

解：Δ  =  a2 − 16 ≤ 0 ⇒ −4 ≤ a ≤ 4。 要点：二次函数恒非负（a > 0）⇔ Δ ≤ 0；这是小题秒杀结论。

⑥ 常见坑清单

  • 一正：基本不等式只对正数成立，x < 0 时要先提负号或加绝对值。
  • 三相等：等号取不到时最值不成立——a  =  b 是否可取得先检验。
  • 解不等式"大于取两边"前提是开口向上且因式分解正确；a < 0 先变号。

  • 恒成立"分离参数"：分离后别忘了定义域对参数的约束。

均值不等式（基本不等式）

√(ab) ≤ (a+b)/2 ≤ √[(a2+b2)/2]（a,b ≥ 0）

  • 大白话两个正数的几何平均 ≤ 算术平均 ≤ 平方平均，一串从小到大。
  • 用的时候：高考最常用中间一段 √ab ≤ (a+b)/2；必须满足"一正二定三相等"。
  • 记忆要点：几何平均不超过算术平均。

三个变形：a+b ≥ 2√(ab)；ab ≤ [(a+b)/2]2；a2+b2 ≥ 2ab

  • 大白话和与积互相挤——知道和求积用第二式，知道积求和用第一式。
  • 用的时候：第三条 a2+b2≥2ab 对任意实数都成立，不限正数；前两条要 a,b>0。

极值定理（求最值）

积定：xy  =  p（定值）⇒ x+y ≥ 2√p，x = y 时和最小为 2√p

  • 大白话两个正数乘积固定，它们相等时加起来最小。
  • 用的时候："积定"求"和"的最小值；对勾函数 x+1/x≥2 就是它。

和定：x+y  =  s（定值）⇒ xy ≤ s2/4，x = y 时积最大为 s2/4

  • 大白话两个正数加起来固定，它们相等时乘积最大。
  • 用的时候："和定"求"积"的最大值；用前先检查 a=b 能不能取到。

"1 的代换"：x+y = 1 时 1/x+1/y  =  (x+y)(1/x+1/y) ≥ 4

  • 大白话见到"和为 1、求倒数和"，把 1 换成 x+y 乘进去展开。
  • 用的时候：展开后用 x/y+y/x ≥ 2；取等 x=y=1/2。

一元二次不等式

a>0 时：(x−x1)(x−x2)>0 ⇒ x<x1 或 x>x2；<0 ⇒ x1<x<x2

  • 大白话开口向上，"大于取两边，小于取中间"。
  • 用的时候：先把 a 化成正数再因式分解；Δ<0 时 >0 解集是 R、<0 解集是空。

恒成立问题

ax2+bx+c ≥ 0 对一切 x 恒成立 ⇔ a>0 且 Δ  =  b2−4ac ≤ 0

  • 大白话开口向上的抛物线全程贴在 x 轴上方或相切。
  • 用的时候：二次项含字母 k 时先讨论 k=0（变一次式），别直接套判别式。

分离参数：a ≤ f(x) 恒成立 ⇔ a ≤ f(x)_min；a ≥ f(x) 恒成立 ⇔ a ≥ f(x)_max

  • 大白话要恒成立，参数就得不超过右边的最小值（或不小于最大值）。
  • 用的时候：分离后别忘了定义域对参数的限制。

比较大小与常用结论

作差法：a−b 的正负定大小；作商法：同正时 a/b 与 1 比

  • 大白话比大小先作差，把结果因式分解再看每段正负。

对勾函数：x>0 时 x + 1/x ≥ 2（x = 1 取等）；x<0 时提负号得 ≤ −2

  • 大白话正数和它倒数的和，最小值是 2。

绝对值：|x|<a（a>0）⇔ −a<x<a；|x|>a ⇔ x>a 或 x<−a

  • 大白话小于夹中间，大于取两边。

三元均值与平方平均（苏州教研·专题37）

(a+b+c)/3 ≥ ∛(abc)（a,b,c>0）；(a2+b2)/2 ≥ ((a+b)/2)2

  • 大白话三个正数的算术平均 ≥ 几何平均；平方的平均 ≥ 平均的平方。
  • 用的时候：三个正数和定求积最大、积定求和最小套第一式；已知 a+b 求 a2+b2 下界套第二式。

糖水不等式：a>b>0，m>0 ⇒ b/a < (b+m)/(a+m) < 1

  • 大白话真分数越加越大，假分数越加越小；淡糖水加糖更甜。
  • 用的时候：比较 (a+m)/(b+m) 这类分数大小直接秒选。

绝对值与高次不等式工具（苏州教研·专题38）

|f(x)| < g(x) ⇔ −g(x)<f(x)<g(x)；|f(x)|>|g(x)| ⇔ f2(x)>g2(x)

  • 大白话带 g(x) 的绝对值不等式，拆开或平方。
  • 用的时候：两边都是绝对值直接平方；一边是 g(x) 就拆成双向不等式。

数轴穿根法：一次因式乘积 >0，从右往左、奇穿偶切，上正下负

  • 大白话根标在数轴上，波浪线穿过去，线上方的区间就是解。
  • 用的时候：每个因式 x 的系数先化成正；分式先移项通分再穿。

|x−a|+|x−b|（a<b）最小值  =  |a−b|

  • 大白话数轴上一点到两定点距离之和，点在两定点之间时最小。

证明不等式的方法选择（苏州教研·专题40）

比较法（作差/作商）→ 综合法（由因导果）→ 分析法（执果索因，用⇔）→ 反证法 → 放缩法 → 换元法 → 构造法 → 数学归纳法

  • 大白话证不等式八把刀，按题目形状挑。
  • 用的时候：思路卡壳用分析法倒推；证 n 有关命题用归纳法；函数型不等式构造差函数（学导数后用）；放缩不能过度、首项不吻合就延迟放。

含参讨论三条线：二次项系数 = 0、两根相等、Δ = 0

  • 大白话参数临界值就是让"退化"发生的那些点。
  • 用的时候：讨论完写"综上所述"；已知解集反求参数时，端点代入方程。

4.1 基本不等式"三件套"技巧

大白话·本质一句话：三件套的本质，是把"已知和求积最值、已知积求和最值"这类题，翻译成一次乘法（1 的代换）、一次配方搭桥（和积转化 S2≥4P）、一次换元消分母（a/b 型令 t = a/b）——核心就一句话：和定积最大、积定和最小，三件套只是把这句话搬进不同长相的题里。

4.2 绝对值三角不等式

进阶 1：基本不等式"三件套"

适用信号：给了一个和（或积）的定值，求另一个式子的最值。 操作步骤：

  1. 1 的代换：已知 x+y = 1，求 1/x+1/y——乘 (x+y)，展开后用 x/y+y/x≥2；

  2. 分解 (x−1)(x−a)<0。若 a>1：1<x<a；若 a<1：a<x<1；若 a=1：(x−1)2<0 无解。
  3. 2x·(8/x)=16 定，2x+8/x ≥ 2√16=8，2x=8/x 即 x=2 取等。
  4. k=0 时 1>0 成立；k≠0 需 k>0 且 Δ=k2−4k<0 ⇒ 0<k<4。综上 0≤k<4。

C 组答案

C 组

  1. 设公共值为 k，则 x=2^{k−2}，y=3^{k−3}，z=5^{k−5}。取对数比较：x=y 在 k≈4.71、x=z 在 k≈7.27、y=z 在 k≈9.30 处互换。随 k 从小到大，可能出现的顺序为 x>y>z（A）、y>x>z（C）、y>z>x（D）、z>y>x；唯独 x>z>y（选项 B）不可能，故选 B。

一通百通

遇到本章任何题，本质都是"先把谁和谁比说清楚，再算这个差（或比值）的符号"：解二次不等式先求根、看开口，套"大于取两边、小于取中间"；求最值先认准"一正二定三相等"——和定就挤积的最大值、积定就挤和的最小值；恒成立先翻译成"参数 ≤ 右边的最小值"或"参数 ≥ 右边的最大值"。会这一套，解二次不等式、用基本不等式求最值、证不等式就是同一把"比较大小"尺子的不同量法。这套"先翻译大小关系、再定符号"的骨架，后面函数值域（02）、导数求单调与最值（05）里还会一再用到。

跨章结合

  • 本章二次不等式 × 第 02 章二次函数：解一元二次不等式根本不是另一套技术，就是把二次函数图像"翻下来"读——抛物线在 x 轴上方对应的 x 区间就是 >0 的解。想通这一点，你不用记"大于取两边、小于取中间"的口诀也能自己画出解集；Δ 的三种情况、开口方向全由图像决定。（综合原理说明，非真题）
  • 本章比较与放缩 × 第 11 章数列：数列里的不等式证明，是"数列递推"和"不等式放缩"两件事碰在一起——先用数学归纳法把通项压出一个下界（如 an≥n+2），再用不等式把每一项放大成等比数列，最后求和。本章 3.5 那道苏州教研题（an+1=an2−nan+1，原书 p.143）正是这个结合的样板。（苏州教研·专题40）

本章与前后章

按全书蓝图，12 章的前置是第 02 章函数——解二次不等式靠二次函数图像"翻下来读解集"，因式分解、一元二次方程更是初中老本；它和第 11 章数列同属"数列+不等式"这一阶段，数列题里的放缩、求和不等式（如本章 3.5 那道 an+1=an2−nan+1 的经典证明）用的正是本章的比较与最值工具。往后，第 05 章导数求单调区间、极值，本质就是解 f′(x)>0；第 16 章圆锥曲线的"取值范围""恒成立"，也都是不等式的活。学完这章，你手里多了一把"比较大小"的通用尺。

高考怎么考

新高考Ⅰ卷里不等式很少单独出大题，主要藏在小题里：基本不等式求最值（"1 的代换"是最高频）、恒成立求参数范围、以及和指对数函数结合的比较大小（如本章 C 组 2025 年卷第 8 题）。二次不等式的解法则更多作为函数、数列、解析几何题的中间步骤出现，不单独成题。位置多在选择题中段，难度中档，3 分钟内拿下——它考的不是背公式，而是"把谁和谁比"一眼看对。
