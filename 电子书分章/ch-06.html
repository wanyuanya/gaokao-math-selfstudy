公式速查：修订版 第3部分（三角函数）

本章本质核心：三角函数本质上就是"圆周运动的坐标投影"——把角的终边放到单位圆上，那个交点绕原点转一圈，它的横坐标就是 cos、纵坐标就是 sin；后面所有东西——象限正负号、同角关系 sin2+cos2=1、周期 2π、图象的波浪、奇偶对称——全是这一个模型的自然推论。不用死背：让那个动点转起来，转一整圈坐标回到原位，一切性质就都跟着出来了。 为什么有用：想通"单位圆上那个点一转、横纵坐标就是 cos、sin"这一件事，你既看得懂现实里所有周而复始的现象（交流电按正弦波动、声波传播、弹簧振动），也能把高考里"给波形求 A/ω/φ、数两条曲线交点个数"这类题一眼看穿——原理想通了，性质表只是想通之后顺带的速查。

3.1 弧度制（新教材默认用弧度）

先想一个生活场景。 你坐摩天轮，座舱从最低点转到最高点，到底转了"多少"？用角度说 180° 也行，可角度这个单位其实是人为定的——古人把一圈分成 360 份，凭什么是 360 而不是 100？没道理。数学家想要一个"天生的"量角办法：干脆用转过的弧长来量。轮子半径是 1 米，座舱在边上走了 1 米长的弧，就说转了 1"弧度"。这样量出来的角，和圆的大小无关——半径 1 的圆走 1 米弧、半径 2 的圆走 2 米弧，都是 1 弧度，因为弧长正好等于半径。

定义（人教A版口径）：长度等于半径长的圆弧所对的圆心角，叫做 1 弧度（rad） 的角。

换算关系（一定要背）：

  • 整圈的弧长是周长 2πr，除以半径 r，得整圈 = 2π 弧度。
  • 而整圈又是 360°。所以 2π rad = 360°，即 π rad = 180°。
  • 由此推出：1 rad = (180/π)° ≈ 57.3°；1° = (π/180) rad。

常用对应表（背到条件反射）：

度 30° 45° 60° 90° 180° 270° 360°
弧度 π/6 π/4 π/3 π/2 π 3π/2 2π

弧长与扇形面积：设圆心角 α（弧度）、半径 r，则

  • 弧长 l = |α|·r（弧度制下这个式子干净；若用角度制还得乘 π/180，麻烦）
  • 扇形面积 S = ½·l·r = ½·|α|·r2

为什么高中非要换弧度制？ 因为以后学导数，(sin x)' = cos x 这个漂亮结论只在 x 用弧度时才成立。用角度的话，求导会冒出一堆 π/180，没法看。所以从这章起，做题默认弧度。

计算流程（角度↔弧度）：

  1. 度化弧度：乘以 π/180。例：120° = 120 × π/180 = 2π/3。
  2. 弧度化度：乘以 180/π。例：5π/6 = 5π/6 × 180/π = 150°。
  3. 算弧长/面积时，先确认角是弧度；是角度就先换算。

例题跟讲例题 3.1-1：把 67°30′ 化成弧度（结果保留 π）。 解：67°30′ = 67.5°。乘以 π/180：67.5 × π/180 = (67.5/180)π = (3/8)π。答案 3π/8。 要点：先把分（′）化成小数度，再乘 π/180，别带着 30′ 硬乘。

例题跟讲例题 3.1-2：扇形半径 r = 6，圆心角 α = 2π/3，求弧长和面积。 解：l = |α|r = (2π/3)×6 = 4π。S = ½|α|r2 = ½×(2π/3)×36 = 12π。 要点：直接套公式，角已是弧度，不用换算。

陷阱：看到"°"别顺手当弧度。题目写 30° 就是角度，写 π/6 就是弧度，两者差远了。

3.2 任意角的三角函数（单位圆定义）

先把"角"这个概念放大。 初中的角只到 0°~360°。可现实里轮子转一圈不够：摩天轮转两圈就是 720°，倒车时方向盘往回转就是负角。于是规定：逆时针旋转成的角为正角，顺时针为负角，没转就是零角。把角的顶点放原点、始边对齐 x 轴正半轴，终边落在第几象限，就叫第几象限角。

定义（人教A版口径）：在直角坐标系中，设角 α 的终边与单位圆（半径为 1 的圆）交于点 P(x, y)，则：

sin α  =  y　　cos α  =  x　　tan α  =  y/x（x ≠ 0）

看这张图：P 点的纵坐标就是 sinα，横坐标就是 cosα。这一下把"角"和"坐标"死死绑在一起——以后 sin、cos 你就当成"单位圆上那个点的 y、x"。

为什么是单位圆？ 半径取 1，r = 1，sin = y/r = y，cos = x/r = x，公式最干净。若半径是 r，终边上任一点 (x,y)，则 sinα = y/r，cosα = x/r，tanα = y/x（r = √(x2+y2)）。

符号判断（象限口诀："一全正，二正弦，三正切，四余弦"）：

  • 第一象限（x>0, y>0）：sin、cos、tan 全正；
  • 第二象限（x<0, y>0）：只有 sin（即 y）正；
  • 第三象限（x<0, y<0）：只有 tan（y/x，负负得正）正；
  • 第四象限（x>0, y<0）：只有 cos（即 x）正。

例题跟讲例题 3.2-1：角 α 终边经过点 P(−3, 4)，求 sinα、cosα、tanα。 解：r = √((−3)2+42) = 5。sinα = y/r = 4/5；cosα = x/r = −3/5；tanα = y/x = 4/(−3) = −4/3。 要点：先算 r，再套 sin=y/r、cos=x/r；P 在第二象限，sin 正、cos 负，和口诀一致。

例题跟讲例题 3.2-2：判断 sin 200° 的符号。 解：200° = 180°+20°，终边在第三象限，"三正切"，sin 在第三象限为负。故 sin 200° < 0。 要点：先定象限，再背口诀，别去算具体值。

陷阱：tan 在终边落在 y 轴上（x=0，即 α = π/2 + kπ）时无意义，这是 tan 定义域的根源。

编者注·本质回扣：这一节是整章的"纲"。前面反复说"sin 是纵坐标、cos 是横坐标"，听着像一句口诀，其实它就是本章本质核心的落地：单位圆上那个点 P 一转，横纵坐标怎么变，sin、cos 就怎么变。所谓象限符号"一全正、二正弦、三正切、四余弦"，说白了就是看 P 落在哪个象限时 x、y 谁正谁负；tan=y/x 在 x=0 处没意义，也只是因为 P 爬到了 y 轴上、横坐标变成了 0。把 P 这个动点想活了，符号、定义域这些结论根本不用背。

3.3 同角关系（必背）

单位圆上 P(x,y) 在半径为 1 的圆上，自然满足 x2 + y2 = 1。把 x 换回 cosα、y 换回 sinα，就得到：

  • sin2α + cos2α = 1（平方关系，对任意角成立）
  • tan α = sin α / cos α（商数关系，要求 cos α ≠ 0）

这两条为什么对？ 第一条就是单位圆方程本身；第二条是 tan 的定义 y/x = (y/r)/(x/r) = sin/cos。

用它们干嘛？ 已知 sinα 和 α 所在象限，就能反推 cosα，进而 tanα——这是"给值求值"的根。

计算流程：

  1. 由 sin2α + cos2α = 1 求出 cos2α；
  2. 开方前先看象限，决定 cosα 取正还是负；
  3. tanα = sinα/cosα 相除。

例题跟讲例题 3.3-1：已知 cosα = −4/5，且 α 是第三象限角，求 sinα 与 tanα。 解：sin2α = 1 − cos2α = 1 − 16/25 = 9/25。第三象限 sin 为负，故 sinα = −3/5。tanα = (−3/5)/(−4/5) = 3/4。 要点：开方这一步的正负号，完全由象限决定，这是本节唯一的坑。

陷阱：cos2α = 16/25 开方得 cosα = ±4/5，别默认写正号——象限说了算。

3.4 诱导公式（口诀："奇变偶不变，符号看象限"）

干嘛用？ 把任意大的、负的、钝角的三角函数，化成 0°~90° 的锐角三角函数，好查表好心算。

核心逻辑：终边相同的角三角函数值相同；再利用对称把负角、补角、余角一步步搬回来。常用的几组（把 α 先当成锐角来记符号）：

  • 负角：sin(−α) = −sinα，cos(−α) = cosα，tan(−α) = −tanα
  • 补角：sin(π−α) = sinα，cos(π−α) = −cosα
  • 平角：sin(π+α) = −sinα，cos(π+α) = −cosα
  • 互余：sin(π/2−α) = cosα，cos(π/2−α) = sinα

口诀怎么用："奇变偶不变"看的是 π/2 的倍数是奇数还是偶数倍——偶数倍（如 π、2π）函数名不变，奇数倍（如 π/2、3π/2）函数名变（sin↔cos）。"符号看象限"：把 α 当锐角，看原式那个角在第几象限、原函数取正还是负，符号就带过去。

例题跟讲例题 3.4-1：求 sin(7π/6)。 解：7π/6 = π + π/6，用 sin(π+α) = −sinα：sin(7π/6) = −sin(π/6) = −1/2。 要点：先把大角拆成"π + 锐角"或"π/2 + 锐角"，再套对应公式。

例题跟讲例题 3.4-2：化简 cos(π/2 + α)。 解：π/2 是 π/2 的 1 倍（奇数），函数名变：cos → sin；把 α 当锐角，π/2+α 在第二象限，cos 在第二象限为负。故 cos(π/2+α) = −sinα。 要点："变名"+"看象限定号"，两步缺一不可。

陷阱：符号看的是变换前那个角在象限里的原函数符号，不是变换后的。

3.5 三个基本三角函数的图象与性质（必背表）

先看图，再背表，脑子里要有"波形"。

正弦像水波一样上下抖，余弦只是把正弦左移了 π/2。它们都周而复始——这正是三角函数天生用来描述周期现象的原因（潮汐、季节、交流电）。

正切不一样：它在 x = π/2 + kπ 处"断"掉，冲向无穷，周期也短，只有 π。

把三条函数的性质并排放（这张表整章最重要，背熟）：

性质 y = sin x y = cos x y = tan x
定义域 R R x ≠ π/2 + kπ
值域 [−1, 1] [−1, 1] R
周期 2π 2π π
奇偶 奇 偶 奇
递增区间 (−π/2+2kπ, π/2+2kπ) (−π+2kπ, 2kπ) (−π/2+kπ, π/2+kπ)
对称轴 x = π/2 + kπ x = kπ 无
对称中心 (kπ, 0) (π/2+kπ, 0) (kπ/2, 0)

这些性质怎么来的？

  • 值域 [−1,1]：单位圆上点的坐标本来就在 −1 到 1 之间。
  • 周期 2π：角转一整圈 2π，终边回到原位，函数值当然重复。
  • sin 奇、cos 偶：sin(−x)=−sinx、cos(−x)=cosx，就是诱导公式里那两条负角公式。
  • tan 周期 π 而非 2π：因为转 π 后 (x,y)→(−x,−y)，y/x 不变，所以半圈就重复。

"五点法"画正弦曲线：一个周期内取五个关键点 (0,0)、(π/2,1)、(π,0)、(3π/2,−1)、(2π,0)，描出来连成波浪，就是草图。以后画 y=Asin(ωx+φ) 也靠这五点。

例题跟讲例题 3.5-1：求 y = sin x 的对称轴和对称中心。 解：最大值点、最小值点在轴上 → 对称轴 x = π/2 + kπ；曲线与 x 轴交点为对称中心 → (kπ, 0)。 要点：正弦"峰谷连线是轴，零点是中心"。

陷阱：tan x 没有对称轴，但有对称中心 (kπ/2, 0)，别漏。

编者注·本质回扣：这一节那张"性质对照表"看着要背十几行，其实条条都能从单位圆那个动点 P 推出来。值域 [−1,1] 不过是 P 的坐标本来就夹在 −1 到 1 之间；周期 2π 不过是 P 转一整圈回到原位、坐标原样重复；sin 奇 cos 偶，就是 P 转到 −α 时 y 变号、x 不变；tan 周期只有 π，是因为转半圈后 (x,y) 变成 (−x,−y)，比值 y/x 不变。所以这张表不是靠背，是脑子里放一个轮子在转，转到哪就知道坐标落在哪。

3.6 y = A sin(ωx + φ)（A > 0, ω > 0）

实际的波动很少是"标准"正弦。交流电电压、声波振幅、弹簧振子，都可能被放大、被压扁、被平移。一般式 y = A sin(ωx + φ) 就是干这个的。

三个参数各管一件事：

  • 振幅 A：管上下拉伸，最大值 A、最小值 −A。
  • ω（欧米伽）：管横向压缩，周期 T = 2π/ω。ω 越大，波形挤得越密。
  • φ（读作 fài）初相：管左右平移。φ>0 向左移，φ<0 向右移。

图象变换顺序（从 y=sin x 出发）：

  1. 左右平移 φ 个单位（得 y=sin(x+φ)）；
  2. 横向伸缩 1/ω 倍（得 y=sin(ωx+φ)）；
  3. 纵向伸缩 A 倍（得 y=A sin(ωx+φ)）；
  4. 如有 b，再上下平移 b。

由图象反求解析式（高考常考）：

  1. A = (最大值 − 最小值)/2；
  2. 读出周期 T（相邻两个零点或两个峰的距离），则 ω = 2π/T；
  3. φ 用"五点法"：把某个关键点的坐标代入 y = A sin(ωx+φ) 反解。

例题跟讲例题 3.6-1：简谐运动的位移 y = 3 sin(2x + π/4)，求振幅、周期、初相。 解：A = 3；T = 2π/ω = 2π/2 = π；初相 φ = π/4。 要点：对着标准式 y=A sin(ωx+φ) 对号入座即可。

例题跟讲例题 3.6-2：某曲线振幅为 2，周期为 π，过点 (0, 1)，求 y = A sin(ωx+φ) 的一个解析式。 解：A=2；ω = 2π/T = 2。代入 (0,1)：2 sin(φ) = 1 → sinφ = 1/2，取 φ = π/6。故 y = 2 sin(2x + π/6)。 要点：φ 的解不唯一（π/6 或 5π/6），结合图象趋势取一个即可。

陷阱：T = 2π/ω，别把 ω 和 T 搞反——y=sin 2x 的周期是 π，不是 2π。

小结：这一章把"角"从初中的直角三角形推广到了单位圆，又从单位圆长出了一整套周期函数。记住三件事：sin 是纵坐标、cos 是横坐标、一切大角都靠诱导公式化回锐角。

④ 例题详解（先做再看）

例题例 1（同角关系）：已知 sin α = 3/5，且 α 在第二象限，求 cos α 与 tan α。

自己做：用平方关系 + 象限定符号。

解：cos2α = 1 − sin2α = 1 − 9/25 = 16/25。α 在第二象限 ⇒ cos α < 0，故 cos α = −4/5。tan α = sin α/cos α = −3/4。 要点：开方前必须先定象限符号，正负号是本题唯一的坑。

例题例 2（诱导公式化简）：化简 sin(π + α) · cos(π/2 − α)。

自己做：分别用诱导公式。

解：sin(π + α) = −sin α；cos(π/2 − α) = sin α。原式 = −sin2α。 要点：逐项化简，别合并符号。

例题例 3（由图象求解析式）：某简谐运动图象周期为 π，振幅为 2，初相为 π/6，写出 y = A sin(ωx + φ) 的解析式。

自己做：A、ω、φ 逐个定。

解：A = 2；T = π ⇒ ω = 2π/T = 2；φ = π/6。故 y = 2 sin(2x + π/6)。 要点：ω 由周期反推，别把 ω 和 T 搞混。

例题例 4（换元求值域 + 恒成立，苏州教研·专题27，原书p.117）：已知函数 f(x) = 4 sin(2x + π/6) + 1。 (1) 当 x∈[−π/6, π/3] 时，求 f(x) 的值域； (2) 若不等式 −10 ≤ m − f(x) ≤ 10 对一切 x∈[−π/6, π/3] 都成立，求实数 m 的取值范围。

自己做：把括号里的 2x+π/6 当成一个整体 t。

解：(1) x∈[−π/6, π/3] ⇒ t = 2x+π/6 ∈ [−π/6, 5π/6]。t 在这个区间上 sin t 的最小值在 t=−π/6 处取 −1/2，最大值在 t=π/2 处取 1，故 sin t ∈ [−1/2, 1]。 f(x) = 4 sin t + 1 ∈ [4×(−1/2)+1, 4×1+1] = [−1, 5]。 (2) −10 ≤ m−f(x) ≤ 10 等价于 f(x)−10 ≤ m ≤ f(x)+10。它要对所有 x 成立，m 就得不超过右边的最小值、不低于左边的最大值： m ≤ min(f(x)+10) = −1+10 = 9；m ≥ max(f(x)−10) = 5−10 = −5。 故 m∈[−5, 9]。 要点：求 y=A sin(ωx+φ) 在区间上的值域，先把 ωx+φ 整体换元成 t，再看 sin t 在 t 的区间上的最大/最小；恒成立问题最后归到"m 夹在值域两端"。

⑥ 常见坑清单

  • 象限定符号：平方关系开方后正负号由象限决定，不是默认正。
  • 诱导公式"符号看象限"：把 α 当锐角，看原角所在象限原函数的符号。
  • tan x 定义域 x ≠ π/2 + kπ：求定义域别忘。
  • 周期 T = 2π/ω：y = sin 2x 周期是 π 不是 2π。
  • 弧度值要带"rad"感：高中做题默认弧度，角度要换算。

本章公式速查表

与《高中数学常用公式·修订版》第三部分核对一致。

弧度制：用弧长量角

π rad  =  180°；1°  =  π/180 rad；1 rad  =  (180/π)°  ≈  57.3°

  • 大白话半圈就是 π 弧度，角度和弧度是量同一个角的两把尺子。
  • 用的时候：度化弧度乘 π/180，弧度化度乘 180/π；从这章起做题默认弧度。
  • 记忆要点：整圈 2π = 360°，其余都从这一句推。

弧长 l = |α|·r；扇形面积 S = ½·l·r = ½·|α|·r2（α 必须用弧度）

  • 大白话弧度制下弧长就是"圆心角乘半径"，扇形面积是弧长乘半径再折半。
  • 用的时候：题目给角度就先换成弧度；看到扇形直接套，别再绕"底乘高"。

三角函数的定义（单位圆）

单位圆上交点 P(x,y)：sinα  =  y，cosα  =  x，tanα  =  y/x

  • 大白话sin 就是那个点的纵坐标，cos 就是横坐标。
  • 用的时候：别死守初中"对边比斜边"，直接把 sin、cos 想成单位圆上点的 y、x。

终边上一般点 P(x,y)、r = √(x2+y2)：sinα = y/r，cosα = x/r，tanα = y/x

  • 大白话圆半径不是 1 也不怕，先把 r 算出来再比。
  • 用的时候：给终边上一点求三角值，第一步永远是先算 r。

符号口诀：一全正，二正弦，三正切，四余弦

  • 大白话按象限记谁正谁负——第一象限全正，第二象限只有 sin 正，第三象限只有 tan 正，第四象限只有 cos 正。
  • 用的时候：判断正负不用算具体值，先定象限再套口诀。

同角基本关系

sin2α + cos2α = 1

  • 大白话同一个角的 sin、cos 平方和永远等于 1，不管角多大。
  • 用的时候：已知 sin 求 cos 时用它；注意开方取正负要看角所在象限。
  • 记忆要点：画单位圆，斜边是 1，勾股定理就是它。

tanα = sinα / cosα（要求 cosα ≠ 0）

  • 大白话tan 就是 sin 除以 cos。
  • 用的时候：角落在 y 轴上（cos=0）时 tan 没意义，这是 tan 定义域的根。

诱导公式（大角化锐角）

口诀：奇变偶不变，符号看象限

  • 大白话加减的是 π/2 的几倍？奇数倍函数名 sin↔cos 互换，偶数倍名字不变；再把 α 当锐角，看原来那个角在第几象限、原函数取正还是负，符号就照带过去。
  • 用的时候：负角、补角、平角、互余全靠它化回锐角；符号看的是变换前那个角，不是变换后。

常用四组（大角化锐角的成品公式）

负角：sin(−α)  =  −sinα，cos(−α)  =  cosα，tan(−α)  =  −tanα

补角 π−α：sin(π−α)  =  sinα，cos(π−α)  =  −cosα

平角 π+α：sin(π+α)  =  −sinα，cos(π+α)  =  −cosα

互余 π/2−α：sin(π/2−α)  =  cosα，cos(π/2−α)  =  sinα

  • 大白话上面口诀在负角、补角、平角、互余四种情形下的成品，直接套用。

三条基本函数的性质

周期：y = sin x、y = cos x 周期 2π；y = tan x 周期 π

  • 大白话正弦余弦转一整圈才重复，正切转半圈就重复。
  • 用的时候：tan 周期别误写成 2π。

值域与奇偶：sin、cos ∈ [−1,1]，tan ∈ R；sin、tan 是奇函数，cos 是偶函数

  • 大白话sin、cos 被夹在 −1 到 1 之间；sin 关于原点对称，cos 关于 y 轴对称。
  • 用的时候：求最值先看值域；判奇偶就看 sin(−x)=−sinx、cos(−x)=cosx。

对称轴与中心：sin x 轴 x = π/2+kπ、中心 (kπ,0)；cos x 轴 x = kπ、中心 (π/2+kπ,0)；tan x 无对称轴、中心 (kπ/2,0)

  • 大白话正弦"峰谷连线是轴、零点是中心"；余弦正好错开 π/2；正切没有轴但有中心。
  • 用的时候：tan 别漏了对称中心 (kπ/2,0)。

y = A sin(ωx + φ) 的读法

振幅 A、周期 T  =  2π/|ω|、初相 φ；最大值 A、最小值 −A

  • 大白话A 管波形上下拉多高，ω 管波形挤多密，φ 管波形左右挪多少。
  • 用的时候：ω 越大周期越小；T=2π/ω，别把 ω 和 T 搞反（y=sin2x 周期是 π）。

对称轴令 ωx+φ  =  π/2+kπ；对称中心令 ωx+φ  =  kπ；y = A tan(ωx+φ) 周期 T  =  π/|ω|

  • 大白话把括号里那串整体当作标准正弦的角，套进 sin 的轴/中心公式再反解 x。
  • 用的时候：正切型周期是 π/|ω|，别套成 2π/|ω|。

周期与对称的进阶结论（苏州教研·专题27）

加绝对值后周期减半/不减半：y = |sin(ωx+φ)|、|cos(ωx+φ)|、|tan(ωx+φ)| 的周期 T  =  π/ω；y = |A sin(ωx+φ)+B|、|A cos(ωx+φ)+B|（B≠0）的周期 T  =  2π/ω（不减半）

  • 大白话光给 sin、cos 套一层绝对值会把负半周"翻上去"，波形挤成原来一半密（周期减半）；但如果底下还垫了常数 B（整体平移过），翻上去后破坏了对称，周期又恢复成 2π/ω。
  • 用的时候：见 |sin(ωx+φ)| 直接写 T=π/ω；见 |A sin(ωx+φ)+B|（B 不为 0）别减半。
  • 记忆要点：纯绝对值包函数本身减半，包"函数+竖直平移"不减半。

对称轴过最值点：x = m 是 f(x) = A sin(ωx+φ) 的对称轴 ⇔ f(m) = ±A；点 (m,0) 是对称中心 ⇔ f(m) = 0

  • 大白话正弦曲线的对称轴一定穿过峰或谷（函数取到 ±A 的地方），对称中心一定落在平衡位置（函数取 0 的地方）。
  • 用的时候：判断直线 x=m 是不是对称轴、点 (m,0) 是不是中心，只需代入看它取不取到 ±A / 0，不用画图。

确定性奇偶性的条件：y = A sin(ωx+φ)、A cos(ωx+φ)、A tan(ωx+φ) 有确定奇偶性 ⇔ φ  =  k·π/2（k∈Z）

  • 大白话当初相 φ 是 π/2 的整数倍时，这个函数才"天生"是奇函数或偶函数；否则既非奇也非偶。
  • 用的时候：题目问"f(x) 是奇函数/偶函数求 φ"，答案就是 φ=kπ（sin 型奇、cos 型偶）或 φ=kπ+π/2 这一类，圈在 φ=k·π/2 上。

由一段最值反求 A、B：y = A sin(ωx+φ)+B（A>0）的值域为 [−A+B, A+B]，故 A = (ymax−ymin)/2，B = (ymax+ymin)/2

  • 大白话有上下平移 B 时，最大值与最小值不再关于 0 对称，中线就是 B，振幅是上下两半差的一半。
  • 用的时候：给一段图象读出最大、最小值，直接套这两条反解 A 和 B。

三角方程：sin α  =  sin β ⇒ α  =  β + 2kπ 或 α + β  =  π + 2kπ（k∈Z）

  • 大白话两个正弦值相等，要么两个角终边相同，要么它们关于 π/2 对称（和为 π 的奇数倍）。
  • 用的时候：解 sin 方程别只写 α=β，漏掉"和为 π"那组解就扣分。

三角不等式与勾股数速算（苏州教研·专题26）

x∈(0, π/2) 时：sin x < x < tan x

  • 大白话在锐角范围内，正弦比弧度 x 小，正切比 x 大，x 夹在中间。
  • 用的时候：比较 sin、x、tan 三者大小，或给"sin x<x"这类不等式提供直觉。

x∈(0, π/2) 时：1 < sin x + cos x ≤ √2

  • 大白话锐角正弦加余弦，最小趋近 1（不取到），最大是 √2（在 x=π/4 取到）。
  • 用的时候：判断 sin x+cos x 的范围，或辅助角 sin x+cos x=√2 sin(x+π/4) 的最值。

勾股数速记（秒出三角函数值）：(3,4,5)、(5,12,13)、(8,15,17)、(7,24,25)

  • 大白话背熟这四组勾股数，遇到直角三角形边长能立刻写出 sin、cos、tan。
  • 用的时候：给了两条边长求三角值，先看是不是这几组勾股数，是的话直接读比值，但别忘了先按象限定符号。

一通百通

遇到三角函数的概念题、图象性质题、由图求解析式题，通用骨架只有三步：① 脑子里先放一个单位圆、一个动点 P(x,y)；② 把题目问的东西翻译成 P 的坐标（sin=y、cos=x、tan=y/x）或它转了多少角度；③ 让 P 转起来看坐标怎么重复，周期、最值、对称、单调就全读出来了。会这一道"单位圆投影"题，后面同角求值、诱导化简、画波形、求 A/ω/φ 这一整类题都会——这套"先建单位圆、再读坐标"的骨架，第 07 章做恒等变换、第 08 章解三角形时还会反复用到。

跨章结合

  • 06 的"单位圆坐标投影" + 第 02 章函数的"换元求值域 / 恒成立"：把 ωx+φ 整体换元成 t，再看 sin t 在 t 的区间上取到最大、最小，就解决了"已知 f(x)=4sin(2x+π/6)+1 在某区间上的值域、反推恒成立参数 m 的范围"这类题（苏州教研·专题27，即本章例 4，答案 m∈[−5,9]）。这是"三角函数"撞上"函数值域与恒成立"的典型结合点。
  • 06 的"画波形看交点" + 区间讨论：两条三角函数曲线在给定区间交几次，靠画图看正负号变号、不用硬列三角方程——这正是 2024 新高考Ⅰ卷第 7 题（y=sin x 与 y=2sin(3x−π/6) 在 [0,2π] 内交点 6 个，答案 C）；而 2025 新高考Ⅰ卷第 4 题（y=2tan(x−π/3) 的对称中心，答案 B），本质也是把 tan 的对称中心知识套到平移后的曲线上。
  • 06 的 y=A sin(ωx+φ) + 第 02 章函数图象变换（综合原理说明，非真题）：正弦型曲线的"左右平移 φ、横向压缩 1/ω、纵向拉伸 A"，就是第 02 章学过的函数图象"平移 + 伸缩"那套动作，原样搬到正弦波上——想通 02 章的图象变换，这里三个参数各管一段就不用死记。
  • 06 由图反求 ω、φ + 第 15 章直线与圆（综合原理说明，非真题）：用对称轴 x=m、对称中心 (m,0) 反解 ω、φ 时，本质是"令 ωx+φ=kπ/2，解出 x 落在某条竖直直线上"——这一步"把几何对称条件翻成关于 x 的方程"，和第 15 章处理直线方程、用条件定参数是同一种动作。

本章与前后章

本章上接第 02 章函数（定义域、值域、奇偶性那套语言），把"函数"第一次用到"周期现象"上；再往前是初中直角三角形里的锐角三角比，本章把它推广到了任意角、推广到单位圆。本章是三角函数板块的地基：第 07 章的和差角、倍角、辅助角公式，全都建立在本章的单位圆定义和同角关系 sin2+cos2=1 之上；第 08 章解三角形里的正弦、余弦定理，又是把这些三角函数用到三角形的边角上去。学完本章，你手里有了一个能描述一切周而复始现象（潮汐、交流电、声波）的数学模型。

高考怎么考

新高考Ⅰ卷里三角函数概念与性质通常出 1~2 道小题，位置在选择题中段（第 4~8 题一带），考法集中在：由图象/对称中心求参数（如 2025 新高考Ⅰ卷第 4 题，y=2tan(x−π/3) 的对称中心，答案 B，a 的最小值 π/3）、两条三角函数曲线在给定区间内的交点个数（如 2024 新高考Ⅰ卷第 7 题，靠画图数变号、交点 6 次）、同角关系与诱导公式化简。难度中等、套路固定——核心还是"脑子里有没有那个转着的单位圆"，会画波形、会读 A/ω/φ，这些题就是送分。
