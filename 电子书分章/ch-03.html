公式速查：修订版 第2部分（指数/对数）

本章本质核心：指数、对数、幂函数其实是同一个"增长/收缩"原理的三副面孔——指数函数是"底数固定、指数在变"，对数是它的逆操作（把乘法变回加法），幂函数是"底数在变、指数固定"；而这三副面孔的脾气（增还是减、过哪个定点、值落哪一档）几乎全由"底数 a>1 还是 0<a<1"这一件事决定。本章所有题型（指数对数运算、求过定点、比较大小）都是这一条原理的变体。

为什么有用学会指对幂，你就有了三件能"估"的具体武器——凡是题目拿三个数比大小、问曲线和直线谁追谁、求含参函数过哪个定点，靠的都是想通"底数决定方向、0 和 1 是天然分界"，而不是把数硬算出来。原理一通，运算和比大小就只是顺手。

3.1 指数运算

先问一个问题：2 的多少次方等于 8？ 你脱口而出 3，因为 23=8。再问 2 的多少次方等于 1/8？是 −3，因为 2−3=1/8。指数就是"几个几相乘"的 shorthand。这一章要把指数从整数推广到分数、实数。

整数指数幂的运算律（a>0，m、n 为整数，先背熟）：

  • am · an = am+n（同底相乘，指数相加）
  • am ÷ an = am−n
  • (am)n = amn
  • (ab)n = anbn

分数指数幂（把根号写成分数指数，方便运算）：

  • a^(m/n) = n√(am)（a>0，m、n 为正整数）
  • a^(−m/n) = 1 / a^(m/n)（负指数=倒数）
  • 例：4^(3/2) = (√4)3 = 23 = 8；27^(1/3) = 3。

【跟讲例题 3.1-1】 计算 8^(2/3) × (1/2)−1。 解：8^(2/3) = (n√8)2 = 22 = 4；(1/2)−1 = 2。原式 = 4×2 = 8。

【跟讲例题 3.1-2（苏州教研·专题9，原书p.40）】 已知 a^(1/2) + a^(−1/2) = 3，求 a + a−1、a2 + a−2、a − a−1 的值。 解：用"平方法"——见到 √a + 1/√a 这种成对的式子，先平方。 - (a^(1/2) + a^(−1/2))2 = a + 2·a^(1/2)·a^(−1/2) + a−1 = a + a−1 + 2 = 9，故 a + a−1 = 7； - (a + a−1)2 = a2 + 2 + a−2 = 49，故 a2 + a−2 = 47； - (a − a−1)2 = a2 − 2 + a−2 = 47 − 2 = 45，故 a − a−1 = ±3√5。 要点：√a ± 1/√a、a ± a−1、a2 ± a−2 这一串互为"平方升级"关系，平方法一层层往上打，不用各自硬算。

易错点：4√(x2) 不一定等于 √x——先看 x 的正负。4√(x2)=|x|^(1/2)，别直接脱根号丢了绝对值。

小结：指数律"同底相乘指数加"；分数指数幂就是根号的另一种写法。

3.2 指数函数 y = ax（a>0 且 a≠1）

为什么规定 a>0 且 a≠1？ a≤0 时 x=1/2 就没法算（负数开根号）；a=1 时 y=1x=1 是常数函数，没看头。所以底数限定 a>0 且 a≠1。

定义：形如 y = ax（a>0 且 a≠1） 的函数叫指数函数。

性质对照表：

性质 a>1（如 y=2x） 0<a<1（如 y=(1/2)x）
定义域 R R
值域 (0, +∞) (0, +∞)
定点 恒过 (0, 1) 恒过 (0, 1)
单调性 递增 递减
图象 左低右高 左高右低

关键点：ax 永远是正的（图象在 x 轴上方），恒过 (0,1)。a>1 时底数越大，第一象限越陡。

一个直觉：一张纸对折 30 次，厚度会超过珠穆朗玛峰——这就是指数增长"爆炸式"的可怕。y=2x 一开始慢，后来陡得竖起来；这和第 04 章要讲的"指数模型"直接相关。

【跟讲例题 3.2-1】 f(x)=ax+1 − 2 恒过哪个定点？ 解：让指数部分 a 的指数取 0（因为 a0=1，与 a 无关）。令 x+1=0，x=−1，f(−1)=a0−2=1−2=−1。恒过 (−1, −1)。

【跟讲例题 3.2-2】 比较 2^0.3 与 2^0.5 的大小。 解：底 2>1，指数函数递增。0.3<0.5，故 2^0.3 < 2^0.5。同底就看单调性，不用算具体值。

小结：指数函数恒正、恒过 (0,1)；a>1 增、0<a<1 减；定点题"让指数为 0"。

编者注·本质回扣：为什么一张表里 a>1 增、0<a<1 减，全看底数？说白了，指数函数就是"底数自己乘自己若干次"：底数比 1 大，乘的次数越多结果越往上爬（递增）；底数是 0 到 1 之间的小数，乘的次数越多结果越往 0 缩（递减）。恒过 (0,1) 也不是巧合——任何数的 0 次方都是 1，这就是"指数为 0 时与底数无关"。所以整章的单调性判断，本质就是在问一句：底数比 1 大还是小？定点题让指数等于 0，也是借 a0=1 这个与底数无关的点把参数"藏"起来。

【方法补丁·指数函数家族里的奇偶函数】（苏州教研·专题9，原书p.39） 高考常拿指数函数拼出奇偶函数，记住这四个"脸熟"的：

  • 奇函数：f(x) = (ax − a−x)/2；f(x) = (ax − 1)/(ax + 1)（第二个可变形为 1 − 2/(ax+1)，单调性一眼看穿）。
  • 偶函数：f(x) = a^|x|（图象是 y=ax 保留 y 轴右侧、左侧镜像翻折）；f(x) = (ax + a−x)/2。

【方法补丁·含参指数函数过定点】（苏州教研·专题12，原书p.48） 题里带个参数 a（a>0 且 a≠1），问"不管 a 怎么变都过哪个定点"——关键是让含 a 的那一项化为 a0=1：

  • y = a^(x−1) + 3：令 x−1 = 0 ⇒ x=1，y = 1+3 = 4，过定点 (1, 4)；
  • y = a(x−3) + 5（a 为一次项系数）：令 x−3 = 0 ⇒ x=3，过定点 (3, 5)（用的是 a·0=0）。

大白话参数想"隐身"，就让它乘的那个东西等于 0，或让它的指数等于 0，剩下的 y 就定了。

3.3 对数

先讲对数是干嘛的。 指数问题问"2 的几次方是 8"，答案 3。换个角度问："以 2 为底 8 的对数是多少？"答案还是 3。对数就是把这种问题反过来问。

定义：如果 ab = N（a>0，a≠1），那么 b 叫做以 a 为底 N 的对数，记作 b = logaN。a 叫底数，N 叫真数。因为 ab=N>0，所以真数 N 必须 >0，负数和 0 没有对数。

两个必背恒等式：

  • loga1 = 0（a0=1）；logaa = 1（a1=a）。
  • a^(logaN) = N（底数不动，指数和对数互相抵消）。

对数运算律（M、N>0）：

  • loga(MN) = logaM + logaN（积的对数=对数的和）
  • loga(M/N) = logaM − logaN
  • logaMn = n·logaM
  • 换底公式：logab = (log꜀b)/(log꜀a)（换成常用对数 lg 或自然对数 ln 算）

换底公式三个好用的推论（苏州教研·专题10，原书p.42）：

  • log_{an} bm = (m/n)·logab（底数、真数同时开 n 次方 / 提 m 次方，提前变成系数 m/n）；
  • log_{an} bn = logab（底数真数同次幂，约掉）；
  • logab = 1/(log_b a)（底数真数颠倒，对数取倒数，如 log23 = 1/log32）。

常用记号：lg N = log10N；ln N = logeN（e≈2.718）。

读一段历史：16、17 世纪，天文和航海要算很大的数相乘，天文学家累死累活。1614 年纳皮尔发明对数，把"乘法"变成"加法"——两个大数相乘，查对数表变成相加，再查回去。拉普拉斯说对数"等于把天文学家的寿命延长了许多倍"。你现在学的 loga(MN)=logaM+logaN，就是这把"省力钥匙"。

【跟讲例题 3.3-1】 计算 log28 + lg 0.01。 解：log28 是"2 的几次方是 8"，=3。lg 0.01 是"10 的几次方是 0.01=10−2"，=−2。原式 = 3+(−2) = 1。

【跟讲例题 3.3-2】 用换底公式算 log23·log34·log48。 解：全换成以 2 为底：log34 = log24/log23，log48 = log28/log24。乘起来 = log23 · (log24/log23) · (log28/log24) = log28 = 3。中间全约掉了，这就是换底的好处。

易错点：loga(M+N) ≠ logaM + logaN！对数只对"乘除"拆成"加减"，不对"加法"拆。

两个苏州书特别强调的细节（苏州教研·专题10，原书p.42）：

  • logax2 = 2loga|x|，不是 2logax！真数是 x2 时 x 可以取负值，提出来的 2 必须配绝对值；只有事先限定 x>0 时才等于 2logax。
  • lg2 + lg5 = 1（因为 lg2 + lg5 = lg10 = 1）。化简常用对数式时，这一对经常一起冒出来，先凑出 lg2+lg5 往往能消项。

小结：对数是指数的逆运算；真数>0；积化和、商化差、幂提前；换底靠 lg 或 ln。

编者注·本质回扣：对数那几条运算律（积化和、商化差、幂提前）看着像新规矩，其实就是指数律倒过来写。指数里"同底相乘指数相加"，把这句话翻译成对数语言，就是 loga(MN)=logaM+logaN——乘法自动降成加法。纳皮尔发明对数的全部动机就在这：让天文学家把大数连乘查表变成连加。所以你不用把运算律当口诀硬背，只要记住"对数是指数的逆"，看到乘除就能自动想到加减；真数必须 >0，也只是因为 ab=N 永远是正数这一条的必然推论。

3.4 对数函数 y = logax（a>0 且 a≠1）

定义：形如 y = logax（a>0 且 a≠1） 的函数。它和指数函数 y=ax 互为反函数（图象关于直线 y=x 对称）。

性质对照表：

性质 a>1 0<a<1
定义域 (0, +∞) (0, +∞)
值域 R R
定点 恒过 (1, 0) 恒过 (1, 0)
单调性 递增 递减

陷阱：loga(x2) 的定义域是 x≠0；而 2logax 的定义域是 x>0。两者不是同一个函数（定义域不同）。

反函数关系：指数函数 y=ax 和对数函数 y=logax 互为反函数，它们的图象关于直线 y=x 对称。你把 y=2x 的图象沿对角线 y=x 翻折，就得到 y=log2x。这解释了为什么一个恒过 (0,1)、另一个恒过 (1,0)——点 (0,1) 翻折过去就是 (1,0)。

【跟讲例题 3.4-1】 求 y = log2(x−1) 的定义域。 解：真数 x−1 > 0 ⇒ x>1，即 (1, +∞)。

小结：对数函数定义域是"真数>0"；恒过 (1,0)；a>1 增。

【方法补丁·对数函数家族里的奇偶函数】（苏州教研·专题10，原书p.42）

  • 奇函数：f(x) = loga(√(x2+1) + x)（里面 √(x2+1)+x 与 √(x2+1)−x 互为倒数，一中和就出 f(−x)=−f(x)）；f(x) = loga[(1−x)/(1+x)]。
  • 偶函数：f(x) = loga|x|（注意它和 y = |logax| 图象不一样：前者把 y 轴左侧也补出来，后者只翻折右侧）。

【方法补丁·含参对数函数过定点】（苏州教研·专题12，原书p.48） 同理，让真数等于 1（因为 loga1 = 0）：

  • y = loga(x−2) + 4：令 x−2 = 1 ⇒ x=3，y = 0+4 = 4，过定点 (3, 4)。

3.5 幂函数 y = xα

定义：形如 y = xα（α 是常数）的函数叫幂函数。注意它和指数函数的区别：幂函数是"底数在变、指数固定"，指数函数是"底数固定、指数在变"。

高考常考五种（α = −1, 1/2, 1, 2, 3）：

  • y = x−1 = 1/x：过 (1,1)，(0,+∞) 递减。
  • y = x^(1/2) = √x：定义域 [0,+∞)，递增，过 (0,0)、(1,1)。
  • y = x：过原点直线。
  • y = x2：过原点，偶函数。
  • y = x3：过原点，奇函数，R 上递增。

共性：所有幂函数都过点 (1, 1)（因为 1α=1）。

单调性规律（苏州教研·专题11，原书p.43）：在第一象限 (0, +∞) 内——

  • 当 α > 0 时，y = xα 是增函数（图象从左下往右上，过 (0,0) 和 (1,1)）；
  • 当 α < 0 时，y = xα 是减函数（图象以 x 轴、y 轴为渐近线，过 (1,1)）。

注意注意：上面只说了第一象限；第二、三象限有没有图象，要看定义域和奇偶性（如 y=x2、y=x3 是偶函数/奇函数，会延伸到 y 轴左侧）。

小结：幂函数底数变、指数固定；都过 (1,1)；α>0 在第一象限增、α<0 减。

3.6 比较大小四法（小题高频）

高考常给三个数（指数型、对数型、幂型）排大小。四招：

  1. 中间量法：先把数往 0、1 上靠。正数>0>负数；大于 1 的数>0到1之间的数>负数。
  2. 同底比单调：底数相同的指数/对数，直接用单调性比。
  3. 同指比底：指数相同的 am 与 bm（m>0），看幂函数单调性。
  4. 作差/作商：差与 0 比，商与 1 比。

【跟讲例题 3.6-1】 比较 a=2^0.3，b=0.32，c=log20.3 的大小。 解：先定符号和档次——a=2^0.3>20=1；b=0.09∈(0,1)；c=log20.3<log21=0。 所以 c < b < a。先分三类再排序，不用硬算。

【跟讲例题 3.6-2】 比较 log23 与 log25 的大小。 解：同底 2>1，对数函数递增。真数 3<5，故 log23 < log25。同底直接看单调性。

小结：比大小先分"正负、是否过 1"三档，再用单调性精排。

3.7 复合指对函数的单调性（"同增异减"）

遇到 y = a^(f(x)) 或 y = logaf(x) 这种"套娃"函数怎么判断单调？（苏州教研·专题11，原书p.43）

法则：同增异减——外层函数和内层函数单调性相同时，复合函数增；相反时，复合函数减（口诀"大同小异"）。

  • 例：y = (1/2)^(x2−4x+3)。外层 (1/2)^u 是减函数（底<1）；内层 u = x2−4x+3 在 (−∞, 2] 减、在 [2, +∞) 增。外层减、内层减 ⇒ 复合在 (−∞, 2] 增；外层减、内层增 ⇒ 复合在 [2, +∞) 减。
  • 求这种函数的值域，一般先换元（令 u = f(x)，先求 u 的范围，再套外层函数的值域）。

④ 例题详解（先做再看）

例题例 1（运算）：计算：(1/2)−2 + 27^(1/3) + log28 − lg 0.01。

自己做：负指数、分数指数、对数分别算。

解：(1/2)−2 = 4；27^(1/3) = n√27 = 3；log28 = 3；lg 0.01 = −2。原式 = 4 + 3 + 3 − 2 = 8。 要点：log28 是"2 的几次方等于 8"——直接想答案，别写公式。

例题例 2（比较大小）：比较 a = 2^0.3，b = 0.32，c = log20.3 的大小。

自己做：用中间量 0 和 1 框住。

解：2^0.3 > 20 = 1 ⇒ a > 1；0.32 ∈ (0, 1) ⇒ 0 < b < 1；log20.3 < log21 = 0 ⇒ c < 0。故 c < b < a。 要点：先定符号，再定是否大于 1，三类数自然排序。

例题例 3（图象定点）：函数 f(x) = ax+1 − 2（a > 0 且 a ≠ 1）恒过哪个定点？

自己做：让指数部分为 0。

解：令 x + 1 = 0 ⇒ x = −1，此时 f(−1) = a0 − 2 = 1 − 2 = −1。恒过 (−1, −1)。 要点：ax 过 (0,1)，平移/伸缩后"让底数项化为 a0"。

⑥ 常见坑清单

  • loga(M + N) ≠ logaM + logaN（对数不分配加法）。
  • loga(x2) 与 2logax 定义域不同，不是同一函数。
  • ax 恒正：值域 (0, +∞)，不会取到 0 或负数。
  • 底数范围：a > 0 且 a ≠ 1；真数必须 > 0，负数没有对数。
  • 比较大小先定符号再定 1，别硬算。

本章公式速查表

与《高中数学常用公式·修订版》第二部分 8（基本初等函数）核对一致。

指数运算

指数律：am·an=am+n，(am)n=amn，(ab)n=anbn（a>0）

  • 大白话同底相乘指数加，幂上叠幂指数乘。
  • 用的时候：化简指数式先看底数是否相同；am÷an=am−n。

分数指数幂：a^(m/n)=n√(am)，a^(−m/n)=1/a^(m/n)（a>0）

  • 大白话根号就是分数指数，负指数就是倒数。
  • 用的时候：如 4^(3/2)=(√4)3=8；4√(x2) 要带绝对值。
  • 记忆要点：分子是"几次方"，分母是"开几次根"。

对数的定义与恒等式

对数定义：ab=N ⇔ logaN=b（a>0，a≠1，N>0）

  • 大白话a 的几次方等于 N，那个"几次方"就是 logaN。
  • 用的时候：负数和 0 没有对数；真数必须 >0。

对数恒等式：a^(logaN)=N

  • 大白话底数不动，指数和对数互相抵消。
  • 用的时候：见到 a^(logaN) 直接换成 N。

loga1=0，logaa=1

  • 大白话a0=1，a1=a，所以 log 出来就是 0 和 1。
  • 用的时候：常数秒算，别硬套公式。

对数运算律

积：loga(MN)=logaM+logaN

  • 大白话乘出来的对数 = 对数相加。
  • 用的时候：注意 loga(M+N) 不能拆！只对乘除拆加减。

商：loga(M/N)=logaM−logaN

  • 大白话相除的对数 = 对数相减。
  • 用的时候：M、N 都得 >0。

幂：logaMn=n·logaM

  • 大白话幂上的 n 可以搬到前面当系数。
  • 用的时候：化简 log29=2log23。

换底公式：logab = log꜀b / log꜀a

  • 大白话随便换个好算的底（lg 或 ln）来比。
  • 用的时候：连乘 log23·log34·log48 中间全约掉，只剩 log28=3。

换底推论：log_{an}bm = (m/n)logab；logab = 1/log_b a（苏州教研·专题10）

  • 大白话底数真数的次方提前当系数；底数真数一颠倒，对数就取倒数。
  • 用的时候：log29 = log_{22}32 = log23（同次约掉）；log23 = 1/log32。
  • 记忆要点：logax2 = 2loga|x|（提幂必带绝对值），常用 lg2+lg5=1。

指数函数

y=ax（a>0，a≠1）：定义域 R，值域 (0,+∞)，恒过 (0,1)

  • 大白话指数函数永远为正，都从 (0,1) 出发。
  • 用的时候：a>1 递增、0<a<1 递减；定点题"让指数为 0"，如 ax+1−2 过 (−1,−1)。

对数函数

y=logax（a>0，a≠1）：定义域 (0,+∞)，值域 R，恒过 (1,0)

  • 大白话真数必须 >0，图象都过 (1,0)。
  • 用的时候：a>1 递增；它和 y=ax 互为反函数，图象关于 y=x 对称。

幂函数

y=xα：都过点 (1,1)；α>0 在 (0,+∞) 增，α<0 在 (0,+∞) 减（苏州教研·专题11）

  • 大白话底数在变、指数固定，x=1 时永远是 1；正指数第一象限往上走，负指数第一象限往下走。
  • 用的时候：常见 α=−1,1/2,1,2,3；注意和指数函数区分（谁在底数谁在指数）。

指对函数里的奇偶模型与定点（苏州教研·专题9/10/12）

奇函数：f(x)=(ax−a−x)/2、f(x)=(ax−1)/(ax+1)、f(x)=loga(√(x2+1)+x)；偶函数：f(x)=a^|x|、f(x)=(ax+a−x)/2、f(x)=loga|x|

  • 大白话指数项"正负成对"拼出奇偶，对数套"√(x2+1)±x"也出奇函数。
  • 用的时候：含参 a 的指对函数过定点——令 a 的指数=0（或令真数=1），参数即隐身，剩下的坐标就是定点。
  • 记忆要点：a^(x−1)+3 过 (1,4)；loga(x−2)+4 过 (3,4)。

比较大小

先分档（0、1），再用单调性精排

  • 大白话正数>0>负数，大于 1 的>0到1的>负数，先分三类再排。
  • 用的时候：同底看单调、同指看幂函数；两数接近时构造函数或作差作商。
  • 记忆要点："先定符号，再定过不过 1"。

高级方法·进阶

对应方法手册：1.7 小题·比较大小的构造模型速查。下面把本章的"比较大小"从"四招"升级成"构造函数"。

进阶 1：中间量 + 同型函数构造（不超纲，高考可放心用）

  • 适用信号：三个数，一个指数型、一个对数型、一个常数型，比大小。
  • 操作步骤：① 先用 0 和 1 把三个数分到不同档（正/负、大于1/小于1）；② 同档的再用同底单调性或构造 f(t)=… 比。
  • 例：a=0.1e^0.1、b=1/9、c=−ln0.9=ln(10/9) 都在 0.1 附近，靠切线放缩 e^0.1≈1.105、ln(1.111)≈0.105 分出 c<a<b。
  • 依据：指数/对数函数单调性（课标内）。✓ 不超纲（但 e^0.1 这类近似要会估）。

进阶 2：等号设值法（对应手册 1.7，不超纲）

  • 适用信号：出现 "k+logax = k+log_b y = …" 这种连等式。
  • 操作步骤：设公共值为 k，把 x、y、z 全用 k 表示（x=a^(k−…），再对不同 k 讨论大小关系。
  • 例：2025 新高考Ⅰ卷第8题，设公共值为 k，x=2^(k−2)、y=3^(k−3)、z=5^(k−5)，逐个 k 试即知 x>z>y 不可能。
  • 依据：指数与对数互化（课标内）。✓ 不超纲。

A 组

  1. (−8)^(1/3)=n√(−8)=−2；2−1=1/2。原式 = −2 × 1/2 = −1。
  2. 32=9 ⇔ log39=2；log5125=3 ⇔ 53=125。

  4. log26−log23 = log2(6/3) = log22 = 1。
  5. 令 3x 的指数为 0：x=0，f(0)=2×1−1=1。恒过 (0, 1)。
  6. 真数 x>0 且根号内 log2x≥0 ⇒ x≥1。定义域 [1, +∞)。

B 组答案

B 组

  1. log29 = log232 = 2log23；原式 = 2log23·log32 = 2×(log23·log32)。由换底 log32 = 1/log23，相乘=1，故原式 = 2。
  2. log0.5 底 <1 递减：真数 3>2 ⇒ log0.53 < log0.52，两者都 <0（真数>1）；c=0.53=0.125>0。故 a < b < 0 < c，即 a<b<c。

C 组答案

C 组

  1. a=0.1·e^0.1≈0.1105；b=1/9≈0.1111；c=−ln0.9=ln(10/9)≈0.1054。排序 c<a<b，选 C。

一通百通

这一章的"通用骨架"是三步：① 先盯住底数（a>1 还是 0<a<1，这一条定了增还是减）→ ② 再用定点和中间量把数分档（指数恒正、对数真数>0，往 0 和 1 上靠，先分出正负、是否过 1）→ ③ 最后拿同底单调性或指对互化精排。高考里不管是指对运算、求过定点还是三个数比大小，本质都是这三步：先判底数定方向，再借 0、1 分档，最后用单调性收口。会做一道比大小题，就会做这一类；这套"先定底数、再分档、后精排"的顺序，04 章零点、05 章导数里估函数值时还会接着用。

跨章结合

  • 03 的"指对估值 + 单调性" 碰 02 章的比大小骨架：典型如 2022 新高考Ⅰ卷 T7（a=0.1e^0.1、b=1/9、c=−ln0.9 三数排序）。这题没人硬算 e^0.1，靠的是 02 章"先分正负、再分是否过 1"的分档动作，加上 03 章"同底看单调、指对互化"的工具，三个数各归其档再精排——想通了是"比"出来的，不是"算"出来的。
  • 03 的"指数爆炸增长" 碰 04 章零点与二分法：ex、ln x 这些曲线和一条直线能有几个交点，本质就是问"爆炸增长的指数曲线"和"匀速直线"谁先追上谁（综合原理说明，非真题）。04 章用零点定理判断交点个数，用的还是本章这几条曲线的脾气。

本章与前后章

本章接在第 02 章函数性质之后：02 章教你的"定义域、单调、奇偶"那套通用动作，本章第一次套在指数、对数、幂这三个具体函数上——定义域看真数>0、单调看底数和 1 的大小、奇偶用正负成对的模型判断，全是 02 章骨架的复用。本章是"基本初等函数"的总仓库，向后直接喂给第 04 章函数的应用与方程（零点、二分法、指数模型）和第 05 章导数（ex、ln x 是导数题里最常出现的函数）。学完本章，你手里多了三个"会爆炸增长、会平滑收缩"的具体函数，后面估任何函数值、画任何草图都离不开它们。

高考怎么考

本章在新高考Ⅰ卷里以"指数对数运算 + 比大小"小题为主，多在选择题第 6–8 题区间，常和函数性质揉在一起考：2022 卷 T7（指对常数混比）、2025 卷 T8（连等式设值比大小）都是本章地盘。考法高度套路化：运算靠指数律、对数律和换底，比大小靠"先分正负与是否过 1、再用单调精排"。它不考偏题怪题，就考你底数判断熟不熟、0 和 1 这两个中间量用得快不快——这正是本章"一通百通"骨架要练到肌肉记忆的原因。
