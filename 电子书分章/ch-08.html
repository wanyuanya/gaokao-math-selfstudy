公式速查：修订版 第3部分（正余弦定理）

本章本质核心：解三角形的本质就是"六个元素（三条边 a、b、c 和三个角 A、B、C）里知三求其余"——三角形一共六个量，只要给够独立的三个（至少含一条边），剩下的全能算出来。正弦定理和余弦定理就是沟通"边"与"角"的两个翻译器：正弦定理管"角↔它对的那条边"的比例，余弦定理管"三边↔夹角"；本章所有题型（求边、求角、判形状、求面积）都是这两个翻译器的来回调用。 为什么有用：想通"边和角能互相翻译"这一点，现实里够不着的河宽、塔高、两点距离，只要测一两个角和一段走得到的距离就能算出来；考卷上那道必考的解三角形解答题，本质就是这套翻译来回倒腾——想明白正余弦定理为什么成立，大题套路自然就通了。

② 学习目标

  • 掌握正弦定理、余弦定理及其变形
  • 会用正余弦定理解三角形（解边、解角、判定形状）
  • 掌握三角形面积公式（含正弦形式）
  • 能完成高考"解三角形解答题"（第 17 题左右，必考大题）

③ 正文讲解

解三角形，就是知道三角形里的几个边角条件，把剩下的边和角全部算出来。工具只有两把：正弦定理、余弦定理。先看地图：

已知条件三选二
   ├─ 两角一边  ──→ 正弦定理
   ├─ 两边夹角  ──→ 余弦定理
   ├─ 三边      ──→ 余弦定理
   └─ 两边一对角 ──→ 正弦定理（警惕两解）
        ↓
配合面积公式 S = ½ab·sinC、边角互化
        ↓
搞定高考第 17 题大题

3.1 正弦定理

先看几何直觉。 把一个三角形放进它的外接圆里（圆心 O，半径 R）。一条边 a 对着角 A。你会发现：不管三角形怎么摆，边 a 越长，它对的角 A 也越大——精确地说，a 恰好等于"外接圆直径 2R"乘以 sinA。这就是正弦定理。

定理（人教A版口径）：在 △ABC 中（角 A、B、C 对边分别为 a、b、c）：

a / sin A  =  b / sin B  =  c / sin C  =  2R（R 为外接圆半径）。

它有什么用？

  • 已知两角和任一边 → 求其余边和角；
  • 已知两边和其中一边的对角 → 求另一边的对角（注意可能有两解）。

边角互化（高考大题第一步常用）：

  • a : b : c  =  sin A : sin B : sin C；
  • a  =  2R sin A，b  =  2R sin B，c  =  2R sin C。 看到"边的齐次式"，可以整体换成"正弦的齐次式"，反过来也行。

例题跟讲例题 3.1-1：在 △ABC 中，A  =  45°，B  =  60°，a  =  2√2，求 b。 解：由正弦定理 a/sinA  =  b/sinB，得 b  =  a·sinB/sinA  =  2√2  ×  (√3/2)/(√2/2)  =  2√2  ×  √3/√2  =  2√3。 要点：正弦定理是比例式，交叉相乘；最后 √2 约掉。

陷阱：已知两边及一边对角用正弦定理求角，可能有两解，先判断（见 3.4）。

编者注·本质回扣：正弦定理写出来是 a/sinA = b/sinB = c/sinC = 2R，看着像三条孤立的等式，本质其实是一句话："每条边和它对角的正弦永远成正比"。把三角形装进外接圆后，这条比例就是直径 2R——边越长，它撑出来的弦越长、对的角也越大。所谓"边角互化 a:b:c = sinA:sinB:sinC"，说白了就是这条比例的另一种写法：边的关系可以直接搬进角里，角的关系也能搬进边里，这正是高考大题第一步最常用的那一下翻译。

3.2 余弦定理

什么时候用余弦定理？ 正弦定理处理"角↔对边"，可一旦知道两边夹一角或三条边，正弦定理使不上劲，就轮到余弦定理。它其实是勾股定理的推广——直角时 cos 90° = 0，就退化成勾股定理。

定理（人教A版口径）：

记住它之前先看懂它：余弦定理就是"带修正项的勾股定理"——两条已知边 b、c 若夹角是 90°，cos90° = 0，就退回成 a2 = b2+c2；夹角一旦不是直角，就多减一个 2bc·cosA 把"歪掉"的那部分补回来。三条公式是同一个道理对着三个角各说一遍，记一条即可。

a2  =  b2 + c2 − 2bc·cos A b2  =  a2 + c2 − 2ac·cos B c2  =  a2 + b2 − 2ab·cos C

变形（已知三边求角）：cos A  =  (b2 + c2 − a2)/(2bc)。

它有什么用？

  • 已知两边及夹角 → 求第三边；
  • 已知三边 → 求角，或判断角是锐角/直角/钝角。

判定角的类型（记住）：对边平方 a2 与另两边平方和比较：

  • a2  =  b2 + c2 → A  =  90°（直角）；
  • a2 > b2 + c2 → A 为钝角；
  • a2 < b2 + c2 → A 为锐角。

例题跟讲例题 3.2-1：已知三角形三边 a = 3、b = 5、c = 7，求最大角。 解：最大边 c = 7 对最大角 C。cos C  =  (a2+b2−c2)/(2ab)  =  (9+25−49)/(2 × 3 × 5)  =  −15/30  =  −1/2。C∈(0,π)，故 C  =  120°。 要点：cos 为负说明钝角；cos C  =  −1/2 对应 120°。

陷阱：分子是 b2+c2−a2，对边 a 的平方带负号，别写反。

3.3 三角形面积公式

初中的 S  =  ½·底·高 谁都会，但高往往不知道。用正弦能把高换掉：

记住它之前先看懂它：这条公式就是初中"½ 底  ×  高"的换皮——把一条边 b 当底，高正好等于另一边 c 乘夹角正弦 sinA，于是 S = ½·b·(c·sinA) = ½bc·sinA。三条写的是同一块面积，只是轮流挑不同的边当底。

  • S  =  ½·bc·sin A  =  ½·ac·sin B  =  ½·ab·sin C

一句话记忆：两边及其夹角正弦乘积的一半。夹角必须是那两边夹住的角。

海伦公式（了解即可）：S  =  √(s(s−a)(s−b)(s−c))，其中 s  =  (a+b+c)/2。三边全给时可用。

例题跟讲例题 3.3-1：已知 b  =  3，c  =  4，A  =  30°，求面积。 解：S  =  ½·bc·sin A  =  ½ × 3 × 4 × (1/2)  =  3。 要点：直接套"两边夹一角"。

3.4 解三角形的"已知三选二"模型

拿到题先看给了哪几个条件，照着表选定理：

已知 首选定理
两角一边 正弦定理
两边夹角 余弦定理
三边 余弦定理
两边及一边对角 正弦定理（警惕两解）

"两解"怎么判断：已知 a、b 及 A（a 对 A）。设 h  =  b·sin A（b 边在 A 方向上的高）：

  • a > b → 一解；
  • a  =  b·sin A → 一解（相切，直角）；
  • b·sin A < a < b 且 A 为锐角 → 两解；
  • a < b·sin A → 无解。 考小题时，直接画个图看射线和圆弧有几个交点更快。

例题跟讲例题 3.4-1：我站在地面看塔顶，仰角 30°，水平距离塔底 30 米，求塔高。 解：直角三角形中 tan30°  =  高/30，高  =  30 × tan30°  =  30 × (√3/3)  =  10√3 米。 要点：实际问题先抽象成直角三角形，仰角对的就是"对边/邻边"。

3.5 高考大题结构（第 17 题左右）

解三角形是新高考必考大题，通常两问：

  • 第一问：给一组边角混合条件，求某条边或某个角；
  • 第二问：求面积、周长，或它们的范围/最值。

两大常用手法：

  1. 边角互化：把"边的齐次式"用正弦定理换成"正弦的齐次式"，或反过来。
  2. 余弦定理配完全平方：求周长/范围时，常把 a2+b2 凑成 (a+b)2−2ab。

3.6 判断三角形的形状

高考常给一个边角混合条件，问"这是什么三角形"。套路固定：用定理把条件化成"纯边"或"纯角"，再看能推出什么。

  • 想推等腰/等边 → 争取化到 a = b 或 A = B；
  • 想推直角 → 争取化到 a2+b2 = c2 或某角为 90°。

例题跟讲例题 3.6-1：已知在 △ABC 中 a·cosB  =  b·cosA，判断形状。 解：用正弦定理"边化角"（a = 2R·sinA，b = 2R·sinB），约掉 2R： sinA·cosB  =  sinB·cosA ⇒ sinA·cosB − cosA·sinB  =  0 ⇒ sin(A−B)  =  0。 三角形内角 A、B 都在 (0,π)，它们的差也在这个范围附近，sin(A−B) = 0 只能 A−B = 0，即 A = B。 故 a = b，△ABC 是等腰三角形（顶角 C，两腰 a、b）。 一步一验：取 A = B = 50°，则 a·cosB 与 b·cosA 因 a = b 而相等，条件成立。

例题跟讲例题 3.6-2：已知 a2  =  b2 + bc + c2，判断角 A。 解：对照余弦定理 a2  =  b2+c2−2bc·cosA，两式相减： 0  =  −bc − 2bc·cosA ⇒ −1 − 2cosA  =  0 ⇒ cosA  =  −1/2，A∈(0,π)，故 A  =  120°（钝角）。 要点：看到 a2 的表达式，先往余弦定理上靠，配出 cosA。

小结：正弦定理管"角↔对边比例"，余弦定理管"三边↔夹角"；面积公式串起两边一夹角。做题先判类型，再套定理，最后别忘检验角的范围和两解。

编者注·本质回扣：把这一章和前两章连起来看，你会发现它没引入任何新东西。正弦定理、余弦定理不过是把第 06、07 章的 sin、cos 从单位圆搬进了三角形：正弦定理说"角对的边成比例"，余弦定理是勾股定理带上 cos 修正项的推广（直角时 cos90° = 0 就退回勾股）。所谓"知三求其余"，就是手里攥着六个量里的三个，用这两个翻译器把"边"翻成"角"、再把"角"翻回"边"，来回倒腾直到六个量全齐。判形状、求面积、求范围，全是这套翻译的具体应用。

④ 例题详解（先做再看）

例题例 1（正弦定理）：在 △ABC 中，A  =  60°，B  =  45°，a  =  √6，求 b。

自己做：a/sinA  =  b/sinB。

解：b  =  a·sinB/sinA  =  √6 · (√2/2)/(√3/2)  =  √6 · (√2/√3)  =  √4  =  2。 要点：正弦定理是比例式，交叉相乘。

例题例 2（余弦定理 + 面积）：在 △ABC 中，b  =  3，c  =  4，A  =  60°，求 a 和面积。

自己做：余弦定理求 a，面积用正弦公式。

解：a2  =  b2 + c2 − 2bc·cos A  =  9 + 16 − 2·3·4·(1/2)  =  25 − 12  =  13，a  =  √13。 S  =  ½bc·sin A  =  ½·3·4·(√3/2)  =  3√3。 要点：两边夹一角：一条余弦、一条面积公式，都是直接套。

例题例 3（大题边角互化）：在 △ABC 中，2a·sin B  =  √3·b，求角 A。

自己做：把边换成角。

解：由正弦定理 a  =  2R sin A、b  =  2R sin B 代入： 2·(2R sin A)·sin B  =  √3·(2R sin B) ⇒ sin B ≠ 0 消去 ⇒ 2 sin A  =  √3 ⇒ sin A  =  √3/2。 A  =  60° 或 120°（A 是三角形内角，两解都要）。 要点："边角混合"大题第一步常是边化角；消公因子（sin B、2R）前先确认非零。

例题例 4（正余弦整合定理，苏州教研·专题30，原书p.125）：不求角，直接求值 sin221° + sin239° + sin21° sin39°。

自己做：21°+39°  =  60°，两角成三角形的两个内角结构（第三角 120°）。

解：把 21°、39° 想成某个三角形的 B、C，则 A  =  180°−60°  =  120°。由"正余弦整合定理" sin2A  =  sin2B + sin2C − 2 sinB sinC cosA。 代入 B = 21°、C = 39°、A = 120°、cos120°  =  −1/2： sin221° + sin239° − 2 sin21°sin39°·(−1/2)  =  sin2120°， 即 sin221° + sin239° + sin21°sin39°  =  sin2120°  =  (√3/2)2  =  3/4。 要点：看到"sin2B + sin2C ± sinB sinC"这种结构，就把它对应到正余弦整合定理——只要 B+C = 60°（第三角 120°），"±"号正好配 cos120° = −1/2，整体等于 sin2(第三角)。

⑥ 常见坑清单

  • 正弦定理求角可能两解：已知两边及一边对角，先判断解的个数再写答案。
  • 余弦定理的角：cos A 由三边求，分子是 b2 + c2 − a2（对边平方带负号）。
  • 边角互化：只有"边的齐次式"才能整体换成角，混着常数要小心。
  • 面积公式选 ½ bc sin A：夹角必须是两边所夹的角。
  • 大题里"cos A 用余弦定理"与"sin A 用同角关系"常配合，先求 cos 再转 sin。

本章公式速查表

与《高中数学常用公式·修订版》第三部分第 10、11 条核对一致。

正弦定理（管"角 ↔ 对边"的比例）

a / sin A  =  b / sin B  =  c / sin C  =  2R（R 为外接圆半径）

  • 大白话每条边和它对角的正弦之比都相等，而且正好等于外接圆直径 2R。
  • 用的时候：已知两角一边、或两边及一边对角，首选它。

边化角（比例）：a : b : c  =  sin A : sin B : sin C

  • 大白话边的比等于对角正弦的比。
  • 用的时候：见到"边的齐次式"，可以整体换成"正弦的齐次式"，反过来也行。

边化角（代换）：a  =  2R sin A，b  =  2R sin B，c  =  2R sin C

  • 大白话每条边都能写成"外接圆直径乘对角正弦"。
  • 用的时候：大题第一步常把边全换成正弦；混着常数的式子不能硬换。

已知两边及一边对角可能有两解：b·sin A < a < b 且 A 为锐角时，B 有两解

  • 大白话给了两边和其中一边的对角，射线和圆弧可能交两次。
  • 用的时候：先用 h=b·sinA 比一比；a>b 或 a=bsinA 一解，bsinA<a<b 且 A 锐角两解，a<bsinA 无解。

等比性质：a/sinA  =  (a+b+c)/(sinA+sinB+sinC)

  • 大白话连等的比例式，分子分母分别加起来比值不变。
  • 用的时候：知道三边和三个正弦的总和时可一步求 2R。

余弦定理（管"三边 ↔ 夹角"）

a2  =  b2 + c2 − 2bc·cos A（及 b2、c2 两式）

  • 大白话一边的平方等于另两边平方和，再减去"两倍两边乘夹角余弦"；直角时 cos90° = 0 就退回勾股定理。
  • 用的时候：已知两边夹一角求第三边，或已知三边求角，用它。

变形：cos A  =  (b2 + c2 − a2)/(2bc)（及 B、C 两式）

  • 大白话三边全给时反解出角。
  • 用的时候：分子里"对边 a 的平方带负号"，别写反。

判角类型：a2  =  b2+c2 → 直角；a2 > b2+c2 → 钝角；a2 < b2+c2 → 锐角

  • 大白话把最大边的平方和另两边平方和一比，就知道最大角是直、钝还是锐。
  • 用的时候：不用真算角度，比大小就够。

三角形面积

S  =  ½·底·高

  • 大白话初中那条老公式。
  • 用的时候：知道高时最直接。

S  =  ½·ab·sin C  =  ½·bc·sin A  =  ½·ca·sin B

  • 大白话面积等于"两边及其夹角正弦乘积的一半"。
  • 用的时候：夹角必须是那两边夹住的角；大题第二问求面积常用这条。

海伦公式：S  =  √(s(s−a)(s−b)(s−c))，s  =  (a+b+c)/2（选学）

  • 大白话三边全给、又不知道高和角时，用半周长硬算面积。
  • 用的时候：三边已知才方便，平时优先用 ½ab sinC。

外接圆与内切圆

外接圆直径 2R  =  a/sinA  =  b/sinB  =  c/sinC

  • 大白话正弦定理里那个比值就是外接圆直径。
  • 用的时候：题目提到外接圆，立刻想到这条。

内切圆半径 r  =  2S/(a+b+c)

  • 大白话内切圆半径等于面积的 2 倍除以周长。
  • 用的时候：见到内切圆半径直接套；能由面积法现场推。

面积与边角的进阶结论（苏州教研·专题30）

面积外接圆形式：S  =  abc/(4R)（R 为外接圆半径）

  • 大白话面积等于三边乘积除以四倍外接圆半径。
  • 用的时候：题目同时给了三边和外接圆半径（或能求出 R），求面积用这条。

坐标面积：已知 AB = (x1,y1)、AC = (x2,y2)，则 S  =  ½|x1y2 − x2y1|

  • 大白话两边向量坐标知道后，三角形面积就是"交叉相乘再相减"绝对值的一半。
  • 用的时候：建系后求三角形面积直接套；平行四边形面积则是 |x1y2−x2y1|（不折半）。

正余弦整合定理（余弦定理的正弦版）：sin2A  =  sin2B + sin2C − 2 sinB sinC cosA

  • 大白话把余弦定理里的边 a、b、c 全换成对应角的正弦，等式照样成立。
  • 用的时候：遇到 sin2B + sin2C ± sinB sinC 这类结构（两角和确定），用它一步化成 sin2(第三角)，不用真算边长。

边角单调性：A<B ⟺ a<b ⟺ sinA<sinB ⟺ cos2A>cos2B；且 A<B ⟺ cosA>cosB

  • 大白话大角对大边，且这个顺序一路传到 sinA、cos2A、cosB 上。
  • 用的时候：比较两个角的大小，等价于比较对边、比较 sin、或比较 cos2A，挑方便的用。

内角半角：sin((A+B)/2)  =  cos(C/2)，cos((A+B)/2)  =  sin(C/2)

  • 大白话因为 A+B = π−C，所以 (A+B)/2 = π/2−C/2，互余直接换掉。
  • 用的时候：大题里把 (A+B)/2 的三角式化成 C/2，往往能和别的项合并。

锐角三角形与角范围：锐角三角形两内角 A、B 满足 sinA>cosB；三角形最小内角 ∈ (0, π/3]，最大内角 ∈ [π/3, π)

  • 大白话锐角三角形任意两锐角互余有余量，故 sinA>cosB；三个角的平均是 π/3，所以最小角不超过 π/3、最大角不小于 π/3。
  • 用的时候：题目说"锐角三角形"就能用 sinA>cosB；说某角是最大/最小内角，先圈它的范围。

由正弦值定角：sinA = sinB ⇒ A = B；sin2A = sin2B ⇒ 2A = 2B 或 2A+2B = π（即 A+B = π/2）

  • 大白话两个正弦相等，在三角形里要么两角相等，要么它们的二倍角互余（推出直角）。
  • 用的时候：判形状时见到 sin2A=sin2B，要想到"等腰或直角"两种可能，别漏直角。

5.2 解三角形"隐藏公式"速查

大白话·本质一句话：所谓"隐藏公式"其实都是正余弦定理的换皮长相——射影定理 a = bcosC+ccosB 本质是把边 b、c 投影到边 a 上再拼起来（余弦定理移项即得），中线、角平分线、面积公式也都能由正余弦定理现场推出。记它们是为了在小题里一步出结果，不是新知识。

  • 射影定理：a = bcosC+ccosB（可秒解"边角关系"题）；
  • 中线长：ma2  =  (2b2+2c2-a2)/4（向量或余弦定理推）；
  • 角平分线：BD/DC  =  AB/AC；角平分线长 l2  =  bc[1-(a2/(b+c)2)]（选学）；
  • 面积：S = ½absinC；海伦公式（选学）。

课标依据：正弦余弦定理（必修二）。✓

（高级方法手册·5.2）

联动：本条浓缩速记版即下方"### 进阶 1·解三角形隐藏公式速查"；正文 3.3 面积公式、本章例 2 与 B 组第 10 题（用射影定理 2b cosA  =  c cosA + a cosC  =  b 求 A）是它的实战。

5.3 三角形最值套路

大白话·本质一句话：大题第二问求周长 / 面积最值，本质就是三步"先把边翻成角、再把多个角压成一个角、最后用辅助角或基本不等式收尾"——把三角形里乱七八糟的边角量统一成单变量后，求最值就变成了 07 章合一、12 章基本不等式那两步老动作。

  1. 边角互换（正弦定理把边换成角）；
  2. 统一成单变量（一角）；
  3. 辅助角/基本不等式/二次函数求最值。

经典：周长最值（边角互换后辅助角）、面积最值（基本不等式）。

（高级方法手册·5.3）

联动：本条浓缩速记版即下方"### 进阶 2·三角形最值套路"；正文 3.5 高考大题结构、跨章结合"08 边角互化  ×  07 辅助角合一"是这条套路的完整链路。

进阶 1·解三角形"隐藏公式"速查 —— 不超纲（高考可放心用）

对应《不超纲高级方法手册》五.5.2。

  • 适用信号：选择题/填空题里给边角混合关系，想用一步出结果，不想列方程组。

  • 操作步骤： 1. 射影定理：a  =  b cos C + c cos B（边等于另两边在它上面的投影之和），可秒解"边 = cos 组合"型小题； 2. 中线长：边 a 上的中线 m_a2  =  (2b2+2c2−a2)/4； 3. 角平分线定理：角 A 平分线交 BC 于 D，则 BD/DC  =  AB/AC  =  c/b。

  • 例题：已知 b cos C + c cos B  =  6，求边 a。直接由射影定理 a  =  b cos C + c cos B  =  6，一步出。

  • 课标依据 / 超纲红线：都能由正余弦定理现场推出（必修二），不超纲，可放心用；角平分线长公式属选学，大题建议写出推导。

进阶 2·三角形最值套路 —— 不超纲（高考可放心用）

对应《不超纲高级方法手册》五.5.3。

  • 适用信号：大题第二问求"周长范围""面积最值""某表达式最大最小值"。

  • 操作步骤： 1. 用正弦定理把边换成角（边角互换）； 2. 统一成单变量（只剩一个角）； 3. 用辅助角公式 / 基本不等式 / 二次函数求最值。

  • 例题：周长最值——把 a+b+c 用正弦写成 2R(sinA+sinB+sinC)，再合一；面积最值——固定一边时用基本不等式 ab ≤ ((a+b)/2)2。

  • 课标依据 / 超纲红线：就是正余弦定理 + 辅助角 + 基本不等式的综合（均在必修范围），不超纲。红线：别直接套二级结论当证明，大题要写清推导。

课后习题答案

自测答案：1. b  =  a·sinB/sinA  =  1·(√2/2)/(1/2)  =  √2；2. c2  =  9 + 25 − 2·3·5·cos120°  =  34 + 15  =  49，c  =  7；3. 最大边 5：52  =  32 + 42 ⇒ 最大角为直角；4. S  =  ½·2·3·sin30°  =  3/2；5. a : b : c  =  3 : 4 : 5 ⇒ 32 + 42  =  52 ⇒ 直角三角形。

A 组答案

A 组

  1. b = a·sinB/sinA = 3√2 × (√2/2)/(√3/2) = 3√2 × √2/√3 = 2√3。
  2. sin B = b·sinA/a = √6×(√2/2)/2 = √12/4 = √3/2。B∈(0,π)，B = 60° 或 120°（两解）。
  3. a2 = b2+c2−2bc cosA = 25+64−2×5×8×(1/2) = 89−40 = 49，a = 7。
  4. cos B = (a2+c2−b2)/(2ac) = (49+9−25)/(2×7×3) = 33/42 = 11/14。B = arccos(11/14)。
  5. S = ½ab sinC = ½×4×5×(√3/2) = 5√3。
  6. 最大边 √7：(√7)2 = 7，另两边平方和 = 4+9 = 13，7<13 ⇒ 最大边对的角为锐角。

B 组答案

B 组

  1. 由正弦定理：sinA cosB = sinB cosA ⇒ sin(A−B) = 0 ⇒ A = B（三角形内）⇒ 等腰三角形。
  2. S = ½bc sinA = ½×1×4×sin120° = 2×(√3/2) = √3；a2 = b2+c2−2bc cosA = 1+16−2×1×4×(−1/2) = 17+4 = 21，a = √21。
  3. 设塔高 h、第一次测点距塔底 x。仰角45°：h = x；后退20米后仰角30°：h = (x+20)·tan30° = (h+20)/√3。解得 √3 h = h+20 ⇒ h = 20/(√3−1) = 10(√3+1) 米。
  4. (1) 由射影定理 a cos C + c cos A = b，条件 2b cosA = c cosA + a cosC = b ⇒ cosA = 1/2 ⇒ A = 60°。 (2) a2 = b2+c2−2bc cosA：7 = (b+c)2−2bc−bc = 16−3bc ⇒ bc = 3。S = ½bc sinA = ½×3×(√3/2) = 3√3/4。

C 组答案

C 组

  1. (1) 由正弦定理 √3·2R sinA = 2·2R sinC·sinA，消去 sinA：√3 = 2 sinC ⇒ sinC = √3/2 ⇒ C = 60° 或 120°。排除 120°：若 C=120°，余弦定理 c2 = a2+b2−2ab cos120° = a2+b2+ab = (a+b)2−ab，代入 c=√7、a+b=5 得 7 = 25−ab ⇒ ab=18；此时 a、b 是方程 t2−5t+18=0 的根，判别式 25−72<0，无实数解，矛盾，故舍 120°、取 C=60°。 (2) c2 = a2+b2−2ab cos60° = (a+b)2−3ab：7 = 25−3ab ⇒ ab = 6。S = ½ab sin60° = ½×6×(√3/2) = 3√3/2。

  2. (1) a:b:c = 3:5:7，c=14 ⇒ 比例系数 k = 14/7 = 2，故 a = 6，b = 10。 (2) cos C = (a2+b2−c2)/(2ab) = (36+100−196)/(2×6×10) = −60/120 = −1/2 ⇒ C = 120°。S = ½ab sinC = ½×6×10×(√3/2) = 15√3。

一通百通

解三角形的通用骨架只有三步：① 先数条件——题目给了六个量（三边三角）里的哪三个？是"两角一边""两边夹角""三边"还是"两边一对角"；② 选翻译器——两角一边、两边一对角用正弦定理，两边夹角、三边用余弦定理，求面积就套 ½·两边·夹角正弦；③ 边不够就边角互化——把"边的齐次式"整体换成"角的正弦"，或反过来，统一变量后再算，最后圈出角的范围、检查有没有两解。会解一道解三角形题，就会解这一整类；这套"先判条件类型、再选定理翻译"的骨架，就是新高考那道必考大题的全部套路。

跨章结合

  • 08 的"正弦定理边角互化" + 第 07 章的"辅助角合一"：大题第一问先用正弦定理把边的齐次式换成角，第二问多个角的三角函数相加，再用 07 章的辅助角公式合一求最值——这是新高考解三角形解答题的标准两连（苏州教研·专题30）。
  • 08 的"正余弦整合定理" + 07 的 sin2、sin·sin 结构：看到 sin2B+sin2C±sinB sinC 且两角和确定，直接对应正余弦整合定理、一步化成 sin2(第三角)——苏州教研·专题30 的 sin221°+sin239°+sin21°sin39°=3/4（本章例 4）就是这一结合点。
  • 08 的"正余弦定理" + 第 09 章向量的数量积（综合原理说明，非真题）：向量数量积 a·b=|a||b|cosθ，本质就是余弦定理两边同时乘一条边——用数量积算三角形夹角、判断垂直（直角），和正余弦定理互为翻译；建系后解三角形，最后一步常落到数量积上。
  • 08 的"解三角形" + 第 16 章解析几何的几何条件（综合原理说明，非真题）：解析几何大题里"某角为直角 / 两边成夹角 / 三角形面积最值"这类条件，常常要翻译成三角形的边角关系（或向量夹角）来列方程——本章的正余弦定理就是把"几何条件"翻成"可算等式"的那座桥。

本章与前后章

本章是三角函数板块的收官应用章：它前面的第 06 章给了你 sin、cos、tan 的定义和图象，第 07 章给了你和差角、倍角、辅助角这些"加工"工具——本章就是把这些工具全部用回到三角形的边角上。具体地说，正弦定理来自第 06 章的单位圆与外接圆，大题第二问求面积、周长的最值时，要靠第 07 章的辅助角公式合一后再求范围。学完本章，三角函数这条线（06→07→08）就闭环了：从"角是什么"到"角怎么变换"，再到"角怎么用来量三角形、测距离"。

高考怎么考

解三角形是新高考Ⅰ卷必考的解答题，通常放在卷面解答题的第 1 题（第 17 题左右），两问结构固定：第一问给一组边角混合条件求某条边或某个角（第一步往往是正弦定理做边角互化），第二问求面积、周长或它们的最值范围（要配合余弦定理凑完全平方、再用辅助角或基本不等式）。偶尔也以小题形式考"两边一对角的两解判断"，以及 sin2B+sin2C±sinB sinC 这类结构一步化角（如 sin221°+sin239°+sin21°sin39°=3/4）。这道大题位置靠前、套路成熟，是整张卷子必须稳稳拿下的一道解答题。
