本章本质核心：函数就是一条"输入 x → 按规则 f → 唯一输出 y"的传送带——本章讲的一切都是这条传送带的侧面：定义域管"哪些 x 允许上车"，单调与奇偶管"传送带怎么弯、左右对不对称"，最值管"传送带最高最低落在哪"，分段函数只是同一条传送带按区间换了段路面。本章所有题型（求定义域、证单调、判奇偶、求最值）都是这一条"输入→输出规则"的变体。

为什么有用学会这一章，你手里就有了一把"拆任何新函数"的通用尺子——后面 03 指对、06 三角、11 数列里再陌生的函数，你都能照同一套路问出"x 能取哪、随 x 怎么涨、左右对不对称、最高最低在哪"。想通这条输入输出规则，新函数不用背也能自己分析。

3.1 函数的概念

先看两个身边的例子。 你去打车，车费 y 跟着里程 x 变——x 一定，y 就唯一确定了。气象台记录南极臭氧层空洞面积，时间 t 一定时，面积 S 也唯一确定。这些现象的共同点是：一个量定了，另一个量就跟着唯一确定。数学上把这种关系叫函数。

设 A、B 是非空的实数集，如果对于集合 A 中的任意一个数 x，按照某种确定的对应关系 f，在集合 B 中都有唯一确定的数 y 和它对应，那么就称 f: A→B 为从集合 A 到集合 B 的一个函数，记作 y  =  f(x)，x ∈ A。（人教A版口径）

三要素——一个函数由三样东西决定：

  1. 定义域：自变量 x 的取值范围 A。
  2. 对应关系：f，即"怎么由 x 算出 y"。
  3. 值域：所有函数值 f(x) 组成的集合 {f(x) | x ∈ A}，它是 B 的一部分。

同一函数：定义域相同 且 对应关系相同，就是同一个函数（跟用 x 还是 t 做字母无关）。

  • y  =  x 和 y  =  x2/x 不是同一函数：后者 x≠0，定义域少了 0。
  • y  =  x 和 s  =  t 是同一函数：定义域都是 R，对应关系都是"本身"。

判断一个图象是不是函数图象——垂直检验（苏州教研·专题2）：函数 y = f(x) 的图象，和任何一条竖直线 x = m 至多只有一个交点。如果一条竖直线穿过去有两个交点，那它就不是函数图象（一个 x 对应了两个 y）。另外记住：点 (a, b) 在 y = f(x) 的图象上 ⇔ f(a) = b。

定义域优先原则（苏州教研·专题2）：研究任何函数问题，第一件事就是先指出它的定义域。定义域一旦错了，后面单调性、奇偶性、值域全会跟着错——这是铁律，不是建议。

怎么求一个函数的解析式（苏州教研·专题3）：题目告知函数类型，就用待定系数法——先设出该类型的一般式（一次设 f(x) = kx+b，二次设 f(x) = ax2+bx+c），再用条件列方程定系数。

【跟讲例题 3.1-2】（苏州教研·专题3，原书p.18） 已知 f(x) 是一次函数，且 3f(x+1) − 2f(x−1)  =  2x − 17，求 f(x)。 解：设 f(x) = kx+b。则 3f(x+1)−2f(x−1)  =  3[k(x+1)+b] − 2[k(x−1)+b]  =  kx + 5k + b。 令它等于 2x−17：k = 2，5k+b = −17 ⇒ 10+b = −17 ⇒ b = −27。故 f(x)  =  2x − 27。

区间记号（必须滚瓜烂熟）：

写法 含义 端点
[a, b] a ≤ x ≤ b 两端都取到
(a, b) a < x < b 两端都取不到
[a, b)、(a, b] 一头取到一头取不到 看括号
(a, +∞)、(−∞, b)、(−∞,+∞) = R 无限延伸

【跟讲例题 3.1-1】 y  =  x 与 y  =  √x·√x 是不是同一函数？ 解：不是。y = x 定义域是 R；y = √x·√x 里根号下要有意义，x≥0。定义域不同，就不是同一函数（即使 x≥0 时两式都等于 x）。

小结：函数  =  "x 定了 y 唯一确定"；三要素里定义域是命门；判断同一函数先比定义域。

编者注·本质回扣：为什么这一节要把"定义域"捧成命门？说白了，函数的本质是"一个 x 对应唯一的 y"这条规则，那规则从哪开始算？就得先把"哪些 x 能进来"圈死——x 的范围没定死，规则就是空中楼阁。所以"定义域优先"不是一句口号，而是本质核心里"传送带入口"的规矩：入口不画框，后面算出来的 y 全是给"根本不存在的 x"算的，自然全错。判断同一函数先比定义域、求解析式用待定系数，也都是在维护"这条规则到底是哪一条"。

3.2 定义域的求法

求定义域，本质就是找"x 不许踩的红线"，再把所有红线取交集。 高中阶段常见的红线：

式子里出现 红线（限制条件）
分式 1/g(x) 分母 g(x) ≠ 0
偶次根式 √g(x) 根号内 g(x) ≥ 0
零次幂 g(x)0 底数 g(x) ≠ 0
实际问题 符合实际意义（长度>0 等）

流程：① 列出每个红线对应的不等式；② 全部取交集（注意是交，不是并）；③ 写成区间。

【跟讲例题 3.2-1】 求 f(x)  =  √(x − 1) + 1/(x − 2) 的定义域。 解：根号 x−1 ≥ 0 ⇒ x ≥ 1；分母 x−2 ≠ 0 ⇒ x ≠ 2。取交集：x ≥ 1 且 x ≠ 2，即 [1, 2) ∪ (2, +∞)。 要点：x = 1 能取（√0 = 0），写闭；x = 2 绝对不能取，单独挖掉。

易错点：求定义域只看形式，不要先化简。比如 f(x) = (x2−1)/(x−1)，别先约成 x+1——约掉前 x = 1 本来是无意义的，定义域必须把 x = 1 排除。

抽象函数的定义域（苏州教研·专题2，小题高频）——题目不给解析式时，盯住"被同一个 f 作用的对象范围相同"：

  • 已知 f(x) 的定义域是 (a, b)，求 f(g(x)) 的定义域：解不等式 a < g(x) < b，解集就是。
  • 已知 f(g(x)) 的定义域是 (a, b)，求 f(x) 的定义域：由 x∈(a,b) 求 g(x) 的值域，该值域就是 f(x) 的定义域。

【跟讲例题 3.2-2】（苏州教研·专题2，原书p.14） 已知 f(x) 的定义域是 (1, 3)，求 f(2x+1) 的定义域。 解：被 f 作用的对象必须落在 (1, 3) 里，所以 1 < 2x+1 < 3，解得 0 < x < 1。故 f(2x+1) 的定义域是 (0, 1)。 （反过来：若 f(3x−1) 的定义域是 [1, 3]，则 x∈[1,3] 时 3x−1∈[2,8]，故 f(x) 的定义域是 [2, 8]。）

小结：定义域  =  所有红线取交集；分式看分母、根式看根号内。

3.3 单调性

直觉：坐电梯，从 1 楼一直升到 10 楼，高度随时间"单调上升"；坐滑梯则一路下降。函数的单调性就是刻画"随着 x 变大，y 是一路涨还是一路跌"。

定义：设函数 y = f(x) 定义域为 I，区间 D⊆I。如果 ∀x1, x2 ∈ D，当 x1 < x2 时都有 f(x1) < f(x2)，就说 f(x) 在 D 上单调递增；都有 f(x1) > f(x2) 则单调递减。

用定义证明单调性的四步（大题模板，背熟）：

  1. 取值：任取 x1, x2 ∈ D，设 x1 < x2。
  2. 作差：算 f(x1) − f(x2)。
  3. 变形：因式分解、通分、配方，化成几个能判正负的因式相乘。
  4. 定号：由 x1 < x2 推出差的正负，下结论。

常见函数的单调性（要背）：

  • y  =  x：R 上递增。
  • y  =  x2：(−∞,0) 递减、(0,+∞) 递增（两段分开写）。
  • y  =  1/x：(−∞,0) 和 (0,+∞) 上分别递减——千万别说"在整个定义域上递减"，因为 x = 0 处断开了。
  • y  =  x3：R 上递增。

【跟讲例题 3.3-1】 用定义证明 f(x)  =  2x + 1 在 R 上单调递增。 证明：任取 x1 < x2。作差 f(x1)−f(x2)  =  (2x1+1)−(2x2+1)  =  2(x1−x2)。 因为 x1<x2，所以 x1−x2<0，差 < 0，即 f(x1)<f(x2)。故在 R 上递增。

小结：单调就是"x 大 y 大(或小)"；证明按"取值—作差—变形—定号"四步；断开的区间要分开说。

3.4 奇偶性

前提：先看定义域是否关于原点对称。不对称，直接判定"非奇非偶"，不用往下算了。

  • 偶函数：f(−x)  =  f(x)，图象关于 y 轴对称。如 f(x) = x2、f(x) = |x|。
  • 奇函数：f(−x)  =  −f(x)，图象关于 原点对称。如 f(x) = x3、f(x) = 1/x。

判断三步：① 查定义域是否关于原点对称；② 算 f(−x)；③ 和 f(x) 比——相等是偶、相反是奇、都不是就非奇非偶。

常用小结论：奇函数若在 x = 0 有定义，则 f(0) = 0（因为 f(−0) = −f(0)，即 f(0) = −f(0)，得 f(0) = 0）。这是小题秒杀，但只对"奇函数且 0 在定义域里"成立。

【跟讲例题 3.4-1】 判断 f(x)  =  x3 + x 的奇偶性。 解：定义域 R，关于原点对称。f(−x)  =  (−x)3 + (−x)  =  −x3 − x  =  −(x3+x)  =  −f(x)。故为奇函数。（验证 f(0) = 0 ✓）

奇偶函数在对称区间上的单调性（苏州教研·专题6）：

  • 奇函数在关于原点对称的两个区间上，单调性相同；
  • 偶函数在关于原点对称的两个区间上，单调性相反。

偶函数的一个好用变形（苏州教研·专题7）：偶函数 f(x)  =  f(|x|)。解抽象不等式时，比如已知偶函数在 [0,+∞) 上递增，要解 f(x1)<f(x2)，直接翻成 |x1|<|x2| 来比大小，比分正负讨论快得多。

【跟讲例题 3.4-2】（苏州教研·专题7，原书p.33） 已知 f(x) 是定义在 R 上的偶函数，在 [0,+∞) 上是增函数，且 f(−1) = 0，求使 f(x)<0 成立的 x 的范围。 解：偶函数 f(1) = f(−1) = 0。在 [0,+∞) 上递增，f(x)<0 ⇒ 0≤x<1；由偶函数关于 y 轴对称，另一半 −1<x≤0。合起来 −1<x<1。 要点：偶函数 + 单调性，把正负两半对称拼起来；画个图（关于 y 轴对称）一眼就出。

小结：奇偶性先查定义域对称；偶函数对 y 轴、奇函数对原点；奇函数过原点则 f(0) = 0。

编者注·本质回扣：奇偶性看着是新东西，本质还是那条"输入→输出"规则的"对称脾气"。偶函数 f(−x) = f(x)，意思是你把输入换成它的相反数，输出原封不动——这条规则左右照镜子；奇函数 f(−x) = −f(x)，是输入翻号、输出也跟着翻号。所以本节开头先要求"定义域关于原点对称"，本质是：你想拿 −x 当输入，那 −x 必须本身就在定义域里，不然规则对它根本不适用。至于奇函数 f(0) = 0，也只是这个对称关系在 x = 0 处的必然结果，不是另外冒出来的新规矩。

3.5 最大值与最小值

定义：设 f(x) 定义域为 I。若存在实数 M，使 ① ∀x∈I 都有 f(x) ≤ M，② 存在 x0∈I 使 f(x0) = M，则 M 是最大值（最小值把 ≤ 改 ≥）。 注意最大值是个"能取到的高度"——既要是上界，又必须在某个 x0 处真的取到。

本章求法：二次函数配方找顶点；闭区间上画图象，比较端点和顶点。

  • 例：f(x) = x2−2x  =  (x−1)2−1，顶点 (1,−1)，在 R 上最小值 −1，无最大值。

【跟讲例题 3.5-1】 求 f(x) = x2−4x+3 在闭区间 [0, 3] 上的最值。 解：配方 f(x) = (x−2)2−1，顶点 x = 2 在 [0,3] 内，最小值 f(2) = −1。 再比端点：f(0) = 3，f(3) = 0。最大值是 max(3,0,−1) = 3。 故最小值 −1（x = 2），最大值 3（x = 0）。

小结：最值  =  "最上/最下的那个能取到的值"；闭区间上把极值和端点一起比。

3.6 分段函数

生活例子：出租车计费——3 公里内一个价，超过 3 公里另一个价。一个解析式写不下，就分几段写，每段一个范围配一个式子。

定义：在定义域的不同部分，有不同的对应关系，这样的函数叫分段函数。它是一个函数，不是几个函数。

要点：

  • 求 f(某值) 时，先看这个值落在哪个区间，再用对应那段的式子。
  • 画图象要分段画，注意每段端点是实心还是空心。

【跟讲例题 3.6-1】 设 f(x)  =  { x2, x<0 ; 2x+1, x≥0 }，求 f(−2)、f(0)。 解：−2 < 0，用第一段：f(−2) = (−2)2 = 4。0≥0，用第二段：f(0) = 2·0+1 = 1。

小结：分段函数是一个函数分区间用不同式子；求值先找区间。

3.7 函数图象的平移与翻折（苏州教研·专题5）

一句话记住：左加右减、上加下减。

  • 左右平移：y=f(x) 向右平移 a 个单位 → y=f(x−a)；向左 → y=f(x+a)。（左加右减：往左移就把 x 换成 x+a）
  • 上下平移：y=f(x) 向上平移 b 个单位 → y=f(x)+b；向下 → y=f(x)−b。（上加下减）

两种翻折：

  • y  =  |f(x)|：把 x 轴下方的图象"翻上来"（下往上翻），上方不动。
  • y  =  f(|x|)：保留 y 轴右边（x>0）的部分，再沿 y 轴对称出左边——它是个偶函数（右翻左）。

【跟讲例题 3.7-1】（苏州教研·专题2，原书p.14） 把 y = f(x) 的图象先向右平移 2 个单位、再向上平移 3 个单位，求新图象的解析式。 解：右移 2 → y = f(x−2)；再上移 3 → y  =  f(x−2) + 3。 要点：左右平移动的是 x（括号里"左加右减"），上下平移动的是整个函数值（"上加下减"）。

④ 例题详解（先做再看）

例题例 1（教材必修1 1.2 实例改编）：判断下列每组中的两个函数是否为同一函数： (1) f(x)  =  x，g(x)  =  √x · √x (2) f(x)  =  x2，g(t)  =  t2

自己做：看定义域 + 对应关系。

解： (1) 不是。f 的定义域 R；g(x)  =  √x·√x 定义域 x ≥ 0。定义域不同。 (2) 是。定义域都是 R，对应关系都是"平方"，字母不同不影响。 要点：先比定义域，再比对应关系。

例题例 2（求定义域）：求函数 f(x)  =  √(2 − x) + 1/(x − 1) 的定义域。

自己做：列出所有限制取交集。

解：2 − x ≥ 0 ⇒ x ≤ 2；x − 1 ≠ 0 ⇒ x ≠ 1。交集为 x ≤ 2 且 x ≠ 1，即 (−∞, 1) ∪ (1, 2]。 要点：取交集，不是取并集；端点写成区间时注意开闭。

例题例 3（用定义证明单调性）：证明 f(x)  =  x + 1/x 在区间 (1, +∞) 上单调递增。

自己做：严格按四步走。

证明：

  1. 取值：任取 x1, x2 ∈ (1, +∞)，x1 < x2。
  2. 作差：f(x1) − f(x2)  =  (x1 + 1/x1) − (x2 + 1/x2)  =  (x1 − x2) + (1/x1 − 1/x2)
  3. 变形： =  (x1 − x2) + (x2 − x1)/(x1x2)  =  (x1 − x2)(1 − 1/(x1x2))  =  (x1 − x2)(x1x2 − 1)/(x1x2)
  4. 定号：x1 < x2 ⇒ x1 − x2 < 0；x1, x2 > 1 ⇒ x1x2 > 1 ⇒ x1x2 − 1 > 0，且 x1x2 > 0。故 f(x1) − f(x2) < 0，即 f(x1) < f(x2)。 结论：f(x)  =  x + 1/x 在 (1, +∞) 上单调递增。 要点：作差后必须变形到能"由条件推出符号"的程度，变形不彻底是丢分主因。

例题例 4（奇偶性判断）：判断 f(x)  =  x3 + x 的奇偶性。

自己做：先看定义域，再算 f(−x)。

解：定义域 R，关于原点对称。f(−x)  =  (−x)3 + (−x)  =  −x3 − x  =  −(x3 + x)  =  −f(x)。故 f(x) 为奇函数。 要点：奇函数定义域含 0 时 f(0)  =  0（本题 f(0)  =  0 可作验证）。

⑥ 常见坑清单

  • 同一函数≠解析式长得像：先比定义域，再比对应关系。如 y  =  x 与 y  =  √(x2)：定义域都是 R（x2≥0 恒成立），但对应关系不同——√(x2)  =  |x|，前者值域 R、后者值域 [0, +∞)，所以不是同一函数。
  • "单调区间"要分开写：y  =  1/x 说"在 (−∞, 0) 和 (0, +∞) 上分别递减"，不能说"整个定义域递减"。
  • 奇偶性先查定义域：定义域不对称直接非奇非偶，别急着算 f(−x)。
  • f(0)  =  0 只对奇函数且 0 在定义域内成立，偶函数不适用。
  • 值域不是定义域：f(x)  =  x2 定义域 R、值域 [0, +∞)，别混。

函数的概念与三要素

函数三要素：定义域、对应关系、值域

  • 大白话x 取哪些值（定义域）、按什么规则算 y（对应关系）、算出哪些 y（值域）。
  • 用的时候：定义域是命门，一切问题先看 x 能取什么。

同一函数  =  定义域相同 且 对应关系相同

  • 大白话两个函数"x 的范围"和"算 y 的规则"都一样，才是同一个。
  • 用的时候：先比定义域再比对应关系；y=x 与 y=x2/x 不是同一函数（后者 x≠0）。
  • 记忆要点：字母用 x 还是 t 不影响。

垂直检验：函数图象与任意竖直线 x = m 至多一个交点（苏州教研·专题2）

  • 大白话一个 x 只能对应一个 y，竖直线切到两个点就不是函数图象。
  • 用的时候：给一张图判断它是不是函数，拿竖直线去扫一遍；点 (a,b) 在图象上 ⇔ f(a) = b。

定义域的求法

定义域红线：分母 ≠ 0；偶次根号内 ≥ 0；0 次幂底数 ≠ 0

  • 大白话分母不能为 0，根号里不能是负数，底不能为 0。
  • 用的时候：把每条红线列成不等式，全部取交集（不是并集），再写成区间。
  • 记忆要点：求定义域别先化简，约掉前的禁区要保留。

抽象函数定义域：盯住"被同一个 f 作用的对象范围相同"（苏州教研·专题2）

  • 大白话f(x) 定义域是 (a,b)，则 f(g(x)) 要求 a<g(x)<b；反过来 f(g(x)) 定义域是 (a,b)，则 f(x) 定义域是 g(x) 在 (a,b) 上的值域。
  • 用的时候：f(x) 定义域 (1,3) 求 f(2x+1) → 解 1<2x+1<3 得 (0,1)。
  • 记忆要点：括号里整体的范围  =  f 原本的定义域。

单调性

单调递增：x1<x2 ⇒ f(x1)<f(x2)

  • 大白话x 越大 y 越大，图象从左下走到右上。
  • 用的时候：定义法证单调按"取值—作差—变形—定号"四步走。

单调递减：x1<x2 ⇒ f(x1)>f(x2)

  • 大白话x 越大 y 越小。
  • 用的时候：断开的区间要分开说，如 y=1/x 在 (−∞,0) 和 (0,+∞) 上分别递减，不能说"整个定义域递减"。

奇偶性

偶函数：f(−x) = f(x)，图象关于 y 轴对称

  • 大白话左右翻折图象重合，如 f(x)=x2。
  • 用的时候：先查定义域是否关于原点对称，不对称直接非奇非偶。

奇函数：f(−x) = −f(x)，图象关于原点对称

  • 大白话转 180° 图象重合，如 f(x)=x3。
  • 用的时候：同样先查定义域对称；对称后算 f(−x) 跟 ±f(x) 比。

奇函数若在 x = 0 有定义，则 f(0) = 0

  • 大白话奇函数图象过原点。
  • 用的时候：小题秒杀结论；只对"奇函数且 0 在定义域内"成立，偶函数别套用。

奇函数对称区间单调性相同，偶函数对称区间单调性相反（苏州教研·专题6）

  • 大白话奇函数左右两半一增俱增；偶函数左右两半一增一减。
  • 用的时候：已知一半区间的单调性，推另一半；别记反。

偶函数 f(x) = f(|x|)；F(x) = f(x)+f(−x) 为偶，F(x) = f(x)−f(−x) 为奇（苏州教研·专题7）

  • 大白话偶函数问题翻成绝对值比大小；任何对称定义域的函数，加 f(−x) 是偶函数、减 f(−x) 是奇函数。
  • 用的时候：解抽象不等式 f(x1)<f(x2)（偶+单调）→ |x1|<|x2|；对数型函数判奇偶常用后一条。

图象的平移与翻折

左右平移左加右减、上下平移上加下减（苏州教研·专题5）

  • 大白话右移 a 把 x 换成 x−a，上移 b 整个函数加 b。
  • 用的时候：y = f(x) 右移 2、上移 3 → y = f(x−2)+3。
  • 记忆要点：左右动的是括号里的 x，上下动的是函数值整体。

y = |f(x)| 下往上翻；y = f(|x|) 右翻左（偶函数）（苏州教研·专题5）

  • 大白话|f(x)| 把负的图象翻到 x 轴上方；f(|x|) 留右半、沿 y 轴对称出左半。
  • 用的时候：见到套绝对值的函数，先想"翻折"而不是硬画。

二次函数与最值

二次函数顶点式 f(x) = a(x−h)2+k，顶点 (h,k)

  • 大白话配方后一眼看到最高点/最低点。
  • 用的时候：求最值先配方找顶点；a>0 开口向上有最小值，a<0 有最大值。

闭区间最值  =  区间内极值与端点值一起比

  • 大白话把山顶、山谷、两头的函数值摆一块，挑最大最小。
  • 用的时候：先看顶点在不在区间内，再算 f(端点)，三者比大小。

分段函数

分段函数：不同区间不同解析式，仍是一个函数

  • 大白话一个函数分几段写，每段一个范围配一个式子。
  • 用的时候：求 f(某值) 先看它落在哪段，再套那段的式子；画图注意端点实心空心。

高级方法·进阶

本章对应方法手册：无直接对应压轴章节（函数概念与性质是基础章，《不超纲高级方法手册》的"函数与导数"方法要等学完第 05 章导数才用得上）。这里补两个课标内、可放心用的小技巧：

进阶 1：复合函数单调性"同增异减"（不超纲，高考可放心用）

  • 适用信号：看到 f(g(x)) 这种"套两层"的函数要判断单调区间。
  • 操作步骤：① 拆成内函数 u=g(x)、外函数 y=f(u)；② 各自判断单调性；③ 内外同方向→增，反方向→减（同增异减）。
  • 例：y=1/(x2)，内 u=x2 在 (0,+∞) 增，外 y=1/u 减，方向相反→复合后在 (0,+∞) 减。
  • 依据：单调性定义（课标内）。✓ 不超纲。

进阶 2：奇函数+区间对称的最值"配对"（不超纲，高考可放心用）

  • 适用信号：奇函数 f(x) 在 [−a,a] 上的最大值为 M，求最小值。
  • 结论：奇函数在对称区间上，最大值 M 与最小值 m 满足 M + m = 0。因为最高点和最低点关于原点对称。
  • 依据：奇函数图象关于原点对称（课标内）。✓ 不超纲。
  • 注意：这条只对奇函数成立，偶函数没有这个配对关系。

课后习题答案

自测答案：1. x ≥ −1 且 x ≠ 3，即 [−1, 3) ∪ (3, +∞)；2. 是同一函数（y  =  x2，展开后定义域均为 R）；3. 取值作差：f(x1) − f(x2)  =  2(x1 − x2) < 0 ⇒ 递增；4. f(−x)  =  x2 − x ≠ f(x) 且 ≠ −f(x)，非奇非偶；5. f(−2)  =  −5（奇函数 f(−x)  =  −f(x)）。

A 组答案

A 组

  1. B。A 中 g(x)=x2/x 定义域 x≠0，与 f(x)=x 不同；C 中 g(x)=(√x)2 定义域 x≥0，不同；D 中 g(x)=x0 定义域 x≠0，不同。只有 B：f(x)=|x| 与 g(x)=√(x2)=|x|，都是 R 上取绝对值，同一函数。
  2. (1) [−2, 5)；(2) (−∞, 3]；(3) (0, +∞)。
  3. x+2≥0 ⇒ x≥−2；x−1≠0 ⇒ x≠1。取交集：[−2, 1) ∪ (1, +∞)。
  4. C。y=1/x 在 (−∞,0) 和 (0,+∞) 上分别递减，不能合并写成"在定义域上递减"。
  5. 定义域 R 对称。f(−x)=2(−x)2+1=2x2+1=f(x)，故为偶函数。
  6. f(x)=(x−1)2+1 ≥ 1，当 x=1 取到，最小值为 1。

B 组答案

B 组

  1. 任取 x1<x2。f(x1)−f(x2)=(−2x1+3)−(−2x2+3)=−2(x1−x2)。因 x1<x2，x1−x2<0，故差=−2(负)>0，即 f(x1)>f(x2)，递减。
  2. 奇函数 f(−3)=−f(3)=−(−5)=5。f(0) 存在则 f(0)=0。
  3. −1≤0 用第一段：f(−1)=−1+1=0；2>0 用第二段：f(2)=4。f(x)=1：x≤0 段 x+1=1⇒x=0；x>0 段 x2=1⇒x=1。故 x=0 或 x=1。
  4. f(x)=(x−1)2−1，顶点 x=1 在 [0,3] 内，f(1)=−1（最小）。端点 f(0)=0，f(3)=3。最大 3，最小 −1。

C 组答案

C 组

  1. 定义域 (2x−1)/(2x+1)>0 ⇒ x>1/2 或 x<−1/2，关于原点对称。f(−x)=(−x+a)·ln((−2x−1)/(−2x+1))=(a−x)·ln((2x+1)/(2x−1))=(a−x)·(−ln((2x−1)/(2x+1)))=(x−a)·ln((2x−1)/(2x+1))。偶函数要求 f(−x)=f(x)，即 (x−a)=(x+a)，得 a=0。选 B。
  2. 左段 f=−x2−2ax−a=−(x+a)2+a2−a，开口向下，对称轴 x=−a。要在 (−∞,0) 递增，需 0≤−a 即 a≤0。两段在衔接处要"左段右端 ≤ 右段左端"：f(0−)=−a ≤ f(0+)=e0+ln1=1，即 a≥−1。合起来 −1≤a≤0，选 B。
  3. 由 f(x)>f(x−1)+f(x−2) 且 f(0)=0,f(1)=1,f(2)=2，f 至少按斐波那契速度增长：f(20) 下界约 10953>1000，故 f(20)>1000 一定成立。A、C 的 f(10) 下界约 89，不能断定 >100 或 <1000；D 说 f(20)<10000，但下界已超 10000，不成立。选 B。

一通百通

这一章的"通用骨架"是三步：① 先圈定义域（把分母≠0、根号内≥0 这些红线列成不等式取交集）→ ② 再把规则 f(x) 用起来（求代数值按区间套式子，证单调按"取值—作差—变形—定号"，判奇偶先查对称再算 f(−x)）→ ③ 最后借单调和奇偶把结论读出来。高考里不管是求定义域、证单调、判奇偶还是比大小，本质都是这三步的排列组合：先定 x 的活动范围，再对规则动手，最后让性质帮你读数。会解一道函数性质题，就会解这一类；这套"定义域先行"的骨架，后面 03 章指对函数、04 章零点、05 章导数题里还会反复用。

跨章结合

  • 02 的"奇偶性定义 + 定义域对称" 碰 03 章对数真数条件：题目把对数嵌进函数里考奇偶，典型如 2023 新高考Ⅰ卷 T4（f(x)=(x+a)·ln((2x−1)/(2x+1)) 为偶函数求 a）。想通了就知道：第一步永远是先让真数>0 把定义域求出来、看它是否关于原点对称（这是 03 的规矩），第二步才按 f(−x)=f(x) 对比系数（这是 02 的规矩）。参数 a 是两条规矩碰出来的，不是背出来的。
  • 02 的"取值—作差—定号判单调" 碰 05 章导数：导数题第 1 问求单调区间、求最值，本质还是 02 章那套"x 变大时 y 涨还是跌"，只是把"作差变形定号"换成"求 f′(x) 看正负"（综合原理说明，非真题）。想明白这一点，05 章的导数就不是一座全新的山，而是 02 单调性的更快算法。

本章接在第 01 章集合之后：01 章教会你"用区间和集合写范围"，本章把这套语言第一次用到主角身上——函数的定义域、值域、单调区间全是 01 章那套区间记号。本章是整个函数板块的地基：后面第 03 章指对幂函数、第 04 章零点与方程、第 05 章导数，都是先拿本章的"定义域、单调、奇偶"去套一个具体的新函数；第 06 章三角函数、第 11 章数列、第 12 章不等式里见到的"函数性质"，判断套路也都是本章这一套。学完本章，你手里有了一套"研究任何一个新函数"的通用动作。

高考怎么考

本章在新高考Ⅰ卷里以函数性质小题为主，位置在选择题中段：2023 卷 T4（含参奇偶性）、2024 卷 T6（分段函数单调衔接）、2024 卷 T8（函数递推与增长）都是本章地盘。考法套路固定：先卡定义域（分母、根号），再用单调与奇偶去比大小、求参数范围、判对称。难度从中档到压轴小题都有，特点是"不算难但容易在定义域端点开小差"——本章练熟的"定义域先行"，就是为了不在这几题上丢不该丢的分。
