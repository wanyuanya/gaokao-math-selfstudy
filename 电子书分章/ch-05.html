本章本质核心：导数的本质是"瞬时变化率"——它就是曲线在某一点的切线斜率，一个数。本章从切线方程、单调区间、极值、最值，到恒成立、端点效应、切线放缩，全都是这一个原理的变体：算出 f′(x) 这个"斜率函数"，再看它的正负号，就回答了一切问题——斜率正就涨、斜率负就跌、斜率由正转负就是山顶、斜率贴着曲线就是切线。

为什么有用想通了"导数就是斜率、斜率正负就是升降"这一件事，你就不用背"单调区间怎么求、极值怎么判、切线怎么写"——拿到任何函数，求一次导、看符号，单调、极值、最值、切线全自己长出来；高考导数解答题第一问，就是这条原理的直接套用。

3.1 导数的定义与几何意义

先讲一个生活问题。 一辆车从静止出发，第 3 秒末车速表指到 60 km/h——这个"第 3 秒末的速度"叫瞬时速度。它怎么算？你可以算前 1 秒的平均速度（第 2 秒到第 3 秒），再算前 0.1 秒、0.01 秒的平均速度……时间间隔越短，平均速度越接近那个"瞬时速度"。导数就是这个"无限短时间内的平均变化率"。

定义：函数 y = f(x) 在 x0 处的导数 f′(x0)  =  lim(Δx→0) [ f(x0+Δx) − f(x0) ] / Δx。 即：增量比 [f(x0+Δx)−f(x0)]/Δx 当 Δx 无限趋近 0 时的极限。

几何意义：f′(x0) 就是曲线 y = f(x) 在点 (x0, f(x0)) 处切线的斜率。割线两端靠近时，割线就变成切线。

切线方程：y − f(x0)  =  f′(x0)(x − x0)（点斜式）。

正负含义：f′(x0)>0 → 该点附近函数在上升；f′(x0)<0 → 在下降；f′(x0) = 0 → 该处是水平切线（往往是山顶或山谷）。

【跟讲例题 3.1-1】 用定义求 f(x) = x2 在 x = 1 处的导数。 解：[f(1+Δx)−f(1)]/Δx  =  [(1+Δx)2−1]/Δx  =  [1+2Δx+Δx2−1]/Δx  =  (2Δx+Δx2)/Δx  =  2+Δx。 令 Δx→0，极限为 2。故 f′(1) = 2。（和后面公式法 (x2)′ = 2x 在 x = 1 得 2 一致。）

小结：导数  =  瞬时变化率  =  切线斜率；定义就是"增量比取极限"。

编者注·本质回扣：你可能觉得"瞬时速度""切线斜率""增量比取极限"是三个不相干的说法，其实它们是同一件事的三张脸——这正是本章的纲。为什么导数能同时管"速度"和"坡度"？因为变化率的本质就是"走一小步，函数值跟着变多少"：时间走一小步、路程变多少，就是瞬时速度；x 走一小步、y 变多少，就是切线斜率。切线方程里的 f′(x0)、正负含义里的"上升/下降"，都是从这一个斜率里长出来的。先把这张脸记牢，后面看单调、找山顶，不过是把"某一点的斜率"升级成"整个区间的斜率正负"而已。

3.2 基本求导公式与四则运算法则

为什么有公式？ 每道题都用定义取极限太累，数学家把常见函数的导数算好了，制成表，直接查。这一节的 8 个公式考试不给，必须背熟。

基本求导公式（必背表）：

C（常数） 0 常数不变，变化率 0
xn n·xn−1 指数搬下来，指数减 1
sin x cos x
cos x −sin x 余弦求导带负号
ex ex 最"自恋"，求导不变
ax ax·ln a 比 ex 多个 ln a
ln x 1/x
logax 1/(x·ln a)

四则运算法则：

记住它之前先看懂它：这几条不是要背的咒语——和差最好说，各求各的再加减就行；积为什么要拆成"前导后不导 + 前不导后导"？因为两个函数一起涨，乘积的增量得两边分摊；商和复合同理，本质都是"增量比取极限"拆开后的必然结果，链式法则就是"外层斜率乘以内层斜率"，一环扣一环。

  • 和差：[f ± g]′  =  f′ ± g′。
  • 积：[f·g]′  =  f′g + fg′。
  • 商：[f/g]′  =  (f′g − fg′)/g2（g≠0）。
  • 复合（链式）：[f(g(x))]′  =  f′(g(x))·g′(x)。例：(e^(2x))′  =  e^(2x)·2  =  2e^(2x)。

【跟讲例题 3.2-1】 求 f(x) = x3+2x2−5 的导数。 解：逐项求导 (x3)′ = 3x2；(2x2)′ = 4x；(−5)′ = 0。f′(x) = 3x2+4x。

【跟讲例题 3.2-2】 求 f(x) = x·ex 的导数。 解：用积法则：f′ = (x)′ex+x(ex)′  =  1·ex+x·ex  =  (1+x)ex。

易错点：(ax)′ = ax·ln a，只有 ex 求导没有 ln a 系数；(1/x)′ = −1/x2，别漏负号。

小结：公式查表 + 四则法则；和差逐项、积商套法则、复合层层乘。

3.3 导数与单调性（核心用法）

这是导数最值钱的用法。 第 02 章用定义作差证明单调，对稍微复杂的函数就很费劲；有了导数，看 f′ 的正负就行。

定理：在区间 D 上：

  • f′(x) > 0 ⇒ f(x) 在 D 上单调递增；
  • f′(x) < 0 ⇒ f(x) 在 D 上单调递减；
  • f′(x) ≥ 0 且不恒为 0 ⇔ f(x) 单调递增。

求单调区间标准流程（大题四步）：

  1. 写定义域（千万别忘，ln x、1/x 都有坑）；
  2. 求 f′(x)，整理成因式乘积；
  3. 解 f′(x)>0 和 f′(x)<0（找 f′ = 0 的根，穿根法判号）；
  4. 在定义域内写出增、减区间。

【跟讲例题 3.3-1】 求 f(x) = x3−3x 的单调区间。 解：f′(x) = 3x2−3 = 3(x−1)(x+1)。f′>0 ⇔ x<−1 或 x>1；f′<0 ⇔ −1<x<1。 故递增区间 (−∞,−1)、(1,+∞)；递减区间 (−1,1)。

小结：单调区间  =  f′ 判号；先定义域，再穿根，后写区间。

3.4 极值与最值

山顶山谷的数学刻画。 沿函数图象走，走到最高的那个"山头"就是极大值，最低的"山谷"就是极小值。

极值点判定：若 f′(x0) = 0，且 f′ 在 x0 左右变号：

  • 左正右负 → 极大值点；
  • 左负右正 → 极小值点。

注意：f′(x0) = 0 不一定是极值点！如 f(x) = x3，f′(0) = 0，但两侧导数同号（都正），x = 0 不是极值点。变号才是关键。

闭区间最值：把区间内所有极值点的函数值，和两个端点值一起比，最大的是最大值、最小的是最小值。

【跟讲例题 3.4-1】 求 f(x) = x3−3x 在 [−2,2] 上的最值。 解：f′ = 3(x−1)(x+1) = 0 ⇒ x = −1, 1。列表：f(−2) = −2，f(−1) = 2（极大），f(1) = −2（极小），f(2) = 2。 比较：最大 2，最小 −2。

小结：极值看 f′ 变号；闭区间最值  =  极值和端点一起比。

编者注·本质回扣：这一节把"山顶山谷"算出来，本质还是上一条"斜率正负"的主线。为什么 f′(x)>0 就递增？因为斜率为正，曲线每走一小步都往上抬，一路抬上去自然就是增；斜率为负就是一路往下走。为什么 f′(x0) = 0 还不够、非要左右变号才算极值点？因为 f′ = 0 只说明那一点是水平的，可能像 x3 在原点那样"平一下又接着往上走"，并没有真正掉头；左右坡度一反一正，才是真的到了山顶或山谷。闭区间最值也顺理成章：把山顶、山谷、两个端点的函数值摆在一起挑最大最小即可。

3.5 恒成立问题与分离参数

高考大题第 2 问常客。 "对所有 x，a ≤ f(x) 恒成立，求 a 的范围"——怎么转成最值？

口诀：

  • a ≤ f(x) 恒成立 ⇔ a ≤ f(x) 的最小值；
  • a ≥ f(x) 恒成立 ⇔ a ≥ f(x) 的最大值。

分离参数法：把 a 单独分到不等式一边，变成 a ≤ g(x)，再求 g(x) 的最值。

【跟讲例题 3.5-1】 对 ∀x>0，x−lnx ≥ a 恒成立，求 a 的最大值。 解：设 g(x) = x−lnx，g′ = 1−1/x = (x−1)/x。x∈(0,1) 减、(1,+∞) 增，g_min = g(1) = 1。故 a≤1，a 最大值 1。

小结：恒成立 → 分离参数 → 求最值；a≤f 就找 f 的最小值。

3.6 补：苏州书两条压轴恒成立经验

以下两条来自（苏州教研·专题51），是高考导数解答题第 2 问最常见的两类"恒成立求参"套路，先记结论，例题见本节末 例4–例6 与课后 C 组 14–17。

经验一：双变量绝对值恒成立 → 凑出一个单调函数（苏州教研·专题51，题型1）。 题设形如 |f(x1)−f(x2)| ≥ λ|g(x1)−g(x2)| 对区间内任意两点恒成立，其中 g(x) 常取 x、x2、ex、lnx 这类单调简单函数。

方法：不妨先令 x1<x2，去绝对值、移项，把它凑成 f(x1)−λg(x1) ≤ f(x2)−λg(x2) 的样子。 这等价于 h(x) = f(x)−λg(x) 在区间上单调递增（或 h(x) = f(x)+λg(x) 单调递减），再用 h′(x) = f′(x)±λg′(x) 的符号分离参数求最值。 大白话："两点函数值之差要被自变量之差管住"，本质就是让 f 加上（或减去）λg 之后变成单调函数。

经验二：∀x≥p 时 f(x)≥0 恒成立 → 端点效应 / 含参转化（苏州教研·专题51，题型7）。 当端点处恰好 f(p) = 0 时，先算 f′(p)、f″(p) 的符号来定分类标准；一次求导定不了号就二次求导，用 f″ 的含参端点（如 f″(0) = 1−2a）当分界，再分两类说清：函数单调时成立，函数不单调时必在小区间 (p, p+δ) 内破掉。

小技巧（苏州教研·专题51）：如果由 f′(p) = 0 或 f″(p) = 0 能直接解出参数的值，这个值就是分类讨论的分界点。

④ 例题详解（先做再看）

例题例 1（切线）：求曲线 y  =  x3 在点 (1, 1) 处的切线方程。

自己做：斜率  =  导数值。

解：y′  =  3x2，f′(1)  =  3。切线：y − 1  =  3(x − 1)，即 y  =  3x − 2。 要点：切线  =  点斜式，先算斜率再写直线。

例题例 2（单调区间 + 极值 + 最值，大题模板）：设 f(x)  =  x3 − 3x。 (1) 求单调区间；(2) 求极值；(3) 求 f(x) 在 [−2, 2] 上的最值。

自己做：求导 → 解 f′(x)  =  0 → 列表。

解：(1) f′(x)  =  3x2 − 3  =  3(x − 1)(x + 1)。 f′(x) > 0 ⇔ x < −1 或 x > 1；f′(x) < 0 ⇔ −1 < x < 1。 递增区间 (−∞, −1)、(1, +∞)；递减区间 (−1, 1)。 (2) x  =  −1 处左增右减 → 极大值 f(−1)  =  2；x  =  1 处左减右增 → 极小值 f(1)  =  −2。 (3) 比较端点 f(−2)  =  −2、f(2)  =  2 与极值 ±2：最大 2（x  =  −1 或 2），最小 −2（x  =  −2 或 1）。 要点：列表（区间/符号/结论）是大题标准书写，别跳步。

例题例 3（恒成立 → 最值）：若对 ∀x > 0，x − ln x ≥ a 恒成立，求 a 的最大值。

自己做：恒成立问题转成求 g(x)  =  x − ln x 的最小值。

解：设 g(x)  =  x − ln x，g′(x)  =  1 − 1/x  =  (x − 1)/x。 x ∈ (0, 1)：g′ < 0 递减；x ∈ (1, +∞)：g′ > 0 递增。g_min  =  g(1)  =  1。 a ≤ 1 恒成立 ⇔ a 最大值为 1。 要点：恒成立 a ≤ g(x) ⇔ a ≤ g(x) 的最小值；"分离参数"是最常用手法。

例题例 4（必要性探路 / 端点效应）（苏州教研·专题51，原书p.170，例12）：设 f(x) = ex−1−x−ax2，若当 x≥0 时 f(x)≥0 恒成立，求 a 的取值范围。

自己做：注意 f(0) = 0，端点处"恰好贴地"，先二次求导。

解：f′(x) = ex−1−2ax（x≥0），f″(x) = ex−2a，f″(0) = 1−2a。 - 当 1−2a≥0，即 a≤1/2 时，f″(x)≥0，故 f′(x) 在 [0,+∞) 递增，f′(x)≥f′(0) = 0，于是 f(x) 递增，f(x)≥f(0) = 0，恒成立； - 当 1−2a<0，即 a>1/2 时，f″(x) = ex−2a = 0 的根为 x = ln(2a)，在 [0,ln(2a)] 上 f″≤0，f′ 递减，f′(x)≤f′(0) = 0，于是 f(x) 递减，f(x)≤f(0) = 0，在 (0,ln2a) 内必破，不成立。 故 a≤1/2。 要点：端点 f(0) = 0 时，用 f″(0) = 1−2a 的正负一刀切开分类；a = 1/2 时 ex−1−x−x2/2≥0（x≥0）可由再求导验证（h″ = ex−1≥0）。

例题例 5（极值点偏移 / 比值代换）（苏州教研·专题51，原书p.177，例25）：设 f(x) = lnx−ax2−bx 的图象与 x 轴交于 A(x1,0)、B(x2,0) 两点，线段 AB 中点为 C(x0,0)。求证：f′(x0)<0。

自己做：两个零点满足 f(x1) = f(x2) = 0，把 a、b 消掉，再令 t = x2/x1。

解：f′(x) = 1/x−2ax−b，x0 = (x1+x2)/2，故 f′(x0) = 2/(x1+x2)−a(x1+x2)−b。 由 ln x1 = ax12+bx1、ln x2 = ax22+bx2，两式相减得 ln(x1/x2) = (x1−x2)[a(x1+x2)+b]，即 a(x1+x2)+b = [ln(x1/x2)]/(x1−x2)。 代回： f′(x0) = 2/(x1+x2) − [ln(x1/x2)]/(x1−x2)  =  1/(x1−x2)·[ 2·(x1−x2)/(x1+x2) − ln(x1/x2) ]。 不妨令 x2>x1>0，记 t = x2/x1>1，则括号内  =  2(1−t)/(1+t)+lnt。 设 h(t) = 2(1−t)/(1+t)+lnt（t>1），则 h′(t) = (t−1)2/[t(t+1)2]>0，h(t) 在 (1,+∞) 递增，h(t)>h(1) = 0。 又 x1−x2<0，故 f′(x0) = [1/(x1−x2)]·h(t)<0。∎ 要点：两零点问题先联立消参，再令 t = x2/x1 把双变量化成单变量 t；h(t) 的符号由导数定。

例题例 6（隐零点 / 设而不求）（苏州教研·专题51，原书p.174–175，例21）：已知 f(x) = [1+ln(x+1)]/x。当 x>0 时，f(x)>k/(x+1) 恒成立，求正整数 k 的最大值。

自己做：分离 k 后求最小值，最小值的零点解不出来，就设出来整体代换。

解：x>0 时 f(x)>k/(x+1) ⇔ k < (1+1/x)[1+ln(x+1)]。记 h(x) = (1+1/x)[1+ln(x+1)]（x>0），则 h′(x) = [x−1−ln(x+1)]/x2。记分子 p(x) = x−1−ln(x+1)，p′(x) = 1−1/(x+1) = x/(x+1)>0，p 递增。 注意到 p(2) = 1−ln3<0，p(3) = 2−ln4>0，故存在唯一 x0∈(2,3) 使 p(x0) = 0，即 ln(x0+1) = x0−1。h(x) 在 (0,x0) 减、(x0,+∞) 增，最小值 h(x0) = (1+1/x0)[1+ln(x0+1)]  =  (1+1/x0)·x0  =  x0+1 ∈(3,4)。 要 k<h(x) 恒成立，k 须小于 h 的下确界（介于 3 与 4 之间），故正整数 k 最大值为 3。 要点：f′(x) = 0 的根 x0 解不出显式，就设为 x0，用 p(x0) = 0（即 ln(x0+1) = x0−1）整体代换，把 h(x0) 化简成 x0+1，再由 x0∈(2,3) 估值。

⑥ 常见坑清单

  • 极值点 ≠ 导数为零的点：f′(x0)  =  0 是必要条件，两侧必须变号。
  • 定义域先行：f(x)  =  x − ln x 定义域 (0, +∞)，求导后写单调区间不能超出定义域。
  • 切线在"点 (x0, f(x0))"处：切点必须在曲线上；若说"过某点"则可能切点不已知，要设切点。
  • (1/x)′  =  −1/x2，不是 1/x2。
  • (ax)′  =  ax·ln a，只有 (ex)′  =  ex 没有系数。
  • 恒成立：a ≤ g(x) 恒成立 ⇔ a ≤ g(x)_min；a ≥ g(x) 恒成立 ⇔ a ≥ g(x)_max。

导数的定义与几何意义

f′(x0)  =  lim(Δx→0) [f(x0+Δx)−f(x0)]/Δx

  • 大白话无限短时间内的平均变化率，就是瞬时变化率。
  • 用的时候：用定义求导就按"算增量比 → 让 Δx→0"。

几何意义：f′(x0)  =  切线斜率；切线方程 y−f(x0) = f′(x0)(x−x0)

  • 大白话导数就是曲线在那一点切线的坡度。
  • 用的时候：求切线先算导数值当斜率，再用点斜式写方程。

基本求导公式（必背）

(C)′ = 0

  • 大白话常数不变，变化率为 0。

(xn)′ = n·xn−1

  • 大白话指数搬下来，指数减 1。
  • 用的时候：如 (x3)′=3x2，(x4)′=4x3。

(sin x)′ = cos x，(cos x)′ = −sin x

  • 大白话正弦求导变余弦，余弦求导带个负号变正弦。

(ex)′ = ex

  • 大白话e 的 x 次方求导还是自己，最"自恋"。

(ax)′ = ax·ln a

  • 大白话比 ex 多个 ln a 系数。
  • 用的时候：只有 ex 没有 ln 系数，别多写。

(ln x)′ = 1/x

  • 大白话自然对数求导是倒数。

(logax)′ = 1/(x·ln a)

  • 大白话一般对数求导多个 ln a 在分母。

四则运算与复合

和差：[f±g]′ = f′±g′

  • 大白话逐项求导再加减。

积：[f·g]′ = f′g+fg′

  • 大白话前导后不导 + 前不导后导。
  • 用的时候：如 (x·ex)′=ex+x·ex=(1+x)ex。

商：[f/g]′ = (f′g−fg′)/g2

  • 大白话分子是"上导下不导 − 上不导下导"，分母是下的平方。
  • 用的时候：g≠0；如 (lnx/x)′=(1−lnx)/x2。

复合：[f(g(x))]′ = f′(g(x))·g′(x)

  • 大白话外层求导乘以内层求导，链式一路乘下去。
  • 用的时候：如 (e^(2x))′=e^(2x)·2=2e^(2x)。

导数与单调性

f′(x)>0 ⇒ 增；f′(x)<0 ⇒ 减

  • 大白话导数正函数涨，导数负函数跌。
  • 用的时候：求单调区间先写定义域，再求导判号；f′≥0 且不恒为 0 才是增。

极值与最值

极值点：f′(x0) = 0 且两侧 f′ 变号

  • 大白话导数为零还不够，左右坡度得一反一正才是山顶/山谷。
  • 用的时候：左正右负是极大、左负右正是极小；f′(x0)=0 但不变号（如 x3 在 0）不是极值。

闭区间最值  =  区间内极值与端点值一起比

  • 大白话把山顶、山谷、两头的函数值摆一块挑最大最小。

恒成立问题

a≤f(x) 恒成立 ⇔ a≤f(x)_min；a≥f(x) 恒成立 ⇔ a≥f(x)_max

  • 大白话要 a 永远不超过 f，a 最多只能等于 f 的最小值。
  • 用的时候：分离参数把 a 单独放一边，再求另一边函数的最值。

∀x≥p 时 f(x)≥0 恒成立，且端点 f(p) = 0 ⇒ 先看 f′(p)、f″(p) 定分界（端点效应）（苏州教研·专题51，题型7）

  • 大白话函数在起点"贴地"时，拿二阶导数在起点的值当分类分界，一刀切开参数范围。
  • 用的时候：f″(p) 含参，令 f″(p) = 0 解出的那个参数值就是分类标准；a 比它小就单调成立，比它大必在 (p,p+δ) 内破。

|f(x1)−f(x2)|≥λ|x1−x2| 恒成立 ⇔ h(x) = f(x)±λx 单调（苏州教研·专题51，题型1）

  • 大白话两点函数值之差要被 x 之差"管住"，就把 f 加/减 λx 凑成单调函数。
  • 用的时候：去绝对值移项凑成 f(x1)−λx1≤f(x2)−λx2，再对 h′(x) = f′(x)±λ 分离参数。

切线放缩不等式族（苏州教研·专题51）

ex ≥ x+1（x = 0 取等）；lnx ≤ x−1（x = 1 取等）；ln(1+x) ≤ x（x = 0 取等）

  • 大白话指数甩成一次式、对数压成一次式，等号都贴在切点上。
  • 用的时候：证含 ex、lnx 的不等式时，先用它们把超越项"砍"成多项式，再解普通不等式。
  • 记忆要点：每条都是"曲线 ≥ 切线"或"曲线 ≤ 切线"，等号点就是切点 x=0 或 x=1。

ex ≥ 1+x+x2/2（x≥0，x = 0 取等）（苏州教研·专题51，例12/例27）

  • 大白话要更紧的放缩时，把二次项也补上；可由两次求导证（h″ = ex−1≥0）。
  • 用的时候：直接放 ex≥x+1 太松时换这条；答题卡上引用要补一句"可由导数证明"。

进阶 1：同构法（手册 一.1.1）

  • 适用信号：f′(x)=0 解不出显式根，但必须用这个零点代值。
  • 操作步骤：设零点为 x0，满足 f′(x0)=0，把这个关系当方程整体代入消元，不硬求 x0。
  • 例题：证 f(x)≥0 时，f′(x0)=0 解不出，用它把 f(x0) 化简成常数。
  • 课标依据：零点存在+整体代换。✓ 不超纲。

进阶 4：切线放缩（手册 一.1.4）

  • 适用信号：证 ex≥…、lnx≤… 这类指数/对数不等式。
  • 操作步骤：记住两条放缩——ex ≥ x+1（等号 x=0）、lnx ≤ x−1（等号 x=1），用它们把指对数"放"成多项式。

  • 课标依据：导数求最值。✓ 不超纲（高考可直接用结论）。

  • 例题：∀x≥0, f(x)≥0，先代 x=0 得 a 的必要约束。
  • 课标依据：恒成立+特殊值。✓ 不超纲（但严格证明仍需导数）。

进阶 6：双变量问题（手册 一.1.6）

  • 适用信号：题里同时出现 x1、x2 两个变量。
  • 操作步骤：把双变量的对称式设成一个新变量 t=x2/x1 或 t=x1+x2，转成单变量函数。

1.1 同构思想 —— 把"两个变量"变"一个函数"

大白话·本质一句话：同构  =  发现不等式左右两半其实是"同一个函数 f 穿了两件不同的外套"，先脱外套、比里面 f 的单调性，再把 f 这层壳一拆，两个变量就变回一个。

  • 适用信号：不等式或方程两侧结构一模一样，只是变量不同（如 x·ex 与 lnx·x 同型、x+lnx 与 ex+x 同型）。
  • 操作步骤： 1. 把式子变形，让两侧都长成 f(外层) 和 f(内层) 的形式； 2. 判断 f 的单调性（先求导确认）； 3. 由 f(A) ≤ f(B) 且 f 单调 → 推出 A ≤ B（单调增）或 A ≥ B（单调减），把超越式化成普通式。
  • 常用同构模板：x·ex ↔ lnx·x（即 x·ex  =  e^(x+lnx)，与 x+lnx 同构）；x/ex ↔ lnx/x；x-lnx ↔ ex-x。
  • 例题：2022新高考Ⅰ卷第22题、第7题（0.1e^0.1 与 ln0.9 比较大小，同构+放缩）。配套讲义《2022新高考I卷函数压轴多角度解析_同构》。
  • 课标依据：函数单调性定义与复合函数单调性（必修一第三章）。✓ 不超纲。
  • 注意：同构的关键是"脱壳"后别忘定义域；构造失败就换另一个同构式。
  • （与本章前述"进阶 1：同构法"及课后 C 组 14 处例题联动——该题答案 a≤−1/2 即本思想的一次完整落地。）

1.2 极值点偏移 —— 压轴出现率最高的一类

大白话·本质一句话：极值点偏移的本质是图象左右不对称——函数在顶点 x0 两边"胖瘦不一"，两个零点的中点不一定正好压在 x0 上；先画草图看曲线是往左歪还是往右歪，就知道该证 x1+x2>2x0 还是 <2x0，再把右边那半折过来比大小。

  • 适用信号：f(x1) = f(x2)，x0 是极值点，要证 x1+x2 > 或 < 2x0（或 x1x2 与 x02 比大小）。
  • 操作步骤（对称化构造法）： 1. 不妨设 x1<x0<x2； 2. 构造函数 F(x) = f(x)-f(2x0-x)（把 x2 对称到 2x0-x2 一侧）； 3. 证明 F(x) 在 (x1,x0) 定号（求导），推出 f(x1) 与 f(2x0-x2) 的大小关系； 4. 利用 f(x1) = f(x2) 与单调性，得出 x2 与 2x0-x1 的关系 → 结论。
  • 变体：比值代换法（令 t = x1/x2，把双变量化成单变量 t），适用于对称化做不动的题。
  • 例题：2022新高考Ⅰ卷压轴（导数双零点）。配套《导数综合讲义_极值点偏移隐零点凹凸反转》第10.8讲、《极值点偏移与拐点偏移讲义》见素材清单链接。

1.3 隐零点 —— "设而不求"的巅峰应用

大白话·本质一句话：隐零点  =  那个"让导数为零的点"长得太丑、写不出具体数字，但它确实存在；那就大方给它起个名字 x0，不求它的值，只拿"f'(x0) = 0"这个关系当一把钥匙，把原函数里的 ex、lnx 换掉化简——设而不求，用完就走。

  • 适用信号：求导后 f'(x) = 0 的根解不出来，但知道它存在（零点存在定理）。
  • 操作步骤： 1. 设隐零点 x0（x0 满足 f'(x0) = 0，写"由零点存在定理，存在唯一 x0∈(a,b) 使 f'(x0) = 0"）； 2. 把 f'(x0) = 0 这个等式反代回原函数（消掉 ex 或 lnx 项，把超越式化成代数式）； 3. 研究 F(x0)（原函数在极值点取值）时，利用第2步的等式化简； 4. 估值时用放缩（见 1.4）夹出 x0 的范围。
  • 课标依据：零点存在定理+导数（必修一第四章、选必二第五章）。✓ 不超纲。
  • 例题：历年导数恒成立压轴（如"求 a 使 f(x)≥0 恒成立，其中 f 含 ex、lnx 且不可解"）。配套《隐零点的替代以及放缩法(北京考试报)》。
  • 注意：隐零点的核心是"等式代换"，不是真的求出 x0。
  • （与本章前述"进阶 3：隐零点"及例 6 处例题联动——例 6 正整数 k 最大值 3，就是靠 ln(x0+1) = x0−1 整体代换出来的。）

1.4 切线放缩（超越不等式族）—— 比较大小与证明的利器

大白话·本质一句话：切线放缩  =  曲线永远贴着它的切线上方（或下方），那就干脆拿那条一次切线代替弯弯绕绕的曲线来算——ex 太高了就砍成 x+1，lnx 太大了就压成 x−1，先把"看不懂的曲线"换成"算得动的直线"，解完再回头看要不要收紧。

核心不等式（先背会，用前能证）：

ex ≥ x+1（x = 0 取等） - 变式：ex ≥ ex（x = 1 取等）；ex ≥ 1+x+x2/2（x≥0）。

lnx ≤ x−1（x = 1 取等） - 变式：lnx ≤ x/e（x = e 取等）；1−1/x ≤ lnx（x = 1 取等）；ln(1+x) ≤ x（x = 0 取等）。

  • 适用信号：含 ex、lnx 的不等式证明、比较大小、隐零点估值、恒成立求参。
  • 操作步骤： 1. 识别超越项（ex、lnx、xx 等）； 2. 用放缩把它"砍"成多项式/简单式（ex → x+1，lnx → x−1）； 3. 砍完后解普通不等式；若放缩过松（太粗），换更紧的放缩（如 ex ≥ 1+x+x2/2）。
  • 例题：2022新高考Ⅰ卷第7题比较 a = 0.1e^0.1、b = 1/9、c = −ln0.9：放缩 e^0.1>1.1？或 0.1e^0.1 与 1/9——答案 c<a<b。配套《函数比较大小_切线放缩(gdedu)》、《导数证明不等式策略_切线放缩(oajrc)》。
  • 课标依据：切线是导数的几何意义（选必二），不等式可用导数证明。✓ 不超纲（但要写证明）。
  • 红线：在答题卡上直接用"lnx≤x−1"当已知结论而不证明，可能被扣过程分；务必用一句"（可由导数证明）"或当场证一遍（构造 g(x) = lnx−x+1 求导）。

1.5 必要性探路（端点效应）—— 恒成立求参的"先猜后证"

大白话·本质一句话：必要性探路  =  先猜后证——"对所有 x 都成立"，那先挑个最好算的点（往往是端点）代进去，把 a 的范围"猜"个八九不离十（这只是必要条件），再回头严格证明这个范围真的够使；先探路、再修路。

  • 适用信号：恒成立求参数范围（f(x)≥0 对 x∈D 恒成立，求 a）。
  • 操作步骤： 1. 必要性：取特殊点（通常是端点或极限点）代入，得到 a 的必要范围（如取 x = 0 得 a≥2）； 2. 充分性：证明 a 取该范围时确实恒成立（放缩/最值法）； 3. 合并得答案。
  • 选学·验证用：洛必达法则（lim 型极限）可直接算出端点极限得到临界值——超纲，只用于"猜答案"，大题证明仍走第 2 步。
  • 例题：2022新高考Ⅰ卷压轴第 2 问（a 的最小值问题，先猜 a = 2 再证）。
  • 课标依据：不等式恒成立转化为最值（选必二）。✓ 不超纲。
  • 注意：取点要"够用"，一次取不到就多取几个特值缩小范围。

1.6 双变量问题

大白话·本质一句话：一道题里同时冒出 x1、x2 两个未知数，求导求不动；那就想办法"二合一"——要么把一个当常量、另一个当主角（主元法），要么令 t = x1/x2 把它俩打包成一个新变量，把"两个人的方程组"变回"一个人的函数"。

  • 适用信号：x1、x2 两个变量同时出现（零点、切线、极值相关问题）。
  • 三种主流操作：
  • 主元法：固定 x1，把 x2 看成 x1 的函数/变量，单变量化；
  • 比值换元：令 t = x1/x2（或 x2/x1），全部用 t 表示；
  • 和积换元：令 u = x1+x2、v = x1·x2，用 u、v 消元（常配合极值点偏移）。
  • 课标依据：函数与导数综合。✓ 不超纲。
  • （与本章前述"进阶 6：双变量问题"及课后 C 组 15、3.6 补"经验一"联动——C 组 15 答案 a≤−2 即用 h(x) = f(x)+4x 单调化做出来的。）

1.7 小题：比较大小的构造模型速查

大白话·本质一句话：几个数（尤其带 ex、lnx 的）摆一块比不出大小，就观察它们导数式子的"长相"：看到 xf′−f 就配一个 f/x，看到 f′−f 就配一个 f/ex——凑出一个单调函数，大小关系自动揭晓；它是 1.1 同构与 1.4 放缩在小题上的"配方速查表"。

  • f(x) 与 x 的关系：出现 xf′(x)−f(x) → 构造 F = f(x)/x；出现 xf′(x)+f(x) → F = x·f(x)。
  • f(x) 与 ex：f′(x)−f(x) → F = f(x)/ex；f′(x)+f(x) → F = f(x)·ex。
  • 大小比较：先看能否用中间值（0、1、e、1/2），再看能否构造同型函数，最后放缩/泰勒近似（选学·验证用）。
  • 例题：2022新高考Ⅰ卷第 7 题；2023新高考Ⅰ卷比较大小题。

一通百通

这一章的"通用骨架"只有五步：① 写定义域 → ② 求 f′(x) 并因式分解 → ③ 令 f′=0 找分界点、穿根法判 f′ 正负 → ④ 根据正负号写单调区间、找极值、比出最值 → ⑤ 恒成立就分离参数，转成求这个新函数的最值。不管求切线、求单调区间、求极值最值，还是压轴的恒成立、端点效应、隐零点，骨子里都是"求导 → 判正负 → 下结论"这一条线。会做一道 f(x)=x3−3x 的题，就会做所有导数解答题的第一问；这套"求导判号"的骨架，后面解析几何求最值、压轴不等式放缩时还会一再回来用。

这一章是新高考Ⅰ卷解答压轴的固定入口：几乎年年的导数解答题（第 22 题或新结构对应位置）第一问，就是"求单调区间、求切线、求极值/最值"——这正是本章 3.3、3.4 的标准流程，必须稳拿满分；第二问再上难度，考恒成立求参、端点效应、隐零点、切线放缩这类本章末"高级方法"。小题里它也常露面：切线方程与求参数（如本章 C 组收录的 2023 新高考Ⅰ卷第 6 题、2024 新高考Ⅰ卷第 13 题、2025 新高考Ⅰ卷第 12 题），多为中档选择填空。一句话：导数题的第一问是"送分"，第二问才是"拉分"，而能不能拉分，取决于本章这套"求导判号"基本功扎不扎实。
