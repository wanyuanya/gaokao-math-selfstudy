本章本质核心：圆锥曲线的本质是"到一个定点（焦点）与到一条定直线（准线）距离之比为定值 e 的点的轨迹"。e 是唯一的档位开关：e<1 是椭圆、e = 1 是抛物线、e>1 是双曲线——三种曲线不是三样新东西，而是同一个定义的三个档位。本章所有题型都是这一个原理的变体：椭圆"距离和 = 2a"、双曲线"距离差 = 2a"、抛物线"到焦点 = 到准线"，焦点弦、离心率、联立韦达，全是这一个定义换着马甲出现。

为什么有用行星绕太阳的轨道是椭圆、卫星天线的反光面是抛物线——现实里这些曲线都是"按距离规则画出来的"。想通了 e 这个开关，你就明白为什么离心率一确定曲线形状就定了；想通了"设而不求"，高考压轴大题里那些求弦长、证过定点、算定值的题，就有了一套固定打法，而不是见一题慌一题。

3.1 椭圆（定义：到两焦点距离之和  =  2a）

引入：拿一根绳子，两端按在桌上两个钉子上，用笔尖把绳子绷紧画一圈——画出来的就是椭圆。为什么？因为笔尖到两个钉子的距离加起来永远等于绳长。两个钉子叫焦点，绳长就是定长 2a。

正式定义：平面上与两个定点 F1、F2 的距离之和等于常数 2a（2a > |F1F2|）的点的轨迹叫椭圆。两个定点叫焦点，|F1F2|  =  2c。

标准方程（焦点在 x 轴上）：

x2/a2 + y2/b2  =  1（a > b > 0）

其中 b2  =  a2 − c2（这个关系天天用，背死）。焦点 (±c, 0)。

性质（逐条推）：

  1. 顶点 (±a, 0)、(0, ±b)。长轴长 2a（沿 x），短轴长 2b。
  2. a、b、c 的关系：从图上看，短轴顶点 (0,b) 到焦点 (c,0) 的距离正好是 a，于是 a2  =  b2 + c2，即 b2  =  a2 − c2。这是勾股关系。
  3. 离心率 e  =  c/a，范围 0 < e < 1。e 越接近 1，c 越接近 a、b 越小，椭圆越扁；e 越接近 0，b 越接近 a，椭圆越圆。e  =  0 就退化成圆。
  4. 通径：过焦点垂直长轴的弦，长  =  2b2/a（把 x  =  c 代入方程算 y）。
  5. 焦点三角形：椭圆上一点 P 与两焦点 F1、F2 构成三角形，若 ∠F1PF2  =  θ，则面积 S  =  b2·tan(θ/2)。道理：|PF1|+|PF2| = 2a，配合余弦定理和面积公式推得。
  6. 离心率比值式（苏州教研·专题43）：e  =  c/a  =  √(1 − (b/a)2)。给了 b/a 直接算 e，不用先绕到 c。
  7. 第二定义与准线（苏州教研·专题43，新教材作了解）：椭圆上任一点 P 到焦点 F 的距离 |PF|，与到对应准线的距离 d 之比恒等于 e：|PF|/d  =  e。准线方程 x  =  ±a2/c（焦点在 x 轴）。小题里用它能把"到焦点距离"和"到准线距离"互相换算。

计算流程（知二求三）：

  1. 椭圆就三个量 a、b、c，关系 b2 = a2−c2、e = c/a；
  2. 题目给两个量（如 c 和 e），先求 a，再求 b；
  3. 写出标准方程，先看焦点在 x 轴还是 y 轴。

例题跟讲例题：

例 3.1-a：椭圆焦点 (±3, 0)，长轴长 10，求标准方程。 解：c  =  3，2a  =  10 ⇒ a  =  5。b2  =  a2 − c2  =  25 − 9  =  16。方程 x2/25 + y2/16  =  1。 要点：先定焦点在 x 轴（给的是 (±c,0)），套 x2/a2+y2/b2 = 1。

例 3.1-b：椭圆 x2/25 + y2/9  =  1 上一点 P，∠F1PF2  =  90°，求焦点三角形面积。 解：b2  =  9，θ  =  90°。S  =  b2·tan(θ/2)  =  9·tan45°  =  9。 要点：焦点三角形面积公式直接用，不用求 P 坐标。

常见陷阱：

  • c2  =  a2 − b2 是减号！和双曲线相反，最高频错误。
  • a 永远是 a、b、c 里最大的（椭圆）。

小结：椭圆就是"扁圆"，抓住 a、b、c 勾股关系和 e = c/a 两个钥匙。

编者注·本质回扣：为什么这三种曲线叫"圆锥"曲线？说白了，拿一个平面去斜切圆锥，切的角度不同就切出三种曲线——切得平是椭圆（最"胖"），正好斜着一刀切下去是抛物线（不胖不瘦），切得陡就成了开口朝外的双曲线。这个"斜的程度"就是离心率 e：e 越小越接近圆，e = 1 正好卡在抛物线上，e>1 就翻脸成双曲线。所以 3.1 椭圆"距离和 = 2a"、3.2 双曲线"距离差 = 2a"、3.3 抛物线"到焦点 = 到准线"，看似三个定义，本质是同一个 e 在三个档位上的样子——想通 e 这个开关，三种曲线就串成一条线，公式不用分开背。

3.2 双曲线（定义：到两焦点距离之差  =  2a）

引入：双曲线像两条背对背的无限延伸的"喇叭"。发电厂的冷却塔侧面、某些导航系统（双曲线导航）都靠它。它和椭圆长得像，但一个是"距离之和"，一个是"距离之差"。

正式定义：平面上与两个定点 F1、F2 的距离之差的绝对值等于常数 2a（2a < |F1F2|）的点的轨迹叫双曲线。

标准方程（焦点在 x 轴）：

x2/a2 − y2/b2  =  1（a > 0, b > 0）

其中 c2  =  a2 + b2（注意是加号！和椭圆反着）。焦点 (±c, 0)。

性质：

  1. 两支：x ≥ a 或 x ≤ −a，中间是空的。
  2. 渐近线：y  =  ±(b/a)x。曲线无限靠近这两条直线但永不相交。
  3. 离心率 e  =  c/a，范围 e > 1。e 越大开口越阔。
  4. 通径  =  2b2/a；焦点三角形面积 S  =  b2·cot(θ/2)（椭圆是 tan，双曲线是 cot）。
  5. 离心率比值式（苏州教研·专题43）：e  =  c/a  =  √(1 + (b/a)2)。
  6. 准线（苏州教研·专题43，新教材作了解）：x  =  ±a2/c，第二定义同样 |PF|/d  =  e。
  7. 共渐近线的双曲线系（苏州教研·专题43）：与 x2/a2−y2/b2 = 1 同渐近线的所有双曲线可统一设为 x2/a2 − y2/b2  =  λ（λ≠0）。道理：令右边 1 变 0 就得到渐近线，反过来带参数 λ 就是"同一对渐近线"的一族。

例题跟讲例题：

例 3.2-a：双曲线 x2/4 − y2/5  =  1，求焦点坐标、渐近线、离心率。 解：a2  =  4，b2  =  5。c2  =  a2 + b2  =  9，c  =  3。焦点 (±3, 0)。渐近线 y  =  ±(b/a)x  =  ±(√5/2)x。e  =  c/a  =  3/2。 要点：双曲线 c2  =  a2 + b2，别写成减号。

常见陷阱：

  • 椭圆 c2  =  a2 − b2（减）、双曲线 c2  =  a2 + b2（加）——这是本章最高频错误，写之前默念一遍。
  • 渐近线别把 a、b 写反：焦点在 x 轴是 y  =  ±(b/a)x。

小结：双曲线两支、有渐近线，c2 = a2+b2 是它和椭圆唯一的"符号区别"。

3.3 抛物线（定义：到定点与到定直线距离相等）

引入：探照灯为什么能把光聚成一束平行光？因为反光碗是抛物线形——光源放在焦点，光经反射后平行射出。卫星接收天线同理。抛物线的核心是"到一个点的距离  =  到一条直线的距离"。

正式定义：平面上到定点 F（焦点）与到定直线 l（准线）距离相等的点的轨迹。

标准方程（开口向右）：y2  =  2px（p > 0），焦点 F(p/2, 0)，准线 x  =  −p/2。

性质：

  1. 焦点到准线距离  =  p。
  2. 通径（过焦点垂直对称轴的弦）长  =  2p。
  3. 抛物线上任一点到焦点距离  =  到准线距离（定义本身）。
  4. 离心率 e  =  1（不偏不倚，正好是椭圆和双曲线的分界）。

例题跟讲例题：

例 3.3-a：求抛物线 y2  =  8x 的焦点和准线。 解：2p  =  8 ⇒ p  =  4。焦点 (p/2, 0)  =  (2, 0)，准线 x  =  −2。 要点：先把方程写成 y2 = 2px，读出 p。

常见陷阱：

  • 抛物线标准方程有四种开口方向（左右上下），对应焦点位置不同，先看一次项是谁。
  • 别把 y2 = 2px 的焦点记成 (p,0)，是 (p/2,0)。

小结：抛物线就一个参数 p，焦点 (p/2,0)、准线 x = −p/2，到两者距离永远相等。

3.4 直线与圆锥曲线（大题核心流程）

引入：高考压轴大题，十有八九是"一条直线和圆锥曲线相交，问弦长、面积、中点、斜率"。这类题有固定打法，练熟了就是套路分。

标准流程（五步）：

  1. 设直线：斜率存在设 y  =  kx + m；斜率可能不存在要单独讨论（竖直线 x  =  t）。
  2. 联立：把直线代入曲线方程，消元得一元二次方程。
  3. 判别式：写 Δ > 0（相交前提），这一步经常用来反求参数范围，忘了扣分。
  4. 韦达定理：x1 + x2、x1x2 整体写出，不真的去解根。
  5. 用需求：弦长、面积、中点，全用韦达结果代。

弦长公式：直线斜率 k，交曲线于 A(x1,y1)、B(x2,y2)：

|AB|  =  √(1 + k2)·√[(x1+x2)2 − 4x1x2]

道理：两点距离 √[(Δx)2+(Δy)2] = |Δx|√(1+k2)，而 (x1−x2)2 = (x1+x2)2 − 4x1x2。

记住它之前先看懂它：为什么弦长不用真求出 x1、x2？关键就是这个恒等式——把"两根之差的平方"翻译成"两根之和与两根之积"，而和与积正好是韦达定理直接给的。于是弦长、判别式 Δ 全部只用 x1+x2、x1x2 两个整体写，这就是"设而不求"能跑通的底层原因。

例题跟讲例题：

例 3.4-a：直线 y  =  x + 1 与抛物线 y2  =  4x 交于 A、B，求 |AB|。 解：代入：(x+1)2  =  4x ⇒ x2 − 2x + 1  =  0 ⇒ (x−1)2  =  0，Δ  =  0。 Δ  =  0 说明相切，A、B 重合，|AB|  =  0。 换一条：y  =  x 与 y2 = 4x：x2  =  4x ⇒ x  =  0 或 4，A(0,0)、B(4,4)，|AB|  =  √32  =  4√2。 要点：联立先看 Δ：Δ>0 相交、 = 0 相切、<0 相离；弦长公式只在 Δ>0 时用。

常见陷阱：

  • 忘记写"Δ > 0 得 k 范围"——大题常见扣分点。
  • 默认 y  =  kx + m，漏掉斜率不存在的竖直线。

小结：大题五步走：设线、联立、Δ、韦达、代目标。

编者注·本质回扣：为什么大题要"设线、联立、韦达、代目标"五步走？本质还是第 15 章那句"给几何装上方程"——直线和曲线一相交，交点坐标就同时满足两个方程。但高考从不要你真的把 x1、x2 解出来（解出来又烦又易错），只要 x1+x2、x1x2 这两个整体。韦达定理就是让你"设而不求"：交点的名字写上、根不解，把弦长、面积、向量数量积全部用这两个整体代掉。本章 ④例 4（MN 恒过定点 (2p,0)）、例 5（CM⃗·CN⃗ ≡ 17）那两道定点定值题，靠的就是这一招——全程不解根，只靠整体代换把参数消掉。想通了"要的是整体不是根"，压轴题就有了抓手。

3.5 点差法与设而不求（中点弦提速）

引入：题目只给弦的中点，让你求弦斜率，硬联立又烦又慢。点差法专门干这个——不求出交点，两式一减就出斜率关系。

点差法流程：

  1. 设交点 A(x1,y1)、B(x2,y2)，都在曲线上，代入曲线方程；
  2. 两式相减，因式分解出 (x1−x2)、(y1−y2)；
  3. 除以 (x1−x2)，得到弦斜率 k 与中点 (x0,y0) 的关系。

结论（椭圆）：k·(y0/x0)  =  −b2/a2，即 k  =  −(b2/a2)·(x0/y0)。 双曲线：k·(y0/x0)  =  b2/a2（加号）。

设而不求：交点坐标设了但不解，全程用韦达定理整体代换——这是大题的基本素养。

例题跟讲例题：

例 3.5-a：椭圆 x2/25 + y2/16  =  1 一弦中点为 (3, 1)，求弦所在直线斜率。 解：点差法：k·(y0/x0)  =  −b2/a2  =  −16/25。y0/x0  =  1/3。k  =  −16/25 · 3  =  −48/25。 要点：中点已知直接套点差结论，省掉联立。

小结：中点弦问题先想点差法，比联立快一倍。

3.6 三种曲线一表对比

见到一个方程，先看离心率范围（椭圆<1、抛物线 = 1、双曲线>1）定类型，再套对应公式。

3.7 求轨迹方程的五种方法（苏州教研·专题47）

引入：高考压轴第二问常问"求动点 P 的轨迹方程"。题目没给你曲线类型，要你自己判断它是什么、再写方程。苏州教研把这类题总结成"建、设、限、代、化"五步：建坐标系→设动点坐标→挖限制条件→列等式代入→化简成标准方程。具体用哪种"列等式"的招，看下面五种。

五种方法（黑体为首选判断信号）：

  1. 直接法：动点满足的等量关系能直接写出来（如"到两定点距离和 = 常数"），直接翻译成坐标方程。
  2. 定义法（几何法）：动点条件一看就像某条基本曲线（椭圆/双曲线/抛物线/圆/直线）的定义，直接套定义写方程。见到"距离和/差 = 定值""到定点 = 到定直线距离"立刻用。
  3. 代入法（相关点法/转移法）：动点 P 依赖另一个在已知曲线上的点 Q，先用 P 的坐标表示 Q 的坐标，再代入 Q 所在的已知曲线。
  4. 参数法：x、y 关系不好直接找，就都用一个中间变量（角、斜率 t）表示，再消参。
  5. 交轨法：求两条动直线交点的轨迹——把两动直线方程联立消参，或解出交点再消参。

例题跟讲例题：

例 3.7-a（定义法）：（苏州教研·专题47，原书p.153 B组1(1)）已知圆 M:(x+√5)2+y2 = 36，定点 N(√5,0)。点 P 在圆 M 上，Q 在 NP 上，GQ⃗·NP⃗ = 0 且 NP⃗ = 2NQ⃗。求 G 的轨迹。 解：NP⃗ = 2NQ⃗ 说明 Q 是 NP 中点；GQ⃗·NP⃗ = 0 说明 GQ⊥NP，即 GQ 是 NP 的中垂线 ⇒ |GP| = |GN|。于是 |GM|+|GN| = |GM|+|GP| = |MP| = 6（圆 M 半径），而 |MN| = 2√5。因 6>2√5，G 的轨迹是以 M、N 为焦点的椭圆：2a = 6⇒a = 3，2c = 2√5⇒c = √5，b2 = a2−c2 = 9−5 = 4。 方程 x2/9 + y2/4  =  1。 记住它之前先看懂它：NP⃗ = 2NQ⃗ 说明 Q 是 NP 的中点，GQ⃗·NP⃗ = 0 说明 GQ 垂直 NP——一条既过 NP 中点、又垂直 NP 的直线，就是 NP 的中垂线；中垂线上的点 G 到两端 P、N 的距离相等（|GP| = |GN|），于是"GM+GN"被偷换成"GM+GP"，而 P 在圆上、|GM|+|GP| 正好等于圆半径 6 是常数——看到"到两定点距离和 = 常数"，椭圆定义立刻浮出，不用列方程。 要点：看到"到两定点距离和 = 常数"就用定义法，不用硬列方程。

例 3.7-b（代入法）：（苏州教研·专题22，原书p.93 A组3 思想）已知定点 A(1,2)、B(−4,4)，点 C 在圆 (x−3)2+(y−6)2 = 9 上动，求 △ABC 重心 G 的轨迹。 解：设 G(x,y)、C(x0,y0)。重心坐标 (x,y) = ((1−4+x0)/3,(2+4+y0)/3)，反解 x0 = 3x+3、y0 = 3y−6。C 在已知圆上：(x0−3)2+(y0−6)2 = 9 ⇒ (3x)2+(3y−12)2 = 9 ⇒ x2+(y−4)2 = 1。 要点：G 依赖 C，C 在已知圆上——先用 G 表示 C，再代入已知曲线，就是代入法。

常见陷阱：求出方程后要回头看有没有该排除的点（如轨迹是一段弧、要去掉某些点），保证"纯粹性"。

小结：轨迹题先认方法——像定义用定义法，有关联点用代入法，两条动直线交点用交轨法，都不像就直接法/参数法列方程。

④ 例题详解（先做再看）

例题例 1（求椭圆方程）：椭圆焦点 (±√5, 0)，离心率 √5/3，求标准方程。

自己做：c、e → a → b。

解：c  =  √5，e  =  c/a  =  √5/3 ⇒ a  =  3。b2  =  a2 − c2  =  9 − 5  =  4。 方程：x2/9 + y2/4  =  1。 要点：e  =  c/a 是枢纽，三量 c、a、b 知二求三（椭圆 b2  =  a2 − c2）。

例题例 2（焦点三角形）：椭圆 x2/9 + y2/4  =  1 上一点 P，∠F1PF2  =  60°，求焦点三角形面积。

自己做：套 S  =  b2·tan(θ/2)。

解：b2  =  4，S  =  4·tan 30°  =  4·(√3/3)  =  4√3/3。 要点：焦点三角形面积公式直接秒；验证：此题无需求 P 坐标。

例题例 3（联立求弦长）：直线 y  =  x + 1 与抛物线 y2  =  4x 交于 A、B，求 |AB|。

自己做：联立 → 韦达 → 弦长公式。

解：代入：(x + 1)2  =  4x ⇒ x2 − 2x + 1  =  0 ⇒ (x − 1)2  =  0，Δ  =  0（相切！）。 这题直线与抛物线相切，A、B 重合，|AB|  =  0。 换一题：直线 y  =  x 与 y2  =  4x：x2  =  4x ⇒ x  =  0 或 4，A(0,0)、B(4,4)，|AB|  =  √(16 + 16)  =  4√2。 要点：联立后先看 Δ：Δ > 0 相交、 =  0 相切、< 0 相离；弦长公式只在 Δ > 0 时用。

例题例 4（抛物线·定点定值·齐次化思想）（苏州教研·专题47，原书p.153）：过抛物线 y2  =  2px（p > 0）的顶点 O 作两条互相垂直的直线 OM、ON，分别交抛物线于另一点 M、N。求证：直线 MN 恒过定点。

自己做：M、N 用纵坐标作参数，先把"OM⊥ON"翻译成 y1y2 的关系。

解：设 M(y12/2p, y1)、N(y22/2p, y2)。则 k_OM  =  2p/y1，k_ON  =  2p/y2。 OM⊥ON ⇒ k_OM·k_ON  =  4p2/(y1y2)  =  −1 ⇒ y1y2  =  −4p2。 k_MN  =  (y2−y1)/(y22/2p − y12/2p)  =  2p/(y1+y2)。直线 MN：y−y1  =  [2p/(y1+y2)](x − y12/2p)。 令 y  =  0 求横截距：x  =  y12/2p − y1(y1+y2)/(2p)  =  −y1y2/(2p)  =  −(−4p2)/(2p)  =  2p。 所以直线 MN 恒过定点 (2p, 0)。 要点：两垂直 ⇒ 斜率积  =  −1 ⇒ y1y2 为定值，弦的横截距只含 y1y2、与单个点无关——这就是"积为定值 ⇒ 过定点"。对应方法手册 2.1 齐次化的落点。

例题例 5（双曲线·设而不求·定点定值）（苏州教研·专题47，原书p.156）：已知双曲线 x2/4 − y2  =  1，点 B(0,−1)。过 B 的直线 l 交双曲线于 M、N 两点。问在 y 轴上是否存在定点 C，使 CM⃗·CN⃗ 为常数？若存在求出 C。

自己做：设 l:y = kx−1，联立写韦达，把 CM⃗·CN⃗ 全用 x1+x2、x1x2 表示。

解：代入 x2/4 − (kx−1)2  =  1 ⇒ (1−4k2)x2 + 8kx − 8  =  0。 韦达：x1+x2  =  8k/(4k2−1)，x1x2  =  8/(4k2−1)。设 C(0,n)，y1 = kx1−1、y2 = kx2−1。 CM⃗·CN⃗  =  x1x2 + (y1−n)(y2−n)  =  (1+k2)x1x2 − k(n+1)(x1+x2) + (n+1)2  =  (1+k2)·8/(4k2−1) − k(n+1)·8k/(4k2−1) + (n+1)2  =  8(1−nk2)/(4k2−1) + (n+1)2。 要它与 k 无关，让分子分母成倍数：取 n  =  4，则 1−4k2  =  −(4k2−1)，上式  =  8·(−1) + (4+1)2  =  −8 + 25  =  17。 故存在定点 C(0, 4)，使 CM⃗·CN⃗ ≡ 17。 要点：全程只写韦达、不解根（设而不求）；让含 k 的分子与分母配成倍数消掉 k，即得定点 n。对应方法手册 2.4。

⑥ 常见坑清单

  • 椭圆 c2  =  a2 − b2、双曲线 c2  =  a2 + b2——符号相反是最高频错误。
  • 双曲线渐近线：焦点在 x 轴时 y  =  ±(b/a)x，别把 a、b 颠倒。
  • e 的范围：椭圆 (0,1)、双曲线 (1,∞)、抛物线 e  =  1——判断类型第一件事。
  • 直线与曲线联立：Δ ≥ 0 是前提，忘记写"Δ > 0 得 k 的范围"是大题常见扣分。
  • 弦长公式：√(1+k2)·√[(x1+x2)2 − 4x1x2]，判别式部分不能直接抄 x1+x2、x1x2。
  • 斜率不存在（直线垂直 x 轴）情况单独讨论，别默认 y  =  kx + m。

本章公式速查表

与《高中数学常用公式·修订版》第六部分"圆锥曲线"逐条核对一致。

椭圆

|MF1| + |MF2|  =  2a（2a > |F1F2|  =  2c）

  • 大白话椭圆上随便一点，到两个焦点的距离加起来永远等于 2a。
  • 用的时候：用定义求轨迹；必须 2a > 焦距，等号就退化成线段、小于就画不出图。
  • 记忆要点：到两焦点距离和  =  长轴长。

x2/a2 + y2/b2  =  1（焦点在 x 轴，a > b > 0）

  • 大白话椭圆的标准长相，分母大的 a 在 x2 上就是焦点在 x 轴。
  • 用的时候：写方程前先看焦点在 x 轴还是 y 轴；哪个分母大，焦点就在那个轴上。

b2  =  a2 − c2（a 最大）

  • 大白话短半轴 b、半焦距 c、长半轴 a 满足勾股，且 a 是三者里最大的。
  • 用的时候：知二求三天天用；椭圆是减号，最高频写成加号。
  • 记忆要点：椭圆 c2  =  a2 − b2（减）。

e  =  c/a（0 < e < 1）

  • 大白话离心率衡量椭圆有多扁，越接近 1 越扁、越接近 0 越圆。
  • 用的时候：给 c 和 e 先求 a；e 是 a、b、c 知二求三的枢纽。

通径  =  2b2/a

  • 大白话过焦点垂直长轴切出来的那条最短弦。
  • 用的时候：把 x = c 代回方程求 y 即得；小题当结论直接用。

焦点三角形面积 S  =  b2·tan(θ/2)（θ  =  ∠F1PF2）

  • 大白话椭圆上一点跟两焦点围成的三角形，只看顶角就能算面积。
  • 用的时候：题里给 ∠F1PF2 又不需求 P 坐标时直接套；椭圆用 tan。

e  =  √(1 − (b/a)2)（椭圆离心率比值式）

  • 大白话给了 b/a 直接平方算 e，不用先求 c。
  • 用的时候：选择题给"虚轴/实轴""b 与 a 的倍数"时秒算 e。

第二定义 |PF|/d  =  e；准线 x  =  ±a2/c（新教材作了解）

  • 大白话椭圆上一点到焦点的距离，是它到对应准线距离的 e 倍。
  • 用的时候：把"到焦点距离"和"到准线距离"互相换，省得算坐标；准线在焦点外侧 a2/c 处。

双曲线

||MF1| − |MF2||  =  2a（2a < |F1F2|）

  • 大白话双曲线上一点到两焦点距离之差的绝对值恒为 2a，所以有两支。
  • 用的时候：和椭圆就差一个字——"和"变"差"；必须 2a < 焦距。

x2/a2 − y2/b2  =  1（a > 0, b > 0）

  • 大白话双曲线标准方程，中间是减号，中间是空的（|x| ≥ a）。

c2  =  a2 + b2（c 最大）

  • 大白话双曲线里 a、b、c 也是勾股关系，但这次是加号，c 最大。
  • 用的时候：和椭圆反着写！这是本章第一高频坑。
  • 记忆要点：双曲线 c2  =  a2 + b2（加）。

渐近线 y  =  ±(b/a)x

  • 大白话双曲线两头无限靠近但永远碰不到的两条直线。
  • 用的时候：焦点在 x 轴就是 b/a；别把 a、b 写反。
  • 记忆要点：令方程右边 1 变 0 即得渐近线。

e  =  c/a（e > 1）

  • 大白话双曲线离心率必大于 1，越大开口越阔；e  =  √2 就是等轴双曲线。

通径  =  2b2/a；焦点三角形面积 S  =  b2·cot(θ/2)

  • 大白话通径和椭圆同公式；焦点三角形面积把椭圆的 tan 换成 cot。
  • 用的时候：别记混——椭圆 tan、双曲线 cot。

e  =  √(1 + (b/a)2)（双曲线离心率比值式）

  • 大白话给了 b/a 直接算 e；e = √2 就是等轴双曲线。
  • 用的时候：C1 那类"虚轴是实轴几倍"直接套；b/a = √7 ⇒ e = √(1+7) = 2√2。

准线 x  =  ±a2/c；同渐近线双曲线系 x2/a2 − y2/b2  =  λ

  • 大白话准线位置和椭圆同公式；同渐近线的一族双曲线右边换成参数 λ。
  • 用的时候：求"与某双曲线共渐近线"的方程时设成 λ；第二定义 |PF|/d=e 同样适用。

抛物线

y2  =  2px（p > 0，开口向右）

  • 大白话到焦点距离等于到准线距离的点的轨迹，标准式里一次项是谁焦点就在谁轴上。
  • 用的时候：先把方程写成 y2  =  2px 的样子读出 p。

焦点 F(p/2, 0)，准线 x  =  −p/2

  • 大白话焦点在原点右边半个 p 处，准线在左边半个 p 处。
  • 用的时候：别把焦点记成 (p,0)，是 (p/2,0)；焦点到准线距离 = p。

通径  =  2p；离心率 e  =  1

  • 大白话抛物线通径就是 2p；e 恒等于 1，正好卡在椭圆和双曲线中间。

焦点弦 x1x2  =  p2/4，y1y2  =  −p2

  • 大白话过焦点的弦两端坐标乘积是固定的，小题直接套。
  • 用的时候：只对过焦点的弦成立；前面带个负号别漏。

焦半径（角度式）：|AF|  =  p/(1−cosθ)，|BF|  =  p/(1+cosθ)（θ 为焦点弦 AB 的倾斜角）

  • 大白话焦点弦被焦点分成两段，各段长度用倾斜角 θ 直接写。
  • 用的时候：比 x1+p/2 更快；两段一长一短，cosθ 一减一加。

焦点弦长 |AB|  =  2p/sin2θ；S△AOB  =  p2/(2sinθ)；1/|AF| + 1/|BF|  =  2/p

  • 大白话过焦点的弦长、它与原点围成三角形的面积，都只跟倾斜角 θ 有关。
  • 用的时候：θ=90°（通径）时弦最短 =2p；倒数和恒为 2/p，与弦怎么转无关。

直线与曲线联立

|AB|  =  √(1 + k2)·√[(x1+x2)2 − 4x1x2]

  • 大白话用韦达定理写出来的弦长，不用真解出两个交点。
  • 用的时候：联立得一元二次方程后，先写 Δ > 0 再套；Δ ≤ 0 不能用。

点差法：椭圆 k·(y0/x0)  =  −b2/a2；双曲线  =  +b2/a2（中点 (x0, y0)）

  • 大白话已知弦中点求斜率，两式一减直接出，省掉联立。
  • 用的时候：椭圆是负号、双曲线是正号；用完要代回验证 Δ > 0。

进阶 1：齐次化（手册 二.2.1）——斜率之和/积问题

  • 适用信号：过同一点 P 的两条直线，求/证 k1+k2 或 k1·k2 为定值。
  • 操作步骤：①P 不在原点先平移坐标系；②直线写成 mx+ny=1；③联立曲线，把一次项乘 (mx+ny)、常数项乘 (mx+ny)2，凑成关于 (y/x) 的齐次方程；④令 t=y/x（即斜率），韦达定理直出 k1+k2、k1·k2。
  • 例：过椭圆上定点 P 作两互相垂直的弦，证弦过定点。配套例题见本章 ④例 4（抛物线顶点作两垂直弦，证 MN 过定点 (2p,0)，苏州教研·专题47）——k_OM·k_ON=−1 ⇒ y1y2 定值 ⇒ 横截距固定，正是"积为定值 ⇒ 过定点"。
  • 课标依据：直线与曲线联立、韦达定理。✓ 不超纲（高考可放心用，是计算技巧）。平移后记得还原结论；斜率不存在单独讨论。

进阶 2：点差法·中点弦与第三定义（手册 二.2.2）

  • 适用信号：弦中点已知/求中点；两点与中心连线斜率关系。
  • 操作步骤：设 A(x1,y1)、B(x2,y2) 代入曲线两式相减 → 得 k 与中点关系（见速查表）。
  • 第三定义（小题结论）：椭圆上两点与中心连线斜率积 = −b2/a2；双曲线 = b2/a2；圆 = −1。
  • 配套例题：本章 3.5 例 3.5-a（中点求斜率）+ 课后 C4（已知 x1+x2=8，点差法求中垂线与 x 轴交点 D，苏州教研·专题47）。
  • ✓ 不超纲。点差结果要代回验证 Δ>0。

进阶 3：二级结论速查（手册 二.2.3）

  • 椭圆：通径 2b2/a；焦点三角形 S=b2tan(θ/2)；焦半径 r1=a+ex0、r2=a−ex0。
  • 双曲线：焦点三角形 S=b2cot(θ/2)；等轴双曲线 ⇔ e=√2。
  • 抛物线 y2=2px：焦点弦 x1x2=p2/4、y1y2=−p2；以焦点弦为直径的圆与准线相切。
  • ✓ 不超纲（均为定义/方程推论）；大题直接用建议加一句推导。
  • 超纲红线：极点极线理论（可"秒杀"定点定值）——超纲，考试禁用，只用来猜答案、检验结果。

进阶 4：设而不求整体操作（手册 二.2.4）

  • 过定点 (m,0) 设 x=ty+m（避免讨论斜率不存在）；
  • 联立消元 → Δ>0、韦达；
  • 弦长 √(1+k2)·√((x1+x2)2−4x1x2)；面积 ½·|AB|·d；向量 OA·OB = x1x2+y1y2；
  • 把目标式全用 x1+x2、x1x2、k 表示，别中途解根。
  • 配套例题：本章 ④例 5（双曲线 x2/4−y2=1，过 B(0,−1) 设 y=kx−1，韦达整体代换 CM⃗·CN⃗，求得定点 C(0,4)、常数 17，苏州教研·专题47）。
  • ✓ 不超纲（大题标准规范）。

2.1 齐次化 —— 斜率之和/积问题的"降计算"神技

大白话·本质一句话：齐次化=先把整个图形平移过去，让两条直线都过原点，斜率之和/积就变成一元二次方程的韦达，直接抄答案不用硬算。（与本章前述 ④例 4、进阶 1 联动）

适用信号：题目涉及从同一点 P 出发的两条直线，求/证 k1+k2 或 k1·k2 为定值。

操作步骤：

  1. 若 P 不在原点，先平移坐标系（把 P 移到原点；曲线方程同步平移）；
  2. 直线写成 mx+ny=1 的形式（过原点的直线）；
  3. 联立曲线方程，把一次项乘 (mx+ny)，常数项乘 (mx+ny)2，凑成关于 (y/x) 的齐次方程；
  4. 令 t=y/x（即斜率 k），得一元二次方程，k1+k2、k1·k2 直接由韦达定理给出——无需联立消元算到底。

例题：2024年新高考多套卷"过定点 P 的两条直线斜率之积为定值"类题。配套《齐次化妙解圆锥曲线(zizzs)》46页详解。

课标依据：直线与圆锥曲线位置关系（选必一）、韦达定理。✓ 不超纲（属于计算技巧，非新知识）。

注意：平移后要记得"还原"结论；斜率不存在的情形单独讨论。

（高级方法手册·2.1）

2.2 点差法 —— 中点弦与第三定义

大白话·本质一句话：点差法=让弦的两个端点各自代进曲线方程，再把两个式子一减，x12−x22、y12−y22 自动分解成 (x1−x2)、(y1−y2)，一除就露出"斜率"和"中点坐标"的关系，全程不用真把交点解出来。（与本章前述 3.5 例 3.5-a、课后 C4、进阶 2 联动）

适用信号：弦的中点已知/要求中点；两交点与中心（原点）连线斜率关系。

操作步骤（中点弦）：

  1. 设交点 A(x1,y1)、B(x2,y2)，代入曲线方程；
  2. 两式相减，因式分解出 (x1-x2) 与 (y1-y2)；
  3. 除以 (x1-x2)，得到弦斜率 k 与中点坐标 (x0,y0) 的关系（椭圆：k·(y0/x0) = -b2/a2 型）。

第三定义（可直接用的小题结论）：椭圆上两点与中心连线的斜率之积 = -b2/a2；双曲线 = b2/a2；圆 = -1。

课标依据：曲线方程、斜率公式。✓ 不超纲。

注意：点差法结果只给"关系"，代入验证是否满足判别式 Δ>0 是惯例步骤。

（高级方法手册·2.2）

2.4 设而不求的整体操作规范

大白话·本质一句话：设而不求=交点坐标的名字先写上，但死活不解出 x1、x2，全程只拿 x1+x2、x1x2 这两个"整体"去算——因为弦长、面积、向量数量积要的本来就是它们的和与积，不是单个根。（与本章前述 ④例 5、进阶 4 联动）

  • 设直线：过定点 (m,0) 设 x=ty+m（避免讨论斜率不存在；t 为斜率的倒数）；一般直线 y=kx+b。
  • 联立消元：消 y 得关于 x 的二次方程 → 判别式 Δ>0、韦达 x1+x2、x1x2。
  • 整体代换：弦长 |AB|=√(1+k2)·√((x1+x2)2-4x1x2)；面积 S=½·|AB|·d（点到直线距离）；向量 OA·OB=x1x2+y1y2。
  • 目标导向：把要求证的式子全部用 x1+x2、x1x2、k 表示，别中途解出 x 的值。

（高级方法手册·2.4）

一通百通

圆锥曲线大题的通用骨架就是三步：① 设线、联立（直线 y=kx+m 代入曲线，消元得一元二次方程，先写 Δ>0）→ ② 韦达（整体写出 x1+x2、x1x2，绝不真解根）→ ③ 翻译条件（把弦长、面积、中点、斜率积、向量数量积这些几何要求，全部用韦达整体代换，最后解出参数或证明定值）。中点弦还有一条提速道——点差法（两式相减直接出斜率与中点关系）。会这一套"联立→韦达→翻译条件"的设而不求，椭圆、双曲线、抛物线的大题就通了：曲线换了，流程一模一样。
