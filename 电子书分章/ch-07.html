公式速查：修订版 第3部分（和差/倍角/辅助角）

本章本质核心：三角恒等变换的本质是"把不同角的三角函数，统一换成同一个角的三角函数"——题目里冒出 α+β、α−β、2α、两个不同角相加，看着乱，其实都是同一个归约动作：想办法把它们压回到同一个角，再算。本章全部公式（两角差的余弦、和差角、二倍角、降幂、辅助角）都是这一个归约原理的变体；根只有一块砖 cos(α−β)，其余全是它推出来的。 为什么有用：想通"把不同角归约到同一个角"这一招，你就能把乱成一团的 sin、cos 混合式化简成一根干净的正弦波，最大值、周期、单调区间直接读出来；物理里交流电叠加、两个简谐运动合成，背后都是这一手合一变形——想通归约原理，比死背和差角表管用得多。

③ 正文讲解

上一章我们有了 sin、cos、tan，这一章要让它们"互相变换"。先看地图：

两角差的余弦公式 C(α−β)   ← 一切公式的根（用单位圆两点距离推出）
        ↓ 把 β 换成 −β、把 α−β 推广
和角、差角公式（sin / cos / tan）
        ↓ 令 β  =  α
二倍角公式
        ↓ 反解
降幂 / 升幂公式
        ↓ 逆用和角公式
辅助角公式（asinx+bcosx 合一）
        ↓ 应用
给值求值、给值求角

先说一句最重要的：sin(α+β) 不等于 sinα+sinβ（门槛自测第 5 题就是坑你）。正弦不"分配"。这些公式是一个严密的网，记住一个根（两角差的余弦），其余都能推出来，别死背。

3.1 和差角公式（必背）

怎么来的（几何直觉）：在单位圆上取两个角 α、β，它们终边与单位圆交点分别是 (cosα, sinα) 和 (cosβ, sinβ)。这两点连起来的距离，既可以用距离公式写出来，也等于夹角为 α−β 的两点距离。两边一对照，就得到最基础的一块砖——

cos(α−β)  =  cosα cosβ + sinα sinβ。

有了这块砖，其余和差角公式都靠"把负号代进去"推出来。比如把 β 换成 −β（cos(−β) = cosβ，sin(−β) = −sinβ），就得到 cos(α+β)。最终全套：

记住它之前先看懂它：这三条不是三张孤立的表，而是同一块砖 cos(α−β) 在 sin、cos、tan 上的三种长相——把 β 换成 −β、或把 sin 与 cos 角色对调，就能互相推出来。真正要记死的只有"中间符号"这件事：sin 的符号跟着括号走，cos 的符号要反过来。

  • sin(α ± β)  =  sinα cosβ ± cosα sinβ
  • cos(α ± β)  =  cosα cosβ ∓ sinα sinβ
  • tan(α ± β)  =  (tanα ± tanβ) / (1 ∓ tanα tanβ)

记法：

  • sin："正余余正"，中间符号相同（α+β 就用 +，α−β 就用 −）。
  • cos："余余正正"，中间符号相反（α+β 反而用 −，α−β 反而用 +）——这是最容易记反的地方。

例题跟讲例题 3.1-1：求 sin 75°。 解：75°  =  45°+30°，用 sin(α+β)： sin 75°  =  sin45°cos30° + cos45°sin30°  =  (√2/2)(√3/2) + (√2/2)(1/2)  =  √6/4 + √2/4  =  (√6+√2)/4。 要点：把 75° 拆成两个特殊角的和，套公式即可。

例题跟讲例题 3.1-2：已知 tanα  =  2，tanβ  =  3，求 tan(α+β)。 解：tan(α+β)  =  (tanα+tanβ)/(1−tanα tanβ)  =  (2+3)/(1−2 × 3)  =  5/(−5)  =  −1。 要点：分子同号、分母异号，别把分母的符号写反。

陷阱：cos(α+β) 中间是减号，别写成 cosαcosβ+sinαsinβ。

编者注·本质回扣：这一节公式看着一排，其实是"一块砖推出来的一张网"。先记最根的那一条 cos(α−β)，再把 β 换成 −β 就得到 cos(α+β)，把 sin、cos 角色对调又得到正弦的和差——所谓"中间符号相同 / 相反"，不是两条要分开死背的规则，而是同一个展开式落在 sin、cos 身上的自然差别。说白了，你不用背这一整张表：会推这一条根，考场现场也能现算出来，这正是本章本质核心说的"归约到一个根"。

3.2 二倍角公式（由和差角令 β  =  α）

和角公式里令 β  =  α，立刻得到二倍角：

记住它之前先看懂它：二倍角不是新公式，就是把和角公式里"两个不同的角"换成"同一个角自己加自己"。cos2α 之所以有三张面孔，是因为 sin2α+cos2α = 1 可以在 cos2α 与 sin2α 之间自由换——题目给 sin 就用含 sin 的那张脸，给 cos 就用含 cos 的那张脸，本质是同一条。

  • sin 2α  =  2 sinα cosα
  • cos 2α  =  cos2α − sin2α（这是"母版"）
  • tan 2α  =  2tanα / (1 − tan2α)

cos 2α 还能借助 sin2α+cos2α = 1 换成另外两种写法，哪个好用哪个： cos 2α  =  2cos2α − 1  =  1 − 2sin2α。

为什么要有三种写法？ 因为题目给 sinα 就用 1−2sin2α，给 cosα 就用 2cos2α−1，直接代入，不用再开方。

例题跟讲例题 3.2-1：已知 sinα  =  3/5，α 是第二象限角，求 sin 2α 和 cos 2α。 解：第二象限 cosα  =  −4/5。 sin 2α  =  2 sinα cosα  =  2 × (3/5) × (−4/5)  =  −24/25。 cos 2α  =  1 − 2sin2α  =  1 − 2 × (9/25)  =  7/25（用含 sin 的式子，省事）。 要点：求 cos 2α 时，哪种给的三角函数值方便就用哪种写法。

陷阱：sin 2α ≠ 2 sinα；cos 2α ≠ 2 cosα。倍角是"套公式"，不是"把系数乘 2"。

3.3 降幂公式（由二倍角反推，选填必用）

把二倍角公式反解出来，就得到降幂公式——看到平方就想降幂：

  • cos2α  =  (1 + cos 2α) / 2
  • sin2α  =  (1 − cos 2α) / 2

反过来是升幂： 1 + cos 2α  =  2cos2α；1 − cos 2α  =  2sin2α。

什么时候用？ 题目出现 sin2x、cos2x，无法直接化简，降幂后角变成 2x，往往就能和别的项合并、再用辅助角合一。还有一个常用小结论：(sinα ± cosα)2  =  1 ± sin2α。

例题跟讲例题 3.3-1：化简 sin2x + cos2x 之外，求 cos215° 的值（不用计算器）。 解：cos215°  =  (1 + cos30°)/2  =  (1 + √3/2)/2  =  (2+√3)/4。 要点：看到"角度一半的平方"，用降幂公式立刻变成特殊角 30°。

陷阱：方向别反——见到 cos2α 降幂，见到 cos 2α 升幂。

3.4 辅助角公式（合一变形，高考高频）

这是本章最有用的一招。任何 a sin x + b cos x 都能合成"一个正弦"：

a sin x + b cos x  =  √(a2 + b2) · sin(x + φ)， 其中 tan φ  =  b/a，且 φ 所在象限由 (a, b) 的符号决定。

为什么能合？ 右边展开 √(a2+b2)[sin x cosφ + cos x sinφ]，要等于左边 a sin x + b cos x，就得 √(a2+b2)cosφ  =  a、√(a2+b2)sinφ  =  b。于是 cosφ  =  a/√(a2+b2)、sinφ  =  b/√(a2+b2)，φ 就是点 (a,b) 对应的角。

经典两例（背下来）：

  • sin x + cos x  =  √2 sin(x + π/4)（a = 1,b = 1,√(a2+b2) = √2, φ = π/4）
  • √3 sin x − cos x  =  2 sin(x − π/6)（a = √3,b = −1,√(a2+b2) = 2, φ 在第四象限）

用途：合一之后，求周期、最值、单调区间全部"读"出来——最大值就是 √(a2+b2)，最小值是它的相反数。

（合并后仍是一个 y  =  A sin(x + φ) 形式的正弦，图象仍是正弦曲线：从 y  =  sin x 到 y  =  A sin(ωx+φ) 的平移与伸缩过程，见 06 章 3.6 节的配图。）

例题跟讲例题 3.4-1：求 f(x)  =  sin x + √3 cos x 的最大值与周期。 解：a = 1, b = √3，√(a2+b2)  =  2，tanφ  =  √3，且 a,b 都正（φ 在第一象限），φ  =  π/3。 f(x)  =  2 sin(x + π/3)。最大值 2，周期 2π。 要点：合一后最值直接看振幅，不用再想。

陷阱：只写 tanφ  =  b/a 会丢符号——φ 的象限要结合 a、b 正负来定。

编者注·本质回扣：辅助角公式是本章"归约"思想的极致体现。a sin x + b cos x 里有正弦、有余弦、系数还不一样，乱成一锅；但把它写成 √(a2+b2)·sin(x+φ) 之后，就变回了第 06 章那个单一的正弦波——周期、最值、单调区间全部直接读出来。你要做的本质上就是"换个看法"：把点 (a,b) 当直角坐标读出它对应的那个角 φ，再把整坨式子折成一根正弦曲线。所谓"φ 的象限由 (a,b) 符号定"，不过是看这个点落在第几象限而已。

3.5 两类核心题型

第 1 类：给值求值。 已知某个三角函数值，求另一个。 流程：① 先用平方关系补齐缺的三角函数值；② 开方时看象限定正负；③ 套和差角或二倍角公式。

第 2 类：给值求角。 已知某个三角函数值，求角 α。 流程：① 先求该角的一个三角函数值（如 cosα）；② 圈出角的范围；③ 用单调性在范围内确定唯一角。

例题跟讲例题 3.5-1（给值求角）：已知 cosα  =  −√2/2，且 α ∈ (0, π)，求 α。 解：cosα  =  −√2/2，α ∈ (0,π)，cos 在 (0,π) 单调递减，cos(3π/4)  =  −√2/2，故 α  =  3π/4。 要点：不写范围，cosα = −√2/2 在 0~2π 内有两个解（3π/4 和 5π/4），范围一卡就唯一。

小结：这一章的公式是一张网，根是两角差的余弦；二倍角、降幂、辅助角都是它的推论。做题时先判断"缺哪个值、角在什么范围"，再选公式。

3.6 三角式化简的三条路线（提升）

拿到一个长得很吓人的三角式，别慌，按这三条路一条条试：

  1. 降幂路线：见 sin2、cos2 就用降幂公式，把平方"打下来"，角翻倍。
  2. 合一路线：见 a sinx + b cosx（或整理成这个样子）就用辅助角公式合成一个正弦。
  3. 配角路线：题目给 α、β 的某种组合（如给 α+β、α−β），把要求的角用它们表示。比如已知 α+β 和 α−β，求 α，就用 α  =  [(α+β)+(α−β)]/2。

例题跟讲例题 3.6-1：已知 α+β  =  π/3，α−β  =  π/6，求 2α。 解：2α  =  (α+β) + (α−β)  =  π/3 + π/6  =  π/2。 要点：配角思想——不用单独求 α、β，把目标角配成已知角的和差。

进阶/选学（超纲红线，只用于理解）：老教材里还有"积化和差、和差化积"两组公式（如 sinαcosβ  =  ½[sin(α+β)+sin(α−β)]）。新高考已不要求直接背，考试禁用这两组公式跳步，需要时用和差角公式现场推。知道有这回事、能推出来即可，别在卷子上直接套。

④ 例题详解（先做再看）

例题例 1（给值求值）：已知 sin α  =  3/5（α 在第二象限），求 sin 2α 和 cos 2α。

自己做：先补 cos α。

解：cos α  =  −4/5（第二象限）。sin 2α  =  2·(3/5)·(−4/5)  =  −24/25。cos 2α  =  1 − 2sin2α  =  1 − 2·(9/25)  =  7/25。 要点：二倍角用含 sin 的公式最省事；符号由 sin α 本身决定，不需要额外定。

例题例 2（合一变形）：求函数 f(x)  =  sin x + √3 cos x 的最大值与周期。

自己做：先合一。

解：f(x)  =  2 sin(x + π/3)（a  =  1, b  =  √3，√(a2+b2)  =  2，tan φ  =  √3 且在第一象限 ⇒ φ  =  π/3）。最大值 2；周期 T  =  2π。 要点：合一后一切性质（最值/周期/单调）直接读。

例题例 3（化简求值）：化简 (cos 15° − sin 15°)/(cos 15° + sin 15°)。

自己做：分子分母同除以 cos 15°。

解：原式  =  (1 − tan 15°)/(1 + tan 15°)  =  tan(45° − 15°)  =  tan 30°  =  √3/3。 要点：看到"1 ± tan"想到 tan 的和差角公式（tan(45°∓α) 结构）。

例题例 4（tan 和差角变形公式，苏州教研·专题29，原书p.127 B组）：求 tan 18° + tan 42° + √3 tan 18° tan 42° 的值。

自己做：18°+42°  =  60°，凑 tan(α+β)。

解：60°  =  18°+42°。由 tan(α+β) 的变形公式 tanα+tanβ  =  tan(α+β)(1−tanα tanβ)： tan18°+tan42°  =  tan60°·(1−tan18° tan42°)  =  √3(1−tan18° tan42°)。 代回原式：√3(1−tan18°tan42°) + √3 tan18°tan42°  =  √3。 要点：看到"tanα+tanβ"和"tanα tanβ"同时出现，就用 tanα+tanβ  =  tan(α+β)(1−tanα tanβ) 整体代换，乘积项会抵消。

例题例 5（辅助角公式 + 配角，苏州教研·专题30，原书p.127 B组）：求函数 y  =  3 sin(x+20°) + 5 cos(x−10°) 的最大值。

自己做：两个角差 30°，先把它们配成同一个角。

解：(x−10°) − (x+20°)  =  −30°，即 x−10°  =  (x+20°) − 30°。令 θ  =  x+20°，则 cos(x−10°)  =  cos(θ−30°)  =  cosθ cos30° + sinθ sin30°  =  (√3/2)cosθ + (1/2)sinθ。 y  =  3 sinθ + 5[(√3/2)cosθ + (1/2)sinθ]  =  (3+5/2)sinθ + (5√3/2)cosθ  =  (11/2)sinθ + (5√3/2)cosθ。 合一：振幅 R  =  √((11/2)2 + (5√3/2)2)  =  √((121+75)/4)  =  √(196/4)  =  √49  =  7。 故 y 的最大值就是振幅 7。 要点：两个不同角的 sin、cos 相加，先用配角把它们并到同一个角 θ，再用辅助角公式合一，最大值直接读振幅 R。

⑥ 常见坑清单

  • sin(α ± β) 与 cos(α ± β) 中间符号相反：cos 是"cos cos ∓ sin sin"，别记成同号。
  • 二倍角 cos 2α 三种写法要灵活换：求 sin2α 用 1 − 2sin2α 反解最方便。
  • 合一变形 φ 的象限：只写 tan φ = b/a 会丢符号，要结合 a、b 的正负定 φ。
  • 给值求角：范围不写，答案不唯一——这是给值求角的唯一扣分点。
  • 降幂公式方向：见到 cos2α、sin2α 想降幂，见到 cos 2α 想升幂。

本章公式速查表

与《高中数学常用公式·修订版》第三部分第 8、9 条核对一致。

和差角公式（一切的根）

根：cos(α−β)  =  cosα cosβ + sinα sinβ

  • 大白话两角差的余弦，等于"余弦余弦相加、正弦正弦相加"。整套和差角公式都从它推出来。
  • 用的时候：记不住全套时，先推出这一条，再用"把 β 换成 −β"变出其余。

sin(α±β)  =  sinα cosβ ± cosα sinβ（中间符号相同）

  • 大白话正弦展开是"正余、余正"，括号里是加号结果就加号、减号就减号。
  • 用的时候：这是最不容易记反的一条，中间符号跟着 α±β 走。

cos(α±β)  =  cosα cosβ ∓ sinα sinβ（中间符号相反）

  • 大白话余弦展开是"余余、正正"，但中间符号要反过来——α+β 反而用减号。
  • 用的时候：这是最容易写反的地方，cos(α+β) 中间是减号。

tan(α±β)  =  (tanα ± tanβ)/(1 ∓ tanα tanβ)

  • 大白话分子同号、分母反号。
  • 用的时候：分母符号别写反；出现"1±tan"的结构就想到它（如 tan(45°±α)）。

和差角的乘积推论

sin(α+β)sin(α−β)  =  sin2α − sin2β

  • 大白话两个正弦相乘（角相差 2β），能化成"大角正弦平方减小角正弦平方"。
  • 用的时候：选填里见到 sin(A+B)sin(A−B) 这种结构可直接套。

cos(α+β)cos(α−β)  =  cos2α − sin2β

  • 大白话余弦版本的同款化简。
  • 用的时候：和上一条配对记，现场推不出来再查。

二倍角公式

sin 2α  =  2 sinα cosα

  • 大白话二倍角的正弦 = 正弦余弦乘积的 2 倍。
  • 用的时候：注意 sin2α ≠ 2sinα，别把系数直接乘进去。

cos 2α  =  cos2α − sin2α  =  2cos2α − 1  =  1 − 2sin2α

  • 大白话二倍角余弦有三张"面孔"，给 sin 就用 1−2sin2α，给 cos 就用 2cos2α−1。
  • 用的时候：哪种给的三角函数值方便就用哪张脸，省得再开方。

tan 2α  =  2tanα/(1 − tan2α)

  • 大白话正切的二倍角，分子 2tan、分母 1−tan2。
  • 用的时候：分母是 1−tan2α，别漏平方。

升幂与降幂

降幂：cos2α  =  (1+cos2α)/2，sin2α  =  (1−cos2α)/2

  • 大白话看到 sin2、cos2 就用它把平方"打下来"，同时角变成原来的 2 倍。
  • 用的时候：选填见平方先想降幂，降完往往能再用辅助角合一。

升幂：1+cos2α  =  2cos2α，1−cos2α  =  2sin2α

  • 大白话降幂反过来就是升幂，把常数变成平方。
  • 用的时候：方向别反——见 cos2α 降幂，见 cos2α 升幂。

(sinα ± cosα)2  =  1 ± sin2α

  • 大白话正弦余弦和（差）的平方，展开后就剩 1 和 sin2α。
  • 用的时候：见到"sin±cos 的平方"直接化简，省得展开。

辅助角公式（合一变形）

a sinx + b cosx  =  √(a2+b2)·sin(x+φ)，tanφ  =  b/a，φ 所在象限由点 (a,b) 的符号决定

  • 大白话任何"正弦加余弦"都能捏成一个正弦；捏出来的振幅就是 √(a2+b2)。
  • 用的时候：合一后周期、最值、单调区间直接读；只写 tanφ=b/a 会丢符号，φ 的象限要结合 a、b 正负定。
  • 记忆要点：φ 就是坐标平面里点 (a,b) 对应的那个角。

经典两例：sinx + cosx  =  √2 sin(x+π/4)；√3 sinx − cosx  =  2 sin(x−π/6)

  • 大白话两个最常考的合一成品，背下来小题能秒。
  • 用的时候：第一个 a=b=1；第二个 a=√3、b=−1（φ 在第四象限）。

tan 与根式的进阶结论（苏州教研·专题29）

tan 变形公式：tanα + tanβ  =  tan(α+β)(1 − tanα tanβ)；tanα − tanβ  =  tan(α−β)(1 + tanα tanβ)

  • 大白话正切和角公式倒过来用——见到"tanα±tanβ"和"tanα tanβ"同框，就能把前者用 tan(α±β) 整体换掉。
  • 用的时候：tan18°+tan42°+√3 tan18°tan42° 这类题，代换后乘积项抵消，一步出结果。

去根号（半角平方）：1 ± sinα  =  (sin(α/2) ± cos(α/2))2；1 + cosα  =  2cos2(α/2)；1 − cosα  =  2sin2(α/2)

  • 大白话根号里的"1±sinα""1±cosα"都能写成完全平方，根号直接脱掉。
  • 用的时候：化简 √(1+sinα)、√(1−cosα) 时先配方；注意开方后要按角的范围定正负。

两个小结论（选填可秒）：α+β = π/4 时 (1+tanα)(1+tanβ) = 2；α+β = 3π/4 时 (1−tanα)(1−tanβ) = 2

  • 大白话两角和为特殊角 π/4 或 3π/4 时，"1±tan"的乘积是常数 2。
  • 用的时候：选填见到这两个乘积结构，不用展开直接写 2。

辅助角的对称轴：f(x) = a sinx + b cosx 关于 x = x0 对称 ⇔ f(x0) = ±√(a2+b2)（即取到最值）

  • 大白话合一后是 y=R sin(x+φ)，对称轴一定过峰或谷，也就是函数取到 ±R 的地方。
  • 用的时候：题目说"f(x) 关于 x=x0 对称"，立刻知 f(x0) 等于振幅 ±√(a2+b2)，不用求导。

5.1 辅助角公式（合一变形）

大白话·本质一句话：辅助角就是把 a·sin x 与 b·cos x 这两个频率相同、相位不同的波，合体成一个波 a·sin x+b·cosx  =  √(a2+b2)·sin(x+φ)；合成后振幅 √(a2+b2) 直接告诉你最值是多少，周期、单调区间也跟着这个新波一起读出来。

asinx + bcosx  =  √(a2+b2)·sin(x+φ)，其中 tanφ = b/a。

用于求最值、周期、单调区间；求最值时直接看振幅。

课标依据：两角和差公式逆用（必修一）。✓

（高级方法手册·5.1）

进阶·辅助角公式（合一变形）—— 不超纲（高考可放心用）

对应《不超纲高级方法手册》五.5.1。

  • 适用信号：题目里出现 a sinx + b cosx 这种"正弦加余弦"的混合式，要求它的周期、最值、单调区间，或要把复杂三角式化成单一正弦。

  • 操作步骤： 1. 提取 √(a2+b2) 作为新振幅； 2. 由 cosφ  =  a/√(a2+b2)、sinφ  =  b/√(a2+b2) 定 φ（或先算 tanφ = b/a 再按 (a,b) 象限定 φ）； 3. 写成 R sin(x+φ) 后，最值  =  ±R、周期  =  2π、单调区间直接读。

  • 例题：求 f(x)  =  sinx + √3 cosx 的最大值。R  =  √(1+3)  =  2，f(x)  =  2 sin(x+π/3)，最大值 2。

  • 课标依据 / 超纲红线：本质是两角和公式的逆用（必修一 5.5），不超纲，高考解答题可放心使用。红线提醒：不要额外引入"万能公式""积化和差"等超纲推导过程，合一这一步本身合规。

自测答案：1. sin 75°  =  sin(45°+30°)  =  (√2/2)(√3/2) + (√2/2)(1/2)  =  (√6+√2)/4；2. cos 2α  =  2·(1/9) − 1  =  −7/9；3. f(x)  =  2 sin(x + π/6)，最大值 2；4. 2sin2α − 1  =  −cos 2α；5. (1 + tan α)/(1 − tan α)。

一通百通

拿到任何一道三角恒等变换题，通用骨架都是四步：① 先看角——题目里有哪几个角？它们是不是同一个角，还是 α+β、2α、两个不同角在打架；② 配角——把要求的角用已知角表示出来，目标是"统一到一个角"；③ 选公式——见平方就降幂、见 sinx+b cosx 型就合一、见 tanα±tanβ 就配 tan(α±β)；④ 定符号——开方、定象限之前先圈出角的范围，再写正负。会解一道给值求值，就会解这一整类；这套"先归约到同一个角、再套公式"的骨架，第 08 章解三角形做大题第二问求最值时还要再用一遍（合一之后读最值）。

跨章结合

  • 07 的"辅助角合一" + 第 06 章的"y=A sin(ωx+φ) 读法"：把 a sin x+b cos x 合一成 R sin(x+φ) 后，最大值就是振幅 R、周期与单调区间全部直接读——本章例 2（f(x)=sin x+√3 cos x 最大值 2）和苏州教研·专题30 的综合题（y=3sin(x+20°)+5cos(x−10°)，先配角并到同一角 θ 再合一，最大值=7）都是这一结合点。
  • 07 的"tan 变形公式" + 特殊角凑角：看到"tanα±tanβ 和 tanα tanβ 同框"，用 tanα+tanβ=tan(α+β)(1−tanα tanβ) 整体代换、乘积项抵消——苏州教研·专题29 的 tan18°+tan42°+√3 tan18°tan42°=√3（本章例 4）就是这一结合点的成品。
  • 07 的"辅助角求最值" + 第 05 章导数求最值（综合原理说明，非真题）：求 a sin x+b cos x 的最值，合一后直接读振幅 R 最快；若改用第 05 章对 f(x)=a sin x+b cos x 求导、令 f′(x)=a cos x−b sin x=0 找驻点，两条路殊途同归——合一公式本质上就是"不用求导、一步读出那个极值"。
  • 07 的"恒等变换" + 第 16 章椭圆参数方程（综合原理说明，非真题）：椭圆常写成 x=a cosθ、y=b sinθ 的参数形式，椭圆上一点到直线的距离、或三角形面积最值，代入后往往冒出来 a sinθ+b cosθ 型的混合式，最后仍靠本章的辅助角合一收尾。

本章与前后章

本章紧接第 06 章：没有第 06 章的单位圆定义、同角关系 sin2+cos2=1 和诱导公式，本章的和差角公式连推导的地基都没有。本章又为第 08 章解三角形备好武器——大题第二问求面积、周长的最值范围，最后一步往往就是靠本章的辅助角公式把多个三角函数合一、再读出最大值。同时，本章的合一变形也回头解释了第 06 章 y=A sin(ωx+φ) 里那串参数到底怎么来的。所以这一章是三角函数板块承上启下的枢纽：向上把三角函数之间打通，向下给解三角形递工具。

高考怎么考

新高考Ⅰ卷里恒等变换大多以 1 道小题出现（选择题第 4~10 题一带），偶尔融进解三角形大题。典型考法：给 tanα·tanβ 之类的乘积条件，求 cos(α−β) 与 cos(α+β) 的关系（如 2024 新高考Ⅰ卷第 4 题，cos(α+β)=m、tanα·tanβ=2，答案为 −3m）；求 a sin x+b cos x 型函数的最大值、周期、单调区间（辅助角合一后直接读）；以及 tan18°+tan42° 这类"tan 加减 + tan 乘积"的整体代换。难度中档，关键不是背公式，而是看出"该把哪几个角归约成一个"。
