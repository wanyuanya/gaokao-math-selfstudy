公式速查：修订版 第10部分（复数）

本章本质核心：复数的本质是"把数从一维直线搬到二维平面"——规定 i2 = −1 等于把 i 当成一个"逆时针转 90°"的算子，于是每个复数 z = a+bi 就是复平面上的一个点（或一支从原点出发的向量），|z| 就是它到原点的距离。本章全部内容（相等、共轭、模、四则运算、复根）都是这一个原理的变体：运算像多项式展开，唯一新规则是 i2 = −1，几何上和第 09 章向量是同一张图。

为什么有用想通"i 是转 90°、z = a+bi 是平面上的点"，复数运算就只是多项式展开加一条 i2 = −1，除法会乘共轭就行——卷面上固定的第 1 题送分等于白捡；它的几何意义还能帮你看懂圆和旋转。

③ 正文讲解

先想一个让人"卡住"的问题：方程 x2 + 1  =  0，在实数范围内没解——因为没有哪个实数的平方是 −1。数学家不甘心：那就规定一个新数 i，让它满足 i2  =  −1。有了 i，负数就能开平方了，二次方程也总是有解了。这就是复数的来历。

这段历史值得知道：i 刚被提出时，连数学家都觉得别扭——"平方是负数的数，存在吗？"所以给它起名叫"虚数"，意思是"虚幻的数"。后来发现它能描述交流电、波浪、量子力学，才成了正经工具。名字里的"虚"只是历史玩笑，别被它吓到。本章地图：

i（规定 i2 = −1）
   ↓
复数 z  =  a+bi（实部 a、虚部 b）
   ↓
复数相等 / 共轭 / 模
   ↓
四则运算（除法 = 分母实数化）
   ↓
几何意义：复平面上的点与向量

3.1 复数的概念

  • 复数不能比大小：两个复数（只要不全是实数）不能说谁大谁小——你不能写 "1+i > 2−i"。能比大小的只有它的模 |z|（那是个实数）。这和向量不能比大小是一个道理。

i 的幂循环：i1  =  i，i2  =  −1，i3  =  −i，i4  =  1，然后 i5  =  i……每 4 个一循环。

复数（人教A版口径）：形如 z  =  a + bi（a、b ∈ R）的数叫复数。a 叫实部，b 叫虚部。全体复数组成复数集 C。

  • b  =  0：z 是实数；
  • b ≠ 0：z 是虚数；
  • a  =  0 且 b ≠ 0：z 是纯虚数（如 3i、−0.5i）。

复数相等：a + bi  =  c + di ⇔ a  =  c 且 b  =  d（实部等于实部，虚部等于虚部，两个条件缺一不可）。

复数家族的关系：实数是复数的"子集"（b = 0 的复数就是实数）；虚数里再分出纯虚数（a = 0,b≠0）。画个圈想：最大的圈是复数 C，里面套着实数和虚数两块，纯虚数只是虚数里的一小块。考试常考"z 是纯虚数"这个条件，记得要同时写 a = 0 和 b≠0 两个方程。

例题跟讲例题 3.1-1：若 (a+1) + (b−2)i  =  3 + 4i，求 a、b。 解：实部相等 a+1  =  3 → a  =  2；虚部相等 b−2  =  4 → b  =  6。 要点：复数相等要两边实部、虚部分别相等，列两个方程。

例题跟讲例题 3.1-0（i 的幂）：求 i2024 的值。 解：i 的幂 4 个一循环：2024 ÷ 4  =  506 余 0，正好整除，所以 i2024  =  i4  =  1。 要点：求 i 的大数次幂，用指数除以 4 看余数——余 0 是 1，余 1 是 i，余 2 是 −1，余 3 是 −i。

例题跟讲例题 3.1-2：判断 2i、3、−5、0 各是不是纯虚数。 解：纯虚数要求 a = 0 且 b≠0。2i 是纯虚数；3、−5、0 是实数（b = 0），不是纯虚数。 要点：实部为 0 还不够，虚部不能为 0——0 不是纯虚数。

编者注·本质回扣：i 这个"虚幻的数"，本质就是一个"转 90°"的记号。实数只能在一条直线上左右走，乘 −1 是掉头（转 180°）；现在规定乘 i 是转 90°，那转两次就是转 180°，正好得到 i2 = −1——这就是为什么 i2 = −1，不是硬规定。有了它，每个复数 a+bi 就能拆成"实轴走 a 步、虚轴走 b 步"，对应平面上一个点。复数不能比大小，和向量不能比大小是同一个道理：平面上的点没有"谁大谁小"，只有到原点的距离（模）能比。

3.2 共轭与模

共轭复数：z  =  a + bi 的共轭记作 z  =  a − bi（实部不变，虚部变号）。一个好用的结论：z·z  =  a2 + b2（是个实数）。

模：|z|  =  √(a2 + b2)。它是一个非负实数，表示复平面上 z 这个点到原点的距离。

共轭在图上是什么？ z  =  a+bi 对应点 (a,b)，共轭 z  =  a−bi 对应点 (a,−b)——这两个点关于实轴对称。所以"取共轭"就是"把点沿实轴翻个面"。

例题跟讲例题 3.2-1：已知 z  =  3 − 4i，求 |z| 和 z·z。 解：|z|  =  √(32+(−4)2)  =  5；z·z  =  32+42  =  25  =  |z|2。 要点：z·z  =  |z|2 恒成立，小题常用来"消掉 i"。

模的两条好性质：|z1·z2|  =  |z1|·|z2|，|z1/z2|  =  |z1|/|z2|。意思是"乘积的模  =  模的乘积，商的模  =  模的商"。求复杂复数的模时，可以先拆开算模再相乘，比先化简省事。

3.3 四则运算

复数运算就把 i 当成一个字母，像多项式一样展开，唯一的新规则是 i2  =  −1，最后把 i2 换成 −1。换句话说：会做多项式乘法，就会复数乘法；会分数通分，就会复数除法。

  • 加减：实部、虚部分别相加减：(a+bi) ± (c+di)  =  (a±c) + (b±d)i。
  • 乘法：像多项式乘：(a+bi)(c+di)  =  ac + adi + bci + bdi2  =  (ac−bd) + (ad+bc)i。
  • 除法：分母实数化——分子分母同乘分母的共轭，把分母变成实数： (a+bi)/(c+di)  =  (a+bi)(c−di) / [(c+di)(c−di)]  =  [(ac+bd) + (bc−ad)i] / (c2+d2)。

计算流程（除法）：

  1. 看分母是 c+di，写它的共轭 c−di；
  2. 分子分母同乘 c−di；
  3. 分母变成 c2+d2（实数）；
  4. 分子展开、i2 换 −1，整理成 a+bi。

例题跟讲例题 3.3-1：计算 (1+2i)/(1−i)。 解：同乘分母共轭 (1+i)： 原式  =  (1+2i)(1+i)/[(1−i)(1+i)]  =  (1+i+2i+2i2)/(1+1)  =  (1+3i−2)/2  =  −1/2 + (3/2)i。 要点：(1−i)(1+i)  =  1−i2  =  2，分母干净了。

例题跟讲例题 3.3-2：计算 (1+i)2。 解：(1+i)2  =  1 + 2i + i2  =  1 + 2i − 1  =  2i。 要点：常用小结论 (1±i)2  =  ±2i，记下来小题能秒。

例题跟讲例题 3.3-3：计算 (2−i)/(3+i)。 解：分母共轭是 3−i。分子分母同乘： 原式  =  (2−i)(3−i)/[(3+i)(3−i)]  =  (6−2i−3i+i2)/(9+1)  =  (6−5i−1)/10  =  (5−5i)/10  =  1/2 − (1/2)i。 要点：分母实数化后，分母一定是 c2+d2；分子展开别急着约，最后一步再约分。

陷阱：乘完一定要把 i2 换成 −1，这是唯一容易漏的代换。

两个可背的模板：(1+i)/(1−i)  =  i，(1−i)/(1+i)  =  −i。推导：前者分子分母同乘 (1+i) 得 (1+i)2/2  =  2i/2  =  i。选择题里见到这种形式，直接写结果，不用现算。

编者注·本质回扣：复数四则运算看着新，本质就是多项式运算外加一条 i2 = −1。加减是实部虚部分别合并同类项；乘法像 (a+b)(c+d) 那样展开，只是最后把 i2 换成 −1；除法最巧——分母是 c+di，乘上它的共轭 c−di 后，按平方差得 c2+d2 变成纯实数，分母就"干净"了，这一步叫分母实数化，和分数里"分母有理化"是同一个思路。所以会做多项式乘法和分数通分，就会复数运算。

3.4 几何意义（复平面）

把直角坐标系借给复数用：x 轴叫实轴，y 轴叫虚轴，复数 z  =  a+bi 对应平面上的点 (a,b)，也对应从原点到该点的向量 OZ。

  • |z|  =  点 z 到原点的距离；
  • |z1 − z2|  =  两点 z1、z2 之间的距离；
  • 加法的几何意义：向量平行四边形法则。

为什么复数加法像向量加法？ 因为复数 a+bi 本来就对应向量 (a,b)。两个复数相加  =  两个向量相加，坐标对应相加即可，画在图上就是平行四边形法则。这也说明：复数的几何和向量（第 09 章）是同一张图，你已经会了，这里只是换个名字。

例题跟讲例题 3.4-1：|z−1|  =  2 在复平面上表示什么图形？ 解：|z−1| 是点 z 到点 (1,0) 的距离，等于 2，所以是以 (1,0) 为圆心、半径 2 的圆。 要点：|z−z0|  =  r 就是"以 z0 为圆心、r 为半径的圆"。

例题跟讲例题 3.4-2：求 z1  =  3+4i 与 z2  =  0 之间的距离。 解：|z1−z2|  =  |z1|  =  √(32+42)  =  5。 要点：两点距离就是复数差的模，和向量里"两点距离  =  向量模"一模一样——复数和向量在平面上是同一张图。

3.5 实系数二次方程的复数根（了解）

初中说"判别式 Δ<0 时方程没有实数根"。有了复数，这句话要改口：不是没根，是没有实根，但有一对共轭复根。

对实系数一元二次方程 ax2 + bx + c  =  0（a≠0），记 Δ  =  b2−4ac：

  • Δ > 0：两个不等实根 x  =  (−b±√Δ)/(2a)；
  • Δ  =  0：两个相等实根 x  =  −b/(2a)；
  • Δ < 0：实数范围内无实根，复数集内有一对共轭复根：x  =  (−b ± √(−Δ)·i)/(2a)。

例题跟讲例题 3.5-1：解方程 x2 + 2x + 5  =  0。 解：Δ  =  4 − 20  =  −16 < 0。由公式 x  =  (−2 ± √16·i)/2  =  (−2 ± 4i)/2  =  −1 ± 2i。 要点：Δ<0 时照套求根公式，把 √Δ 换成 √(−Δ)·i，最后约分得标准 a+bi。

例题跟讲例题 3.5-2：解方程 x2 + 9  =  0。 解：x2  =  −9  =  9i2，故 x  =  ±3i。两根 3i 与 −3i 互为共轭，符合"实系数方程复根成对"。 要点：这种缺一次项的，直接 x2  =  负数，开方得 ±√(正数)·i。

为什么两根共轭？ 因为系数都是实数，若 x  =  a+bi 是根，把 i 换成 −i（取共轭）等式仍然成立，所以共轭复数 a−bi 也是根。这解释了"复根成对出现"。

3.6 复数方程里的待定系数

高考有一类题：给一个含实数 x、y 的复数等式，让你求 x、y。钥匙只有一把——复数相等 ⇔ 实部相等、虚部相等。把两边都整理成 a+bi 标准形，令实部 = 实部、虚部 = 虚部，就得到两个方程。

例题跟讲例题 3.6-1：已知 (x + yi)·i  =  1 − i（x、y 为实数），求 x、y。 解：左边先展开：(x+yi)·i  =  xi + yi2  =  xi − y  =  −y + xi。 右边是 1 − i。复数相等 ⇒ 实部相等：−y  =  1；虚部相等：x  =  −1。 故 x  =  −1，y  =  −1。 一步一验：代回 (−1−i)·i  =  −i − i2  =  −i + 1  =  1 − i，与右边相等 ✓。

例题跟讲例题 3.6-2：已知 z + 2·z  =  9 + i（z 为复数），求 z。 解：设 z  =  a+bi，则 z  =  a−bi。代入：(a+bi) + 2(a−bi)  =  3a − bi。 等于 9 + i ⇒ 实部 3a  =  9，虚部 −b  =  1 ⇒ a  =  3，b  =  −1。 故 z  =  3 − i。 要点：见到 z 就设 z  =  a+bi 展开，再用"实部 = 实部、虚部 = 虚部"列两个方程。

小结：复数  =  实数 + 一个 i；运算像多项式，只多一条 i2 = −1；除法靠乘共轭"实数化"；几何上它就是复平面上的点和向量。考试拿分的关键就两处：i2 = −1 别代错，除法别忘了乘共轭。

④ 例题详解（先做再看）

例题例 1（运算 + 纯虚数）：已知 z  =  (1 + i)(2 − i)，求 z 的实部与虚部。

自己做：展开，i2 换成 −1。

解：(1 + i)(2 − i)  =  2 − i + 2i − i2  =  2 + i + 1  =  3 + i。实部 3，虚部 1。 要点：i2  =  −1 是唯一的"新"规则，其余都像多项式乘法。

例题例 2（除法  =  分母实数化）：计算 (1 + 2i)/(1 − i)。

自己做：乘共轭。

解：原式  =  (1 + 2i)(1 + i)/[(1 − i)(1 + i)]  =  (1 + i + 2i + 2i2)/(1 + 1)  =  (1 + 3i − 2)/2  =  (−1 + 3i)/2  =  −1/2 + (3/2)i。 要点：分母是 a + bi 就乘 a − bi；(1 − i)(1 + i)  =  1 + 1  =  2 是常见模板。

例题例 3（模与共轭）：已知 z  =  3 − 4i，求 |z| 与 z·z。

自己做：套公式。

解：|z|  =  √(9 + 16)  =  5；z·z  =  32 + 42  =  25  =  |z|2。 要点：z·z  =  |z|2 恒成立，小题常用来化简。

⑥ 常见坑清单

  • i2 = −1：乘完别忘把 i2 换成 −1，这是唯一易错代换。
  • 复数相等：必须两个条件同时成立（实部、虚部各自相等）。
  • 除法别忘分母实数化：结果要写成 a + bi 标准形式。
  • 纯虚数：a = 0 且 b ≠ 0，实部为 0 还不够，虚部不能为 0。
  • |z| 是模（长度），不是"绝对值"——z 是复数时别写成 |z| = z 或 −z。
  • i 的幂循环：i4n = 1，i4n+1 = i，i4n+2 = −1，i4n+3 = −i。

复数的概念

z  =  a + bi（a、b 为实数）：a 叫实部，b 叫虚部；b = 0 是实数，b≠0 是虚数，a = 0 且 b≠0 是纯虚数

  • 大白话复数 = 实数部分 + 一个 i 乘出来的部分；纯虚数要求实部为 0 且虚部不为 0。
  • 用的时候：说"纯虚数"必须同时写 a=0 和 b≠0 两个条件；0 不是纯虚数。

复数相等：a + bi  =  c + di ⇔ a  =  c 且 b  =  d

  • 大白话两个复数相等，必须实部等于实部、虚部等于虚部，两个条件缺一不可。
  • 用的时候：给含 x、y 的复数等式求未知数，就靠它列两个方程。

四则运算（i2 = −1 是唯一新规则）

加减：(a+bi) ± (c+di)  =  (a±c) + (b±d)i

  • 大白话实部、虚部分别相加减。
  • 用的时候：像合并同类项一样，别把实部和虚部混着加。

乘法：(a+bi)(c+di)  =  (ac−bd) + (ad+bc)i

  • 大白话像多项式一样展开，最后把 i2 换成 −1。
  • 用的时候：乘完一定记得 i2=−1，这是唯一容易漏的代换。

除法：(a+bi)/(c+di)  =  [(ac+bd) + (bc−ad)i] / (c2+d2)（分母不为 0）

  • 大白话分子分母同乘分母的共轭，把分母"实数化"成 c2+d2。
  • 用的时候：结果要写成 a+bi 标准形；别忘乘共轭这一步。

共轭与模

共轭：z  =  a+bi 的共轭 z  =  a − bi（实部不变，虚部变号）

  • 大白话取共轭就是把点沿实轴翻个面。
  • 用的时候：除法里乘的那个"分母共轭"就是它。

z·z  =  |z|2  =  a2 + b2

  • 大白话一个复数乘它的共轭，一定等于模的平方，是个实数。
  • 用的时候：小题里常用它"消掉 i"、化简分母。

模：|z|  =  √(a2 + b2)

  • 大白话模就是复平面上点 (a,b) 到原点的距离，是个非负实数。
  • 用的时候：复数本身不能比大小，但模能比。

模的乘法性质：|z1·z2|  =  |z1||z2|；|z1/z2|  =  |z1|/|z2|

  • 大白话乘积的模等于模的乘积，商的模等于模的商。
  • 用的时候：求复杂复数的模，可以先拆开算模再相乘，比先化简省事。

i 的幂与常用小结论

i 的幂每 4 个一循环：i4n = 1，i4n+1 = i，i4n+2 = −1，i4n+3 = −i

  • 大白话i 的大数次幂，指数除以 4 看余数——余 0 是 1，余 1 是 i，余 2 是 −1，余 3 是 −i。
  • 用的时候：求 i2024 这种，先拿指数除以 4。

常用小结论：(1+i)2  =  2i，(1−i)2  =  −2i；(1+i)/(1−i)  =  i，(1−i)/(1+i)  =  −i

  • 大白话见到这两种特殊形式直接写答案，不用现场算。
  • 用的时候：选择题里秒答；不熟就分子分母乘共轭推一遍。

平行四边形恒等式：|z1+z2|2 + |z1−z2|2  =  2(|z1|2 + |z2|2)

  • 大白话两复数和的模平方加差的模平方，等于各自模平方和的 2 倍。
  • 用的时候：知道 |z1|、|z2| 及和（差）模之一时，可求另一个。

实系数二次方程的复根（了解）

ax2+bx+c = 0（实系数），Δ = b2−4ac：Δ<0 时有一对共轭复根 x  =  (−b ± √(−Δ)·i)/(2a)

  • 大白话判别式小于 0 不是"没根"，而是没有实根、有一对互为共轭的复根。
  • 用的时候：照套求根公式，把 √Δ 换成 √(−Δ)·i；两根互为共轭。

复数范围内因式分解与单位根（苏州教研·专题53）

a2 + b2  =  (a + bi)(a − bi)（a、b 为实数）

  • 大白话在实数里 a2+b2 不能再分解，到了复数里就能拆成一对共轭复数的乘积。
  • 用的时候：x2+4  =  (x+2i)(x−2i) 这类题直接套；因式分解范围从实数扩到复数。
  • 记忆要点：平方和  =  共轭两复数相乘，正好和 z·z  =  a2+b2 反过来用。

|z|  =  |z|

  • 大白话一个复数和它的共轭，模是一样大的（它们关于实轴对称，到原点距离相同）。
  • 用的时候：求共轭的模可换成求原复数的模，省一步。

x3  =  1 的三个根（三次单位根）：1、ω、ω̄，其中 ω  =  −1/2 + (√3/2)i，ω̄  =  −1/2 − (√3/2)i

  • 公式：ω3 = 1，ω̄3 = 1；1 + ω + ω2 = 0；ω·ω̄ = 1；ω2 = ω̄，ω̄2 = ω。
  • 大白话把单位圆三等分得到的三个复数，加起来正好归零，互相还是共轭。
  • 用的时候：见到 1+ω+ω2=0 直接代换；−1+√3 i = 2ω，这类提取因子题可秒杀。
  • 记忆要点：ω 是"逆时针转 120°"的单位复数，ω2 是"转 240°"，三个加起来 = 0。

数集包含链：N* ⫋ N ⫋ Z ⫋ Q ⫋ R ⫋ C

  • 大白话自然数→整数→有理数→实数→复数，一层比一层大；注意实数里成立的运算性质（如"任何数平方非负"）到复数里不一定成立。
  • 用的时候：判断"能不能比大小"时心里有这条链——只有实数能比大小，复数不能。

高级方法·进阶

本章主线（复数概念 + 共轭/模 + 四则运算 + 几何意义）已覆盖高考全部考点。高考复数题固定出在选择第 1 题附近，难度很低，只要别在 i2=−1 和分母实数化两处失手，就是送分题。

本章无对应高级方法手册条目。说明：《不超纲高级方法手册》未单列"复数"专题。高考复数题只在第 1 题左右出一道选择，考的就是本章四则运算与 i 的幂循环，全部不超纲。一个可直接用的小结论：实系数一元二次方程 ax2+bx+c = 0 当 Δ<0 时，在复数集内有一对共轭复根 x  =  (−b±√(−Δ)·i)/(2a)（选学了解）。

自测答案：1. −i；2. z  =  2 + 3i，|z|  =  √13；3. (2+i)(3−i)  =  6 − 2i + 3i − i2  =  6 + i + 1  =  7 + i；4. (2 + i)/(4 + 1)  =  2/5 + (1/5)i；5. a + 1  =  3 ⇒ a  =  2；b − 2  =  4 ⇒ b  =  6。

课后习题答案

A 组

  1. i5 = i；i6 = −1；i7 = −i；i8 = 1。
  2. 实部 −3，虚部 5；b≠0，是虚数（不是纯虚数，实部不为 0）。
  3. z = 5 − 12i；|z| = √(25+144) = 13。
  4. (2+3i)(1−2i) = 2−4i+3i−6i2 = 2−i+6 = 8 − i。
  5. (3+i)/(1+i) = (3+i)(1−i)/[(1+i)(1−i)] = (3−3i+i−i2)/2 = (4−2i)/2 = 2 − i。
  6. 实部：2x−1 = 3 → x = 2；虚部：y = −2。

B 组

  1. (1+i)/(1−i) = (1+i)2/2 = (1+2i−1)/2 = i；|i| = 1。
  2. z·z = (1−i)(1+i) = 2；|z|2 = 12+(−1)2 = 2（与 z·z 相等）。
  3. |z| = 1 即点 z 到原点距离为 1，构成以原点为圆心、半径 1 的单位圆。
  4. i+i2+i3+i4 = i+(−1)+(−i)+1 = 0。

C 组 11.【2025·第1题】(1+5i)i = i + 5i2 = i − 5 = −5 + i。写成 a+bi 形式，实部 −5，虚部 1，选 C。

一通百通

这一章的"通用骨架"是：① 拿到复数先整理成 a+bi 标准形 → ② 乘除时把 i 当字母展开、最后把 i2 换成 −1 → ③ 除法就分子分母同乘分母共轭做分母实数化 → ④ 涉及距离/图形就翻译成复平面上的点和 |z−z0|=r 的圆。高考复数题不管怎么出，本质都是"会多项式展开 + 会乘共轭"这两件事。会做一道复数小题，就会做所有复数小题；复数的几何意义（点、向量、距离）和第 09 章平面向量是同一张图，后面解析几何里也常借用。

跨章结合

  • 复数的模与几何意义 ⇔ 第 15 章直线与圆：|z−z0|=r 在复平面上是以 z0 为圆心、r 为半径的圆，和解析几何里 "(x−a)2+(y−b)2=r2" 是同一件事的两种写法；|z|=1 的单位圆、两点距离 |z1−z2|，都是后面解析几何圆方程的"二维坐标版"。想通这一层，复平面上看图和解析几何画圆就打通了。（综合原理说明，非真题）
  • 复数坐标 ⇔ 第 16 章圆锥曲线：复平面的实轴、虚轴就是直角坐标系的 x 轴、y 轴，z=a+bi 对应点 (a,b)，本质和向量（第 09 章）共用一张图。高考里复数本身只出现在第 1 题送分位置（如 2025 新高考Ⅰ卷第 1 题、2023 年卷第 1 题均考复数），但这套"把数看成点、把运算看成向量"的眼光，是后面看懂解析几何的底子。

本章与前后章

复数前接第 02 章（函数与实数系、坐标系）——它是在实数不够用（负数开平方）时把数系从一维扩到二维；几何上它和第 09 章平面向量共用一张复平面图（a+bi 对应向量 (a,b)）。它向后不直接推哪一章，但作为第 01 章集合与逻辑里"数集包含链 R⊂C"的落脚点，以及卷面上固定的第 1 题送分小题，地位是"小而稳"。学完它，你手里多了一套能让负数开平方、能描述旋转的二维数。

高考怎么考

新高考Ⅰ卷里复数固定在选择题第 1 题附近，难度很低、是全卷送分题：考法集中在四则运算（尤其除法的分母实数化）、求实部虚部、共轭与模、i 的幂循环。真题如 2025 新高考Ⅰ卷第 1 题（(1+5i)i 的虚部，答案选 C），以及 2023 年卷第 1 题也考复数（该年集合退到第 2 题）。它考的不是思维，而是你别在 i2=−1 和乘共轭两处失手——一分钟内必须拿下，为后面大题省时间。
