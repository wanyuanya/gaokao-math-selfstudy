公式速查：修订版 第4部分（立体几何）

本章本质核心：立体几何初步的本质是"把空间里的问题降维到平面来解决"——人脑只会算平面图形，所以学立体几何就是想办法把三维图形"拍扁"成二维：展开图把侧面铺平成矩形或扇形、截面把球切出一个圆、斜二测把立体画成平面直观图；而四个公理、平行与垂直的判定定理，就是允许你这样"拍扁"和"翻译"的通行证。本章所有公式（体积表面积、球截面、展开最短路径）与所有证明（线面平行、线面垂直），都是"降维"这一个动作的变体。

为什么有用想通"把三维拍回平面"这个办法，你就能看懂并算准身边的立体——给一个柱锥台球，会算它占多大地方（体积）、包它要多少料（表面积）；给空间里几根线几个面，能判断并证明它们平行还是垂直。锥体为什么是 1/3、展开图怎么找最短路、线面平行怎么证，都能顺着"降维"自己想明白，而不是硬背一堆公式和判定。

3.1 空间几何体

引入：把一个水杯放在桌上，从正面看是长方形，从上面看是圆——同一个物体，不同方向长得不一样。这一章我们就要在脑子里"转动物体"，认清柱、锥、台、球这些最常见的立体。

四类基本几何体：

  • 棱柱：上下两个面是全等且平行的多边形，侧面都是平行四边形，侧棱互相平行。上下底面是三角形叫三棱柱，四边形叫四棱柱。
  • 棱锥：一个多边形底面，其余各面是有公共顶点的三角形。底面是正多边形、顶点在底面的投影是底面中心时叫正棱锥。
  • 棱台：用平行于棱锥底面的平面去截锥体，截下来的"中间那段"就是棱台。
  • 球：半圆绕它的直径旋转一周形成的旋转体。

圆柱、圆锥、圆台是棱柱、棱锥、棱台的"旋转版本"——把多边形底面换成圆。

特殊结论：

  • 长方体长宽高 a、b、c，体对角线 l = √(a2+b2+c2)；
  • 正方体棱长 a，体对角线 √3a；
  • 正四面体（棱长 a）：高 √6/3·a，外接球半径 √6/4·a。

例题跟讲例题：长方体长宽高 2、3、6，求体对角线。 解：l = √(4+9+36) = √49 = 7。

3.2 表面积与体积公式（必背表）

引入：装水问的是"体积"，包包装纸问的是"表面积"。柱体体积 = 底面积 × 高；锥体为什么要乘 1/3？拿三个一模一样的圆锥装满沙倒到等底等高的圆柱里，正好倒满三次——这就是 1/3 的来历。

核心公式表：

几何体 体积 表面积要点
柱体 V = S底·h S = S侧+2S底
锥体 V = ⅓·S底·h S = S侧+S底
台体 V = ⅓(S上+S下+√(S上S下))h S = S侧+S上+S下
球 V = (4/3)πR3 S = 4πR2

圆柱侧面积 2πrh、圆锥侧面积 πrl（l 是母线长）要单独记。 圆台侧面积 S  =  π(r′+r)l（l 是母线长，r′、r 分别是上、下底半径），侧面展开是扇环（苏州教研·专题18）。

球的组合体：长方体外接球直径 = 体对角线；正方体外接球直径 = 体对角线 √3a；正方体内切球直径 = 棱长 a。

例题跟讲例题：正四棱锥底面边长 2、高 3，求体积。 解：S底 = 4，V = ⅓·4·3 = 4。锥体记得乘 1/3。

再跟一道（球的组合体）：一个圆柱底面半径 2、高 3，它的外接球半径是多少？ 解：圆柱上下底面圆心连线是高，中点到圆周上一点的距离就是半径。球心在圆柱中截面处，到下底边缘点：水平 2、竖直 3/2，故 R = √(22+(3/2)2) = √(4+9/4) = √(25/4) = 5/2。

球的截面（苏州教研·专题18）：一个平面截球，截面是个圆；过球心与截面圆心的连线垂直于截面。若球半径 R、截面圆半径 r、球心到截面的距离为 d，则 d2  =  R2 − r2。

  • 大白话截面离球心越远，截面圆越小，这就是截面里的勾股定理。
  • 用的时候：球半径、截面圆半径、球心到截面距离，知二求一。

展开图上的最短路径（苏州教研·专题18）：柱、锥、台的侧面都能展开成平面；几何体表面上两点间的最短距离（或蚂蚁沿侧面爬行、绕侧面几周的最短路程），就是把侧面剪开平铺成平面后两点间的线段长。

  • 大白话把立体侧面"剪开平铺"，在平面上量直线距离。
  • 用的时候：见到"沿侧面绕行""表面两点最短"，先展开放平再套勾股。

斜二测画法的面积比（苏州教研·专题18）：水平放置的平面多边形画成斜二测直观图后，直观图面积 S′ 与原面积 S 的关系是 S′  =  S / (2√2)，即 S  =  2√2·S′。

  • 大白话直观图被"压扁"，面积只剩原图的 1/(2√2)。
  • 用的时候：由直观图反求原图形面积就乘 2√2；正向画直观图就除以 2√2。

常见陷阱：锥体体积 1/3 别丢；台体公式里的 √(S上S下) 别漏。

编者注·本质回扣：这一节里"展开图最短路径""球的截面 d2 = R2−r2""斜二测面积比"看着像三块零散结论，本质却是同一个动作——把三维问题压回二维。蚂蚁沿侧面爬最短，靠的是把侧面剪开平铺后用"两点之间线段最短"这条平面公理；球的截面离球心越远截面圆越小，用的是截面圆里的勾股定理；斜二测面积被压成 1/(2√2)，也是先想清楚"平面上原来的图被缩成了什么样"。说白了，只要你能把空间里的量挪到一个平面上去算，立体就立刻退化成你初中就熟的平面几何。

3.3 空间点、直线、平面的位置关系

引入：一支笔（直线）放在桌面上（平面内），还是悬空（平面外）？两支笔可能平行、相交、或既不平行也不相交（异面）。把这些关系用符号说清楚，后面证明才有依据。

四个公理（了解即可，重点用后两个）：

  1. 不共线的三点确定一个平面；
  2. 两个平面若有一个公共点，就有一条过该点的公共直线；
  3. 过直线外一点，有且只有一条直线与已知直线平行；
  4. 平行于同一直线的两条直线互相平行（平行传递）。

符号：直线在面内 a⊂α；直线在面外 a⊄α；相交 a∩b = P；平行 a∥b。

例题跟讲例题：直线 a⊂α，直线 b⊂α，且 a∥b，能推出 a∥α 吗？ 解：不能！因为 a 已经在平面 α 内了。线面平行要求直线在平面外。

确定平面的三个推论（苏州教研·专题19）：由"不共线三点确定一个平面"（公理2），还推出三条同样好用的定平面依据——

  • 过一条直线和直线外一点，有且只有一个平面；
  • 过两条相交直线，有且只有一个平面；
  • 过两条平行直线，有且只有一个平面。

大白话只要手里有"三点不共线""一直线加线外一点""两条相交线""两条平行线"中的任意一种，就能定一个平面——后面证"若干线共面"全靠它。

等角定理（苏州教研·专题19）：空间中如果两个角的两边分别对应平行，那么这两个角相等或互补。

  • 大白话两组边分别同向平行，角相等；其中一组方向反过来，就互补。
  • 用的时候：定义异面直线所成角时，把两条异面直线平移成相交线来量，依据就是它。

3.4 平行关系（证明题核心）

引入：要证明"一条线平行于一个面"，最省力的办法不是去量线和面的夹角，而是在面里找一条和它平行的线——这就是线面平行的判定。

线面平行：

  • 判定定理：平面外一条直线与平面内一条直线平行 ⇒ 线面平行。符号：a∥b，b⊂α，a⊄α ⇒ a∥α。
  • 性质定理：线面平行，则过该线的平面与已知平面的交线与该线平行。

面面平行：

  • 判定：一个平面内的两条相交直线都平行于另一个平面 ⇒ 两平面平行。
  • 性质：面面平行，则一平面内任意直线平行于另一平面；被第三个平面截出的交线互相平行。

证明链：证线面平行 → 找线线平行（常用中位线、平行四边形）。

例题跟讲例题：正方体中 E、F 分别是棱 A1B1、A1D1 的中点，证明 EF∥平面 BDD1B1。 解：E、F 是中点，在 △A1B1D1 中 EF 是中位线，故 EF∥B1D1。又 B1D1⊂平面 BDD1B1，EF⊄该平面，由线面平行判定，EF∥平面 BDD1B1。要点：见到"两个中点"，先想中位线。

编者注·本质回扣：证"线面平行"为什么不直接去量线和面的夹角？因为一旦降维成平面，几何就好算了——判定定理的全部意思就是：你要证一条线平行于一个面，不必去碰整个面，只要在这个面里找出一条和它平行的线就行（线线平行推出线面平行）。而"找线线平行"又常常靠中位线、平行四边形这些你初中就熟的平面技巧。所以这一章的证明套路，本质是不断把"面与线"的高维关系，翻译成"线与线"的平面关系；后面证垂直也一模一样，只是把"平行"换成"垂直"——这正是本章本质核心说的"降维通行证"。

3.5 垂直关系

引入：一根旗杆要"立直"，就是它和地面内所有直线都垂直，尤其要和地面上两条相交直线垂直——光和一条垂直不够，因为它还能绕着那条线"倒"下去。

线面垂直：

  • 判定：一条直线与一个平面内的两条相交直线都垂直 ⇒ 线面垂直。
  • 性质：线面垂直 ⇒ 它垂直于面内任何直线。

面面垂直：

  • 判定：一个平面过另一个平面的一条垂线 ⇒ 两平面垂直。
  • 性质：两平面垂直，则一个面内垂直于交线的直线垂直于另一个面。

万能思路：

  • 证线面平行 → 找线线平行（中位线、平行四边形）；
  • 证线面垂直 → 找线线垂直（等腰三角形三线合一、勾股逆定理、直径对直角）。

垂直于同一平面的两条直线平行（苏州教研·专题19）： a⊥α，b⊥α ⇒ a∥b。

  • 大白话都直立在同一个面上的两根杆，互相平行。
  • 用的时候：证线线平行的一条冷门但好用的路径。

从教材里提炼的几条常用判定 / 性质（苏州教研·专题19，都可直接当证题依据）：

  • 证面面平行：一个面内两条相交直线分别平行于另一个面内两条相交直线 ⇒ 两面平行；垂直于同一条直线的两个平面平行（l⊥α、l⊥β ⇒ α∥β）。
  • 证线面垂直：两条平行线中一条垂直一个面，另一条也垂直该面（a⊥α、a∥b ⇒ b⊥α）；两个相交平面都垂直第三个平面，则它们的交线垂直第三个平面（α⊥γ、β⊥γ、α∩β = l ⇒ l⊥γ）。
  • 面面垂直的传递：两个平行平面中一个垂直第三个面，另一个也垂直（α∥β、α⊥γ ⇒ β⊥γ）。
  • 唯一性：过空间一点，有且只有一条直线垂直于已知平面；过空间一点，有且只有一个平面垂直于已知直线。

三垂线定理及其逆定理（苏州教研·专题19）：设 PA⊥平面 α，直线 a 在 α 内，AO 是斜线 PO 在 α 内的射影——

  • 正定理：AO⊥a ⇒ PO⊥a；

  • 逆定理：PO⊥a ⇒ AO⊥a。

  • 大白话斜线和平面内一条直线垂直 ⇔ 它的射影也和这条直线垂直。

  • 用的时候：见到"面的垂线 PA + 斜线 PO + 面内直线 a"的格局，证线线垂直或找二面角平面角，它是一把快刀。

3.6 外接球与等体积法（高频小题）

外接球补形：凡是"三条棱两两垂直"的墙角形三棱锥，补成长方体，外接球直径就是长方体体对角线，R = ½√(a2+b2+c2)。

等体积法：求点到面的距离（高）时，换一个更好算的顶点和底面，体积不变，反解出高：h = 3V/S底。这比建系算距离省事。

例题跟讲例题：三条侧棱两两垂直且长为 3、4、5 的三棱锥，求外接球半径。 解：补成长方体，R = ½√(9+16+25) = ½√50 = (5√2)/2。

补形模型的几种情形（苏州教研·专题19）：把四面体补成平行六面体（长方体）是求外接球的大招——

  • 同一顶点处三条棱两两垂直 ⇒ 补成长方体（墙角形，上面已讲）；
  • 三组对棱分别相等 ⇒ 也能补成长方体（见本章例 4）；
  • 正四面体 ⇒ 补成正方体；
  • 棱台、圆台 ⇒ 分别补回棱锥、圆锥（研究台体别忘了还原成锥体）。

多面体内切球半径：等体积法（苏州教研·专题19）：一个多面体若存在内切球（与所有面都相切），把它从球心处切成若干个以各面为底、内切球半径 r 为高的小棱锥，总体积 V  =  ⅓·S全·r，故 r  =  3V / S全。

  • 大白话内切球心到每个面距离都是 r，把多面体拆成一堆高为 r 的小棱锥，体积加起来就解出 r。
  • 用的时候：求三棱锥、多面体内切球半径，别硬画，套 r  =  3V/S全。

小结：立体几何证明就两条线——平行找线线平行，垂直找线线垂直；计算套公式，锥体别忘 1/3。

④ 例题详解（先做再看）

例题例 1（体积计算）：正四棱锥底面边长为 2，高为 3，求体积。

自己做：套锥体公式。

解：S 底  =  22  =  4，V  =  ⅓·4·3  =  4。 要点：锥体记得乘 1/3，柱体不乘。

例题例 2（线面平行证明）：正方体 ABCD−A1B1C1D1 中，E 是棱 CC1 的中点，证明 AC1 ∥ 平面 BDE。

自己做：在平面 BDE 里找一条与 AC1 平行的线。

证：连接 AC 交 BD 于 O（O 为 AC 中点）。连接 OE。 在 △ACC1 中，O 是 AC 中点，E 是 CC1 中点 ⇒ OE ∥ AC1（中位线）。 又 OE ⊂ 平面 BDE，AC1 ⊄ 平面 BDE ⇒ AC1 ∥ 平面 BDE。 要点：中点 → 中位线 → 线线平行 → 线面平行，这是最常用的一条证明链。

例题例 3（球与正方体）：棱长为 2 的正方体的外接球体积是多少？

自己做：体对角线  =  外接球直径。

解：体对角线  =  √(4 + 4 + 4)  =  2√3  =  2R ⇒ R  =  √3。V  =  (4/3)π(√3)3  =  4√3 π。 要点：外接球看对角线，内切球看棱长。

例题例 4（对棱相等·补形求体积与外接球）（苏州教研·专题18，原书p.68）：在四面体 P−ABC 中，PA = BC = √41，PB = AC = √34，PC = AB = 5，求四面体的体积和外接球的表面积。

自己做：三组对棱分别相等，想到补成长方体。

解：设补成的长方体长宽高为 a、b、c，则三组面对角线满足 a2+b2 = 41，a2+c2 = 34，b2+c2 = 25。 三式相加：2(a2+b2+c2) = 41+34+25 = 100 ⇒ a2+b2+c2 = 50。 于是 a2 = 50−25 = 25，b2 = 50−34 = 16，c2 = 50−41 = 9，得 a = 5，b = 4，c = 3。 长方体体积 abc = 5·4·3 = 60。四个角上各切去一个小三棱锥，每个体积为 ⅓·(½ab)·c  =  ⅙abc  =  10，四个共 40，故四面体 V = 60−40  =  ⅓abc  =  20。 外接球直径  =  长方体体对角线：(2R)2 = a2+b2+c2 = 50，故外接球表面积 S = 4πR2 = π(2R)2 = 50π。 要点：三组对棱分别相等 ⇒ 补成长方体；四面体体积  =  ⅓·abc；外接球表面积  =  π·(体对角线)2。

例题例 5（线面角·垂足是外心）（苏州教研·专题19，原书p.76）：在四面体 A−BCD 中，DA = DB = DC = a，BC = √2a，∠ADB = ∠ADC = 60°，求直线 DA 与平面 BCD 所成的角。

自己做：先由等长斜线段判断垂足位置。

解：∠ADB = 60°、DA = DB = a ⇒ △ADB 等边 ⇒ AB = a；同理 AC = a。又 DB = DC = a、BC = √2a，DB2+DC2 = a2+a2 = 2a2 = BC2 ⇒ DB⊥DC，即 △BCD 直角在 D。 过 A 作 AO⊥平面 BCD，垂足 O。由 DA = DB = DC（三条斜线段等长）⇒ 它们在平面 BCD 上的射影 OD = OB = OC，即 O 是 △BCD 的外心。 直角三角形 BCD 的外心是斜边 BC 的中点，外接圆半径 OD = ½·BC = √2a/2 = a/√2。 在直角三角形 AOD 中（AO⊥OD）：AO = √(AD2−OD2) = √(a2−a2/2) = a/√2。 ∠ADO 就是 DA 与平面 BCD 所成的角，tan∠ADO = AO/OD = (a/√2)/(a/√2) = 1 ⇒ ∠ADO = 45°。 要点：斜线段等长 ⇒ 射影等长 ⇒ 垂足是底面外心；线面角  =  斜线与它在面内射影的夹角。

⑥ 常见坑清单

  • 锥体体积 1/3 别丢；台体公式里的"根号"别漏。
  • 线面平行判定：a ⊄ α 是前提，a 在面内就不能用。
  • 面面垂直判定：需要"一条线垂直另一个面"，线要在被证明垂直的平面内。
  • 外接球 vs 内切球：直径对应体对角线 vs 棱长，别混。
  • 三视图已从新高考删除，不考，别花时间。
  • 证明线面垂直：必须证与面内两条相交直线垂直，一条不够。

本章公式速查表

口径与《高中数学常用公式·修订版》第四部分（立体几何）一致。

柱锥台球体积

柱体：V  =  S底·h（圆柱 V  =  πr2h）

  • 大白话底面积乘高，柱体不乘 1/3。
  • 用的时候：柱和锥别混，锥体才要除以 3。

锥体：V  =  ⅓·S底·h（圆锥 V  =  ⅓πr2h）

  • 大白话等底等高的柱，锥只占它的三分之一。
  • 用的时候：最容易漏的就是这个 1/3，写完先检查。

台体：V  =  ⅓(S上 + S下 + √(S上·S下))·h

  • 大白话上下底面积和，再加个"上下底面积几何平均"，一起乘高除以 3。
  • 用的时候：中间那个 √(S上S下) 别漏；台体可看成锥截出来的。

球：V  =  (4/3)πR3，表面积 S  =  4πR2

  • 大白话球的体积和表面积只跟半径有关。
  • 用的时候：表面积是 4πR2，别记成 πR2。

常见几何体表面积

圆柱侧面积 2πrh；圆锥侧面积 πrl（l 是母线长）

  • 大白话侧面展开是个矩形 / 扇形，单独记。
  • 用的时候：表面积 = 侧面积 + 两个（或一个）底面积。

正方体棱长 a：体对角线 √3a，表面积 6a2，体积 a3

  • 大白话六个正方形面，对角线跨三个棱。

外接球与体对角线

长方体体对角线 l  =  √(a2+b2+c2)；外接球直径  =  体对角线

  • 大白话从一个顶点出发三条棱，勾股连套两次就是对角线。
  • 用的时候：墙角形三棱锥（三条棱两两垂直）补成长方体，R = ½√(a2+b2+c2)。

正方体：外接球直径  =  √3a；内切球直径  =  棱长 a

  • 大白话外接球撑到对角，内切球贴到面。
  • 用的时候：外接球看对角线、内切球看棱长，别混。

正四面体（棱长 a）：高 h  =  √6/3·a，外接球半径 R  =  √6/4·a

  • 大白话正四面体高约 0.816a，外接球半径是高的 3/4。
  • 用的时候：这是记牢的结论，小题直接用。

平行与垂直的判定（证明题）

线面平行：面外一条线 a∥面内一条线 b ⇒ a∥α（要 a⊄α）

  • 大白话在面里找一条和它平行的线就行。
  • 用的时候：见到"两个中点"先想中位线；a 在面内就不能用。

面面平行：一个面内两条相交直线都平行于另一面 ⇒ 两面平行

  • 大白话两条相交线都平行，整个面就平行。

线面垂直：一条线垂直于面内两条相交直线 ⇒ 线面垂直

  • 大白话跟面里两条相交线都垂直，才算真立直。
  • 用的时候：只证一条不够，必须两条相交。

面面垂直：一个面过另一个面的一条垂线 ⇒ 两面垂直

  • 大白话一个面里竖着一根垂直另一面的线，两面就垂直。

求距离

等体积法：h  =  3V/S底

  • 大白话换个好算的顶点和底面，体积不变反解高。
  • 用的时候：求点到面的高，建系麻烦时用它。

补充二级结论（苏州教研·专题18/19）

球的截面：d2  =  R2 − r2（R 球半径，r 截面圆半径，d 球心到截面距离）

  • 大白话截面离球心越远、截面圆越小，就是截面里的勾股。
  • 用的时候：球半径、截面圆半径、球心到截面距离知二求一。

展开图最短路径：侧面展开成平面后，两点间线段最短

  • 大白话蚂蚁爬侧面，剪开平铺量直线。
  • 用的时候：绕侧面一周/几周的最短路程，展开后算勾股。

斜二测直观图面积：S′  =  S/(2√2)，即 S  =  2√2·S′

  • 大白话直观图面积是原图的 1/(2√2)。
  • 用的时候：正反面积互算，乘或除 2√2。

三垂线定理：PA⊥α，AO⊥a ⇒ PO⊥a；逆定理：PO⊥a ⇒ AO⊥a

  • 大白话斜线垂直面内直线 ⇔ 它的射影也垂直这条直线。
  • 用的时候：证线线垂直、找二面角平面角的快刀。

棱锥顶点在底面射影的位置（苏州教研·专题19）

  • 大白话侧棱相等（或侧棱与底面所成角相等）→ 外心；各侧面与底面二面角相等（或顶点到底面各边等距）→ 内心；两组对棱垂直 / 三条侧棱两两垂直 → 垂心。
  • 用的时候：看到"侧棱相等"先想垂足是外心，是作高、定外接球心的依据。

多面体内切球半径：V  =  ⅓·S全·r ⇒ r  =  3V/S全

  • 大白话从球心拆成一堆高为 r 的小棱锥，体积加起来解 r。
  • 用的时候：求三棱锥 / 多面体内切球半径专用。

高级方法·进阶

对应《不超纲高级方法手册》第七部分"立体几何"。

进阶 1：外接球"补形模型"速查

适用信号：三棱锥三条棱两两垂直，或"对棱相等"，求外接球半径。 操作步骤：补成长方体，外接球直径 = 长方体体对角线，R = ½√(a2+b2+c2)。 例题：墙角三棱锥三条直角棱长 3、4、5，则 R = ½√(9+16+25) = 5√2/2。 课标依据/红线：球的直径 = 长方体体对角线是教材结论，✓ 不超纲（高考可放心用）。

进阶 2：等体积法求距离

适用信号：求点到平面的距离、求锥体的高，又不想建系。 操作步骤：换一组好算的顶点和底面，体积 V 不变，由 V = ⅓·S底·h 反解 h = 3V/S底。 例题：三棱锥 PA⊥底面，PA = 3，底面 △ABC 面积 4，则 V = ⅓·4·3 = 4；若换用面 PBC 作底，测出其面积即可反求对应高。 课标依据/红线：体积变换是教材内容，✓ 不超纲。

进阶 3：三视图（说明）

课标依据/红线：三视图已从新高考删除，不考，不必花时间；斜二测画法画直观图了解即可。

一通百通

遇到本章的题，本质都是"先把三维降维成二维，再用平面几何算"：计算题认准几何体类型套公式（柱 V=Sh、锥 V=⅓·S底·h 千万别丢 1/3、球 V=4πR3/3）；求距离或表面最短路径，就把侧面展开、把锥体补形，把它搬回平面用勾股；证明题认准一条链——证线面平行就在面内找线线平行（看到两个中点先想中位线），证线面垂直就找面内两条相交直线。会这一套，体积、外接球、平行垂直证明都是"降维"这一个动作的变体。

跨章结合

  • 本章平行垂直证明 × 初中平面几何技巧：一旦按判定定理把"线面关系"降维成"线线关系"，后面用的全是你初中就熟的工具——找线线平行靠中位线、平行四边形；找线线垂直靠等腰三角形三线合一、勾股逆定理、直径对直角。本章例 2（证 AC1∥平面 BDE）就是"两个中点 → 中位线"的典型。（综合原理说明，非真题）
