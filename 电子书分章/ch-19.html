公式速查：修订版 第12部分（统计）

本章本质核心：统计的本质是"用一部分推断整体"——总体太大测不完，就抽一个有代表性的样本，用样本的数字去估计总体的数字，同时守住"样本≠整体"的边界。三种抽样（让样本有代表性）、频率直方图（用图看样本长什么样）、平均数方差（样本的中心与波动）、回归直线（用样本散点配一条估测线）、卡方检验（用样本频数判断两变量有没有关系），全是在"用样本说话"；每一步估计都要记得它来自样本、会有偏差。

为什么有用学了它，"从一部分数据推断整体""两个现象到底有没有关系"这类现实问题就有了章法——抽样定代表性、直方图看分布、回归估趋势、卡方判相关，想通"用样本说话、守住样本≠整体"，就不会把估计当因果。

3.1 抽样方法

引入：想知道全校学生的平均身高，总不能把每个人都量一遍。从里面抽一部分人量，再推算全校——这就是抽样。怎么抽才有代表性？这一节讲三种正规抽法。

方法 什么时候用 怎么做
简单随机抽样 总体小、个体差不多 抽签法 / 随机数表，每个机会均等
系统抽样 总体已编号、很多 按间隔 k = N/n 等距抽
分层抽样 总体分几层、层间差异大 按比例从每层抽

分层抽样核心公式：每层抽取数  =  该层人数  ×  (样本量/总体量)。 为什么按比例？为了让样本里各层的比例和总体一致，样本才有代表性。比如全校高一多、高三少，抽样时也得多抽高一少抽高三，否则用样本估全校就会"偏"。抽样的唯一目的，是用尽量少的人算出尽量准的总体数字——抽得有偏，后面再怎么算都白搭。

例题跟讲例题：

例 3.1-a：高一 500、高二 400、高三 300，分层抽样抽 60 人，各抽多少？ 解：总 1200，比例 60/1200  =  1/20。高一 500/20 = 25，高二 400/20 = 20，高三 300/20 = 15。 要点：各层相加  =  25+20+15  =  60，正好等于样本量。

小结：个体差不多随机抽；编号等距系统抽；差异分层按比例抽。

编者注·本质回扣：三种抽样方法五花八门，骨子里只干一件事——让抽出来的那部分能代表整体。为什么分层抽样非要按比例？因为全校高一多、高三少，你抽样本时也得多抽高一、少抽高三，样本里各层的比例才和总体一致，后面用样本估全校才不会"偏"。简单随机、系统抽样其实是"总体里个体差不多"时的偷懒版；一旦层间差异大，不按比例抽，样本就会被某一层带偏——抽得有偏，后面平均数、回归再怎么精算，都是在错误的样本上算白账。这就是统计"用样本推断整体"的第一道关口：样本先得抽得正。

3.2 频率分布直方图与茎叶图

引入：100 个学生的考试分数堆在面前，密密麻麻看不出规律。把分数分段、数每段多少人，画成柱状图，分布形状一眼就出来了。

读图要点（最容易错）：

  • 纵轴是频率/组距，不是频率！
  • 每个矩形面积  =  频率（宽 × 高  =  组距 × 频率/组距  =  频率）。
  • 所有矩形面积之和  =  1。
  • 求某区间人数：区间面积  ×  总体数。

茎叶图：茎是十位、叶是个位，既保留原始数据又能看出分布形状，适合小样本。它的好处是不用分组、不会丢原始数值，做茎叶图还能顺手看出数据是否对称、有没有离群点。

例题跟讲例题：

例 3.2-a：直方图某组 [10,20)，纵轴（频率/组距） = 0.03，样本 200 人，该组多少人？ 解：频率  =  0.03  ×  组距 10  =  0.3。人数  =  200 × 0.3  =  60。 要点：纵轴要乘组距才是频率，别直接当频率用。

小结：直方图看形状、茎叶图保原始，纵轴是"频率/组距"是命门。

3.3 数字特征（集中趋势 + 离散程度）

引入：两个班平均分都是 80，一个班分数都挤在 80 附近，另一个班一半 60 一半 100——平均一样，但"稳不稳"天差地别。平均数描述"集中在哪"，方差描述"散得多开"。

公式：

  • 平均数 x  =  (x1+…+xn)/n（加权：Σwixi/Σwi）
  • 方差 s2  =  [(x1−x)2+…+(xn−x)2]/n
  • 标准差 s  =  √s2（和原数据同单位）

性质：每个数据加 a → 平均数加 a、方差不变；每个数据乘 b → 平均数乘 b、方差乘 b2。

例题跟讲例题：

例 3.3-a：数据 1、2、3、4、5，求平均数、方差。 解：x = 3。s2 = [(1−3)2+(2−3)2+0+(4−3)2+(5−3)2]/5 = (4+1+0+1+4)/5 = 2。 要点：方差是"离差平方的平均"。

小结：平均数看中心、方差看波动，两者合起来才完整描述一组数据。

例题跟讲例题（分组合并·一步一验）：A 组数据 1、2、3，B 组数据 3、4、5，把它们合成一组求平均数和方差。 解：六个数 1、2、3、3、4、5。总和  =  18，平均数 x  =  18/6  =  3。 方差 s2  =  [(1−3)2+(2−3)2+0+0+(4−3)2+(5−3)2]/6  =  (4+1+0+0+1+4)/6  =  10/6  =  5/3  ≈  1.67。 要点：合并时先把全部数据摆出来重算平均，别拿两组平均直接平均——这里两组平均是 2 和 4，直接平均得 3，恰好碰对；但组人数不等时直接平均就会错（那是加权平均的活）。方差更要从合并后的数据重算，不能把两组方差简单相加。

平均数 vs 中位数（常考辨析）：平均数是"加起来除以个数"，受极端值影响很大——一组工资里如果有一个老板年薪千万，全公司平均工资会被拉得虚高。中位数是"排好序站中间的那个"，不受极端值影响。所以评价收入、房价这类"有极端值"的数据，中位数往往比平均数更真实；但平均数能用每个数据的信息，数学性质更好（后面回归、概率都用它）。

补·百分位数（人教A版必修第二册 p.209–210；课标必修"能用样本估计百分位数，理解百分位数的统计含义"）：中位数其实只是"第 50 百分位数"。把 n 个数据从小到大排好，第 p 百分位数是这样一个值：至少有 p% 的数据 ≤ 它、且至少有 (100−p)% 的数据 ≥ 它。算法三步：

① 排序；② 算 i  =  n  ×  p%；③ 若 i 不是整数，取比 i 大的相邻整数 j，第 p 百分位数  =  第 j 项；若 i 是整数，第 p 百分位数  =  (第 i 项 + 第 (i+1) 项)/2

  • 大白话25%、50%、75% 三个百分位数把数据分成四等份，分别叫下四分位数、中位数、上四分位数；它像中位数一样耐极端值，常被用来定"前百分之几的录取线""百分之多少的人不超标"这类实际门槛。
  • 用的时候：教材例——27 名女生身高排序后，25%×27=6.75（非整数）取第 7 项=155.5，50%×27=13.5 取第 14 项=161，75%×27=20.25 取第 21 项=164，即下四分位/中位/上四分位约为 155.5、161、164。

3.4 回归分析（最小二乘）

引入：人的身高和体重有没有关系？把 (身高, 体重) 画在图上，是一团散点，但大体"越高越重"。能不能配一条直线，用身高估体重？这就是回归直线。

最小二乘回归直线 y  =  bx + a：

  • b  =  Σ(xi−x)(yi−y) / Σ(xi−x)2（斜率）
  • a  =  y − b·x（截距）
  • 回归直线必过样本中心 (x, y)——这是检验计算对不对的照妖镜。

相关系数 r ∈ [−1,1]：|r| 越接近 1 线性相关越强；r>0 正相关、r<0 负相关、接近 0 几乎无线性关系。 最小二乘的道理：这条直线让每个点到直线的"竖直偏差"的平方和最小——偏差有正有负会抵消，所以取平方；平方加权等价于"整体看起来最贴"。这就是为什么回归直线不是随手画的那条。

例题跟讲例题：

例 3.4-a：数据 (1,2)(2,3)(3,4)(4,5)，求回归直线。 解：x = 2.5，y = 3.5。Σ(xi−x)2 = 5，Σ(xi−x)(yi−y) = 5。b = 5/5 = 1，a = 3.5−1·2.5 = 1。直线 y = x+1。验证过 (2.5,3.5)。 要点：b 是协方差除以 x 的方差，直线必过样本中心。

小结：回归直线是"最贴散点的那条线"，必过样本中心、相关系数量强弱。

编者注·本质回扣：回归直线凭什么能"用身高估体重"？本质还是"用样本推断整体"。手里只有几个 (身高, 体重) 的散点，并不知道真关系，最小二乘就是在样本里配一条"整体最贴"的直线（让各点竖直偏差的平方和最小），再假设这条线能代表总体的趋势。所以它必过样本中心 (x,y)——用样本的平均位置定直线，是"用样本说话"的直接体现；相关系数 r 则在替你把关：|r| 太小说明散点根本不成直线，这时候配回归线就是硬凑。记住：回归方程只能"估计/大约"，不能当精确因果。

辨析·b 与 r 同号（快速自检）：斜率 b 和相关系数 r 永远同号——散点整体上扬时 b>0、r>0（正相关）；整体下滑时 b<0、r<0（负相关）。算完 b 是正的，r 却写成负的，立刻知道错了。比如例 3.4-a 那组 (1,2)(2,3)(3,4)(4,5)，点严格排成一条上升直线，算得 b = 1、r = 1（完全正相关），两者同号且 |r| = 1，互相印证。

3.5 独立性检验（卡方检验）

引入：抽烟和得肺病有没有关系？光看列联表两栏比例差多少，还不够"科学"。卡方检验给一个量化标准：算出 χ2，和临界值比，大到一定程度就有把握说"两个变量有关"。

步骤：

  1. 列 2 × 2 列联表（a,b,c,d）；
  2. 算 χ2  =  n(ad−bc)2 / [(a+b)(c+d)(a+c)(b+d)]；
  3. 与临界值比：3.841 对应 95%、6.635 对应 99%、10.828 对应 99.9%。χ2 越大越有把握说"有关"。

表述模板：χ2  ≈  X.XX > 6.635 ⇒ 有 99% 把握认为 A 与 B 有关。统计相关 ≠ 因果。这句话每次正式答题都要带上，是高考评分要点。

例题跟讲例题：

例 3.5-a：列联表 a = 20,b = 180,c = 780,d = 20,n = 1000，算 χ2。 解：ad−bc  =  400−140400  =  −140000。χ2  =  1000 × 1400002/(200 × 800 × 800 × 200)  =  765.6。远大于 10.828 ⇒ 有 99.9% 把握认为有关。 要点：χ2 算出来和临界值比，越大越"铁"。

④ 例题详解（先做再看）

例题例 1（分层抽样）：某校高一 500 人、高二 400 人、高三 300 人，按分层抽样抽 60 人，各年级抽多少人？

自己做：按比例。

解：总 1200 人，比例 60/1200  =  1/20。高一 500/20  =  25；高二 400/20  =  20；高三 300/20  =  15。 要点：每层抽取数  =  该层人数  ×  抽样比例；验证 25 + 20 + 15  =  60。

例题例 2（数字特征）：一组数据 1、2、3、4、5，求平均数、方差、标准差。

自己做：先平均，再算差的平方。

解：x  =  3。s2  =  [(1−3)2 + (2−3)2 + (3−3)2 + (4−3)2 + (5−3)2]/5  =  (4+1+0+1+4)/5  =  2。 s  =  √2。 要点：方差是"离差平方的平均"；标准差开根号，单位还原。

例题例 3（回归直线）：数据 (1,2)、(2,3)、(3,4)、(4,5)，求回归直线方程。

自己做：先算 x、y，再算 b，最后 a。

解：x  =  2.5，y  =  3.5。Σ(xi−x)2  =  (−1.5)2 + (−0.5)2 + 0.52 + 1.52  =  5。 Σ(xi−x)(yi−y)  =  (−1.5)(−1.5) + (−0.5)(−0.5) + 0.5·0.5 + 1.5·1.5  =  5。 b  =  5/5  =  1；a  =  y − b·x  =  3.5 − 2.5  =  1。回归直线 y  =  x + 1。 要点：b 是"协方差/方差"；直线必过 (x, y) 可作检验。

例题例 4（回归直线·分步给分）（苏州教研·专题24，原书p.110）：某设备使用年限 x（年）与维修费用 y（万元）统计如下：x  =  2, 3, 4, 5, 6；y  =  2.2, 3.8, 5.5, 6.5, 7.0。求 y 关于 x 的线性回归方程。

自己做：先算 x、y，再分别算两个求和，最后 b、a。

解：x  =  (2+3+4+5+6)/5  =  4；y  =  (2.2+3.8+5.5+6.5+7.0)/5  =  25/5  =  5。 Σ(xi−x)(yi−y)  =  (−2)(−2.8)+(−1)(−1.2)+0·0.5+1·1.5+2·2.0  =  5.6+1.2+0+1.5+4  =  12.3。 Σ(xi−x)2  =  4+1+0+1+4  =  10。 b  =  12.3/10  =  1.23；a  =  y − b·x  =  5 − 1.23 × 4  =  5 − 4.92  =  0.08。 回归直线 y  =  1.23x + 0.08（验证：过样本中心 (4,5)，代入 1.23 × 4+0.08  =  5 ✓）。 要点：分步算 x、y、两个求和再代公式，这正是高考"分步给分"的写法；用回归方程作预测时回答要带"大约/估计"。

C 真题挑战（真实新高考题）

C1.【频率估计概率·2025 新高考Ⅰ卷第 15 题第 (1) 问】调查 1000 人列联表：患病人群中超声波正常 20、不正常 180；未患病人群中正常 780、不正常 20。记"超声波检查结果不正常者患该疾病的概率"为 P，求 P 的估计值。

C2.【独立性检验·2025 新高考Ⅰ卷第 15 题第 (2) 问】用上面列联表，根据小概率值 α = 0.001 的独立性检验，分析超声波检查结果是否与患该疾病有关。（临界值：α = 0.001 对应 10.828。）

C3.【分层抽样高考高频题型】某校高一、高二、高三人数比为 4:3:3，用分层抽样抽一个容量为 50 的样本，高一年级抽多少人？

⑥ 常见坑清单

  • 直方图纵轴是"频率/组距"，面积才是频率——直接用纵轴数字当频率会错。
  • 方差公式分母是 n（总体）或 n−1（样本，高中一般用 n），跟教材口径一致即可。
  • 回归直线必过 (x, y)，但不过原点（除非 a  =  0）。
  • 独立性检验：χ2 大 → "有把握有关"；统计相关 ≠ 因果关系。
  • 分层抽样验证：各层相加必须等于样本总量。
  • 平均数受极端值影响大，中位数不受——统计评价题里常考这个区别。

抽样方法

分层抽样：每层抽取数  =  该层人数  ×  (样本量/总体量)

  • 大白话总体分几层、层间差得多，就按比例从每层抽，让样本比例跟总体一致。
  • 用的时候：抽完各层相加必须等于样本总量；不等于就抽错了。

系统抽样间隔 k  =  N/n

  • 大白话总体编号很多，每隔 k 个抽一个。
  • 用的时候：k 是总体量除以样本量；先随机定第一个，再等距往后数。

等概率抽样：无论哪种抽样，从 N 个元素中抽 n 个，每个元素被抽到的概率都是 p  =  n/N（苏州教研·专题24）

  • 大白话简单随机、系统、分层，抽法不同，但"每个个体被抽中的机会"一律等于样本量除以总体量。
  • 用的时候：判断样本是否有代表性时，先看每个个体机会均等不均等；分层抽样是每层内等比例，整体仍 p = n/N。

数字特征

平均数 x  =  (1/n)Σxi（加权：Σwixi/Σwi）

  • 大白话所有数加起来除以个数，就是数据的"中心"。
  • 用的时候：两组人数不等时合并要按加权平均，不能把两个平均分直接相加除 2。

方差 s2  =  (1/n)Σ(xi−x)2；标准差 s  =  √s2

  • 大白话每个数离中心多远的平方平均，衡量数据"散得多开"；开根号还原单位。
  • 用的时候：方差是离差平方的平均；合并数据要重算，不能把两组方差相加。

平移缩放：数据 +a → 平均数 +a、方差不变；数据  × b → 平均数  × b、方差  × b2

  • 大白话整体加一个数只平移不影响波动，整体乘一个数波动跟着放大 b2 倍。
  • 用的时候：问"每个数据加几/乘几后新方差"，记住方差里没有加的那个常数。

频率分布直方图

频率  =  (频率/组距)  ×  组距；每个矩形面积  =  频率

  • 大白话纵轴是"频率/组距"不是频率，必须乘组距才是真频率；所有矩形面积加起来 = 1。
  • 用的时候：求某组人数 = 该组面积 × 总体数；直接拿纵轴数字当频率是命门级错误。

直方图各矩形：高之比  =  面积比  =  频率比  =  频数比（苏州教研·专题24）

  • 大白话组距都一样时，柱子的高低直接反映了各组频率、频数的比例。
  • 用的时候：比较两组人数多少，直接比柱子高度即可，不用每组都乘组距算一遍。

用频率分布直方图估计"三数"（苏州教研·专题24）

  • 公式：众数 = 最高矩形中点的横坐标；中位数 = 累积面积达到 0.5 处的横坐标（常设未知数按面积列方程）；平均数 = Σ（各矩形中点横坐标 × 该矩形面积）。
  • 大白话从直方图里反推这组数据的中心——最胖那根柱子的中点是众数，面积对半分那点是中位数，按面积加权的中点是平均数。
  • 用的时候：题目给直方图让估平均数，就把每根柱子中点乘它的面积再加起来；估中位数要"设未知数让左右面积各 0.5"列方程。
  • 记忆要点：众数看最高、中位数对半砍、平均数按面积加权。

两组数据比优劣：先比平均数（通常相当），再比方差（标准差），越小越集中、越稳定（苏州教研·专题24）

  • 大白话两组平均分差不多时，谁方差小谁发挥稳定；评价数据好坏就这两步。
  • 用的时候：运动员得分、零件质量对比题都这么下结论。

回归分析

斜率 b  =  Σ(xi−x)(yi−y) / Σ(xi−x)2；截距 a  =  y − b·x

  • 大白话最小二乘配出来的最贴散点的那条直线，斜率是"协方差除以 x 的方差"。
  • 用的时候：先算 x、y，再算 b，最后 a；斜率 b 和相关系数 r 一定同号。

回归直线必过样本中心 (x, y)

  • 大白话这条直线一定穿过所有点的平均位置。
  • 用的时候：算完拿它代进去验证，是检查对错的照妖镜。

相关系数 r ∈ [−1,1]：|r|→1 线性越强；r>0 正相关、r<0 负相关

  • 大白话衡量两个变量线性关系有多紧，越接近 ±1 越贴一条直线。
  • 用的时候：r 接近 0 几乎无线性关系；b 和 r 同号可快速自检。

相关系数 r 的计算公式：r  =  Σ(xi−x)(yi−y) / √[Σ(xi−x)2·Σ(yi−y)2]（苏州教研·专题57）

  • 大白话分子就是回归斜率 b 乘的那个"协方差和"，分母把 x、y 各自波动归一化，结果落在 [−1,1]。
  • 用的时候：分子和求 b 时是同一个量，算过 b 就不用重算分子；|r|>0.75 就算有很强的线性相关。
  • 记忆要点：r 接近 1 正相关强、接近 −1 负相关强、接近 0 几乎无线性关系。

强相关门槛：|r| > 0.75 认为线性相关性很强（苏州教研·专题57）

  • 大白话相关系数大过 0.75，就有把握说这两个变量线性关系紧密；越接近 0 越弱。
  • 用的时候：题目问"是否适合线性回归"，先看 |r| 过没过 0.75。

相关指数 R2  =  1 − Σ(yi−yi)2 / Σ(yi−y)2；一元线性模型中 R2  =  r2（苏州教研·专题57）

  • 大白话R2 衡量回归直线解释了多少数据波动，越接近 1 说明模型越贴；只有一个解释变量时它正好等于 r 的平方。
  • 用的时候：R2 越大线性回归效果越好；残差平方和 Σ(yi−yi)2 越小，R2 越大。

残差平方和 Q  =  Σ(yi−yi)2  =  Σ(yi−bxi−a)2，最小二乘法就是取使 Q 最小的 b、a（苏州教研·专题57）

  • 大白话每个真实点到回归直线的竖直偏差平方加起来，最小二乘法就是把这个总和压到最小。
  • 用的时候：理解回归直线"为什么最贴"就靠它；b、a 的公式正是 Q 取最小的解。

独立性检验（卡方）

χ2  =  n(ad − bc)2 / [(a+b)(c+d)(a+c)(b+d)]（2 × 2 列联表 a,b,c,d）

  • 大白话两个变量有没有关系，算出 χ2 再和临界值比，越大越有把握说"有关"。
  • 用的时候：套公式时四个分母因子别漏乘、少写零；算完和临界值比。

临界值：3.841（95%）/ 6.635（99%）/ 10.828（99.9%，即 α = 0.001）

  • 大白话χ2 超过哪个临界值，就对应那个把握度。
  • 用的时候：下结论写"有 X% 把握认为有关"，并补一句"这是统计相关，不等于因果"。

完整临界值梯度（苏州教研·专题57）：χ2>2.706 有 90% 把握；>3.841 有 95%；>6.635 有 99%；>10.828 有 99.9%；χ2<2.706 认为没有充分证据显示有关

  • 大白话2.706 是"最低及格线"，过了它才敢说有九成把握；连它都不到，就当没关系。
  • 用的时候：题里若没给临界值，就按这四档对号入座；下结论前先看清 χ2 落在哪一档。

"有关"不等于"一个导致另一个"，"无关"也不等于"两事件互不影响"（苏州教研·专题57）

  • 大白话独立性检验只说明两个分类变量在统计上有联系，不证明因果；算出"无关"也只是没有足够证据，不能断言它俩真没关系。
  • 用的时候：答题结尾那句"统计相关≠因果"不能省；别把检验结论说成"抽烟导致肺癌"。

高级方法·进阶

本章方法（抽样、读图、数字特征、回归、卡方）已全部包含在新教材主线中，不超纲高级方法手册中无"统计"的专属进阶节。下面把高考里最容易丢分的两个"判读规范"点透，均在课标范围内。

操作规范 1：统计量"平移缩放"口诀（适用信号→步骤）

  • 适用信号：题目说"每个数据都加 a / 乘 b"，问新平均数、新方差。
  • 步骤：平均数跟数据一起平移、缩放（加 a 加 a、乘 b 乘 b）；方差只跟缩放、不跟平移（加 a 不变、乘 b 变 b2 倍）。
  • ✓ 不超纲（高考可放心用）。

操作规范 2：卡方"三步判读"（适用信号→步骤）

  • 适用信号：给列联表问"两个变量有没有关系"。
  • 步骤：①套 χ2 公式算值；②和题目给的临界值比；③下结论时写"有 X% 把握认为有关"，并补一句"这是统计相关，不等于因果"。
  • ✓ 不超纲。

课后习题答案

自测答案：1. 40/800 = 1/20 = 5%；2. x = 6，s2 = (4+0+4)/3 = 8/3；3. 1；4. 样本中心 (x, y)；5. 强正线性相关（|r| 接近 1 且为正）。

A 组答案

A1. 总 1000，比例 50/1000=1/20。一车间 300/20=15，二车间 200/20=10，三车间 500/20=25。 A2. x=(3+6+9)/3=6。s2=[(3−6)2+0+(9−6)2]/3=(9+0+9)/3=6。 A3. 频率=0.04×组距10=0.4。频数=500×0.4=200 人。 A4. k=N/n=1000/50=20（每隔 20 抽 1 个）。 A5. a=y−b·x=5−2·3=−1。 A6. χ2=4.5>3.841 但 <6.635，故有 95% 把握认为有关，但不到 99%。

B 组答案

B7. 加权平均=(30×80+20×90)/(30+20)=(2400+1800)/50=84 分。 B8. 方差乘 b2=32：新方差=4×9=36（加 10 不影响方差）。 B9. x=2, y=7/3。Σ(xi−x)2=1+0+1=2。Σ(xi−x)(yi−y)=(−1)(1−7/3)+0+(1)(4−7/3)=4/3+5/3=3。b=3/2=1.5。 B10. ad−bc=40×30−10×20=1200−200=1000。χ2=100×10002/(50×50×60×40)=108/6×106=50/3≈16.67。

C 组答案

C1. "不正常者患疾病"= 不正常且患病的 180 ÷ 不正常合计 200 = 9/10 = 0.9。 C2. χ2=1000×(20×20−180×780)2/(200×800×800×200)=765.6。765.6 > 10.828，故在 α=0.001 下，有 99.9% 的把握认为超声波检查结果与患该疾病有关。 C3. 比例 4:3:3 共 10 份，高一占 4/10。高一抽 50×4/10=20 人。

一通百通

这一章的"通用骨架"是四步：① 抽样本（三种抽样按总体特征选，保证有代表性）→ ② 看数据（直方图看形状、茎叶图看原始）→ ③ 算样本数字（平均数定中心、方差看波动）→ ④ 用样本估整体（回归直线估趋势、卡方检验判两变量是否有关）。每一步都要记得：手里的是样本不是整体，结论带"估计/大约"，卡方结论还要补一句"统计相关≠因果"。会解一道统计解答题，就会解所有统计题——不管考分层抽样、回归还是独立性检验，骨子里都是"抽得正、算得准、估得留余地"。

高考怎么考

新高考Ⅰ卷里统计是统计解答题（第 18/19 题）常客：分层抽样计算、频率分布直方图读"三数"（众数/中位数/平均数）、最小二乘求回归直线（如本章例 4，b=1.23、a=0.08 的分步给分写法）、2×2 列联表独立性检验（本章 B10 的 χ2=50/3≈16.67、C2 的卡方结论）；小题则考抽样方法辨析、平均数方差的平移缩放性质。2025 新高考Ⅰ卷第 15 题就是"频率估计概率+独立性检验"的综合（本章 C1、C2 已收录）。得分关键：直方图纵轴别当频率用、回归必过样本中心自检、卡方下结论必带"统计相关≠因果"。
