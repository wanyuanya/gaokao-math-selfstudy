函数

配方恒等式：x2+1/x2  =  (x+1/x)2 − 2；a2+b2+c2−ab−ac−bc  =  ½[(a−b)2+(a−c)2+(b−c)2]

  • 大白话见到"平方和减两两乘积"，立刻想到它等于三对差的平方之和的一半，方便判号。
  • 用的时候：第二个式子把"a2+b2+c2 与 ab+bc+ca 谁大谁小"一眼看穿（差恒 ≥0）。
  • 记忆要点：a2±ab+b2 = (a±b/2)2 + ¾b2。
  • 出处：（苏州教研·专题B，原书p.5）

分子常数化：y  =  (ax−1)/(ax+1)  =  1 − 2/(ax+1)

  • 大白话分子分母同结构时，把分子凑成分母，剩下一个常数，函数图像就一眼看穿。
  • 用的时候：形如 y=(mx+n)/(px+q) 的分式函数，先分离常数，再看它由反比例函数平移得到。
  • 记忆要点：分子常数化后，单调性、对称中心直接读。
  • 出处：（苏州教研·专题B，原书p.5）

有理化：1/(√a+√b)  =  (√a−√b)/(a−b)；√(n2+1) − n  =  1/(√(n2+1)+n)

  • 大白话分母带根号就乘共轭式去根号；两个相近根号相减，倒过来变一个分式。
  • 用的时候：比较大小、求极限、裂项时，把"√(n2+1)−n"写成 1/(√(n2+1)+n) 方便放缩。
  • 记忆要点：差化和、和化差，符号相反那一项放分母。
  • 出处：（苏州教研·专题B，原书p.5）

双重根号化简：√(p±2√q)  =  √a ± √b（当 p = a+b 且 q = ab，a>b>0）

  • 大白话根号套根号，若里面是 p±2√q，且能拆成两个数 a、b（和为 p、积为 q），就拆成 √a±√b。
  • 用的时候：先凑出"2√"，再把 p 拆成 a+b、q 拆成 ab。
  • 记忆要点：和=p、积=q，大根号套小根号就这么拆。
  • 出处：（苏州教研·专题9，原书p.39）

负指数化正：(ax+a−x)/(ax−a−x) 上下同乘 ax  =  (a2x+1)/(a2x−1)

  • 大白话分子分母同时出现 ax 和 a−x，同乘一个 ax 全变成正指数。
  • 用的时候：研究指数型分式函数时，先把负指数消干净再讨论奇偶、单调。
  • 记忆要点：上下同乘 a 的正指数幂。
  • 出处：（苏州教研·专题B，原书p.5）

韦达定理与两根距离：x1+x2  =  −b/a，x1x2  =  c/a；|x1−x2|  =  √Δ / |a|

  • 大白话二次方程两根的和、积有现成公式；两根在数轴上拉开多远，等于判别式开方再除以 |a|。
  • 用的时候：题里出现"两根之差""两交点水平距离"直接套 |x1−x2|=√Δ/|a|。
  • 记忆要点：和是 −b/a，积是 c/a，距离是 √Δ/|a|。
  • 出处：（苏州教研·专题B，原书p.5）

自对称充要条件：f(a+x) = f(a−x) ⇔ 关于直线 x = a 对称；f(a+x)+f(a−x) = 2b ⇔ 关于点 (a,b) 中心对称

  • 大白话括号里"加 a 减 a"代入值相等 → 轴对称；加起来等于常数 2b → 中心对称。
  • 用的时候：看到这种 f(a+x) 与 f(a−x) 的等式，先判断它是对称轴还是对称中心。
  • 记忆要点：值相等→轴；值相加为定→中心。
  • 出处：（苏州教研·专题5/7，原书p.24、p.32）

对称图象零点之和：图象关于 x = a 对称且共有 n 个零点，则零点横坐标之和  =  n·a

  • 大白话对称的零点成对出现，每对中点都是 a，n 个零点加起来就是 n 个 a。
  • 用的时候：求"所有零点之和"这类题，不用逐个解，用对称性直接乘。
  • 记忆要点：对称零点成对，中点都是对称轴。
  • 出处：（苏州教研·专题7，原书p.32）

单调性结构判定：f(x)+c、√f(x) 与 f 同单调；−f(x)、1/f(x) 与 f 反单调；增+增 = 增，正数增 × 增 = 增

  • 大白话加常数、开根号不改变单调方向；加负号、取倒数方向反转；两个增函数相加仍增。
  • 用的时候：判断复合函数单调性时按这些规则拼，不必每次重新求导。
  • 记忆要点：正操作同调，负操作反调。
  • 出处：（苏州教研·专题6，原书p.27）

换元法要定新元范围：y  =  ax+b ± √(cx+d)，令 t  =  √(cx+d)

  • 大白话带根号的一次式，设根号部分为 t，先写 t 的范围，再把函数化成关于 t 的二次式求值域。
  • 用的时候：必须求两次值域——先是新元 t 的范围，再是新函数的值域；漏掉 t≥0 最易错。
  • 记忆要点：换元必换范围。
  • 出处：（苏州教研·专题4，原书p.21）

反函数交点对称：a>1 时，ax  =  t−x 的根 x1 与 logax  =  t−x 的根 x2 满足 x1+x2  =  t

  • 大白话指数与对数互为反函数、关于 y=x 对称；直线 y=t−x 也关于 y=x 对称，两交点中点在 y=x 上。
  • 用的时候：见到"ax=t−x"和"logax=t−x"两根之和，直接答 t，不必解方程。
  • 记忆要点：反函数+斜率 −1 的直线，交点关于 y=x 对称。
  • 出处：（苏州教研·专题11，原书p.43）

对数型复合函数定义域 / 值域为 R 的条件：f(x) = loga(ax2+bx+c)，Δ = b2−4ac

  • 大白话定义域为 R 等价于真数恒正；值域为 R 等价于真数能取遍一切正数。
  • 用的时候：定义域为 R ⇔ a=b=0、c>0，或 a>0 且 Δ<0；值域为 R ⇔ a=0、b≠0，或 a>0 且 Δ≥0（两者方向相反，别记反）。
  • 记忆要点：恒正→Δ<0；取遍→Δ≥0。
  • 出处：（苏州教研·专题10，原书p.42）

分段函数单调衔接：f(x) = {f1(x), x≤a；f2(x), x>a} 在 R 上递增 ⇔ 每段各自增，且 f1(a) ≤ f2(a)

  • 大白话两段各自递增还不够，接头处左边末端不能超过右边起点，否则在断点处"掉下去"。
  • 用的时候：含参分段函数论单调，除了各段单调，务必比接头点的值。
  • 记忆要点：段内单调 + 接头不倒挂。
  • 出处：（苏州教研·专题17，原书p.63）

抽象函数周期：f(x+a) = −f(x)、f(x+a) = 1/f(x)、f(x+a) = f(x−a) 均 ⇒ T = 2a

  • 大白话解析式里隔一个 a 就翻号、取倒数、或平移复原，那么隔 2a 就回到自己。
  • 用的时候：f(x+a)+f(x−a)=b ⇒ T=4a；f(x+a)=1/(1−f(x)) ⇒ T=3a；两对称轴 x=a、x=b ⇒ T=2|a−b|；一轴一中心 ⇒ T=4|a−b|。
  • 记忆要点：翻号/取倒数→2a；轴+轴→2倍距，轴+心→4倍距。
  • 出处：（苏州教研·专题8，原书p.35~38）

导数

商值定号 ↔ 导数符号：[f(x1)−f(x2)]/(x1−x2) > 0 ⇔ f′(x) ≥ 0 恒成立（单调增）

  • 大白话割线斜率恒正，就是函数单调增，等价于导数不小于 0。
  • 用的时候：题里给"任取 x1<x2 都有 f(x1)<f(x2)"这类条件，翻译成 f′≥0 再做。
  • 记忆要点：割线斜率的符号 = 单调性。
  • 出处：（苏州教研·专题6，原书p.27）

平均变化率  =  割线斜率：Δy/Δx  =  [f(x2)−f(x1)]/(x2−x1)

  • 大白话函数在一段上的平均变化快慢，就是两点连线的斜率；导数是它取极限。
  • 用的时候：题目说"区间 [x1,x2] 上的平均变化率"，直接套这个式子。
  • 记忆要点：平均变化率就是割线斜率。
  • 出处：（苏州教研·专题49，原书p.160）

物理意义：瞬时速度 v  =  s′(t)；加速度 a  =  v′(t)  =  s″(t)

  • 大白话路程对时间求导得速度，速度再求导得加速度。
  • 用的时候：物理背景的导数题，先把 s、v、a 的求导关系摆出来。
  • 记忆要点：s→v→a，逐阶求导。
  • 出处：（苏州教研·专题49，原书p.160）

三函数乘积求导：[f·g·h]′  =  f′gh + fg′h + fgh′

  • 大白话三个函数相乘求导，轮流对其中一个求导、另外两个原样，三项相加。
  • 用的时候：乘积法则 [fg]′=f′g+fg′ 自然推广；遇到三个因子连乘就这么拆。
  • 记忆要点：轮着求导，三项齐。
  • 出处：（苏州教研·专题49，原书p.160）

切线平行 / 相同判定：平行 ⇔ f′(x0) = g′(x0) 且 f(x0)≠g(x0)；相同 ⇔ f′(x0) = g′(x0) 且 f(x0) = g(x0)

  • 大白话斜率相等还不够——两条曲线在同一点切线重合，既要斜率同、又要函数值同。
  • 用的时候：判"公切线"时先求斜率相等的 x0，再看是否还需函数值相等。
  • 记忆要点：平行只要斜率同；相同要斜率+函数值都同。
  • 出处：（苏州教研·专题49，原书p.161）

二阶导数的意义：f′ 的正负看 f 增减；f″ 的正负看 f′ 增减（即曲线凹凸方向）

  • 大白话一阶导数管函数升降，二阶导数管一阶导数怎么变，也就是曲线向上翘还是向下弯。
  • 用的时候：分界点、凹凸讨论时算 f″；f″ 的严格凹凸定义见 ④（选学，大题改用构造差函数）。
  • 记忆要点：一阶管升降，二阶管弯曲。
  • 出处：（苏州教研·专题49，原书p.161）

双函数 ∀∃ 最值组合（f 定义域 A，g 定义域 B）

  • 大白话把"任意/存在"两两组合，翻译成 f 与 g 的最值关系。
  • 用的时候：∀x1∀x2 f≥g ⇔ f_min ≥ g_max；∀x1∃x2 f≥g ⇔ f_min ≥ g_min；∃x1∀x2 f≥g ⇔ f_max ≥ g_max；∃x1∃x2 f≥g ⇔ f_max ≥ g_min。
  • 记忆要点：两个任意→最小对最大；两个存在→最大对最小；混着就看谁在前。
  • 出处：（苏州教研·专题13，原书p.52）

其余导数技巧（f′(x)=0 先试 x=0,±1,e 等观察根、f(x)=xx 改研究 ln f(x)、极值点偏移的比值代换）为压轴工具，需长段推导，见第 05 章与二轮资料，不在此堆公式。

向量

a+b+c = 0 时：移项平方或同乘其中一个向量，求模或夹角

  • 大白话三个向量首尾相接和为零，把其中一个移到等号另一边，再两边点乘（平方）就能解出模长或夹角。
  • 用的时候：三角形里三个向量和为 0，求某边向量的模、某两边夹角，就"移项 + 平方"。
  • 记忆要点：和为零→移项→点乘。
  • 出处：（苏州教研·专题28，原书p.120）

同乘法解系数：AC⃗  =  x AB⃗ + y AD⃗ 时，两边分别点乘 AB⃗、AD⃗ 列方程组

  • 大白话一个向量用两个基底表示，求系数 x、y，就把等式两边分别点乘两个基底，得到两个方程解二元一次组。
  • 用的时候：非坐标背景分解向量求系数时用；客观题也可取特殊多边形建系。
  • 记忆要点：点乘基底，两式解 x、y。
  • 出处：（苏州教研·专题28，原书p.120）

数列

除法裂项：(a−b)/(ab)  =  1/b − 1/a；(b+c)/a  =  b/a + c/a

  • 大白话分子是两项之差、分母是两项之积，就能裂成两个分式相减，求和时逐项抵消。
  • 用的时候：1/[n(n+1)] = 1/n − 1/(n+1) 是它的特例；数列求和见差就想裂项。
  • 记忆要点：积在分母、差在分子 → 裂项相消。
  • 出处：（苏州教研·专题B，原书p.5）

高次放缩（1/k3 型）：1/k3 < 1/[(k−1)k(k+1)]  =  ½[1/((k−1)k) − 1/(k(k+1))]（k≥2）

  • 大白话要证含 1/k3 的和不等式，先把它放大成可裂项的相邻两项差。
  • 用的时候：数列型不等式放缩求和时用，放缩后正好裂项相消。
  • 记忆要点：立方倒数 → 中间插 (k−1)、(k+1) 变连乘裂项。
  • 出处：（苏州教研·专题36，原书p.放缩节）（原书符号转写存疑，待复核）

2k−1 放缩：1/(2k−1) ≤ (1/3)·1/2^{k−2}（k≥2）

  • 大白话分母 2k−1 比 2k 小一点，放缩成等比数列 1/2^{k−2} 就好求和。
  • 用的时候：证 1/(2−1)+1/(4−1)+… 这类和的上界，先放大成等比再求和。
  • 记忆要点：减 1 比不减 1 略大，按 1/3 系数放。
  • 出处：（苏州教研·专题36，原书p.放缩节）（原书符号转写存疑，待复核）

整数解配约数：F(m,n) = 0 化 (k1m+b1)(k2m+b2) = p，对 p 因数分解

  • 大白话两个正整数满足的方程，整理成"两整数相乘等于常数 p"，就去分解 p 的约数。
  • 用的时候：数论小题、数列求正整数项时用；把方程凑乘积形式是关键一步。
  • 记忆要点：凑乘积 → 分解常数的约数。
  • 出处：（苏州教研·专题17，原书p.63）

不等式

a2+b2 ≥ 2|ab|；ab ≤ (a2+b2)/2

  • 大白话两数平方和不小于两倍乘积的绝对值；乘积不超过平方和的一半。
  • 用的时候：不限正负（第一式带 |ab|），比基本不等式更通用。
  • 记忆要点：和平方 ≥ 2|积|。
  • 出处：（苏州教研·专题37，原书p.备用结论）

a>b>c 且 a+b+c = 0 ⇒ a>0 且 c<0

  • 大白话三个数排好序、加起来是 0，最大的必为正、最小的必为负。
  • 用的时候：涉及 a+b+c=0 的符号判断题直接用。
  • 记忆要点：和为零排序，最大正、最小负。
  • 出处：（苏州教研·专题37，原书p.备用结论）

a,b,c>0 且 ab ≤ c2 ⇒ a≤c 或 b≤c 至少一个成立

  • 大白话两正数乘积不超过第三个数平方，则至少有一个不超过第三个数。
  • 用的时候：反证常用——若两者都大于 c，乘积就超过 c2，矛盾。
  • 记忆要点：都大于 c → 积超 c2，故至少一个 ≤c。
  • 出处：（苏州教研·专题37，原书p.备用结论）

单调定义拆段：a<x<y<b ⇔ a<x<b 且 a<y<b 且 x<y

  • 大白话要同时满足"x、y 都在区间内且 x 在 y 左边"，就拆成三条分别写。
  • 用的时候：用单调性定义证明时，规范地把 x、y 的关系拆开讨论。
  • 记忆要点：区间内 + 自带大小。
  • 出处：（苏州教研·专题37，原书p.备用结论）

立体几何

圆锥过顶点截面：S  =  ½·l2·sinθ（l 母线长，θ 两母线夹角），轴截面不一定最大

  • 大白话过圆锥顶点的截面是等腰三角形，面积随两母线夹角 θ 增大而增大；θ 受圆锥顶角限制，所以最大截面未必是轴截面。
  • 用的时候：问"过顶点截面何时面积最大"，别默认轴截面，要看顶角与 90° 的关系。
  • 记忆要点：S=½l2sinθ，θ 到不了 90° 就不是轴截面最大。
  • 出处：（苏州教研·专题18，原书p.67）

平面内切圆半径：多边形 S  =  ½·周长·r ⇒ r  =  2S/周长

  • 大白话有内切圆的多边形，面积等于半周长乘内切圆半径，反过来就能解出 r。
  • 用的时候：三角形内切圆半径 r = 2S/(三边之和)；空间内切球半径类比 r = 3V/S_表面积。
  • 记忆要点：面积 = 半周长 × 内切圆半径。
  • 出处：（苏州教研·专题19，原书p.73）

共面/共点/共线证题思路

  • 大白话证明几条线共面——先用公理定一个平面，再证各线在面内；证三线共点——两线交点是两面公共点，故在交线上；证三点共线——三点都是两面公共点，故在交线上。
  • 用的时候：立体几何证明书写时按这套路组织"公共点 ⇒ 交线"。
  • 记忆要点：公共点落交线。
  • 出处：（苏州教研·专题19，原书p.74）

异面直线/二面角"过定点直线条数可为 0/1/2/3/4"属竞赛化分类讨论，新高考极少考，仅作背景了解。

解析几何

抛物线垂直焦点弦倒数和：1/|AB| + 1/|MN|  =  1/(2p)（AB、MN 互相垂直，y2 = 2px）

  • 大白话从焦点引出两条互相垂直的焦点弦，它们长度的倒数之和恒为 1/(2p)。
  • 用的时候：小题里见到两条互相垂直的焦点弦，直接套定值；大题需补推导。
  • 记忆要点：垂直焦点弦，倒数和定值 1/(2p)。
  • 出处：（苏州教研·专题43，原书p.148）

过 T(p,0) 的弦：1/|RT|2 + 1/|ST|2  =  1/p2（定值）

  • 大白话过点 (p,0) 任作一条直线交抛物线于 R、S，两段长度平方倒数和恒为 1/p2。
  • 用的时候：抛物线小题里见到过定点 (p,0) 的弦，可秒判定值。
  • 记忆要点：定点 (p,0)，长度平方倒数和定值。
  • 出处：（苏州教研·专题43，原书p.148）

过 Q(2p,0) 的弦：OR⃗ ⟂ OS⃗（O 为原点）

  • 大白话从 (2p,0) 引出的直线与抛物线两交点 R、S，对原点张开一个直角。
  • 用的时候：抛物线小题里"OR⊥OS"等价于直线过定点 (2p,0)。
  • 记忆要点：张直角 → 直线过 (2p,0)。
  • 出处：（苏州教研·专题43，原书p.148）

弦长第二形式（联立消 x 得 y 的二次方程时）：|AB|  =  √(1+1/k2)·√[(y1+y2)2 − 4y1y2]

  • 大白话当你把直线与曲线联立、消去 x 得到关于 y 的二次方程，弦长就用 y 的两根和与积来算。
  • 用的时候：直线方程适合写成 x=my+n（消 x 方便）时，用这个形式代替常用的 √(1+k2)·√Δ。
  • 记忆要点：对 y 用韦达时，系数是 √(1+1/k2)。
  • 出处：（苏州教研·专题43，原书p.147~148）

双曲线过焦点最短弦  =  min{2a, 2b2/a}

  • 大白话椭圆里通径最短；双曲线过焦点的弦里，最短的可能是实轴长 2a，要和通径 2b2/a 比大小。
  • 用的时候：求双曲线过焦点弦的最值，别只记通径，先比较 2a 与 2b2/a。
  • 记忆要点：双曲线最短焦点弦 = 2a 与通径取小。
  • 出处：（苏州教研·专题46，原书p.150~151）

焦半径取值范围：椭圆 PF∈[a−c, a+c]；双曲线 PF≥c−a（或 PF≥c+a）；抛物线 PF≥p/2

  • 大白话曲线上点到焦点的距离有固定上下界；求离心率范围题常据此列不等式。
  • 用的时候：由 |PF| 的范围反推 a、c 的关系，列不等式求 e 的范围。
  • 记忆要点：椭圆焦半径夹在 a−c 与 a+c 之间。
  • 出处：（苏州教研·专题45，原书p.150）

直线系 / 曲线系：过两直线交点 A1x+B1y+C1 = 0、A2x+B2y+C2 = 0 的直线系为 A1x+B1y+C1 + λ(A2x+B2y+C2) = 0

  • 大白话过两条已知直线交点的所有直线，可以写成"第一条 + λ 倍第二条"；定点由联立两方程解出。
  • 用的时候：含参直线过定点问题，把参数提出来按 λ 整理，令各部分系数为 0 解定点。
  • 记忆要点：f1 + λf2 = 0 表示过 f1=f2=0 交点的一族。
  • 出处：（苏州教研·专题20，原书p.84；专题43，原书p.148）

抛物线点参数表示：直线 y = kx+m 交 y2 = 2px 于 A(y12/2p, y1)、B(y22/2p, y2)

  • 大白话抛物线上的点用纵坐标 t 表示为 (t2/2p, t)，联立后直接对 y 用韦达。
  • 用的时候：抛物线设点避免带 x 的根式，配合上面"弦长第二形式"用。
  • 记忆要点：y2=2px 上的点写 (y02/2p, y0)。
  • 出处：（苏州教研·专题43，原书p.148）

概率统计

异面直线组数：n 个顶点几何体中，异面直线组数  =  3·(C(n,4) − m)

  • 大白话每个四面体对应 3 组异面直线；m 是四点共面的组合数，要扣掉。
  • 用的时候：立方体、棱柱等数异面直线对数时用，先算四面体个数再乘 3。
  • 记忆要点：一个四面体 = 3 对异面直线。
  • 出处：（苏州教研·专题54，原书p.185）

圆内交点最多个数：圆上 n 个点连成的弦在圆内交点最多  =  C(n,4)

  • 大白话每四个圆上的点确定一个圆内接四边形，两条对角线交一点，所以最多 C(n,4) 个交点。
  • 用的时候：数"圆内最多几个交点"，等价于数圆内接四边形个数。
  • 记忆要点：四点定一交点。
  • 出处：（苏州教研·专题54，原书p.185）

连号情形数：n 个连续号码中出现两组 m 个连号的情形数  =  C(n−2(m−1), 2)

  • 大白话把两组 m 连号各捆成一个"大块"，剩下的位置数里选 2 个放这两大块。
  • 用的时候：排列组合里"连号"模型，先捆绑再插空。
  • 记忆要点：连号先捆绑。
  • 出处：（苏州教研·专题54，原书p.185）

抛掷 n 次硬币（或一次抛 n 枚）：基本事件总数  =  2n

  • 大白话每次两个结果，n 次就是 n 个 2 相乘。
  • 用的时候：算概率时分母直接写 2n。
  • 记忆要点：每次 2 种，n 次 2n。
  • 出处：（苏州教研·专题25，原书p.109）

蒙特卡罗随机模拟：均匀随机数线性变换 Y  =  a + (b−a)X（X∈[0,1]）则 Y∈[a,b]

  • 大白话把 [0,1] 上的均匀随机数缩放平移到 [a,b]；用"面积之比 = 质点数之比"估计面积或圆周率。
  • 用的时候：几何概型、随机模拟题里做区间变换。
  • 记忆要点：Y = 起点 + 长度·X。
  • 出处：（苏州教研·专题25，原书p.109）

独立性检验临界值全表（χ2）

复数

三次单位根 ω 的倍式：−1+√3 i  =  2ω，−1−√3 i  =  2ω̄，√3+i  =  −2iω，√3−i  =  2iω̄

  • 大白话带 √3 的纯复数，常可凑成三次单位根 ω 的倍数，方便提公因式。
  • 用的时候：复数计算里出现这些数，认出是 ω 的倍式，乘除就变成指数运算。
  • 记忆要点：ω = (−1+√3 i)/2。
  • 出处：（苏州教研·专题53，原书p.184）

实数性质不可照搬到复数："任意数平方非负""|a|<|b| ⇒ a<b"在复数集不成立

  • 大白话复数不能比大小，平方也可能是负数，实数集的老规矩别硬搬。
  • 用的时候：复数题里不写 a<b 这种大小关系，只算模、算实虚部。
  • 记忆要点：复数无大小，只比模。
  • 出处：（苏州教研·专题53，原书p.184）

其他

繁分式化简：分子分母同乘最简公分母 abc

  • 大白话繁分式上下都是几个分数相加，就上下同乘各分母的乘积，一次消掉所有分母。
  • 用的时候：(1/a+2/b+1/c)/(3/(ac)−…) 这类，同乘 abc 变整式。
  • 记忆要点：同乘公分母，繁分变整式。
  • 出处：（苏州教研·专题B，原书p.5）

乘法公式（立方和差、完全立方）：a3±b3  =  (a±b)(a2∓ab+b2)

  • 大白话立方和可以分解成"和"乘"平方和减积"；立方差类似。
  • 用的时候：因式分解、化简时见立方项就拆；初中已学，速查备用。
  • 记忆要点：a3+b3=(a+b)(a2−ab+b2)。
  • 出处：（苏州教研·专题B，原书p.5）

值域 / 最值十法清单

  • 大白话求值域最值，按顺序试：观察法、配方法（对称轴法）、换元法、图象法、单调性法（优先）、有界性法、基本不等式法、判别式法、导数法（万能）、分类讨论法。
  • 用的时候：拿到最值题先想单调性，再上基本不等式/判别式，最后才动导数。
  • 记忆要点：单调优先，导数兜底。
  • 出处：（苏州教研·专题4，原书p.21）

反证法三步：反设 → 归谬 → 结论

  • 大白话先假设结论不成立，由此推出与已知/定义/公理矛盾的结果，就说明原命题成立。
  • 用的时候：正难则反，"至少""唯一""否定式"命题常用反证法。
  • 记忆要点：反设、矛盾、肯定原命题。
  • 出处：（苏州教研·专题52，原书p.183）

③ 数学解题表（专题D·解题思维总表）

这是全书的解题思维总表，源自波利亚"怎样解题"表。核心思想：不断变换问题、连续简化问题，把解数学题看成"化归"过程，最终归结为熟悉的基本问题。（苏州教研·专题D，原书p.207）

第一步 弄清问题

  • 已知数据、条件是什么？未知数是什么？条件是否充分？有没有隐含条件？
  • 画张图，引入适当符号，把条件各部分分开，有条理地写下来。

第二步 拟定计划

  • 你以前见过相同或形式稍有不同的问题吗？知道与之有关的定理吗？
  • 看着未知数，想一个具有相同或相似未知数的熟悉问题，能不能利用它的结果、方法？要不要引入辅助元素？
  • 能不能重新叙述、换一种说法？回到定义去。
  • 想不出直接联系时，先解决一个有关问题：更容易着手的、更普遍的、更特殊的、可类比的，或只解决一部分；保持条件一部分能把未知数确定到什么程度？
  • 从已知数据能导出什么有用的东西？把得到的都写出来；改变未知数或数据，让新旧更接近。
  • 是否用了所有已知数据？是否考虑了可能涉及的全部概念和定理？

第三步 实现计划

  • 实现求解计划，检验每一步；
  • 能否清楚看出这一步正确？能否证明这一步正确？

第四步 回顾总结

  • 能否检验这个结果？能否用别的、尽可能多的方法得到它？
  • 这个方法能否用于其他问题？还能推出别的结论吗？结论能否推广？
  • 把已知条件适当变更，对方法和结论有什么影响？

第 20 章 附录：不超纲公式与结论

为什么有用高考的坑常常不是"不会"，而是"会但太慢"——错位排列、焦点弦倒数、三角不等式这类二级结论，现场推要两三分钟，记住了直接用只要十几秒；附录就是把"现场推导"变成"考前扫一遍就有印象"，把省下的时间留给压轴题。它不是多考几分的问题，而是"少丢不该丢的分、快做会做的题"。

一通百通

附录的"通用骨架"就三步：① 定位板块（这结论属于函数/数列/解析几何哪条线）→ ② 对号入座（它是我主线的延伸还是捷径？超纲与否？）→ ③ 带回主线（去对应章节找它的推导，能推出来才敢用）。一条二级结论，你能在自己会的主线里把它推出来，才算真的会；推不出来就只背不用的，考场上容易用错。会查一个板块的附录，就会查所有板块——因为附录永远是主线的影子，不是新的山。

跨章结合

附录里的卡，本身就是跨章结合的产物，最典型的几处： - 错位排列（专题54）⇔ 17 章计数原理：它是在排列公式之上"排除回位情况"的二级结论，直接用于排列组合小题的快速计算； - 焦点弦倒数 1/|AF|+1/|BF|=2/p（专题45）⇔ 16 章圆锥曲线：它把抛物线焦点弦的长度问题压成一行公式，是"联立→韦达"的通法在抛物线上的速算版； - 三角不等式 sinx<x<tanx（专题27）⇔ 06 章三角函数：它和 05 章导数放缩 ex≥x+1、lnx≤x−1 同属"用切线夹逼函数"一族，常在选填压轴里帮你快速判断大小。 这三条的共同本质：附录的结论大多是把两章的原理拧在一起的捷径，所以用之前回主章找推导，用的时候才知道它凭什么成立。

本章与前后章

第 20 章不与任何一章构成前后依赖，它平行服务于 01–19 章：各章的速查表是"本章当场要用"的公式，附录收的是"各章装不下"的延伸结论，两者互补不重叠。使用时配合 00 章的总地图定位板块、配合方法手册理解结论的适用信号。考前一周的用法是"主线过一遍 + 附录扫一遍"：主线管会不会，附录管快不快。

高考怎么考

附录本身不直接对应卷面上的某一道题，它影响的是解题的速度与稳定性：错位排列（17 章）、焦点弦倒数关系（16 章）、三角不等式（06 章）这类结论，能直接用就能省出压轴题的思考时间；④ 选学·不考专区里的内容（定积分、参数方程、柯西不等式）新高考Ⅰ卷不考，知道了也不会出现在卷面上。所以附录的价值不是"多考几分"，而是"少丢不该丢的分、快做会做的题"——这正是二轮复习扫附录的意义。

④ 选学·不考专区（新高考Ⅰ卷不考·统一放最后）

下列各专题在老教材里是"必修3 / 选修2-2 / 选修4-1 / 选修4-4 / 选修4-5"，新课标与新高考Ⅰ卷已删去或改为不考。逐项说清"是什么、当年考什么、现在为什么不考、保留什么价值"。全部不纳入学习计划，知道即可。

编者注·本质回扣：为什么超纲内容要写清楚却不让你学？因为"超纲"不等于"没用"——定积分的"面积=积分"直觉能帮你理解导数，参数方程能帮你理解曲线，柯西不等式能开阔思路；但新高考Ⅰ卷明确不考，花时间去练就是拿 100 分的精力换 0 分的题。本附录的处理原则是本质核心的另一面：分清"理解价值"和"得分价值"——理解价值保留给你看，得分价值为零的就只作背景，绝不混进学习计划。这也是全书一贯的边界：不超纲的进正文，超纲的停在红线外。

专题23 算法、程序框图、程序（老教材必修3）

  • 是什么：算法概念与三种逻辑结构（顺序、条件、循环）、五种基本语句；四个算法案例——辗转相除法、更相减损术（求最大公约数）、秦九韶算法（一元 n 次多项式嵌套求值）、进位制（除 k 取余法）。
  • 当年考：给程序框图读输出结果、补全框图、把算法步骤画成框图。
  • 现在为什么不考：新课标把"算法初步"整块移出必考内容，程序框图不再命题。
  • 保留价值：秦九韶算法、除 k 取余的"短除法"是很好的逻辑训练；了解即可。
  • 出处：（苏州教研·专题23，原书p.102~104）

专题50 定积分（老教材选修2-2）

  • 是什么：定积分定义（分割、近似代替、求和、取极限）∫ab f(x)dx = lim Σ f(ξi)·(b−a)/n；几何意义是曲边梯形的面积；微积分基本定理 ∫ab f(x)dx = F(b)−F(a)（F′(x)=f(x)）。
  • 当年考：求曲边梯形面积、变速直线运动路程、变力做功。
  • 现在为什么不考：新高考Ⅰ卷已删去定积分及其简单应用。
  • 保留价值："面积 = 积分"的直观，对理解导数与面积的互逆关系有帮助；不纳入学习计划。
  • 出处：（苏州教研·专题50，原书p.164）

专题58 几何证明选讲（老教材选修4-1）

  • 是什么：相似三角形的判定（AA/SAS/SSS）与性质、直角三角形射影定理；圆的一系列定理——圆周角/圆心角、圆内接四边形、切线判定与性质、弦切角定理，以及圆幂定理：相交弦定理 PA·PB = PC·PD、割线定理、切割线定理 PC2 = PA·PB、切线长定理。
  • 当年考：以圆为背景用圆幂定理、相似三角形对应边成比例求线段长。
  • 现在为什么不考："几何证明选讲"整模块随选做题取消而不考。
  • 保留价值：相交弦、切割线、射影定理在小题里作直观背景仍很快；正式解题不依赖它。
  • 出处：（苏州教研·专题58，原书p.195）

专题59 坐标系与参数方程（老教材选修4-4）

  • 是什么：极坐标与直角坐标互化 x=ρcosθ、y=ρsinθ；直线/圆/椭圆/双曲线/抛物线的参数方程；过定点 M0(x0,y0)、倾斜角 α 的直线标准参数方程 { x=x0+tcosα，y=y0+tsinα }，其中 |MM0|=|t|、弦长 |M1M2|=|t1−t2|、M0 为中点时 t1+t2=0。
  • 当年考：选做题里做极坐标/参数方程与普通方程互化、求交点与弦长。
  • 现在为什么不考：选做题取消，极坐标与参数方程不再单独命题。
  • 保留价值：直线参数方程"弦长=|t1−t2|、中点 t1+t2=0"可作选填技巧的背景思路；不纳入学习计划。
  • 出处：（苏州教研·专题59，原书p.196）

专题60 柯西不等式、排序不等式（老教材选修4-5）

  • 是什么：柯西不等式 (Σai2)(Σbi2) ≥ (Σaibi)2；排序不等式（反序和 ≤ 乱序和 ≤ 顺序和）；贝努利不等式 (1+x)n ≥ 1+nx（x>−1）。
  • 当年考：选做题里用柯西/排序求最值、证不等式。
  • 现在为什么不考："不等式选讲"随选做题取消而不考。
  • 保留价值：柯西不等式对"积和型最值"（如 √a+√b 型）有很强的直观判断作用；正式证明仍用基本不等式或导数法。
  • 出处：（苏州教研·专题60，原书p.197）
