## 快速开始

1. **日常学习打开 `电子书分章\index.html`** —— **分章版**（导读 + 19 章 + 附录，每章一个独立页面）。每页只装一章，**打开和展开答案秒开不卡**，旧电脑也流畅。首页是 20 章卡片，点卡进入；章与章用顶部 `← 上一章 | 目录 | 下一章 →` 切换。
2. **另有**：`电子书\高中数学自学系统电子版.html` 单文件版，全书一页，带**跨章全文搜索**——需要一次搜整本时用它。
3. 每章页 / 单文件版都带：**字号调节、衬线/黑体切换、夜读模式、本章搜索、答案折叠**（答案默认隐藏，按"门槛自测 / A 组 / B 组 / C 组"分组标注），顶栏有**三种完全分开的打印模式**（只打当前章，不会整本打出来）：
   - **打印讲义**：本章正文讲解，**题目和答案全部去掉**；
   - **打印题目**：干净的**练习卷**（门槛自测 + 出口检测 + A/B/C 课后习题，无答案）；
   - **打印答案**：**答案卷**（门槛自测答案 + A/B/C 组答案，只含答案）。
4. 按 00 章导读的"六步闭环"学每一章：**门槛自测 → 学习目标 → 正文讲解（含"大白话"旁注）→ A/B/C 分层习题 → 公式速查 → 高级方法 → 答案**。
5. 每章顶部有"本章配套资料"直达 + "看不懂怎么办"指引；卡住超过 30 分钟先标记跳过，回头再攻。
6. 想让 AI 助手按同一套方法答疑/出题/验收？安装 `技能包\gaokao-math-selfstudy\`（见 `系统文档\技能包安装说明.md`）。

## 学习方法（一句话）

- **一条主线**：19 章按依赖关系排好，每章告诉你"学之前必须会什么、学完能干什么、怎么证明过关"。
- **门槛控制**：每章入口有门槛自测（不过关先补前置），出口有检测（过关才解锁下一章）。
- **三层递进**：看得懂（老教材图解 + 大白话旁注）→ 会做题（方法卡）→ 做得对（真题分层 A/B/C）。
- **讲本质**：每章先讲"本质核心一句话 + 为什么有用"，再给通用骨架——会一道题就会一类题，知识可跨章结合出题（举一反三）。
